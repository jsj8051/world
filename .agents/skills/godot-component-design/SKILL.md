# Godot 组件设计与实现

先查看项目约定、相关代码、场景和调用方。根据组件职责选择合适的载体，例如节点、资源或普通对象。

## 设计

开始编码前，按以下顺序明确三项设计。用简短的工作说明记录即可。

1. **它是干什么的？** 用一句话定义组件的主要职责，列出它负责的行为。涉及相邻职责时，明确这些行为分别由谁负责。
2. **它需要什么数据？** 列出必要的输入、内部状态和输出。对相关数据明确类型、来源和所有权，以及何时可用、缺失或更新。
3. **它如何与外界环境交互？** 说明谁创建、配置和调用组件，依赖如何传入，以及组件通过什么方法、信号或事件接收输入和发布结果。涉及订阅或异步操作时，明确连接时机以及停用或释放时的处理。

## 实现

三步明确后，在同一次任务中按设计完成代码实现和必要的场景接线。用户只要求设计时，交付三步设计即可。实现中发现设计假设与代码现状冲突时，先修正受影响的设计，再继续编码。

遵循项目的命名和目录规则。按改动范围验证关键逻辑，并检查相关调用方或场景接线是否符合设计。本项目的自动化测试聚焦逻辑行为。
