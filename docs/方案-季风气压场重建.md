## 一、结论：现在不是"大陆高压、海洋低压"

不是增益没调够，是**结构和位置**不对。四条，按重要性排：

1. **模型里没有气压这个变量。** 季风是 `+∇T′` 直接当一个风项加上去的
   （`DiagnosticWindModel.cs:105`），`T′ = T_陆 − 同纬海洋均温`。`−∇p ∝ +∇T` 只在
   "热低压 = 地面温度高点"这一层近似成立；真实的季风低压是**整层气柱加厚**导致的
   地面减压——热低压中心的地面温度几乎是平的，气压却还在往中心掉。对**地面温度**
   求梯度，只会在温度变化快的地方有值，也就是海岸线一带。
2. **梯度只能在海岸存在。** `T′` 先做 6 遍邻居平均（`DiagnosticWindModel.cs:68`）。
   res4 格距 ≈ 48 km，6 遍 ≈ 100–300 km 的过渡带；几千 km 的大陆内部平滑后的 `T′` 趋于平台，
   `∇T′ ≈ 0`。所以"大陆"没有中心，只有一圈海岸。
3. **海洋是参照面，不是参与者。** `T′` 只在陆格上赋值，海格恒 0
   （`DiagnosticWindModel.cs:59-64`）；季风 mask 只给陆格和离岸 2 格以内的海格
   （`:103`），再远 `mask = 0`。海洋没有自己的高压/低压，也不会向陆地的热低压辐合。
4. **`∇T′` 里混着纬度方向的变化。** `T′` 随纬度差一个量级（合成网格实测 33°N：
   7 月 +26.8 °C、1 月 −39.3 °C；赤道带只有 ±3 °C），所以季风项的主分量常常是
   **南北向**的，与海陆分布无关。实测赤道带季风项 `(u, v)` = 7 月 `(0.04, 0.30)`、
   1 月 `(−0.03, −0.34)`——纯南北。

另外两个"让它看起来没发生"的因素：

- **年均把季节反转抵消掉了。** 合成网格岸内 1 格：7 月 `(−0.43, 0.18)`、1 月 `(0.50, −0.21)`，
   年合成只剩 `(−0.08, −0.03)`。风场图默认参数是**年均**（`WindMode.cs:25,40`），
   不切到 1 月/7 月就看不到反转。
- **"季风强度"是另一套定义。** `MonsoonStrength = clamp(冬夏 (水汽×月辐射) 反差)`
  （`MonthlyClimate.cs:188-204`、`:352`），测的是降水季节性，跟风向、气压都没有因果关系。
  它目前**没有下游消费者**（只有 `WorldFacts` 携带 + 冒烟测试打印），改口径是低风险动作。

## 二、当前风场的实际构成（代码口径）

同一个月、逐格，四项相加后归一化（`DiagnosticWindModel.Build`）：

```
band = (east·u + north·v) · (w · WindBandBoost)      // 纬度查表，sampleLat = lat − 热赤道
geo  = r × ∇T / f · (0.02 · WindGeoBoost)            // 旋转 90°，沿等温线；|geo| ≤ 2
mon  = +∇T′ · (0.035 · WindMonsoonBoost · mask · latWindow)   // mask：陆 1 / 离岸 ≤2 格 0.35 / 其余 0
raw  = band + geo·(1 − w) + mon
s    = (1 − e^(−|raw|·WindSpeedScale)) · (1 − 0.45·smoothstep(0, 2500, 海拔))
```

两个性质要记住：

- `mon` 是标量梯度 ⇒ **无旋**，只能辐合/辐散，绕不出闭合环流；
- `geo` 是旋转 90° 的梯度 ⇒ **无辐散**，只沿等温线转，不负责穿越海陆。

两者都没有"绕热低压的旋转入流 + 返回流"，而且风是单层二维场，季风的定义性特征
（低层跨赤道急流 + 高层反向）在这个数据结构里不可能出现。

**合成网格**（18×36，10° 格距，140°×90° 大陆；把季风项按代码复刻后单独取出来）：

| 位置 | 7 月季风项 (u,v) | 1 月季风项 (u,v) | 说明 |
|---|---|---|---|
| 33°N 东岸 | (−0.21, 0.03) | (+0.15, 0.03) | 向岸/离岸分量成立，但只在岸边 |
| 33°N 内陆（离岸 7 格） | (0.00, 0.03) | (0.00, 0.05) | 向岸分量**归零**，只剩南北向残量 |
| 5°S 东岸 | (0.04, 0.30) | (−0.03, −0.34) | 纯南北，海陆分量≈0 |

  赤道带：5°S 的 1 月 `T′` 原始只有 +0.1，平滑后变成 +2.1——当地本不该有这么大的季节异常。

## 五、目标与验收

1. **中心存在且在内陆**：7 月大陆出现 995–1010 hPa 级热低压、1 月出现 1020–1035 hPa 级冷高压；
   中心离海岸 ≥ 5 格（≈250 km），不是贴海岸的一条带。
2. **符号反转**：同一格 `Δp = p_陆 − 同纬海洋均 p` 冬夏符号反转，且 `|Δp|` 超过标定阈值。
3. **副高东西位置**：开 E 项时副高中心落在大洋东侧；与关掉 E 项相比，中心经度东移 ≥10°。
4. **风**：东岸/南岸冬夏风矢量反转 ≥120°；赤道 `f=0` 处风速有界、方向 ≈ `−∇p`。
5. **无环**：p 场与风场沿经度扫描，0°/±30°/±60° 不进台阶前八。
6. **预算**：res4 全链 ≤ 现状 × 1.5；实测增量目标 <0.5 s。
7. **风档可切**：风场图能在"地面 / 850 hPa / 自由低层"之间切换；切档只换数据源，
   不重新生成、不改世界事实、底色与风丝同源。

## 六、方案

### A. 气压：三项叠加

```
p(λ,φ) = p_z(φ − Δc)                                  // ① 纬向气压带
        − α · G_650km[(T_sl − T̄_λ) · eff(φ)]          // ② 海陆热力差异
        + A · B(φ) · G_300km[E]                        // ③ 副高的东西不对称
```

| 项 | 管中心的 | 机制 |
|---|---|---|
| ① `p_z` | **纬度** | 13 节点 **PCHIP** 廓线：赤道低 / 副高 / 副极低 / 极地高；季节整体移 `Δc` |
| ② 热力 | **经度、强度、正负号** | 陆海温差平滑后直接加减压：夏陆暖 → 低压，冬陆冷 → 高压 |
| ③ E | 副高的**东西位置** | 东侧 12–24° 有陆的洋面（= 大洋东部）加正异常，把副高推到大洋东侧 |

实现要点：

- `T_sl` 用**海平面等效温度**（`MonthlyClimate.seaLevelTemp` 已有）——用地面气温会让青藏、
  安第斯变成永久低压。
- `T̄_λ` 用**同纬带均值（海陆都算）**，海洋因此也能成为相对高压/低压；这是它比现方案
  "海洋恒 0 参照面"强的地方。
- `Δc` 由 **热赤道**（`ThermalEquatorDeg`）给，不写死 ±6°——换倾角/辐照的行星仍然成立。
- **`eff(φ)` 是必要的 closure**，不是冗余：诊断模型里风不反馈气压，"低纬梯度被环流抹平"
  只能靠它预先压平；高纬则因冷气团浅薄而收窄。
- **E 是静态场**（只依赖海陆分布），`B(φ)` 也是静态 ⇒ **第③项整项可一次算好**，不进月循环。
  参考模型里第③项与季节无关；若想让它只在夏季生效，乘一个夏季权重即可（属可选改进）。
- PCHIP 不是审美选择：普通三次样条在 13 个节点之间会过冲，过冲就是**多出来的局部极值**，
  在气压场上表现为一圈圈不该闭合的等压线。

**中心是怎么"闭"上的**（这一条是参考模型最值得学的地方）：

- 没有任何"放置中心"的步骤。中心 = 三项叠加后的**局部极值**。
- 纬向：`p_z` 不随经度变，`∂p/∂x = 0` 只由②③决定 ⇒ 中心落在**平滑后异常的经向极值**处
  （大陆加热的质心，不是海岸线）。
- 经向：`∂p/∂y = p_z′ + ∂q/∂y = 0` ⇒ **只有背景廓线接近极值（`p_z′≈0`）时，异常才有机会
  把残余斜率抵消掉、闭合出中心**；否则只是一个槽/脊。
- 所以"中心"的本质是：**异常的经度极值落在背景带的纬度极值附近**。`Δc` 的 6° 级位移
  就是把这个极点挪到大陆异常最强的纬度上——1 月冷高压落在副高带上、7 月热低压落在
  副低带上，同一个机制。
- 平滑尺度决定"一个中心"还是"一串小中心"：650 km 让异常铺满一块大陆而不跟海岸起伏；
  300 km 只修副高东西位置。

参考读数（标定锚点）：1 月北半球大陆 1029–1032 hPa、副极地洋面 ~986 hPa；
7 月大陆 1001–1008 hPa、副高中心在大洋上。

### B. 风：带线性摩擦的定常解

```
f k×v = −∇p/ρ − r·v
u = −( r ∂x p + f ∂y p ) / ( ρ (r² + f²) )
v = (  f ∂x p − r ∂y p ) / ( ρ (r² + f²) )
```

三个性质，正好治现方案的三处病：

1. **赤道不发散**：`f→0` 时退化成 `v = −∇p/(ρr)`（顺梯度直吹低压），分母恒正，**不需要夹 `f`**。
2. **偏转角连续**：`arctan(r/f)` 从地转（沿等压线）过渡到摩擦流（偏向低压）；
   陆地 `r` 取海洋 2 倍 ⇒ 陆上风速更小、更偏向低压。
3. **跨赤道自动正确**：`f` 变号，南半球东南信风过赤道转西南风，不需要任何特判。

因此可以**整段删掉** `BandU/BandV` 查表、`CoriolisSafe` 夹子、`band·w + geo·(1−w)` 的拼接、
以及 `mon` 的 mask——风只剩"气压 → 摩擦解 + 地形减速"。信风/西风/极地东风会从 `p_z`
的梯度里自然出现，**风带和季风不再是两套东西**。

成本：每格一次切平面梯度（现在就有）+ 三组 `r` 的乘加，O(n)，不迭代。

### C. 三套风（拍板：三套都要能看）

| 风 | 摩擦 | 用途 | 存档 |
|---|---|---|---|
| 地面风 | `r_s`（陆 ×2） | 出图、辐合、季风判定、侵蚀 | **逐月** |
| 850 hPa 风 | `r_m ≈ 0.3–0.5 r_s` | 内陆水汽输送（降水链） | **逐月**（地图可选看） |
| 自由低层风 | `r_f ≈ 0.5 r_s` | 洋流（年合成） | **逐月**（地图可选看） |

三套风共用同一个 `p` 和同一个 `∇p`，差别只在 `r`——不是三个模式、也不是三层大气，
是同一诊断平衡的三个摩擦闭合（没有垂直层时，用 `r` 偷带进来的"高度"）。

**下游接线**：降水吃 850 风；洋流吃自由风的**年合成**；出图/季风判定/侵蚀吃地面风。
三者必须同源（同一个 `p`），否则会出现"图上吹东风、洋流却按另一套转"的矛盾。

**地图上怎么选**：

- 风场模式加**第二轴**，不拆成三个新模式：`MapMode` 扩一个可选的
  `VariantOptions / VariantIndex / SetVariant`（与 `ParameterOptions` 同构）。
  参数行仍是"年均 + 1–12 月"，变体行是"地面风 / 850 hPa / 自由低层"。
- 坞里在参数行上方多构建一行变体按钮（哑组件，文案由模式下行）；点选 → 控制器
  `mode.SetVariant` + 重烘。没有变体的模式这一行隐藏——现有模式零改动。
- `WindFlowOverlay`（风丝/粒子）必须和底色读**同一套**，否则风速色和流线会打架；
  切档时按当前月重积几何。
- 切档**只换数据源，不改生成**：三套风在生成期已全部算好归档，地图只是选一个数组。

**内存**：三套逐月 = 3 × 41.5 = 124.5 MB（净增 83 MB）。两个方案：

| 方案 | 内存 | 切档成本 | 取舍 |
|---|---:|---:|---|
| A. 三套逐月全存（默认） | +83 MB | 0 | 简单、零分歧；桌面端可接受 |
| B. 只存 `p` 逐月 + 地面风逐月，另两套现算 | +7 MB | ~10 ms/次（一次 O(n) 梯度） | 省内存，但切档要重算，两条路径要保持同一公式 |

建议先 A（先跑通、零分歧）；若总量吃紧再换 B，并把"现算 = 归档"做成一条等价测试。

**地形减速乘哪套**：只乘地面风。850 风不该被山脉简单压慢，它需要的是地形抬升项
（`v·∇h`）产生迎风坡降水，而不是被当成地面风截断。

### D. 平滑与粗层实现（不迭代、无 CFL）

`G_650` / `G_300` 都是**固定核的一次卷积**，在粗层做，然后按父格映射回 res4：

```
G_650：res2（186 km），L = 3.5 格，核半径 6 格（≈1.7L）   12 个月 ~10 ms，核 ~6 MB
G_300：res2（186 km），核半径 2 格（≈370 km）              12 个月 ~2 ms，核 ~1 MB
       嫌副高东西边界糙时，G_300 改用 res3（93 km，半径 5） +50 ms、+30 MB
```

- **不在 res4 上卷积**：650 km 在 res4 是 13.5 格、2L 半径 27 格，每格约 2200 个邻居、
  总量 6 亿+ 条边（≈5 GB）——不是慢，是放不下。
- **不用 SOR/迭代**：SOR 是逐遍松弛（把椭圆方程当扩散推），要遍数/收敛判据/热启动；
  直接卷积把"积分"这一步彻底去掉，单遍、确定性、线程安全。
- **不要用"多遍邻居平均"凑尺度**：平滑 P 遍的扩散长度 ≈ √P 格，650 km 在 res4 要 ~180 遍
  （12 个月十几秒）——又回到迭代。
- 核按**大圆距离**取权重（H3 等积格，跳数≈等距，直接用跳数也够），按行归一化补回截断尾部。
- 上采样后加 2 遍 res4 平滑，消掉粗层边界的六边形台阶。

| `anomaly` + 6 遍平滑 | 换成 `G_650` 粗层卷积 |
| 地形减速 `1 − 0.45·smoothstep(0,2500,H)` | **保留**（乘在风速上） |
| `WindSpeedScale` 软饱和 0–1 | **保留**（按新的物理量级重标） |
| 水汽上游链（`BuildMoisture`） | **保留**，换用水汽风、重标 `MoistureDecayPerStep` |
| `MonsoonStrength = 水汽×辐射反差` | 换成 `Δp` 符号反转（见 §F） |

### F. 季风强度：气压口径

```
Δp_i(m)  = p_i(m) − 同纬海洋平均 p(m)
季风强度 = clamp(|Δp(夏) − Δp(冬)| / MonsoonStrengthScale, 0, 1)
          × 1{ sign(Δp_夏) ≠ sign(Δp_冬) }
```

- 符号门控是必须的：没有它，年均偏置（低纬陆冷 / 中纬陆暖）会被误判成季风。
- 风向反转**不进定义**，只做测试断言（§五.4）：气压反转 → 风反转是因果链的验证。
- 删除 `_monsoonPeak/_monsoonTrough` 的记账（只服务旧口径）。

### G. 性能与内存预算（本机实测，Release，res4 = 288,122 格）

| 项 | 实测/估算 | 12 个月合计 |
|---|---:|---:|
| `G_650` 卷积（res2，r=6） | ~10 ms | ~10 ms |
| `G_300` 卷积（res2，r=2） | ~2 ms | ~2 ms |
| 第③项（静态，含 `G_300[E]`） | 一次 | ~5 ms |
| 热力异常聚合 + 上采样 + 窗口 | ~5 ms/月 | 60 ms |
| 风（一次梯度 + 三套 `r`） | 与现风场同量级 | 中性 |

| 核构建（BFS 逐格，两套小核） | ~100 ms | 一次性（`GridDisk` 更快） |

- 总增量 **≈0.1 s**（气候阶段 7.7 s 的 ~1.3%），**没有时间积分、没有 CFL、没有收敛判据**。
- 内存（方案 A，三套逐月全存）：`p` 年均 + 1/7 月（3.5 MB）；三套风逐月（3 × 41.5 = 124.5 MB，
  现已有 1 套 ⇒ 净增 83 MB）；两套核 ~7 MB。合计净增 ~90 MB。

- 若 `G_300` 移到 res3 提升副高东西精度：+50 ms、核内存 +30 MB（见 §D）。

## 九、测试计划

现有 14 个必须全绿（`零倾角无季风` 改口径后仍应绿：无季节 ⇒ 冬夏 `Δp` 相同 ⇒ 0）。

1. **气压中心符号与位置**（合成大陆）：7 月陆地 `p` < 同纬海洋、1 月相反；中心离岸 ≥5 格。
2. **副高东西位置**：开/关第③项，副高中心经度差 ≥10°。
3. **风向反转 ≥120°**：东岸/南岸 7 月与 1 月风矢量夹角。
4. **赤道有界**：`f=0` 处 `|v|` ≤ 上限，且方向与 `−∇p` 夹角 ≤30°。
5. **无纬度环**：`p` 与风沿经度扫描，0°/±30°/±60° 不进台阶前八。
6. **回退等价**：`WindPressureDriven=false` 时风场逐格复现当前结果（≤1e-4）。
7. **三套风差异**：同格 `|v_free| ≥ |v_850| ≥ |v_surface|`，越等压角随 `r` 递减。
8. **三档取用**：`WindSet(地面/850/自由)` 返回三个不同数组，同一档重复取返回同一引用
   （切档零重算；"变体只换显示"由 §五.7 的视觉验收覆盖，不进单元测试）。

res4 冒烟：`--world 4` 出 1/7 月海陆极值、季风区占比、`Δp` 反转格数、气压中心经纬度；
年温/年降水变化 >10% 必须解释并更新 `设计-气候链` §八。
