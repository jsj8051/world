# 验证：地图数据导出与导入

状态：第 6/6 步验证包。适用范围：本轮地理地图（`.wmap`）的导出、识别、导入与只读浏览。
不包含：文明演化、可玩世界、人口与经济。

## 1. 运行方式

### 1.1 直接运行游戏

```powershell
# 在编辑器里按 F5，或：
& 'D:\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe' --path E:\godotGames\world
```

启动后进入主界面。主界面不生成任何世界，日志中不应出现 `[WORLD]` / `[TERRAIN]` / `[CLIMATE]`。

页面与展示层按需加载：`AppRoot` 只实例化主界面，进入某个功能时才加载对应页面；世界展示层 [WorldPresentation.tscn](<../scenes/render/WorldPresentation.tscn>) 作为可复用子场景，由地理演化页或浏览页在打开时实例化，不参与启动。

页面通过 `IAppPage.Configure(PageContext)` 接收宿主与取消令牌，不反查场景树；导航与跨页提示经 `IPageHost` 调用。独立 F6 运行页面时宿主为空，页面自行降级。

### 1.2 自动验证


预期：

已有地图时，脚本会对 `%APPDATA%\Godot\app_userdata\world\maps\*.wmap` 中最新一张执行无头导入，打印：

```

```

## 2. 手工验收流程

### A. 导出地图

1. 主界面点「地理演化」，等待 res4 世界生成完成。
2. 左上角点「菜单」→「导出地图数据」。
3. 底部状态文字显示导出路径。
4. 文件位于：

```text
%APPDATA%\Godot\app_userdata\world\maps\map_<时间戳>.wmap
```

本次实测：res4 地图 `216,662,566` 字节，导出约 `8.4 s`。

### B. 重启后导入

1. 关闭并重新启动游戏，回到主界面。
2. 点「地图库」。列表应出现刚导出的地图名称，右侧显示「可识别的地理地图」与完整路径。
3. 选中后点「浏览所选地图」，进入只读地图浏览。
4. 可切换地图模式、点选格子查看信息卡；返回用左上角「菜单」→「返回地图库」。

也可以点「导入地图数据…」，用文件对话框直接选择任意目录下的 `.wmap`。

### C. 损坏文件必须被拒绝

1. 把一个 `.png` 或任意文本文件改名为 `broken.wmap`，放进地图目录。
2. 地图库列表该项显示「损坏或缺失：…」。
3. 点击「浏览所选地图」不会进入浏览页，状态栏显示带错误码的提示。

### D. 版本不支持必须被拒绝

清单中 `schemaVersion` 不是 `1` 的包，探测结果为「不支持」，不会加载。

## 5. 已知限制

1. 导入是主线程同步执行：res4 约 5.5 秒，期间界面会停顿，加载提示不一定来得及重绘。
2. res4 地图包约 216 MB；文件上限为 512 MB，接近上限的增长需要重新审查。
3. 文明演化、可玩世界、人口经济本轮完全不实现；主界面对应按钮禁用。
4. 地理演化页与浏览页共用 `WorldPresentation.tscn` 与 `AppMenu.tscn`，只保留各自的页面级脚本；展示层不包含世界生成器。
5. `OperationContext` 的取消/迟到提交规则已实现并测试，但当前同步流程尚未实际使用。
