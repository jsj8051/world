## 1. 背景与定位

- **聚集地 = 物理场所实体**：独立于社会单元（Polity）存在——场所比人长寿：
  农业部落（settle）的驻扎点固化为聚落；部落迁徙/灭绝 → 聚落留为废墟（考古 mound 语义），
  新部落迁入可接管。
- **实体统一**（2026-08-23 用户推导）：Camp/Settlement 不是并列类，是 **Habitation 实体的形态**——
  聚集地 = "一个东西装配不同功能"（双轴：概念轴 band/tribe/chiefdom/state × 聚集地轴 camp/settlement）。
- 实行 single 实体：`scripts/CivSim/Entities/Habitation/`（Habitation.cs 核心 + Habitation.Settlement.cs
  聚落形态 + Habitation.Camp.cs 营地形态占位）。

## 2. 实体模型（Habitation，v17 存档段）

```
public partial class Habitation {          // 核心（贫血模型——纯数据）
    int Id; int Cell;                      // 所在格（settlement 固定；camp 形态随迁——nomadic 未落地恒固定）
    int BornTick;                          // 形成 tick（场所连续性起点：camp→settlement 演化不重置）
    int DwellFrom;                         // 当前占据者定居起点 tick
    int OccupantId = -1;                   // 占据 Polity Id（-1=废墟/空置）
    int RuinFrom = -1;                     // 废墟起点 tick
    // 职能条件（v17 入档——2026-08-23 功能定性；每 tick 派生缓存，读档恢复+重算覆盖无分叉）：
    bool HasAdmin;                         // 治理条件：酋邦中心（至尊酋长聚落）→ 城市
    bool HasMarket;                        // 市场条件：商路节点（贸易成交伙伴 ≥ 2——TradeModel 写）
    bool HasRitual;                        // 仪式条件：宗教圣地（主导派别份额 < 0.7）
    // 复合条件（"集镇/城市也是一个条件"——用户拍板）：
    bool IsMarketTown => HasMarket || HasRitual;   // 集镇资格（门控集镇级行为）
    bool IsCity       => HasAdmin;                  // 城市资格（门控城市级行为）
    int  TownTier     => IsCity ? 2 : IsMarketTown ? 1 : 0;   // 城镇级收益系数
}
// Habitation.Settlement.cs：聚落形态专属——Stocks（粮仓，场所属性）；
//   旧 Level/LastLevelUpTick 已删（等级体系废止）
// Habitation.Camp.cs：营地形态占位（nomadic 概念落地时填：季节营地格/相位）
```

## 3. 功能定性：村庄/集镇/城市 = 职能条件（2026-08-23 用户拍板）

**旧体系（已删）**：Dwell（定居时长）× P 人口阈值 → 等级升阶（3/8/20 tick × 200/800/3000 人），
都城阈值减半——**拿人口结果当定义**，废止。

**新体系（职能条件）**——"有了什么条件才能做什么；集镇/城市也是一个条件"：

| 定性 | 条件 | 涌现源 | 行为门控（收益/功能） |
|---|---|---|---|
| 村庄 | 无职能（条件缺省态） | 农业定居 | 粮仓（容量 ×(1+0.5×0)）、基础增长 |
| 集镇 | `IsMarketTown`（市场 ∥ 仪式） | TradeModel 商路节点 / ReligionModel 圣地 | 粮仓 +0.5×1、增长 +0.25×1；集镇级吞吐 |
| 城市 | `IsCity`（治理） | 酋邦中心（D2：历史上酋邦中心即城市——杰里科/乌尔前期）| 粮仓 +0.5×2（2.0×）、增长 +0.25×2；贡赋中枢、战争要塞 |

- **D2 决策**："历史上存在什么就是什么"——酋邦中心（至尊酋长聚落）即城市（含国家都城——同一聚落）。
- **人口是结果不是定义**：收益跟随条件（条件吸引人聚集，不是人多了变条件）。

## 4. 机制（HabitationModel，Order 48，Territory 域）

1. **占据同步**：已死/迁走部落释放聚落（废墟——场所比人长寿；迁走清 PlaceId/SettledSince）。
2. **形成/接管**：IsFarming 部落无聚落 → 所在格废墟接管（占据恢复，**无 Level 继承**——条件由新占据者
   重新涌现）/ 新建（Habitation 默认状态）。
3. **职能条件收集**（2026-08-23，替代旧等级演化）：
   - `HasAdmin` = 占据者 IsChief && ChiefdomId==Id（酋邦中心）
   - `HasRitual` = ShareField.DomFrac01(ReligionShare) < 0.7（宗教多教汇聚）
   - `HasMarket` = TradeModel 本 tick 成交伙伴 ≥ 2（Order 55 写入，晚于 48）

## 5. 收益接线（2026-08-23 功能定性）

| 消费点 | 公式 |
|---|---|
| 粮仓容量（CivEngine.AccumulateStorage / GrowthModel） | settle 容量 × P × (1 + 0.5×TownTier) |
| 增长加成（GrowthModel） | 定居生育 × (1 + 0.25×TownTier) |
| 战争要塞（WarModel） | `IsCity` 计数 → 防御方城墙加成；都城加成 = capitalTier |
| 国家涌现（阶段4） | 都城 `IsCity`；次级中心 `IsMarketTown`（Childe：城市+官僚节点） |
