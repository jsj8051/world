> **v1.11（2026-09-14，造山高度对齐设计口径 + 海平面/位移脱钩修正）**：用户看世界判读"板块碰撞出来的山脉都很高"，
> 实测坐实——304 My 时陆海拔 p90 = 6.0 km、13.5% 陆地 >3 km、12.3% >5 km，**不是"几座高峰"而是整片 6–7 km 高原**。
> 两处根因都与 02 §5.2 用户拍板的设计峰值（**+5.3 km / 峰值壳厚 60 km**）对不上：
> ① **陆壳参考厚 28300 → 35000**（`H3Isostasy.LandReferenceThicknessM`）：28300 是老 Init 山地模板曲线的**膝点**
> （最薄的低地壳），不是大陆平均厚——参考薄了 6.7 km ⇒ 所有被增厚的碰撞带**平白多抬 `kAiry`×6700 ≈ 1.0 km**。
> 顺带与 01 §3.3「陆壳 35 km」、地球大陆平均 35–40 km 对齐（初始陆壳同时从 28.3 km 回到 35 km，海拔不变）。
> ② **厚度帽 70000 → 65000**（`H3DynamicTectonics.MaxCrustThicknessM`）：本路线**无侵蚀**（03 §1）⇒ 碰撞带质量只进
> 不出 ⇒ 造山**必然单调饱和到帽高** ⇒ 帽就是唯一的高度旋钮。帽 65 km ⇒ 高原面 = 800 + kAiry×(65−35 km) ≈ **+5.4 km**
> （实测 600 My max = 5.39 km ✓）。**格局未变**（无侵蚀的必然）：600 My 仍有 31.2% 陆地 >3 km（地球 2.4%）——
> "整片高原"要有峰有谷，得等侵蚀/沉积那一批（03 §7 后续清单）。
> ③ **顺带修一个真 bug（海平面/位移脱钩）**：挠曲与海沟下挖改变洋底体积后会重解海平面，而**陆格位移
> （= 海平面 + 自由板 + Airy 增量）停在旧海平面上** ⇒ 渲染海拔 = 位移 − 海平面整体偏掉这个差值（本案例单步
> **+118 m**）。是新写的「造山高原面 = 厚度帽的 Airy 当量」断言反查出来的（实测 2463 m vs 当量 2345 m）。
> 修法 = 新增 `H3Isostasy.RebaseLandToSeaLevel`（口径同 `ComputeDisplacement` 的两遍收敛，只是只动陆格），
> 在两个重解点（每步第 8 步、终态放样 `H3BoundaryRelief`）调用；挠曲/下挖这类装饰项**不随海平面重算**。
> ④ 判读/回归口：`HexDynamicDiag` 每步新增 `[地形]` 行（陆海拔 p50/p90/p99/max + >3 km / >5 km 占比）；
> 新增单测 `OrogenCeiling_EqualsThicknessCapAiryEquivalent` 把"山有多高 = 帽的 Airy 当量"钉住（同类漂移当场打到断言）。

## 1. 本批范围（**首先需要判读的一条**）

| | 内容 |
|---|---|
| **本批做** | 板块运动学（浮力→速度→刚体旋转）→ 平流 → 合并 → 边界分类（汇聚/离散/转换）→ 裂谷（新洋壳）→ 俯冲回收 + 增生楔 → 均衡位移 + 挠曲 → 水量守恒海平面 → 超大陆聚合/裂解循环 |

## 2. 老机制速写（搬的是什么）

### 2.1 数据模型

**八物质场**（`Crust.cs`）：`Sediment` / `Sedimentary` / `Metamorphic` / `FelsicPlutonic` / `FelsicVolcanic` / `MaficVolcanic` / `MaficPlutonic` / `Age`。
- **守恒组 = 5**（沉积、沉积岩、变质、长英深成、长英火山）：合并时**直接相加**（碰撞增厚 = 两侧地壳叠起来）。
- **顶层决定组 = 3**（mafic 两场 + Age）：取密度最小的那块板（浮力大的盖在上面）。
- 派生公式：`厚度 = Σ(质量/ρ)`；`密度 = 总质量/厚度`；`浮力 = (ρ − ρ_mantle)·g ≤ 0`；`均衡位移 = t − t·ρ/ρ_mantle`（Airy，与 02 的 `kAiry` 同源）。

### 2.2 每步流水线（`TectonicsSimulation.RunWithProgress`）

```
1 洋壳老化        age += stepMy（→ 密度涨 → 负浮力 → 驱动俯冲）
2 各板并行 Move   浮力 → v = n̂·(buoyancy·k) → 刚体旋转拟合 → 累积 LocalToGlobal → 重采样映射
3 Merge          逐板重采样到全局：守恒组相加 / 密度最小者赢顶层 / PlateCount++
4 碰撞缝合        两板接触边界 ≥2% 全球 → 合并（印度-欧亚式）
5 UpdateRifting   离散边界露出的空当 → 填 age=0 新洋壳（洋中脊）；大陆裂谷带 felsic 减薄
6 UpdateSubducted 被压在下面的板：felsic→变质；密度>地幔的板缘格消减 → 转到 Accretion
7 ApplyAccretion  增生楔加到顶层板（俯冲上盘造山带）
8 超大陆裂解      最大板块 >25% 全球 → 切大板成 3 块（继承式，保留位置）
9 ComputeDisplace 均衡位移 + ApplyFlexure（山体负载 → 邻域下沉 = 前陆盆地）
10 SolveSeaLevel  按水量守恒二分求海平面（平均海洋深度 = TotalOceanDepth 常量）
11 地表过程       侵蚀/风化/成岩/变质（**本批不做**）
```

### 2.3 实测（老实现现状，2026-09-11 本机复跑）

## 3. H3 原生化（"不照抄"的核心在这里）

### 3.1 干掉"每板一份网格副本 + Voronoi 爬山"

老实现的板（`Plate.cs`）持有：**全局网格拓扑的完整副本** `LocalGrid` + `Mask` + **自己的 `Crust`（8 场 × N）** + 旋转矩阵 + 双向映射 `LocalIdsOfGlobalCells` / `GlobalIdsOfLocalCells`；移动后用**欧氏最近邻爬山**（`NearestIdSeeded`，种子来自上一步映射，候选超 64 次则退化为全桶精确查询）重算映射 —— 还专门加了「每 25 步全量重同步」的性能补丁。

**H3 上这一整套都不需要**：格心旋转 → 经纬度 → `H3.LatLngToCell(..., res)` 就是 **O(1) 精确**的"落进哪一格"，没有 Voronoi、没有爬山、没有桶索引、没有重同步。

| | 老式（照抄） | **H3 原生（本批）** |
|---|---|---|
| 板块表示 | 每板：全网格副本 + 局部 crust + 双向映射 | `plateId[cell]` + 每板一个旋转矩阵 |
| 平流 | 局部→全局最近邻重采样（并行 × 2 方向） | 旋转格心 → `LatLngToCell` → 目标格 |
| 内存（res4 / res5） | 8 板 × N × 8 场 × 4 B ≈ **74 MB / 517 MB** | 8 场 + plateId ≈ **10.4 MB / 72.6 MB** |
| 每步成本 | O(板块数 × N) 双方向最近邻 | O(N) 一次查询 |

> ⚠️ 内存那一行是本批的**硬约束**：用户目标世界是 res5（2,016,842 格），老式的每板副本直接 500 MB+ 且随板块数线性涨。**照抄在 res5 上跑不动**——这不是优化问题，是结构问题。

### 3.2 平流的多对一 / 空洞（H3 上必然出现，必须定规则）

旋转是连续映射、网格是离散的 → 一格可能**收不到任何源格**（空洞）、也可能**多个源格落到同一格**（多对一）。老实现用「`dst[i] = src[localIdsOfGlobalCells[i]]`」——后写者赢，按板序，多对一被静默吞掉。

**本批规则（提议）**：
- **多对一** → **面积守恒聚合**：目标格的每个场取所有源格的**加权平均**，权重 = 源格心落入目标格 Voronoi 单元的占比（等面积网格近似下权重相等，取算术平均即可）。
- **空洞** → 分两类：板上空洞（板内出现无源格）= **裂谷候选**（老实现正是把 `PlateCount==0` 当洋中脊 → 与 §2.2 第 5 步天然对齐）；板缘空洞 = 平流撕裂，按邻格补。
- **对账**：每步结束时校验「质量守恒组总量 = 上一步 − 消减量 + 新增量」，偏差 > ε 即报错（老实现无此校验，质量悄悄流失的 bug 修过两次）。

### 3.3 刚体性怎么维持

老实现每步用**逐格速度场拟合刚体旋转**（绕质心 ω_c = v×(p−c)/|p−c|²、绕世界中心 ω_w = v×p，各自平均 × dt → 两矩阵相乘）；速度场本身来自 `v = n̂ × (buoyancy·k)`，即**方向由板的几何边界法线定、大小由浮力定**。

本批保留这套结构（它是老机制的核心物理），但**速度场不再"只由本板算"**：H3 上直接用全局 `plateId` 的邻居差分求边界法线（等价于老实现的 `FieldOps.Gradient(mask)`，不需要每板 mask 副本）。

### 3.4 板块归属：跟着物质走，不做逐格重新分派（v1.2；口径由用户 2026-09-11 两次纠偏定）

**用户口径（原话）**：

1. 「归属是固定的，你哪怕旋转了依然归属原来板块，**不要直接 Voronoi 最近邻改变归属**」；
2. 「板块划分**只在最开始进行一次**，之后就一直是自己运动了，**不应该出现一个板块的一个格子嵌入另一个板块里**」。

**根因**（静态链路）：渲染按 `Crust.PlateId` 逐格上色（`PlateMapMode.PlateColor`）→ 争议全落在"一块格子的归属怎么定"。

**离散网格上必然要有一处裁决**：板块随旋转是**刚体**，但"格集合旋转之后"不再是格集合 —— 部分格收不到任何源（**落空**），部分格收到多个板的源（**重叠**）。所以"归属零裁决、永不变化"在离散上做不到；能做到的是：**让裁决方式本身不产生嵌入格**，且裁决以"物质"为准而非以"几何近"为准。

**三种口径实测对照**（res3 / 8 板 / seed 42 / 600 My；指标 = 连通分量 / 孤立格 / 强少数格）：

| 口径 | 归属怎么定 | 连通分量 | 孤立格 | 强少数格 | 判定 |
|---|---|---|---|---|---|
| ① 密度（顶层板） | 谁在这个格露在最上面（物理量） | 162 | 108 | — | ❌ 用户报的"格子嵌入别的板块" |
| ② 最近邻（Voronoi） | 落到该格的源里**离格心最近**者 | 11 | 0 | 53 | ❌ 仍属"逐格从物质反推归属" |
| ③ 面积多数决 | 落到该格的源里**面积最大**的板 | 13 | 4 | 87 | ❌ 同上，且残留 4 个嵌入格 |
| ④ **板体覆盖（现行；用户拍板"甲"）** | 每板属格集合当**面片**整体旋转，格心落在谁的板体里就归谁（离散 = 全体像点取最近） | **8** | **0** | 40 | ✅ 归属 = 被搬运的**板体**，不再从物质反推；连通分量 = 板数 |

> ②③④ 的差别不在数值调参，而在**架构方向**：①②③ 都是"从这一步物质落在哪里反推归属"（离散化抖动会直接改归属），④ 是"归属 = 板体自身随运动搬运的结果"，物质落点只决定**材料**。
>
> ④ 的成本：散射 7 格/源格 ⇒ res3 由 50 ms/步升到 **95 ms/步**（res5 需早退剪枝优化）。
> ④ 残留的 40 个强少数格不是平流产生的：**初始分板**在第 1 步就有 574 个（1.4%），随演化衰减到 40（0.1%）—— 要更干净得改初始分板（§9-8）。

**归属与材料仍是两件事**：材料（哪一层的壳**露在最上面**）走密度裁决（老 Merge 的 onTop），被压下去的源记入 `RecycledToMantleMass` = 俯冲回地幔。

**已拍板（2026-09-11，用户选"甲"）**：归属 = **板体覆盖（分区）** —— 归属由**板块自己的几何**决定（每板属格集合整体刚体旋转后的覆盖），不再从"这一步物质落在哪"反推。实现见 `H3PlateAdvection` 的散射段（像点散射到 1 环 7 格、各格取最近像点所属板）。

**架构结论（用户追问"是不是架构有问题"）**：是，且已按此修正 ——
- **固有的**：固定网格 + 刚体板块 ⇒ 边界带每步扫过新的格，"这一格归谁"必有一条规则（老实现也有）。这不是架构错。
- **曾错的（①②③）**：把归属做成"每步从物质落点重建的场" —— 归属本是板块自身属性（初始分板定一次、随后随板运动），物质搬运只该影响**材料**。三种反推规则换来换去都在同一个错方向。
- **现行（④）**：归属 = 被搬运的板体；落空/重叠只影响材料（洋脊新壳 / 碰撞堆叠），不再改归属。

**新增判读量测**（`H3DynamicTectonics.MeasurePlateTopology`，每步 O(N)）：无主格 / 孤立格 / 强少数格（本板邻居数 < 任一他板邻居数 —— 平直边界 3:3 不计，只算"被别板包住"的毛刺）/ 连通分量数 / 最大分量占比 / 最大板占比 / 归属与密度不一致格数 / 归属与最近邻不一致格数。

**归属场进速度拟合**（每板速度 = 本板各格速度平均）⇒ 归属口径一变，速度变、终态整体变（陆占比/海平面/混合格数都会变）。三个口径的终态数值不构成"哪个更对"的判据，**形态与观感由判读决定**。

### 3.5 碰撞阻挡：上盘停、下盘俯冲（v1.3；用户 2026-09-11 拍板"甲"）

**症状**（用户原话）：「碰撞时板块会原地不动，而不是**如入无人之境**继续平移，不是说给了初速度就一定会移动那么多」。

**根因（架构级）**：老实现靠**碰撞缝合**（两板接触边界 ≥2% 全球 → 并成一块刚体，从此一起动）来终止互穿；我们的缝合是空实现（用户指定"先讨论机制"），于是**每板各自算速度、各自平移，边界上没有任何相抗的项** ⇒ 板与板互穿。互穿的后果一路外溢：空洞/重叠格数被撑大（958 / 657 格每步）→ 归属场被撕（连通分量 17 ≠ 板数 8、孤立格 7）。

**机制（甲）**：逐条异板边判**汇聚**，汇聚则按"谁停"分派 ——

| 情况 | 处置 |
|---|---|
| **陆-陆汇聚** | **两侧都停**（谁都俯冲不下去 → 转成增厚；将来接缝合） |
| 其他（有洋壳参与） | **较浮的一侧 = 上盘 = 停**；**较重的一侧 = 下盘 = 继续运动**（其前缘物质由平流的顶层裁决记账为回地幔 = 俯冲消减） |

**实现**：对"被挡"的板加**线性约束** —— 接触点 c 处沿 n̂ 的速度必须 ≤ 0。由三重积 `(θ × c)·n̂ = θ·(c × n̂)`（θ = 本板本步旋转向量），约束即 `θ_p · u ≤ 0`（u = c × n̂，|u| = 1）；逐约束序列投影两遍后，`FromRotationVector(θ)` 重建该板旋转矩阵。**该板其他方向的运动（板片自沉拖动板块）保留** —— 这正是"给了初速度不会一直平移"：被挡的那个方向被抵消，没被挡的方向照旧。

**配套的两处口径修正**（同一根因，必须一起改，否则判据符号是反的）：

1. **驱动速度 ≠ 实际运动速度**：驱动速度 `v = n̂·buoyancy·k` 在边界上**朝板内**（n̂ 指对方、buoyancy ≤ 0），拿它判"汇聚/离散"必然判反。现拆成两个场：`_driveVelocity`（拟合的输入）与 `Velocity`（拟合后的**实际刚体运动**，板缘分类 / 洋脊判定 / 接触阻挡都读它）。
2. **`H3PlateBoundary` 汇聚/离散判反（真 bug）**：02 §2.3 的约定是 `v_rel = v_i − v_j`、`v_n > 0 = 汇聚`，它写成了 `v_j − v_i`，于是"汇聚"被判成 `Divergent`、"离散"被判成 `Convergent` —— UI 格信息行的板缘类型一直是反的。已修正。

**实测（res3 / 8 板 / seed 42 / 600 My；接触阻挡每步约 1,218 → 1,290 格）**：

| 指标 | 无阻挡（互穿） | 有阻挡（甲） |
|---|---|---|
| 空洞格/步 | 958 | **239** |
| 异板混合格/步 | 657 | **148** |
| 归属连通分量 | 17 | **8 = 板数** |
| 孤立格 | 7 | **0** |
| 强少数格 | 95 | **12（0.03%）** |
| 陆占比（终态） | 17.9% | 22.8% |

> 结论：用户指的"互穿"正是空洞/重叠与归属碎片的总根 —— 堵住它，平流与归属两个场一起变干净。

### 3.6 顶死接触零功修正：堵住不动的接触不做功（v1.8；碰撞减速的第 1 级）

**缺口定性（架构缺口，非固有约束）**：v1.4 删 §3.5 的板级阻挡是对的（它挡不住刚性旋转从别的边界段推进去），但删的时候把"碰撞让板减速"这个**目的**也一起丢了，且没有替代物——位置阻挡（顶死）只回答"这一格归谁"，不回答"这板还转不转"。后果链：被顶死的致密板缘格仍按满额 `−浮力×厚度×面积` 计入 F → 全顶死的板照"无接触自由解"起跳（`PlateFired` 恒真）→ 持续往造山带进料 → 70 km 厚度帽每步把超出部分**删掉**（记账平、地形侧只增厚不收敛）= 生产-回收永动机。

**分级修复（本批做第 1 级，第 2 级待量测拍板）**：

| 级 | 内容 | 状态 |
|---|---|---|
| 0 量测 | 顶死实测（平流 Pass C）/ 顶死预测（运动学）/ 幻影 F 占比 | ✅ v1.8 |
| 1 零功修正 | "本步必被顶死"的致密板缘格**不进净驱动力 F**（零参数，纯口径修正） | ✅ v1.8 |
| 2 接触阻力 | v = (F−R)·δ/(η·A)，R = Σ_顶死接触格 σ_contact·格面积（σ_contact ~ 几十 MPa 观测板块边界应力，**勿用静岩压**——30 km 柱 ≈ 0.8 GPa，一格顶死抵五十格驱动，第一格碰撞全场冻死） | ⏳ 待量测 |

**为什么是力级不是约束（与 §3.5 的分界）**：§3.5 是对 ω 的**硬约束**，挡不住别的边界段绕行；v1.8 是改 F 的**统计口径**——力全边界可加、天然不存在绕过，且位置语义（谁顶死、谁俯冲）仍完全归物质层。判据抽 `H3PlateContact.JamsInto` 与平流 Pass C 共用（两处口径不许漂移）；落点邻居选择共用 `FlowNeighbor`（运动学传边界法线 = 驱动方向，平流传实际速度切向）。

**⚠️ 只认 foreign 接触**：链头撞**同板**未起跳格是相位停驻（下一步就走），撞无主格不是接触——都不算碰撞、不剔除、不计数。运动学用的是"当前场 + 法线方向"的**预测**（Step 保持单向，不需要 advection→motion 反馈通道，双缓冲交换的确定性设计不动）；平流是**实测**。两者每步对照（`JamContactCellsLastStep` vs `JammedCellsLastStep`），分叉大 = 预测口径漂了。

**已知边界（诚实记账）**：顶死判据要求来料**不比目标密**，能进驱动名单的致密格撞上更轻目标时走俯冲——所以第 1 级咬合的只是"等密/撞重目标"的僵死格；**大陆板缘浮力恒 0 本就不在 F 里**，陆-陆顶死段对板速的影响只经"等密僵死"这一条通道——"顶死段拖慢整板"若还不够，才是第 2 级 R 项的题。

**实测（v1.8 当步 A/B，res3 / 8 板 / seed 42 / 600 My / step 4 My，同配置仅开关剔除）**：

| 指标 | 无剔除（基线） | 有剔除（v1.8） |
|---|---|---|
| 顶死实测（链头真顶死/步，600 My） | 266 | **40**（6.6×） |
| 速度钳制格/步 | 443（常态触发） | **0** |
| 幻影驱动力占比 | 不可见（ silently 计入 F） | **82%**（1273 格顶死接触，逐涨：43%→82%） |
| 生产-回收（回地幔/增生楔） | 每步持续为正 | **基本归零**（仅个别尖峰步） |
| 异板混合格/步 | 15 | 0（尖峰步 19–88） |
| 归属连通分量 | 一次 9 ≠ 板数（撕碎毛刺） | 恒 8 = 板数 |
| 板速 | 高于 CFL 上限（被钳到 ~2 cm/yr 兜底） | **0.05–0.3 cm/yr**（板2 独苗 1.9） |

**判读输入（第 2 级拍板用，2026-09-12）**：
1. 基线完整复现了 §3.6 开头的伪影链（顶死板每步起跳、生产-回收永动、CFL 常钳、归属毛刺）——第 1 级全部消掉，"印度式减速"实际已经涌现（顶着大碰撞带的板 0.05 cm/yr ≈ 停）。
2. **幻影 F 占 82%**远超预期（原判"小头"错了）——这个世界里老洋壳等密碰撞带吸收了绝大部分板缘拉力，第 1 级一开全世界板速从"超 CFL 被钳"掉到 0.05–0.3 cm/yr，**低于 1–10 cm/yr 观测带**。
3. 顶死预测（1273，法线朝向口径 = 接触压力图）与实测（40，拟合速度真推进去的链头）差 30×：预测是静态应力图，实测被"板已减速→少起跳"负反馈压低。若嫌第 1 级拖太慢，收窄方向是把剔除口径从"法线朝向"换成"上一步刚体速度实际汇聚"（更贴"是否真的移动"，但要处理冻结板的振荡）；而不是回退第 1 级。
4. 结论待拍板：第 2 级 R 项可能**不再需要**（减速已由第 1 级给出）；若要加，须同步重看速度带标定。
