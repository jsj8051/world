## 一、现状与史实依据

### 1.1 现状（可复用）

| 机制 | 现状 | 贸易角色 |
|---|---|---|
| CommodityTable.Stocks | 6 商品（grain/berry/meat=Food；leather/wool/straw=Material） | 贸易的商品池 |
| Material 商品 | 只存+衰变+容量，**无消耗** | 贸易的**可交换品**（用户"备货"） |
| TribesTouch | 领地接触检测（ChiefdomModel 用） | 贸易**接触条件** |
| SpreadModel | 邻格科技传播 | 贸易的对照（接触即互通） |
| ChiefdomModel | 领地接触 + 产出互补 → 酋邦 | 贸易互补的**制度化** |

### 1.2 史实锚点（物物交换）

- **新石器贸易**：黑曜石/燧石/绿松石等**稀缺石料**跨 300+ km 交换（考古：土耳其 Çatalhöyük
  黑曜石贸易网）；贝壳、玉石成"准货币"雏形。
- **农业-游牧互补**：农业部落粮 ↔ 草原游牧毛/皮/畜（丝路前身的欧亚草原交换）。
- **比较优势驱动**：商品丰缺差异 → 互通有无 → 专业化（各产所长）——贸易是文明整合的纽带。
- **物物交换限制**：无货币 → 需**需求匹配**（我要你的、你要我的）+ **运输成本**（距离衰减）+ 规模（小部落交换量小）。

## 二、机制设计

### 2.1 贸易模型（TradeModel，Order 55——介于 Spread(50) 与 Culture(60) 之间）

**触发**：领地接触（`TribesTouch`，同酋邦接触判定）→ 接触部落对每 tick 一次贸易机会。

**商品流（物物交换核心——比较优势）**：
- 对每个接触部落对 (A, B)，逐商品比较**人均库存**（Stocks[i]/P——相对丰缺）：
  - A 的 X 商品人均 > B 的 X 商品人均 → A 出口 X 给 B；
  - 同时 B 的 Y 商品人均 > A 的 Y 商品人均 → B 出口 Y 给 A；
  - **交换量 = 双方各取所需的最小盈余**（等量交换，物物交换无货币）。
- **需求匹配**：只有"你多我少、我多你少"的商品才交换（无货币 → 无单向贸易）。
- **运输成本**：接触距离（领地边界格距离）折减交换量——远地贸易量小（史实：黑曜石随距离衰减）。

**效果**：
- Material 商品（皮革/羊毛/秸秆）真正**流通**（备货变贸易品）；
- Food 盈余也可换（农业部落粮 ↔ 狩猎/畜牧部落肉/毛——互补）；
- 部落库存趋同化 → **专业化涌现**（各部落专注自己的优势商品，其余靠贸易——比较优势的模型涌现）。

### 2.2 参数（★ 标定；✅ 已按拍板值落地）

| 参数 | 值 | 依据 |
|---|---|---|
| TradeRate（接触对/ tick 交换比例） | 0.1（人均库存差的 10%） | 低频——物物交换是偶发集市，非每日 |
| 距离折减 | 接触格距 d → ×(1/(1+0.5d)) | 运输成本史实（黑曜石随距衰减）；接触对 d=1 → ×0.667 |
| 最小交换量 | 人均差 < 0.01 不换 | 防噪声抖动 |
| TradeFoodFloor（食物出口保底） | 0.05（出口后人均 ≥ 5%×P≈5 年存粮） | 饥荒最后防线——防贸易拆粮仓（2026-08-18 拍板"Food+Material 全开放"配保底；当前 TradeRate 下防御性不触发） |

### 2.3 演化级观测（2026-08-19 收尾标定）

- **流量**（n64 全演化 296 tick）：贸易 7908 次 / 856 人当量——"偶发集市"量级符合设计意图（TradeRate=0.1 保持）。
- **专业化涌现**（n128_v2 末态）：生产方式×人均库存画像分化——农持秸秆 0.18/皮革 0.05、牧持羊毛 0.03、猎近 0 → 比较优势各产所长 ✓。
- **洞察：备货依赖存储科技链**——Material 年衰变（皮革 0.03）经 100 年 tick 聚合每 tick 仅存 ~5%；无 storage 科技几乎无法囤积（猎 0.00）；有 settle+grinding 后存活 ~74% → 可囤积 → 贸易量与存储技术正相关（Testart 存储→盈余→贸易链路涌现，符合设计非 bug）。若需更大贸易量：↑TradeRate 或 ↓Material BaseDecay（待用户拍板）。

### 2.3 确定性（阶段3架构化红利）

- TradeModel 无 Rng（纯比较+等量交换）→ 读档续跑无分叉（T04 保证）。
- Stocks 是持久字段，贸易是副作用（每 tick 一次）——放 AccumulateStorage 同层语义
  （演化循环内），SettleDerived 不碰。
- 接触检测确定性：固定遍历顺序（部落 Id 序，同 ChiefdomModel）。

### 2.4 存档

- Stocks 已入档 v12——贸易只是 Stocks 的**转移**，无新存档字段 → **版本不变**。
