# 阶段4设计：国家涌现（酋邦 → 国家）

> 2026-08-16 · 用户拍板 1A2A3A4A：**综合涌现 + 全四项机制差异 + 纯派生不存档 + 对称可逆崩溃**。
> 本文档为设计蓝图 + 实施记录。对应路线图"人文层：部落→酋邦→国家（unlock_state）"项。

## 一、现状与史实依据

### 1.1 现状（可复用）

| 机制 | 现状 | 国家角色 |
|---|---|---|
| ChiefdomModel（酋邦） | 至尊酋长庇护（个人化权力，ChiefReach 半径） | 国家的**前身**——个人化→制度化 |
| 贡赋 Contributed / TributeRate=0.1 | 互惠记录（Earle 实物税） | 国家的**税基**——互惠→税收 |
| 精英供养 EliteFrac=0.1 | 酋长 band 非生产者（祭司/战士/亲信） | 国家的**官僚**——亲信→官职 |
| 继承窗口 SuccessionUntil | 酋长死亡→权力真空→继承竞争（Kirch） | 国家的**制度化分水岭**——继承战争→王朝 |
| 聚落体系（SettlementModel） | 新村→村庄→城镇→城市 + 都城（酋长聚落） | 国家的**决策层级**（Wright-Johnson 3 级） |
| ConflictModel 内部冲突 ×0.5 | 酋长仲裁（pax 不存在） | 国家的**强制力垄断**（Weber） |

### 1.2 史实锚点

- **Childe 城市革命**：剩余集中→城市→国家——剩余是国家的物质基础；
- **Wright & Johnson**：国家 = **3 级聚落层级**（都城 > 次级中心 > 村庄）——决策层级是国家的结构特征；
- **Earle**：酋邦 = 个人化权力（patronage），国家 = **制度化官职**（不依赖个人）；
- **Kirch 1984**：继承战争常态化（Polynesia）→ 国家 = **继承制度化**（王朝规则固定，权力真空不再引发内战）；
- **Weber**：国家 = 合法暴力垄断 → 内部秩序（同邦冲突概率显著下降）。

**关键洞察（本项目一贯原则）**：酋邦 vs 国家**没有硬性人口/面积阈值**——区分在**权力性质**：
个人化（patronage，随酋长生灭）→ 制度化（官职/税制/继承规则，不依赖个人）。

## 二、机制设计（拍板 1A：综合涌现）

### 2.1 国家状态（Tribe 派生字段，不存档——拍板 3A）

```csharp
public int StateId = -1;    // 所属国家 id = 至尊酋长 Id（-1=非国家；派生，同 ChiefdomId 模式）
public int StateSize = 1;   // 国家内部落数（≥2 = 正式国家；派生）
```

- 纯派生：从**已入档持久字段**（ChiefdomId、聚落 Level/BornTick、Contributed、Prestige）确定性重建；
- **零新存档字段**（都城 BornTick 已在 v13 聚落段）→ **版本不变 v13**，读档续跑无分叉（T04 保证）。

### 2.2 涌现条件（StateModel，Order 49——Chiefdom 46 之后、Conflict 75 之前）

酋邦 **AND** 以下条件全部满足 → 国家：

| # | 条件 | 判定（★ 待校准） | 史实 |
|---|---|---|---|
| ① | 都城 | 至尊酋长（ChiefdomId==Id 且 IsChief）占据聚落，且 **Level ≥ 2（城镇+）** | Childe：权力中心（剩余集中地） |
| ② | 决策层级 | 酋邦内 **≥2 个成员聚落**，且存在 **Level ≥ 1 的次级中心**（非都城） | Wright-Johnson：3 级聚落层级 |
| ③ | 贡赋盈余持续 | 酋邦贡赋池 `TributePool ≥ 酋邦总人口 × StateTributePerCap` | Childe：剩余集中支撑官僚 |
| ④ | 存续 | `Tick − 都城.BornTick ≥ StateDwellTicks`（都城实体存续时长） | 制度化需要时间（场所比人长寿） |

- 无人口/面积/成员数硬阈值（项目原则：**规模从机制涌现**——酋邦本就无上限，国家是"性质跃迁"不是"体积达标"）；
- 全部条件用**已入档字段**：①聚落 Level/OccupantId ②聚落 Level ③Contributed ④聚落 BornTick → 纯派生确定性。

### 2.3 维持与崩溃（拍板 4A：对称可逆）

```
判定为**同一条件**（无滞回字段——纯派生无记忆）：
  ① 都城仍在（酋长聚落，Level ≥ 2——聚落等级单调，天然弱滞回）
  ② 贡赋池 ≥ 总人口 × StateTributePerCap
  ③ 酋邦仍 ≥ ChiefdomMinTribes（邦没散）
  ④ 存续（都城 BornTick）只增不减 → 天然单调
条件满足即国家，任一断开即退化（对称可逆，4A 拍板）
```

**崩溃路径（自然涌现，无事件）**：
- **贡赋断流**：饥荒（FLast<P）→ 无盈余 → 无贡赋流入 → 精英供养持续消耗池 → 池跌破线 → 退化
  （国家 EliteFrac 0.25 > 酋邦 0.1 → 官僚成本高 → 更容易崩——自洽：国家靠持续征收维持）；
- **都城失守**：酋长迁徙/灭绝 → 都城变废墟/易主 → 条件①失效 → 退化；
- **继承绝嗣**：国家酋长死亡后，若 ChiefReach 内无新酋长庇护 → 成员解散 → 退化
  （制度化只豁免内部继承战争，不提供永生——王朝绝嗣即崩溃，Kirch 史实）。

### 2.4 国家 vs 酋邦机制差异（拍板 2A：全四项）

| # | 差异 | 酋邦 | 国家 | 实现点 |
|---|---|---|---|---|
| ① | **官僚供养↑** | EliteFrac 0.1 | **0.25** | PrestigeModel 精英消耗：`EliteFracOf(e)` |
| ② | **税制化** | TributeRate 0.1 | **0.2** | PrestigeModel 贡赋流入：`TributeRateOf(e)` |
| ③ | **继承制度化** | 继承窗口（真空→竞争→分裂风险） | **王朝：继承危机豁免** | ChiefdomModel ①危机检测跳过国家 |
| ④ | **内部秩序** | 同酋邦冲突 ×0.5 | **×0.25** | ConflictModel：`InternalConflictMultOf(e)` |

**③ 继承制度化的具体语义**（Kirch→王朝）：
- ⚠️ 实现位置：**ConflictModel**（Order 75，晚于 StateModel 49）——国家成员之间的继承窗口 **×2 豁免**
  （国家内部继承不引发战争；酋邦照常 ×2）。不做"窗口消失/成员不解散"——ChiefdomModel（46）早于
  StateModel（49），若它读 StateId 会导致读档续跑分叉（滞后 1 tick 的值 vs 重建值无法对齐，T04 类 bug）；
- 效果：国家酋长死亡 → 成员间冲突不因权力真空 ×2（制度化缓和继承战争，非消除——pax 不存在）；
- 对照酋邦：酋长死亡 → 继承窗口 → 窗口内冲突 ×2（现状，Kirch 继承战争）；
- 国家绝嗣（ChiefReach 内无新酋长）→ 成员解散 → 退化（§2.3 崩溃路径）。

⚠️ 滞后 1 tick 说明：PrestigeModel（25）读 StateId 是**上一 tick** 值（StateModel 49 在其后）。
读档续跑无分叉：SettleDerived 重建的 StateId 与演化末写入值相同（同输入同公式），
读档端下一 tick 的 Prestige 读到重建值 = 内存端同 tick 读到的演化值 ✓（T04 验证）。

## 三、实施步骤（每步可验证）

1. **字段 + 参数**：`Tribe.StateId/StateSize`（派生，**不存档**——CivArchiveSchema 白名单无此行，版本不变 v13）；
   `CivSimContext` 加：StateTributeRate=0.2、StateEliteFrac=0.25、StateInternalConflictMult=0.25、
   StateCapitalLevel=2、StateSubCenterLevel=1、StateTributePerCap=0.1、StateDwellTicks=20。
2. **StateModel**（Order 49）：`Rebuild(ctx)` 纯派生——按酋邦（ChiefdomCells）判定涌现条件，写成员 StateId/StateSize；
   注册进 `CivModelRegistry.StoneAge()`；`SettleDerived` 末尾（⑤b）追加 `StateModel.Rebuild(ctx)`。
   ⚠️ 性能（T18 暴露 309s 劣化 → 修复 915ms）：每 tick 执行，必须 O(1) 索引——
   Id→Tribe 数组（同 ChiefdomModel 缓冲）+ PlaceId→Settlement 字典，禁 FindTribe/SettlementOf 线性扫描。
3. **接线**：PrestigeModel（税/精英按 StateId 分档）、ConflictModel（内部秩序倍率 + 继承窗口 ×2 豁免，
   提取 `ConflictChanceOf` 纯函数——T67 直接断言）、SettleDerived ⑤b。
4. **显示**：MapViewer 政体图层（18）加第 4 档"国家"（PolityOf 国家→3 + 图例，金色 0.12）；
   HumanLayersProbe 加国家统计（国家数/人口/都城等级）。
5. **测试**：T64 涌现（都城+层级+贡赋+存续 → 国家；缺任一 → 非国家）；T65 机制（税率 0.2/精英 0.25/
   内部冲突 ×0.25 断言）；T66 崩溃（贡赋断流/都城失守 → 退化，对称可逆）；T67 继承制度化
   （同国窗口 ×2 豁免 vs 同邦 ×2 照旧 vs 跨邦 ×2）。T04 读档续跑无分叉自动覆盖
   （StateModel 入 SettleDerived + EntitiesEqual 加 StateId/Size 对比）。
6. **全量回归 + 演化验证**：66P 基线 + T64-67；n64 回归 915ms（T18）✓；n128 再演化 → 探针出国家分布。

## 四、参数表（2026-08-19 已校准——n64/n128 双图演化验证）

> 校准结论（2026-08-19，T 测试 + 演化探针双轨）：
> - **n64**（40962 格，237 tick，人口 4169）：无国家。最大酋邦 61b/1813p 都城 L2、
>   聚落 14，卡在贡赋池（2/需 18）与存续（16/需 20）——小图人口基数小，贡赋积累慢；
> - **n128**（163842 格，130 tick，人口 1868 万）：**涌现 1 个国家**（127b/11.2 万人口/
>   都城 L3）✓ 机制自然工作；55 个都城中仅 1 个成国——大邦普遍卡贡赋池
>   （前 10 大邦池/需 约 60%）与"成员聚落 ≥2 + 次级中心"（大邦多 1 个聚落）。
> - **判定：参数保持不动**。国家=性质跃迁（稀缺符合早期文明史实）；贡赋池是主要
>   天然瓶颈（官僚成本 0.25 持续消耗），若后续阶段想加速国家化，优先降
>   `StateTributePerCap` 或提高 `TributeRate`，需同步校准 T64/T66 断言。

| 参数 | 初值 | 说明 |
|---|---|---|
| StateCapitalLevel | 2（城镇） | 都城最低等级（都城判定本就放宽一档——首都更易达标） |
| StateSubCenterLevel | 1（村庄） | 次级中心最低等级（决策层级第 2 级） |
| StateTributePerCap | 0.01 | 贡赋池 ≥ 总人口×此值（剩余集中线；0.1→0.01 已随 T64/T66 校准，见提交 c90ca42） |
| StateDwellTicks | 20 | 都城实体存续时长（对应聚落城市阈值 Dwell 20 tick 量级） |
| StateTributeRate | 0.2 | 国家贡赋率（酋邦 0.1 翻倍） |
| StateEliteFrac | 0.25 | 国家官僚/精英比例（酋邦 0.1） |
| StateInternalConflictMult | 0.25 | 国家内部冲突概率倍率（酋邦 0.5；Weber 强制力垄断） |
| 判定 | 同一条件无滞回 | 聚落等级单调 + 存续单调 = 天然弱滞回（4A 对称可逆） |

## 五、范围边界（明确不做）

- **无军事/战争机制**（国家崩溃不靠征服——后续阶段；冲突仍走 ConflictModel 软冲突）；
- **无官僚实体/官职系统**（精英供养比例即"官僚化"代理——不引入新实体）；
- **无法律/文字/度量衡**（科技层后续项）；
- **无硬性规模阈值**（国家=性质跃迁，非体积达标）。
