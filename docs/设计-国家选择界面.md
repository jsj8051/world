- 评估"选谁"需要背景：海拔/河流（农业潜力）+ 矿藏/土壤（资源）+ 政体/等等；

- 选国只读、不随时间推进——图层浏览无副作用。

## 三、界面设计

### 3.1 流程接线

```
主菜单「正式游玩」 → SaveSelectMenu(游玩模式) → ★ NationSelect（本场景：3D 星球 + 图层坞 + 侧栏）
   ├─ 3D 星球：政体四色打底（可切任意图层）——
   │    拖拽旋转 / 滚轮缩放 / 在可点选图层下点击政权 = 选中（高亮+相机转向+侧栏同步）
   ├─ 图层坞（左下，同 MapViewer）：20 层可切；可点选层带"点击可选势力"标记
   ├─ 图例（左，随图层刷新）
   ├─ 右侧栏：🏛 国家置顶列表 + 选中详情卡 + 「▶ 开始游玩」
   └─ 确认 → RequestMapView + RequestPlayerBind + MarkGameplayMap → ChangeScene(MapViewer) 正式形态
主菜单「加载存档」/「查看地图」→ 直进 MapViewer（不经过选国）
```

### 3.2 场景结构

```
NationSelect (Control FullRect, script=NationSelectMenu.cs)
├─ Map (instance: res://scenes/core/MapViewer.tscn)   ← 全屏 3D 底（星球+光照+相机+政体层）
│    选择形态改动（§五）：隐藏 Progress/Epoch/Save/CivPanel；保留 CukDock+LegendPanel；
│    点击走白名单 → 发 TilePicked；SelectionOverlay + LookAtPoint
├─ UiSelect (CanvasLayer)  ← 选国 2D 层
│  ├─ HintBar（顶部中央）："🌍 拖拽旋转 · 滚轮缩放 · 在政体/势力图层点击政权选择 · 月亮副屏无需"
│  ├─ SidePanel（右侧羊皮纸卡 ~360 宽）：
│  │  ├─ HeadRow：⚑ Logo + "选择国家" + CountBadge("政权 N")
│  │  ├─ StatusRow：● 状态点 + 文案（载入中/已载入/切层提示）
│  │  ├─ Scroll → List（🏛 国家分组置顶 / 🌾 其他政权；行=概念徽标+两行文本）
│  │  ├─ DetailCard（选中政权：都城/人口/贡赋/成员/科技/领地/⚔/文化）
│  │  └─ FootRow：← 返回 │ ▶ 开始游玩（未选中 Disabled）
│  └─ Toast
```

### 3.3 交互状态机

```
左键按下：记 (位置, 时间)
  └ 移动(按住)：OrbitalCamera 旋转（既有行为）
左键释放：位移 <8px 且时长 <300ms → 【点击】：
    当前图层 ∈ 白名单 {14,17,18,12} → 拣选 → TilePicked(polityId)
    当前图层 ∉ 白名单           → no-op + 状态行提示 "当前图层为浏览模式——切到 政体/独立势力/势力范围/人口 图层可点击选择"
          位移 ≥8px 或时长 ≥300ms → 【拖动旋转】，不拣选
```

- 点击海洋/无主格 → no-op（不清除选择）。
- 选中跨图层保留：切换图层 → SelectionOverlay 仍画选中政权领地（金网格），政体层下才压暗其余。
- 侧栏行/地图点击双向绑定；相机 LookAtPoint 转向。
- ⚠️ 月份类图层（风场4/月降水10/月温度11）在选国形态无月份滑块 → 用存档默认月份（读档初值/末值），只作浏览示意；不可点选。

### 3.4 高亮渲染（P3 方案 A）

```
SelectionOverlayLayer.cs（Id 20，独立注册，非分类图层）：
  BuildOverlay(ctx, host)：读 ctx.SelectionId → 收集领地格（TilePower==Id 的显示格）
    → 金网格 MeshInstance（半透明亮金，浮高系数略高防 z-fighting——OverlayLiftFactor 惯例）
    选中变更 → 重建覆盖网格（格集合重算，非整层重着色）
PolityLayer（Id 18）增量：ColorOf 读 ctx.SelectionId：
    SelectionId<0 → 现状四色（向后兼容）
    SelectionId≥0 且 powerId==SelectionId → 亮金（饱和度/亮度抬升）
    SelectionId≥0 且 powerId!=SelectionId → 政体色 ×0.55（压暗）
LayerContext 加字段：public int SelectionId = -1;   // 数据通道，选国面板写、策略读
```

### 3.5 状态

| 状态 | 表现 |
|---|---|
| 载入中 | 侧栏呼吸点 + "正在载入文明…"；图层坞/列表空 |
| 载入失败 | 红状态行 + Toast；可返回 |
| 无存活政权 | 空态卡（EmptyPanel 同款） |
| 已选中 | 金网格 + 政体层压暗 + 相机转向 + 详情 + 开始激活 |
| 浏览层点击 | no-op + 状态行提示可点选图层 |

## 四、数据与读取（全复用）

- 读档：MapViewer 既有 Generate() 管线；选国不自读。
- 列表/详情：CivOverlay.Observe → CivSnapshot。
- 点选：TilePower/CellOwner（白名单层同源机制）；聚落层 v1 不点选。
- 高亮：TilePower==SelectionId 的格集合 → SelectionOverlay 金网格。
- 相机转向：选中政权 Cell（顶点 × RadiusKm，MapViewer.cs:918 同款公式）。

### 5.3 MapViewer 选择形态（增量，不动既有路径）
1. `_Ready` 消费标记：隐藏 `ProgressPanel/EpochPanel(+SaveBtn)/CivPanel`；**保留 CukDock + LegendPanel**（图层切换全量可用）；默认层 = 政体18。

3. `SetSelection(int polityId)` → `SelectionId` 更新 → SelectionOverlay 重建 + RequestRecolor()。
4. `NationMapReady` 信号（读档收尾，携带 CivSnapshot）。
5. OrbitalCamera 加公开 `LookAtPoint(Vector3 dir)`（球坐标反解）。
