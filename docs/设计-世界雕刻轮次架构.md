# 设计：世界雕刻轮次架构

## 状态与范围

- 状态：生产生成和地理页面已接入完整雕刻轮，默认在进入地图前完成第 1 轮。
- 目标：以完整世界轮次作为唯一调度/提交单位。轮次号只计完成的雕刻轮，不表示地质时间、墙钟时间或模块局部时间。
- 本阶段包含：显式模块依赖图、事实契约校验、稳定拓扑排序、候选状态传递、取消/失败隔离、原子提交和逻辑测试。
- 本阶段包含：不可变持久地表、板块移动、球面地表搬运、局部构造地形修整，以及同轮气候、水文、陆格生物群系和空间索引。

## 职责

- `IWorldSculptingModule<TWorldState, TModuleOutput>`：独立模块契约，声明稳定模块 ID、直接依赖、读取事实和产出事实，再通过共享轮次数据读写。
- `WorldSculptingRoundData<TWorldState, TModuleOutput>`：每个世界的每轮候选共用一份数据，持有上轮只读快照及本轮输出。模块只读依赖祖先的输出，并写入自身名下的类型化结果。关闭写入后，同一份数据直接交给合并器和发布准备。
- `WorldSculptingPipeline<TWorldState, TModuleOutput>`：按本次启用的模块注册构建依赖图，验证标识/依赖/事实契约并作稳定拓扑排序，为每个模块开启本轮数据读写范围。
- `IWorldSculptingRoundComposer<TWorldState, TModuleOutput>`：领域合并器，聚合全部模块输出，生成完整候选世界状态。
- `WorldSculptingSession<TWorldState, TModuleOutput>`：持有唯一当前状态与完成轮数；准备期间不改当前状态，仅接受基于当前状态、轮号正确且尚未过期的完整结果。
- `WorldSculptingRound`：跨模块轮次身份载体。值从 1 开始；初始世界为第 0 轮。

模块 ID 与事实 ID 使用小写 ASCII 标识（首字符为小写字母，后续可含小写字母、数字、点、短横线和下划线）。模块契约中的事实 ID 用于静态校验；实际领域载荷由模块自行定义的 `TModuleOutput` 类型承载，不用字符串字典承载领域数据。模块输出必须按不可变快照使用。

## 依赖和扩展规则

1. 调用方按世界配置注册启用的模块；编排器不枚举固定模块名单。增加独立模块不需要改编排器。
2. 依赖是同轮内的先后保证。模块必须声明它消费的事实，并声明对相应生产模块的依赖路径。只因 ID 排序而恰好先执行，不算有效依赖。
3. 初始世界已具备的事实由 `initialFacts` 显式注册。其余所需事实必须由唯一已注册的模块产出，且生产模块必须是消费者的依赖祖先。
4. 可选模块通过是否注册启用。其他模块若依赖被省略模块或其事实，管线构造时即报配置错误，不静默跳过。
5. 无依赖关系的模块按 ordinal 模块 ID 排序，以保证同一注册集的执行顺序可复现。依赖本身由拓扑顺序优先。
6. 拒绝空模块 ID、重复模块 ID、重复依赖/事实、未注册依赖、事实多重生产、未提供输入事实和循环依赖。
7. 模块输出使用一个由应用组合根选择的共享类型（可为类型化联合载体）；每个模块只可读取自身依赖闭包中模块的输出。事实 ID 校验依赖声明，但不会反射检查输出对象内部字段；领域输出的形状由类型系统和 composer 负责。

## 固定领域数据流（注册为依赖，不是编排器硬编码）

```text
plate.movement
  → surface.transport
  → terrain
  → climate
  → hydrology
  → biome.classification
  → 可选：vegetation.cover / glacier / weathering / ...
```

上图只是当前世界生成目标下的推荐注册关系。未来可以增加其他领域或支线模块；通过输入事实依赖合流，通过显式模块依赖约束顺序。需要反馈前序阶段的信息保存在轮次状态中，只能在下一轮消费，不能反向修改本轮已完成阶段。

## 数据生命周期约定

| 数据类别 | 生命周期 | 当前落地情况 |
|---|---|---|
| 网格、世界身份、初始布局 | 初始化后持久 | `WorldSculptingState` 保留 Guid、H3 分辨率/半径和稳定板块参考种子 |
| 板块位置与姿态 | 跨轮持久，每轮更新 | `SculptingPlateState` 保存累计姿态、吞并进度和消亡状态，`PlateMovementModule` 接收每轮的世界轴与转角 |
| 板块局部高程 | 跨轮持久，修整和地表交接时更新 | `PlateElevationState` 保存板块参考姿态和局部 H3 高程块，候选轮共享未改动的块 |
| 世界地表快照 | 每轮由板块局部高程重建，供当轮模块及展示消费 | `SculptingSurfaceState` 冻结格序、归属、高度、壳型、省编号/省表、海平面和实际采样姿态 |
| 海陆、海岸与空间派生事实 | 由本轮地表重算 | 复用现有地形事实和空间索引 |
| 气候与水文 | 按本轮地表重算 | 复用现有 Pipeline，逐月数据表达本轮世界的季节差异 |
| 生物群系 | 按本轮环境更新 | `BiomeClassifier` 按现有柯本词表判别陆格，海洋和湖面为空 |
| 模块工作区/中间候选 | 仅本轮有效 | 同一轮的模块共用一个数据对象，合并为完整候选后统一发布，多世界的候选互相隔离 |

## 板块移动与地表规则

- `WorldSculptingStateFactory` 从初始化地表或完整快照复制雕刻状态，并把来源布局定为采样参考姿态。生产开始至少一轮时，只生成初始板块和高度，气候、水文等派生事实在第 1 轮生成。
- 初始陆壳沿种子确定的低阻力区生长，形成大陆尺度的海湾和半岛。大陆边缘的距离场由陆面与大陆架共用，高程衔接后再用海平面判陆海。第 0 轮和首张地图生成时，完全封闭且最深处不超过 400 米的浅海填到最低出口。通海的水域与深盆地保留。
- `SculptingSurfaceState` 校验 H3 ID 唯一且分辨率匹配、各逐格列等长、板块引用合法，并复制外部数组；`WorldSculptingState` 校验世界规格、连续板块 ID 和姿态表一致性。
- `PlateRotation` 表示每轮绕世界坐标单位轴旋转的总弧度，可为负数、零或超过一周。`RotationOps.Compose(after, before)` 先应用 before 再应用 after；模块对世界轴旋转左乘当前姿态并归一化。
- `SculptingCoverage` 把目标格中心及周边探针分别反向旋转到各板块的旧地表，判断覆盖、碰撞和张裂。多个目标格可以复用同一来源格。缺少覆盖且未判为张裂的格子，通过 H3 邻接继承最近的已采样来源。
- `SculptingSurfaceTransportModule` 从主采样格取得归属、壳型和省编号，并按板块的累计姿态从固定的局部高程场采样。省种子随采样移动，失去原种子时取同省的一个幸存格。
- 高程采样在参考格的球面切平面拟合局部坡度和径向曲率，只使用同板块、同壳型、同海陆的邻格。结果限制在这些格子的高程范围内。采样点超出邻域范围或邻格近共线时保留局部来源格高程。
- 地形修整仍在世界网格上计算。轮次合并器将修整产生的高程差按球面格的重叠面积写回局部高程；新生、易主或缺少局部来源的地表按最终高程初始化。修改随候选状态一起提交。纯旋转的地表一轮轮从同一份局部高程读值。
- `SculptingSurfaceGaps` 根据两侧的壳型、高程和张开宽度填补张裂空缺。陆壳张开先保留陆壳并画出裂谷。洋壳张开的部分，以及开度足够且两侧已沉到海下的宽裂谷，才在张裂处铺新洋壳。
- `PlateCollisionRetreat` 先比较上一轮共享边界的相对法向位移，再统计这轮搬运的真实接触。开始吞并需有朝内的边界运动、约 3.5% 的受压板重叠，以及面积至少大 25% 的接收板。位移跨过原先间隔时，前期无共享边界的两块用板块中心接近判断。每轮以当轮碰撞损耗降低剩余领地，搬运中已经消散的格子计入损耗，差额从接触边向内转交并保留高程和壳型。碰撞持续多久取决于板块运动，地表归属耗尽时板块消亡并停止旋转。
- `PlateRift` 每轮检查吞并后的格数。最大活动板块超过全球格数的 26% 时，在主连通区的 H3 格边上搜索连续裂带。搜索使用本轮搬运后的高程，比较按格边长度累计的海拔代价，并验证裂带能把主连通区切成两块。平坦地形倾向近似平分，明显的低谷可以让裂带偏离中部。两块继承原来的地壳和当轮采样姿态，下一轮叠加方向相反的转角并分别搬运。
- `SculptingTerrainModule` 将实际重叠格做局部抬升，并向同板块同壳型的一圈邻格衰减。新洋壳的连续空缺带形成水下脊，邻近陆壳轻微下切。原有相对法向位移和多源 Dijkstra 影响场继续提供较宽的边界地形，最后重算海陆与海岸，修整后的高度进入下一轮。
- 补壳深度和每轮高程改变量沿用初始地表的垂直倍率。边界影响先在生成基准尺度算出，再换算成与持久高程一致的最终米。
- `WorldSculptingGeneration` 是生产组合根，注册模块及事实依赖，冻结配置并合并持久状态和展示快照。默认旋转方案由生成板块的方向和相对幅度给出，每单位幅度每轮旋转 0.10 弧度（约 5.7°），整轮使用该旋转直接搬运。

## 失败、取消与并发

1. 每模块收到同一轮身份及取消令牌。
2. 模块失败、返回空状态或收到取消时，不创建可提交结果；session 的当前状态和完成轮数不变。
3. 计算结果可能在后台准备。提交时校验结果来源仍与当前状态为同一对象，且轮号正好是下一轮，防止过期结果覆盖新世界。
4. `WorldSculptingPlayback` 每次只在后台准备一轮，到调用线程校验来源并提交。播放速率决定启动频率，跳转逐轮计算并发布到目标轮号。

## 与现有实现的关系

- `WorldFacts` 继续作为展示/查询/导出的完整派生快照，不直接作为雕刻模块的持久可变工作区。
- 配置页通过 `WorldGenerationFlow.CreateProduction` 进入后台生成。直接启动地理页和重新生成也调用 `WorldGenerationJob`。任务从初始地表完成至少一轮，加载页读取实际开始的模块，随后 `WorldSession` 接管同一雕刻会话。
- 旧静态生成和地质时间演化由测试工程的 `LegacyWorldGeneration` 与 `LegacyEvolutionPlayback` 显式调用，作为回归和效果对照。初始板块、地表、气候和水文领域算法继续由生产雕刻按需复用。
- `.wmap` 保存完成时的地图快照。从地图包读取时，群系随已有温度、降水、水文事实恢复。轮次、板块累计姿态和板块局部高程仅保存在正在雕刻的会话中。

## 验收

- 任意非空模块集可注册；模块 ID 不需在编排器中预先声明。
- 同一模块集不受注册输入顺序影响，拓扑顺序确定；新增独立模块只需注册和声明依赖。
- 重复 ID/依赖/事实、缺失模块依赖、未提供事实、依赖循环、事实重复产出及未声明生产者依赖均会在管线构造时失败。
- 所有模块共享同一轮次号；成功候选提交后更新状态与轮号；同一候选不可重复提交。
- 模块异常、取消或过期候选不能改变已提交状态。
- 真实雕刻状态复制并校验网格/逐格列；零角、负角和超整圈旋转正确，姿态跨已提交轮次累积且不依赖旧物理时钟。
- 完整轮用同一地表重建地形、气候、水文和生物群系。发布后，下一轮从上轮修整过的高程继续。
- 吞并随每轮碰撞损耗推进，同一板块在不同碰撞强度下可经历不同轮数。测试覆盖缺少收拢或当轮碰撞时的暂停、消亡时地貌转交，以及超大板块裂解后两个碎片下轮分开并搬运格子。
- 生产跳转按轮号依序发布，保存与再次读取地图时得到相同的群系分类。
- 编译和 `World.Tests.Local` 逻辑测试通过。
