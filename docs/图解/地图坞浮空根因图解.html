🧭 地图坞为什么"浮在空中"

2026-08-31 排查：CenterBottom 锚点下 offset_bottom 符号错了（设计文档公式抄错，代码照搬）

❌ 修复前（你看到的）

屏幕下部（视口 H）
█ 地图
分类按钮行
图层按钮行
面板完整露在屏幕内，悬在底部上方——"浮在空中"
offset_top = -30（面板顶在 H-30）
offset_bottom = -(h-30) = -127（面板底在 H-127）
→ rect 高度为负，被最小尺寸撑开 → 面板浮起 88px

✅ 修复后（埋进地里）

屏幕下部（视口 H）
█ 地图
分类按钮行
图层按钮行
（屏幕外）
面板主体沉到屏幕外，只露 30px 标题条「地图」
offset_top = -30（面板顶在 H-30，贴底）
offset_bottom = +(h-30) = +127（面板底在 H+127，屏幕外）
→ 屏幕内仅露标题条，hover 时向上滑出全貌
原理：CenterBottom 锚（anchor_top = anchor_bottom = 1.0）下，rect.top = 屏高 + offset_top、rect.bottom = 屏高 + offset_bottom。 "埋进地里"= 面板底部要沉到屏幕下方（屏高之外）→ offset_bottom 必须是正号。旧公式写 offset_bottom = -(高-30)（负号），把面板底算到了屏高上方，rect 倒置 → 布局引擎按最小尺寸 把它撑成 88px 高的浮空条。
