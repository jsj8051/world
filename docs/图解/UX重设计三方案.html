C · 圣典（Codex）

把整个界面做成一本摊开的典籍

  • 顶部纹章标题栏：世界纹章 + 圣典名 + 纪元刻记；
  • 左右书页：左页=图层卷轴+图例（卷 一），右页=观测百科（卷 二·总览/政权/国家/科技/史录）；
  • 页角卷曲、书脊、羊皮纸质感——中世纪语汇做到位；
  • 纪年命名：tick→"刻"、年→"纪"、事件→"史录"、"读档→开卷"、按钮→"宣"——全套动作改词；
  • 星球居中留最大呼吸空间，两侧书页可合拢（翻页动画收纳）。
✓ 风格最极致、独一无二（"游戏气质"最强）· 信息两侧对称
✗ 开发量最大（书页动画/卷曲细节/叙事词条系统）· 右侧百科信息密度受书页宽限制

全流程信息架构（三方案共用主干，差异在运行视图）

① 启卷（主菜单）纹章标题 · 创建世界 / 进入世界
→
② 造世（生成）星球参数 + 文明演化 分章表单，一步预览
→
③ 卷册（存档）列表 = 卷册目录：含文明/纯自然/损坏 徽记
→
④ 观史（运行）星球 + 图层 + 观测五页 + 事件时间线
→
⑤ 详读（点选）点政权/国家/聚落 → 详情卡（边远信息）
我的推荐：A（地图集）为主干，吸收 C 的语汇。理由：① 信息架构最完整——图层/图例/观测/时间各归其位，与现有 CivPanel 代码结构零冲突（右观测卡=现面板，左书卷=现有底部工具栏重排）；② 开发量可控（无书页动画/叙事词条系统）；③ 中世纪气质通过"卷/金条/徽记"完成而非重叙事词汇——避免给用户生造理解成本。C 的纹章/纪年命名可作 A 的装饰层逐步渗透。B 留作"极简偏好"备选。
