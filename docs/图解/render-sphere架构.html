派生层 · 新增 渲染细分球体 RenderSphere（n′ = 2n = 128，163,842 顶点）

几何
  • Icosahedron.Subdivide(2n) 单位方向顶点
  • 嵌套性质：2n 细分 ⊇ n 细分（同 12 基础顶点，偶数坐标精确重合）→ 粗顶点在细球上有精确对应
归属 + 插值场
  • 每细顶点 → 最近模拟顶点 id（桶索引，~O(270)）
  • 细海拔 = Shepard cos⁴ 插值（连续场，探针友好）
  • 细格距 ≈ 99 km → 渲染分辨率翻倍
✕ 禁止：在细球体上重算水文（ComputeFlow/ComputeWater）——会产出与存档/CivSim 平行的第二套河网，位置/流量与逻辑层脱节。RenderSphere 只做几何 + 插值派生，不产生任何新语义事实。
