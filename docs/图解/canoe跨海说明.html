独木舟（canoe）科技的「跨海」效果

数据行：canoe,独木舟,coast,0.01,100,0.02,fire,unlock_sea:1 —— 沿海发明（coast），依赖火（烧凿成舟），效果 unlock_sea:1 → TechDef.UnlockSea

本质：把「海」从一堵墙，变成一条低成本的路

全模拟里地形障碍不是「二值墙」而是成本梯度（TerrainCost，0 = 不可穿；火/皮毛解锁冰原、独木舟解锁海洋）。海洋格：

状态TerrainCost(海)含义
无独木舟0海 = 绝对墙：BorderCost=0，一切跨格流动在此切断
有独木舟0.3海可穿，成本与沙漠同级（0.3），代价随跳数相乘衰减

🚫 无独木舟——海是墙

✅ 有独木舟——海是「0.3 的低成本路」

「跨海」生效在哪四条机制上（全部走 BorderCost）

机制代码有 canoe 后的变化
迁徙 / 殖民SplitMigrateModel.PickMigrateTargetBFS 能跳岛殖民对岸（T76 测试：canoe 渡海 vs 无 canoe 阻挡）
科技传播SpreadModel文化知识能跨海峡传向邻岛（波利尼西亚式逐岛扩散）
文化转移CultureModel主导文化能跨海同化对岸
宗教传播ReligionModel信仰能渡海传教

边界语义（跨海 ≠ 远洋）

  • 海只是「经过」，不是「定居」：BFS 目标要求 R>0（可居格）——海格/冰盖永远不会成为殖民地。
  • 航程有限：BFS 限 ColonizeRadius = 6 跳；且每过一海格成本相乘（0.3 → 0.09 → 0.027），距离越远得分越低 → 涌现出沿岸 / 岛链跳跃（史实：波利尼西亚逐岛、大洋洲殖民需 canoe），不会出现横渡大洋。
  • 与后世 sail 是两层：canoe = 石器时代人口迁徙/扩散的跨海通行权；古典时代的 sail 解锁的是「商路通道 / 跨海贸易」（阶段6设计）——流动的是货物与商路，不是人。
设计出处：2026-08-19 用户拍板「波前推进 + 跨海合理」——跨海只做通行权放开，殖民仍受 6 跳航程与肥度偏好约束；无 canoe 时海 cost=0 不可穿，保证大陆板块的文化独立演化。
