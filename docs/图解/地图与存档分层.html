🗺️ 地图 ≠ 💾 存档 —— 两层分家

2026-08-25 用户拍板：演化跑出来的是地图；只有游玩产生的才叫存档。开新档可选不同地图。

🗺️ 地图 只读素材

自然地图user://maps/*.mpa板块/气候/河流——世界本体
演化产物user://maps/*.cmp文明/国家演化完成的世界
🎯 创建世界 = 产出地图。地图是素材池——每次开新存档都能挑一张不同的。

💾 存档 可读写进程

游戏存档user://saves/*.sav选定的地图 + 游玩进程
内容世界快照 + 玩家状态 + 来源地图引用国库/稳定度/君主/命令…
🎯 存档 = 你选定一张地图后开始的那局游戏。保存 → 可以接着玩；加载 → 恢复那局。

三种流程

📂 正式游玩（开新档）
选地图（maps/ 任一张）→ 进图选国家 → 开始→💾 保存
写 saves/*.sav→🕹️ 继续玩
随时再保存
📂 加载存档（接续）
选 .sav → 恢复到上次保存的 tick → 继续
🗺️ 查看地图
只浏览 maps/，不产生存档（纯观赏/观察层）

主界面四个入口

🛠 创建世界 🗺 查看地图 ⚔ 正式游玩 （新档：选地图） 📂 加载存档 （选 .sav 接续）
🔧 实现要点：.sav 复用现有段表容器（magic SAV1）——世界快照段与 .cmp 同布局 + REFS 段记录来源地图（路径/seed/开始 tick）。读档 = 恢复到保存时的世界（无需重放）。
