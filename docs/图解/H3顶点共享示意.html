CellToVertexes：一个格子的顶点（全局共享 id）

传进 1 个格子索引，返回这个格子自己的边界顶点 id —— 但这些 id 全星球唯一、相邻格共用

两个相邻格子的真实关系

调用CellToVertexes(A) → 返回 A 的 6 个顶点 id
CellToVertexes(B) → 返回 B 的 6 个顶点 id（五边形只给 5 个）
关键共边的两个格子在返回里拿到 同一对 id（v4、v5）——不是两份拷贝。6 + 6 去重后 = 10 个唯一顶点，不是 12
为什么顶点 id 是"格子的图结构"里的真顶点：每条边的两端被相邻格共享。H3 v4 特意暴露这种共享 id —— 渲染时相邻格拼同一批顶点 → 无缝无裂缝，且顶点数组省 3 倍内存

它是 / 它不是

✓ 是「给我某一个格子，还你它自己的边界顶点 id」的单格函数，输入输出都是 64 位索引
✗ 不是没有任何「一次调用返回全星球所有顶点」的 API —— 全图顶点表必须你自己遍历所有格 + HashSet 去重收集（就是两遍构建的第一遍）
收集完的唯一 id 集，就是整张网格的顶点表。之后对每个唯一 id 调一次 VertexToLatLng（4,033,680 次而非 12M 次），转成经纬度 → ECEF × R = 球面位置。
