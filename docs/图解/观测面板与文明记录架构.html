四层各司其职 · 两层可读性先行 · 只读事实，永不穿透

壹四层三明治（单向依赖，永不反向）

呈现层 面板 UI MapViewer UiLayer + CivPanel 场景：总览 / 政权 / 国家 / 科技（未来+事件）页签，中世纪主题，图标现成
▼ 只读投影 DTO（CivSnapshot）
投影层 Snapshot CivOverlay.Observe(ctx) 纯函数——所有字段读取集中一个文件；加字段=Observe 一处+面板一行，UI 零改动，编译器护航
▼ 只读 Context（模拟永不知 UI 存在）
模拟层 CivSim Context / 实体 / 机制——零 UI 引用；新机制不改任何 UI 代码
记录层 CivEvents 模型关键时刻 append 一条记录（旁路只写）：不读、不参与分支、不产生 Rng——开/关事件系统，演化结果逐比特不变
铁律：模拟只负责事实 → 投影只负责搬运 → UI 只负责呈现 → 事件只负责说"发生了"。任何一层修改不穿透其他层。
