地形"带宽"是什么

对应设计文档 设计-new_HexWorld-地壳运动-02 §5/§8；实现 = LandformGenerator.cs L34–59（参数）与 PlateBoundary.cs 的距离场 BFS（深度上限 = 带宽 ÷ 格宽）。
一句话：板块边界是一条线，运动造出的地形是一条带；带宽 = 这条带从边界向外铺开、到幅度归零为止的距离。

① 带 = 边界两侧的影响区；带宽 = 它垂直边界伸多远定义

关键：带宽是"垂直边界的距离"，不是沿边界的长度。沿边界方向不需要宽度参数——它由"哪些边被分类成这个类型"决定（02 §3 逐边分类：41,713 条异板共享边里，汇聚 42.2% / 离散 42.3% / 转换 15.5%）。所以"带有多长"是分类的产物，"带有多宽"才是参数。

② 带宽内不是一个方块，是"半余弦"衰减——带宽控坡度，峰值控幅度形状

公式（02 §5.2，所有要素共用同一个形状函数）：Δt(d) = 峰值 · 0.5·(1 + cos(π·min(d/W, 1)))。
所以：峰值决定"抬多高"（OrogenThickenMaxM = 25 km），带宽决定"从峰值降到 0 用多长距离"（OrogenHalfWidthBaseKm = 600 km）。两者正交——改带宽不改峰值，只改地形陡缓。这就是为什么"把带宽缩到 0.60"会让剖面变陡（同级峰值挤进 720 km 而不是 1200 km）。

③ 海沟/火山弧：带宽是"半宽"，弧还多一个"偏移"（峰值不在边界上）不对称

所以参数表里"带宽"一项对不同要素含义并不完全一样：造山 / 裂谷 / 被动陆缘是半宽（峰值贴边界、两侧对称）；海沟是半宽（峰值贴边界、只往外海一侧衰减）；火山弧是"偏移 + 半宽"两个数——偏移把峰值从边界推到 120 km 外（弧离沟 100–300 km 是地球实测），半宽决定这条弧带自身多宽。图上能看到弧峰的横坐标明显不在红线上。

④ 同一个带，两种分辨率：带宽 ÷ 格宽 = 剖面能被取几个采样点离散化

这是"海拔看起来离散、不连续"的直接来源：带宽是连续量，网格是离散量，带内幅度只能在格心取值。
res3 下造山带宽 360 km ÷ 111 km = 3.2 格 → 整条带只剩 4 个采样点，走 100% → 78% → 32% → 1% → 0；乘上造山峰值 Δh=4545 m，就是 +4545 / +3560 / +1460 / +66 m，相邻格跳 1.0 / 2.1 km——肉眼必然读成"等值块"。res5 下同样的带分到 23 格，相邻格差最大 315 m，就读成连续的了。
⚠️ 更极端：带形全宽 < 格宽时，该要素在网格上完全消失——弧带全宽 420 km 撞上 res2 的 294 km 格宽，带体落在格与格之间，弧岩浆什么都生不出。故形态判读与断言一律 res3 起（02 §7）。

为什么要有"×0.60"这一列：基准列是地球尺度（知识库抄来的），但本世界的板块平均边界间距只有 ~1,235 km（地球 ~2,040 km）——实测边界总长 41.3 万 km 是地球 25 万 km 的 1.65 倍。不缩就会互相叠置：实测 16.4% 的格同时落进 ≥2 条带，最厚的格叠出 87 km 壳厚。缩到 0.60 后叠置降到 11.2%。
⚠️ 注意 res3 那一列：海沟带只剩 1.4 格——在 res3 上"海沟"几乎就表现为"边界那一格变深 2.5 km"，槽形（缓外坡 / 陡内坡）根本画不出来。这不是 bug，是"带形全宽 ≥ 2 格"这条分辨率纪律的具体体现（入口 §4）。
