静态板块运动 → 地形：几何、剖面与流水线

设计依据：docs/设计-new_HexWorld-地壳运动-02-板块运动与地形要素生成.md（v1 草案）
运动只抽一次（欧拉极 Ω），只用来分类边界与定幅度；没有时间步进、没有格在动。

① 符号约定：vn 的正负就是"汇聚 / 离散"最易写错

为什么只看相对速度：给所有板同时叠加一个共同旋转，所有相对速度逐位不变——所以 Ω 的绝对基准是任意的，地形只允许依赖 Ω_p − Ω_q。这是严格等价，不是近似。
两遍分类：第一遍只算 vn 定"汇聚/离散/转换"；离散边的洋侧格即脊轴 → BFS 出洋壳年龄；第二遍才用年龄判"洋-洋汇聚谁下插"（老壳下插）——这样避免"要年龄就得先分类，要分类就得先有年龄"的循环。

② 洋底深度 = 离脊距离 ÷ 扩张速率（= 相对速度）→ 年龄 → 热沉降"运动塑造地形"最直接处

公式：Age = 2 · d_ridge / vOpen（半扩张速率 = vOpen/2）→ Elevation = −(2500 + 350·√Age)（Parsons & Sclater 半空间冷却）。
同一个公式全域生效：洋中脊"自然浮起"、深海平原"自然变深"都不需要生成器去写剖面——扩张速率直接来自该边界边的相对法向速度。Mafic 厚度不动（热沉降是热状态效应，不是壳厚效应）。

③ 汇聚边界的两种剖面（全部是"基准 + Σ 增量"，累加、无覆盖）写场规则

两种机制的写场差别（这是纪律修订的核心）：
造山带 / 弧 = 写地壳厚度（FelsicThick += Δt），海拔由 Δh = Δt · kAiry 增量导出（kAiry = 1 − 2700/3300 ≈ 0.182）；弧岩浆是地幔→地壳的净输入，上盘是洋壳时 felsic 从 0 增到 30 km，岛弧出露由此自然发生（`IsLand` = 长英质厚 > 0，不写特判）。
海沟 = 只写海拔（挠曲是几何下弯，不是壳减薄——纯 Airy 到不了 -9 km，知识库已论证）。
弧能否出水取决于该处洋底基准深度：近脊处（-2500）弧峰到 +3 km 会出露成岛，老洋底处（-6500）弧峰只剩 -1 km 不出露——物理上诚实，不是 bug。

④ 离散边界陆侧：裂谷（减薄 → Airy 下沉）+ 肩部（热穹窿/回弹 → 纯海拔）两种机制并列
无肩部（被动边缘已冷却）。
