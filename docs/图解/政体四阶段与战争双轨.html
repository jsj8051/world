政体四阶段 · 战争双轨

band / tribe / chiefdom / state —— 一个实体，四个发育阶段；战争，两条并行轨道

壹它们是不是一个东西？—— 是同一个东西的四个成长阶段

游戏里所有"人"都是同一个实体类型：Polity（政治实体）。band / 部落 / 酋邦 / 国家不是四种东西， 而是同一个实体活到不同阶段的姿态——每升一级，身上多叠一组机制（机制像图层一样往上盖，新层包含旧层）。

游群band▲
起点——旧石器狩猎采集，一人一格的游动小群
起源播种采集狩猎能量核算人口增长 分裂迁徙文化互动宗教（万物有灵）物物交换 边境冲突①影响力场
部落tribe▲
= band + 农业定居：开始种地、占地、发明
农田开垦领地凝聚生产方式（猎↔农） 科技发明科技传播聚落实体 …band 全部机制
酋邦chiefdom▲
= tribe + 酋长整合：声望、贡赋、吞并小部落
声望/贡赋/精英供养酋邦凝聚（庇护）吞并吸收 内部冲突 ×0.5（酋长仲裁） …tribe 全部机制
国家state◆
= chiefdom + 制度化：都城、税制、官僚——以及唯一的战争权
国家涌现（都城+贡赋池+存续）税制化 ×2官僚供养 ×2.5 国家战争②（仅国家可宣战）内部冲突 ×0.25（强制力垄断） …chiefdom 全部机制
※ 概念 = 机制包（配方），实体 = 一个活着的 Polity（有格子、人口、科技树、文化）。概念轴与实体轴是两个轴，不要压扁。

贰战争其实是两条轨——所以"国家对 band 用武"要分情况

轨道① 边境冲突

全层级都有的格级械斗 —— band 也会打架
  • 抢的是格子控制权（一格的归属），不是灭国
  • 触发：僵持窗口 + 饿/人口超载（生存压力才打）
  • 胜率 = 人口 × 军事科技 对比，弱方也可能爆冷
  • 结果：损耗 + 掠夺格 + 败者被驱逐迁徙
  • 酋邦内部 ×0.5、国家内部 ×0.25（有秩序）
⚠ 国家对 band 用武，走的是这条轨

轨道② 国家战争

国家专属的外交状态 —— band 不够格上牌桌
  • 宣战主体：只有国家（WarPolicies 查表，策略多态）
  • 目标筛选：只在国家两两之间配对，band 不在集合里
  • 动机门：领土野心 / 资源压力 / 军事优势 / 世仇
  • 会战：军力 × 士气骰子 × 真实天气（严寒/雨季阻进攻）
  • 结算：碾压→吞并（效忠+流放）／险胜→朝贡／超时→停战
⚠ 永不宣战 band —— 宣战对象只能是国家

叁"国家对 band 用武"的真实场景

一句话总结：band / 部落 / 酋邦 / 国家是同一个 Polity 实体的四个发育阶段（机制逐层叠加）； 战争有两条轨——格级边境冲突人人会打（国家对 band 用武 = 边境清剿，单向碾压：夺格 → 饿 → 驱逐）， 国家战争是国家牌桌上的外交状态（band 不够格被宣战）。国家出现的那一刻，band 就从"主角"变成了"被清剿的对象"—— 这正是"国家时代"的开始。
