## 二、单步流程

```text
Transport（旋转 + 裁剪到目标格）
  → ResolveAndFill（同格重叠：洋壳俯冲入池 / 陆壳增厚；张裂空位补新洋壳）
  → Dominant + Boundary（主导板块、壳型、逐边物理运动）
  → ApplyTectonics（俯冲弧/洋中脊火山、海沟/裂谷地形松弛）
  → Projection（高程、海底年龄、覆盖率）
  → Budget（地壳/池分账） + Frame.Validate
  → 提交时钟、姿态、材料、库存、帧
```

关键口径：

- **搬运**：每片绕本板块欧拉矢量旋转 `|ω|·Δt`；裁剪到源格及 3 环邻格，面积由交集保持。
- **重叠**：洋—洋取更老者俯冲；洋—陆取洋壳俯冲；陆—陆体积并入上盘厚度。被消去体积全额入池或增厚。
- **退化差集**：若差集产生自交碎片，整片移除并按全量体积记账，避免非法几何进入下一步。
- **张裂**：每格未覆盖面积由池释放新洋壳补足，出生时间 = 当前时间，年龄从 0 开始。
- **火山**：俯冲上盘与洋中脊按速率从池取料，增加壳厚与火山地形；库存不足则整步失败。
- **地形**：海沟/裂谷按 `1 − exp(−Δt/τ)` 向目标负地形松弛。
- **高程**：参考高程 + 壳厚均衡增量 + 相对参考年龄的冷却沉降 + 构造/火山地形。
- **账本**：本步与累计分别校验地壳、库存、总量残差，不允许互相抵消。

## 五、偏离与限制

1. **未接入场景**：播放循环、渲染刷新、UI 面板与逐帧 Tick 留到第 6 步；`EvolutionSimulation` 目前是纯逻辑入口。
2. **未接入 `WorldFacts`**：零步从逐格数组装配，而不是从 `WorldFacts` 取数；第 6 步接场景时统一。
3. **不支持向后跳转**：`SeekToStep` 只向前；从零重演与快照回放未实现。
4. **无运行时存档**：帧不可序列化恢复，符合第 3 步约定。
5. **裂谷伸展应变未使用**：`RiftBreakupStrain` 暂未驱动减薄/破裂，张裂直接由几何空隙补壳体现。
6. **碰撞地形只靠增厚**：没有独立的碰撞隆起尺度参数，避免在第 3 步模型外新增字段。
7. **热点未实现**：需求允许“俯冲、裂谷或热点”之一，本版覆盖前两者。
8. **几何兜底有近似**：差集退化时整片移除下盘，体积全额记账；可能把少量非重叠材料也移走，由补壳恢复覆盖。
9. **性能未实测**：3 环裁剪与逐格多边形计算在 res4 生产尺度上的耗时未知；测试只覆盖 80 格合成球。
10. **生产 H3 路径未跑通测试**：`EvolutionGrid.FromBall` 已实现，但测试用合成二十面体球，未在 H3 原生库上跑演化。
