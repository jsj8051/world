# 共用地图查看器

## 已批准范围

采用共用查看器、阶段组合内容的方案。世界阶段依次为地理 → 文明 → 游玩；阶段不等同于地图显示模式。当前仅迁移已有地理演化页和地图浏览页，不实现文明、游玩、阶段转换或存档迁移。

## 职责、数据和交互

- `MapViewer` 场景组合 `WorldPresentation`、地图模式坞和选择详情卡，负责显示、交互门禁及界面绑定。
- `MapViewerContent` 提供世界事实源、模式列表、独立图层实例及选择详情生成函数。列表注册被复制，世界数据仍由外部会话拥有。
- `GeographyMapViewerContent` 装配现有地理模式、自然图层和地理详情；地壳模式判断留在地理装配，不进入共用查看器或详情卡。
- `MapSelectionPresenter` 订阅选择与模式变化，调用外部详情函数。详情卡仅显示摘要、详情和可展开文本。
- 页面仍拥有世界推进、加载进度编排、保存、图片导出和导航。世界发布新帧后沿原链路重烘并刷新选择。

## 所有权与生命周期

1. 页面实例化共用查看器，进入场景树后调用一次 `Configure`；重复配置明确报错，不支持原地换世界或热切阶段。
2. 内容工厂每次创建独立图层。注册到 `WorldView` 后，节点图层随子树销毁，非节点可释放图层由 `WorldView` 释放。装配失败时查看器释放尚未接管的图层；内容仅供一个查看器使用。
3. `SetActive(false)` 隐藏画面和面板并禁止相机/拾取，不解除绑定；构建和重烘门禁继续由底层控制。
4. `ReleaseBindings` 解除详情和模式坞绑定，可重复调用；释放后不可激活。节点与图层仍随页面子树销毁。
5. 后续阶段通过各自内容工厂提供模式、图层及详情，不向查看器加入阶段分支。涉及城市/单位选择和操作工具时再扩展对应契约，不提前模拟未有业务。

## 验收与限制

- V1：两个现有页面使用同一个查看器场景；Godot 浏览加载与地理演化检查验证。
- V2：地图模式、自然图层、地理详情、选中后重烘刷新保持；逻辑格式化测试和地理演化检查验证。
- V3：注入自定义详情、取消选择、模式刷新、释放后解绑；本地逻辑测试验证。
- V4：无自然图层的组合可运行，隐藏/释放门禁及失败资源清理正确；`WorldPresentationCheck` 验证。
- V5：存档和导出保持原有路径与格式；现有持久化、导出逻辑测试验证。

当前世界读取与拾取仍基于 `IWorldFactsSource` / `PickedCell`，不宣称已支持城市、单位、战争迷雾等后续业务。地图查看器不是世界阶段状态机。
