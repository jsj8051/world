## §0 两个参考源与可借鉴点清单

### 0.1 Mindwerks/plate-tectonics（platec，C++，LGPL）

2D 环面高度图上的板块模拟库（WorldEngine 底层）。对本项目**可借鉴的机制级思想**：

| # | 借鉴点 | platec 出处 | 对应我们的缺口 |
|---|---|---|---|
| P1 | **大陆分段（segments）**：一板可载多个大陆连通域；聚合时只搬运**被撞的那个分段**，不是整板合并 | `segment_creator.cpp` span-flood-fill 惰性创建 + `plate.aggregateCrust` | 03 §9 缝合空实现：合并粒度没定 |
| P2 | **聚合判据**：碰撞面积比 ≥ `aggr_overlap_rel`(0.33) 触发（碰撞次数阈值形同虚设） | `updateCollisions` | 缝合触发口径没定 |
| P3 | **俯冲增生的内陆偏移**：沉积/火山物质落在接收板**内陆**（俯冲方向 × 若干格 + 随机偏移）= 岛弧火山 | `addCrustBySubduction` | 增生楔只记账不落地（03 §7） |
| P4 | **场保留式重启**：能量死亡判据触发 → 全部重分板，**物质场保留**（大陆地壳跨旋回存活） | `restart()` + 能量比判据 | 03 §10 裂解空实现 + 无全局兜底 |
| P5 | 新洋壳年龄-浮力衰减（洋中脊地形） | `lithosphere.cpp` virginity buoyancy | 已有等价物（`MaficDensityAtAge` + 热沉降律），不搬 |

**不搬**：2D 环面、随机初速+摩擦的速度模型（我们有更对的力平衡）、局部窗口内存布局、
非线程安全的全局态。

## §5 批次 2 —— 动力学补强（03 §3.6 的 R 项与力项补全）

力平衡框架不变（v = F·δ/(η·A)，η 真值），净力改为：

```
F_net(p) = F_板缘负浮力(非顶死) + F_板片账户(p) + F_洋脊推力(p) − R_造山负载(p)
R(p)     = μ_orogen × F_幻影(p)          ← 顶死段接触阻力（幻影力 ∝ 造山带厚度增长 ⇒ 自限）
F_板片(p) = κ_slab × g × |slabDir(p)|    ← 账户方向 = 俯冲发生时的边界法线（质量加权累计）
F_洋脊(p) = κ_ridge × sqrt(平均洋龄/80My) × 洋格数(p)
账户      : 平流 Pass C 俯冲裁决时入账（mafic 质量 × 法线方向），每步 ×(1 − StepMy/记忆My)，
            上限 = SlabCapFraction × 板质量
```

- 账户钩子现成：`H3DynamicTectonics.cs:213` 已在每步读 `RecycledToMantleMass`（只记了账）。
- **判读口**：每板力分解表（板缘/板片/洋脊/阻力/净力）+ 板速 cm/yr，进 `HexDynamicDiag`。
- 验收：板速分布进入 1–10 cm/yr 观测带量级；幻影占比下降（顶死段开始真实做负功）。
- 不做冻结标定（§2 决策 1）；若量测后仍偏低，另立判读批次再议。

## §7 批次 4 —— 缝合 / 裂解 / 重启循环 / 大陆生长

1. **逐对接触度量**（缝合与重启的共用输入）：`MeasurePlateTopology` 单遍顺带累计
   逐板边界边数与逐板对共享边数（每边两侧各记一次，比例口径一致）。
2. **缝合（segments 粒度，P1+P2）**：板对共享边占比 ≥ `SutureContactFraction`(默认 1/3，
   platec `aggr_overlap_rel` 口径) 持续 ≥ `SutureStreakSteps`(5) 步 → **只把小板侧实际接触
   该边界的连通分量**改判给大板（惰性 BFS 分段，无持久分段表——platec 惰性创建的精髓）；
   物质不动，只改 `PlateId`；板片账户按搬移格数比例划转。
3. **局部裂解**：最大板占比 > `SupercontinentFraction`(0.25) 且（全局板均速 < 失速阈值 或
   占比 > 0.35 硬顶）→ 对该板做**继承式三分**（远点采样种子 + 板内 Voronoi），物质不动；
   冷却 `SplitCooldownSteps`(10) 步防振荡。
4. **全局重启循环（§2 决策 5 新增）**：全球板均速 < `RestartStallSpeed` 持续
   `RestartStallSteps`(8) 步，或最大板占比 > `RestartSupercontinentFraction`(0.5) 持续同长
   → **全部重分板**（复用 `H3Plate.SplitIntoPlates`，seed 派生自 restart 计数），物质场保留，
   板级状态（账户/相位）复位；`RestartCount` 记账进判读口。
5. **增生楔落地（P3）**：`ApplyThicknessCapToAccretion` 缩掉的溢流质量不再只记账——
   按 felsic 85/15 落到本板顶死接触格（造山前缘），`AccretionDepositedLastStep` 对账。
6. **大陆生长（T6）**：批次 3 弧物质含 felsic ⇒ `IsLand` 转 true ⇒ 陆壳可生长；
   `LandFractionLastStep` 已有，全程陆占比演化进判读。
7. 验收：600 My 内板数有降有升（缝合/裂解/重启都有发生）；终态守恒对账仍绿；
   golden 结构带仍绿。

### §11.2 实施中修掉的 **6 个真实 bug**（全部由新护栏或量测口暴露）

1. **平流链式补位成死代码**（Pass C 的 `else` 缺 `_movés[t]` 门控）——链中格被原地结算 ⇒ 队列/环传播永不执行、`同板多源` 恒 0、**造山堆厚结构性不可能**（v1.7 引入的回归，量测口一直挂着"同板多源=0"信号没人盯）。
2. **双记账**：俯冲目标自身移走、唯一落位 = 埋入层时，mafic 既保留在场上又记了"回地幔"（质量凭空消失，量子 = 一个新洋壳格）。
3. **孤儿格**：顶层裁决全埋入时 `PlateId=-1` 而 mass>0 ⇒ 下步平流当无料跳过 + 写出跳过 ⇒ 双缓冲乒乓复活陈旧质量（账面失守 4×；修法：无条件清写 + 全埋入格整柱保留）。
4. **顶层裁决丢账**：被后来更轻者顶替的**前胜者** mafic 既没写出也没记消减（三源混合链每步蒸发格级质量）。
5. **生命周期每步跑两遍**（`CycleStep()` 重复调用）——判读口被第二步复位。
6. **厚度帽份额算术错**：`85:15` 被当成"felsic 占总质量 85%"（实际只落 85% 场质量）⇒ 每次帽活动蒸发 15%；修正为"深成:火山 = 85:15、全额落场"。
   （另有增生楔单格瞬时堆积导致位移尖峰 124 km —— 加余量帽后 max 4.2 km。）

**方法论收获**：这 6 个里有 4 个是**质量守恒审计口**逐个逼出来的。批次 0 那一句"把 03 §3.2 的口头要求落成断言"，是本轮性价比最高的一步——没有它，这些账目误差会伪装成"地形看起来怪"。

### §11.3 遗留判读项（不做"算完成"判定，供后续批次）

- **均速偏低**：全球均速 0.49–0.54 cm/yr，低于 1–10 cm/yr 观测带中值（单板多数 0.6–2.2 cm/yr 在带内）。
  力项系数（`SlabPullWeightFraction`/`RidgePushStressPa`）已是物理量级且**未做标定**（按 §2 决策 1）。
  若要入带中值：下一轮按量测把两系数上调 2–3 倍即可，是标定不是结构问题。
- **增生楔落地率低**：前缘格常已达 70 km 厚度上限 ⇒ 余量帽拒收（实测堆回 4.1e8 / 缩掉 3.09e10）。
  物理上"前缘已到上限"是自洽的；要更像造山带需提高上限或让山脉向陆内扩散（另立项）。
- **边界类型占比**：汇聚仍偏高（02 §14.2-13 的老账，与 Ω 抽取分布有关）。
- **`空洞` 遥测**已修正（曾把未实际填充的格计入 `filled`）；`无主格=0` 是权威口径。
- 换色事件 `ChangeEvents` 每步 Clear（诊断用），若要做"行星史"需改为可选累积。

## §12 参考方案评估：MPM 式"多边形局部场 + 重采样到固定网格"

> 用户在实施期间提出的替代方案（局部坐标系 + 局部数据场 + 逆变换采样回全局网格 + 空洞检测/修复 + 主动覆盖约束）。
> 结论：**思想与我们的架构同源，但"重采样"这一步会毁掉已拍板的守恒口径；其中 4 条子机制值得吸收为局部解。**
> 逐条对照见下（"我们已有"= 现有实现；"可借鉴"= 真能改进的点）。

### §12.1 结构对照

| 用户方案的环节 | 我们的对应物 | 结论 |
|---|---|---|
| 多边形 = 拉格朗日区域，携局部数据场 | **板块** = 一组 H3 格（`PlateId` 标记），物质随格搬运 | 同源。我们的"局部场"不是坐标系而是**格本身**——物质就装在被搬的格里 |
| 局部坐标系 + 形变梯度 F | 刚体旋转（欧拉位移定理：球面上整体漂移 = 绕某轴旋转） | 我们**不做内部形变**（板块是刚体，03 §2.2 拍板）；形变在格级由"多源求和 = 压缩增厚"承担 |
| 逆变换采样（双线性/双三次回全局网格） | **守恒 CA 流链**（一格一落位、多源求和、顶层裁决） | ⚠️ **这里冲突**：重采样是"加权插值"，会引入场扩散（板界变模糊）且**不严格守恒**；v1.7 拍板的 CA 保界又保量 |
| 雅可比校正保证总量守恒 | 质量守恒审计（04 批次 0 落地，614 绿） | 同目标，不同手段：我们是**逐格记账**（reconciled to 1e-6），不需要雅可比 |
| 覆盖判定（重叠包含）+ 超采样抗锯齿 | 离散格归属（`PlateId`）+ 板缘描边（几何线带） | 我们不需要"覆盖分数"：格是离散量子，不存在部分覆盖；抗锯齿由渲染层负责 |
| 空洞检测（洪水填充/距离变换）+ 修复（最近多边形外推/FMM/泊松） | `FillHolesWithNewOceanicCrust`（恒等填充：有本板陆邻则重采样陆壳，否则注新洋壳）+ 孤立空洞并入多数邻居 + **碎片板吸收** | 同思路、更简单：我们的空洞**有确定来源**（链尾腾空），归属由链尾板给定——不需要距离外推 |
| 主动覆盖约束（PBD 投影顶点位置） | CFL 钳制（每步 ≤0.8 格宽）+ 板级相位起跳 | **不采纳**：让物理去迎合网格会把运动学变成网格的奴隶；我们反过来**用相位/CFL 保证离散安全**，且"空洞必被填"是机制不变量（实测无主格=0） |
| MPM 的 P2G/G2P | 平流 = 物质搬运 + 写出 | 我们等价于"P2G 每步一次、G2P 隐含"；MPM 的多次子步只对形变剧烈的连续体有意义 |

### §12.2 可吸收的 4 条（已落地 or 可排期）

1. **"重叠包含"取代中心点判定** → 我们的对应物是**板缘描边 + 板缘格边集**（不靠中心点判归属），已在渲染层解决（09-09 v2 拍板）。**已落地**。
2. **"修复数据须来自最近多边形边界外推，不凭空生成"** → 我们的恒等填充正是这条：陆链尾重采样最近本板陆壳（`CopyCell`），洋链尾注 0 龄新洋壳（洋中脊）。**已落地**，且批次 4 修好了它的记账。
3. **"只对受影响区域重算"（脏区域/空间哈希）** → 我们尚未做：目前每步 3 遍全表（缓存/法线、平流、量测）。若 res5 全流程要交互化，**这是下一轮性能的主抓手**（现已有 O(P) 分桶、量测门控打底）。**可排期**。
4. **"覆盖不变量全局校验"** → 我们把它当**回归护栏**而非物理约束：`无主格=0` + 孤立格带宽 + 质量守恒 三条断言。**已落地**（批次 0）。

### §12.3 明确不采纳（附理由）

- **局部坐标系 + 形变梯度**：球面刚体没有平移，形变会立刻破坏"球面等面积格"这一唯一几何正确性来源；我们的压缩增厚在格级已够用。
- **双线性/双三次重采样回网格**：与 v1.7 守恒 CA 冲突（扩散 + 不严格守恒）；MPM 的 P2G 用核函数加权是为连续体，我们的物质是**离散格量子**，加权只会制造半格幽灵。
- **PBD 覆盖约束**：把网格当物理约束会污染动力学（速度不再由力平衡解出）；我们的等价保证是"填充机制 + CFL/相位"，且不干扰力平衡。
- **FMM/泊松图像修复**：我们无"未知空洞"——空洞成因明确、归属明确；引入图像修复会掩盖真实机制错误（本轮 6 个 bug 里两个正是被"看起来能跑"掩盖的）。

**一句话**：方案的**目标**（数据随物质走、移动后仍铺满、无空洞）我们已实现且更严格（逐格记账守恒）；方案的**手段**（局部坐标系 + 重采样 + 图像修复 + 物理约束）对我们的是**降级**——因为我们的优势恰恰是"离散量子 + 守恒搬运 + 板级运动学"，而不是连续场。
