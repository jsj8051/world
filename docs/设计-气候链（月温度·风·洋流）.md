## 一、一句话

**一个温度场 → 一个风场 → 一条水汽链 → 月降水**，年均温 = mean(12 月)、年降水 = Σ(12 月)——
年值全部由月值涌现，不存在"年值再分配"或"另一套年均公式"。

## 二、因果序（`ClimatePipeline.Run`，不可换序）

```
洋流第一遍（解析盛行风驱动）
  → 年基温（纬度曲线 + 沿岸冷暖 + 大陆性噪声 + 海拔递减）
  → 湿润降温闭环（纬向估算降水，一步解析）
  → 月循环：月温 → 气压（三项叠加）→ 三套风（地面 / 低空 / 自由）→ 水汽追踪（低空）→ 月降水 / 季风
  → 温度（年均 = mean 月）· 降水（年 = Σ 月）· 气压（年均 = mean 月）· 风（年合成）
  → 洋流第二遍（自由低层风年合成 + 年均温热成风）——最终存档场
```

## 三、公式（`ClimateSpec` 里的每个旋钮都对应这里的一处符号）

**年基温**（`TemperatureModel`）：

```
baseT = 52·cos^1.1(lat) − 22          // 赤道 +30、极地 −22
      − (倾角−23.44)/46.6 · 25 · highLat          // |lat|>45° 才生效
      + (辐照−1)·(24 + 12·cosLat)                 // 近恒星：升温且温差拉开
      + 噪声·7 + 沿岸冷暖·5 − 6.0·海拔km
```

**月温度**（`MonthlyInsolation` 与 `MonthlyTemperatureModel`）

```
δₘ = asin(sin(倾角)·cos(2π·(m/M − 5.2/12)))     // 1 月中起算，M 默认 12
a = sin(lat)·sin(δₘ)，b = cos(lat)·cos(δₘ)
Qₘ = (a·H + b·sin(H))/π                        // H 为日落时角，极夜 0，极昼 π
c = d/(d + 1000 km)                            // d 为距海距离，海格 c = 0
τ = 4 个月 / (1 + 3.5·c)，r = exp(−(12/M)/τ)
Sₘ = r·Sₘ₋₁ + (1−r)·Qₘ                        // 年末与年初的状态闭合
Tₘ = baseT + (25/0.20)·(Sₘ − mean(Q)) − ground·Sₘ·10
ground = 海 0.06 / 陆 0.15 / 高山 0.45
ice = smoothstep(Tₘ 从 0 °C 到 −8 °C)，再扣 ice·(0.65 − ground)·Qₘ·10
```

全天积分使用月中代表日，地表温度以月为步长。海洋的热响应慢，季节温差更小、峰值更晚。离海越远，热响应越快。周期解让季节辐照异常的年均为零。

**气压**（同一个月，`PressureFieldModel`，Step 0 已接入）：

```
p(φ,λ) = p_z(φ − Δc)                                 // 13 节点 PCHIP 纬向带；Δc = 0.3×太阳赤纬
        − α·G_650[(T_sl − T̄_λ − bias)·eff(|φ|)]      // 海陆热力；bias = 年均偏置
        + A·B(|φ|)·G_300[E]                          // 副高东西位置；E = 大陆东侧洋面
```

★p 是**世界事实**（`WorldFacts.PressureMonthlyHpa`），气压图直接读它；风也从它算（Step 4 之后是唯一路径）。
α 默认 1.2（参考模型 1.7），标定与两处偏差登记在
[`设计-季风气压场架构.md`](./设计-季风气压场架构.md) §十四。

季风强度由 `MonsoonIndex` 从逐月 p 现算：`Δp = p_陆 − 同纬海洋平均 p`，冬夏反号才记强度
（方案 §F；`MonsoonStrengthScale = 30 hPa`）。

**风**（同一个月，`WindSolver`；摩擦定常解，一次算三套闭合）：

```
f k×v = −∇p/ρ − r·v
u = −( r ∂x p + f ∂y p ) / ( ρ (r² + f²) )
v = (  f ∂x p − r ∂y p ) / ( ρ (r² + f²) )

r      = FrictionSurface × (陆地 ? FrictionLandFactor : 1)
三套    地面 r / 低空 0.5r（水汽、地形雨）/ 自由 0.3r（洋流）
显示风速 = (1 − e^(−|v|/WindSpeedRefMs)) × 地形减速（地形只乘地面）
```

★三套风是**同一个 p、同一个梯度、三个摩擦闭合**，不是三个模型、也不是三层大气。
f→0 时退化为顺梯度直吹（无 1/f 奇点）；f 变号自动处理跨赤道。
20° 东风 / 40° 西风从 p_z 的梯度里自然出现，季风与风带不再是两套东西。
详见 [`方案-季风气压场重建.md`](./方案-季风气压场重建.md) §六 B 与架构文档 §十四。

**水汽 / 降水**（`MonthlyClimate.BuildMonthPrecip`）：

```
moist = (0.35 + 0.65·|v|)·exp(−步数·0.08)     // 陆地沿 −v 走到海，≤25 跳
月降水 = (30 + 235·exp(−(lat−δ)²/2σ₁²) + 100·exp(−(|lat|−62)²/2σ₂²))
        · (1 − 0.85·exp(−(|lat|−26)²/2σ₃²))            // ITCZ + 极锋 − 副热带
        · 辐照 · 噪声 · 沿岸洋流 · 地形抬升
        · (1 + 1.2·moist·max(0, cos(lat − δₘ)))           // 季风增雨的经验权重
        · (1 + clamp(v·∇h·0.5, −0.65, +0.65))           // 迎风坡 / 背风坡
```

**洋流**（`OceanCurrentModel`，流函数法）：

```
curl(τ) = ∮ (风 + 0.15·∇T×r)·dl / deg      // 风应力 + 热成风
curl /= cos(lat)^β                          // Sverdrup：低纬驱动效率高
∇²ψ = curl（SOR，ω=1.7，陆地 ψ=0）          // 等值线 = 流线 ⇒ 自动闭合环流
流向 = ∇ψ×r；强度 = 0.3 + 0.7·min(1, |∇ψ|·8·√(n/10242))
冷暖 = 流向的经向分量 × min(1, |sin lat|/sin45°)（向极 = 暖流）
       ← 权重 = 经向温度梯度的形状：赤道为 0、45° 满权。**不能**只取向极的符号
```

**湿润降温闭环**（`TemperatureModel.ApplyWetCooling`）：`T = T₀ − k·P/(1+g)`，k = 0.004 °C/mm、g = 0.3。
作用在**月温度公式的 base 上**——这是旧链的一处接线缺陷的修正（旧实现写在年温数组上，
而月循环读的是 `TempBase`，等于没生效）。

## 五、与旧链的差异（都是修正，不是重设计）

1. **南半球季节反相**：旧公式的季节项用 `|sin lat|`，南北半球同相（南半球 1 月最热）。
   现乘 `sign(lat)`，南半球 7 月是冬天。
2. **风必须切向**：旧实现直接用邻居弦差当梯度，含径向分量（实测 `v·r ≈ 0.04`）。
   现在先投影回切平面再旋转。
3. **湿润降温接线**：见上文（旧实现写进年温数组后被 `AnnualTempField` 覆写）。
4. **降水幅度重标定**：旧月骨架直接搬过来全球均值 ~2,350 mm/年（地球 ~1,100），
   现按 ITCZ/极锋/底值三项下调到 ~1,100，与 `PrecipitationModel` 的纬向 LUT 同量级。
5. **海洋也有降水**：旧实现海格月降水恒 0，导致 `meanPrecip` 腰斩、河流阈值失真；
   现在海格取月纬向骨架（真实海面降水本就不为零）。
6. **大陆性前置**：`ClimateGrid` 自带海陆 BFS 距离场，`ClimateGrid.From` 不再依赖
   `Icosahedron.GridNFromVertexCount` 之类旧几何工具，跳数 ⇄ km 走 `SpatialScale.NeighborCenterKm`。
7. **冰线按温度生成**（2026-10-22 用户报告"南北极都有一个很明显的圈"）：旧实现是
   `|纬度| > 60° → 反照率 0.65`，实测在 60° 处造成 **6.2 °C 的阶跃**（55–60° 海面 −0.3 °C、
   60–65° 直接 −6.5 °C），在球面上就是一个正圆环。现在冰比例由**当月温度**经 smoothstep
   （0 → −8 °C）决定，冰边跟着温度/海拔/洋流走，且是渐变的；改后同一剖面 55–60° 为 −1.0 °C、
   60–65° 为 −4.6 °C，逐行降温幅度与中位值相差 < 15%（测试 `纬度剖面没有台阶` 钉住）。
8. **赤道的横贯断裂**（2026-10-23 用户报告"温度图有个很明显的跳跃式温度变化"）：洋流冷暖按
   "向极 = 暖流"取**符号**，而"向极"在南/北半球方向相反 ⇒ 同一条洋流跨赤道就被判成一暖一冷，
   海温沿赤道整圈出现 ±5 °C 台阶（实机 = 一条横贯画面、只出现在海面的直线；年温场跨赤道实测
   +5.1 °C、逐经度正负交替）。现在冷暖乘 `min(1, |sin lat|/sin45°)` —— 经向热输送 ∝ 经向温度
   梯度，而梯度在赤道为 0 ⇒ 赤道冷暖无定义、权重收 0，45° 以外维持原读数。改后跨赤道最大温差
   4.8 → 0.24 °C，全球均值不变（12.6 °C），冷暖饱和格占比 74% → 51%（测试 `赤道没有温度台阶` 钉住）。

9. **风改为诊断场**（历史阶段）：旧实现是“气压异常 + 纬度温度梯度 + 科里奥利”的混合式；当时拆成四项：
   地转/热成风（∇T × 1/f）、三圈纬向风带、海陆温差季风（`T' = T − 同纬海洋均值`）、地形减速。
   ★这四项已在 2026-10-24 被**摩擦解**整体取代（气压 → `WindSolver`，三套闭合），
   见本文 §三与 [`方案-季风气压场重建.md`](./方案-季风气压场重建.md)。

## 六、渲染（地图模式）

| 模式 | 数据源 | 口径 |
|---|---|---|
| 温度 / 降水 | `Facts.Temperature*` / `Precipitation*` | 年均 + 逐月（参数行），固定物理域 |
| 气压 | `Facts.Pressure*` | 发散色带固定域 970–1050 hPa（中点 1013）：蓝 = 低压 / 红 = 高压；年均 + 逐月 |
| 风场 | `Facts.Wind`（三份视图） | 参数行 = 月份；变体行 = 地面 / 低空 / 自由。底色 = 风速（软饱和 0–1：蓝→绿→黄→橙红）；白色风丝 = 风向/流动（`WindFlowOverlay`，与底色同一档） |
| 洋流 | `Facts.OceanCurrent*` | 四档：**粒子（默认）** / 冷暖 / 强度 / 方向 |

粒子档 = `CurrentFlowOverlay`（预积分流线 + GPU 沿程动画）：重烘时双向 RK4 积出流线，
生成为静态 ribbon（每点 2 顶点）；运行时 shader 用 `u_time` + 512×4 彗星 LUT 沿 `u = ∫ds/v` 播放，
CPU 只积分一个时间 uniform。宽度是屏幕空间恒 px（与河流同一套投影差分 + NDC 深度偏移）。
近景按 (camDist−R) 反比压 LUT 可见尾长，并同步缩小时间积分速率；只改尾长/时间，不改彗星相位，
所以缩放不会“回放”，也不会淡出消失。
同路线流线按“1 格半径 / 55% 重叠”合并（先按长度降序，只留长线主干），避免同一支流上叠出多条光带。
每条保留的流线先画成一条低亮度连续淡带（`u_base`），彗星只是带上跑的高亮段——同一条路径不会再被切成多段光带。
底图**必须是一色深海蓝**——按洋流强度分两档会在海面上画出同心纬度带（2026-10-23 实机截图暴露）。

风场粒子档 = `WindFlowOverlay`：复用同一套预积分流线 + 风丝 LUT，但周期更长、速度更快、线条更细，
陆海都撒点（风是全局场）；`u_base = 0.03` 只留极淡风路。底色 = 风速（软饱和 0–1，蓝→绿→黄→橙红），
白色风丝只表达风向/流动。切月 / 切风档时按当前 `(month, kind)` 重积几何，底色与风丝读同一份 `WindSet`。
风场本身是**诊断月/年均场**：气压梯度 → 线性摩擦定常解（`WindSolver`，三套闭合：地面 / 低空 / 自由）；
风带与季风都从同一个 p 的梯度里出来，没有独立的"风带查表"或"季风项"。地形只乘地面风。
年均会把季节反转抵消掉：同一格 7 月风向与 1 月相反，年合成只剩净输送——看季风必须切月参数，
不能在“年均”档下结论。
不含冷锋线或瞬变涡旋——这些是天气尺度现象，月/年均场只保留风带、季风和准静止热力结构。
视觉参考 cambecc/earth（MIT）的 wind map；实现是 Godot 流线粒子重写，不含其源码。

## 七、已知边界（登记，不掩盖）
- **没有经向热输送**：极地完全由本地平衡决定，比真实地球更冷（−34 °C 量级）。
  季节环流由季风项部分补偿，但极地冬季仍然偏冷。
- **旧风已退场（2026-10-24）**：`+∇T′` 季风项、`BandU/V/W` 查表、6 遍平滑、`CoriolisSafe` 全部删除；
  风由 `WindSolver` 从 ∇p 算出（三套摩擦闭合），f→0 无奇点。历史诊断（海岸带限制、南北向伪分量）
  留在 [`方案-季风气压场重建.md`](./方案-季风气压场重建.md) §一–三，不再描述现状。
- **`MonsoonStrength` 改成气压口径**（2026-10-24）：`Δp = p_陆 − 同纬海洋平均 p`，冬夏极差异号才算，
  强度 = `clamp((max Δp − min Δp) / MonsoonStrengthScale, 0, 1)`。它现在是风反转的**因**，
  不再是降水季节性的代理；下游仍只有 `WorldFacts` 携带与冒烟打印。
- **年均偏置（旧风时代）**：低纬陆地年均比同纬海洋冷 3–7 °C（湿润降温 + 海拔 + 反照率），
  旧风把它变成常年离岸/向岸；新的气压口径用"减年均偏置"处理，不再依赖这条。
- **风是单层二维场**：没有垂直速度，季风的上升支与高层反向不存在；气压场接上了，
  辐合也无法在垂直方向闭合（要垂直结构必须有层）。
- **ψ 是准静态近似**：res4（537 跳半径）下 300 遍 SOR 的残差 ~2e-4，环流形态与方向可信、
  强度绝对值偏弱。要精确解需多重网格或 H3 父层粗解；当前预算 = 第一遍 120 遍 + 第二遍 300 遍。
- **两遍洋流的时序折让**：温度用第一遍（解析风）洋流的沿岸冷暖，第二遍（真实风 + 热成风）
  才是存档场；差异只在沿岸数 °C。
- **无柯本分类**：`BiomeType` 当前只剩陆格柯本词表（海格/高山型已按裁决删除），
  本轮不产出 biome 事实；月温度/最热最冷月/最干月等柯本输入已经齐备，接入是独立一步。
- **海拔尺度**：地形高度是米（当前世界 ±500 m 量级），6 °C/km 递减只贡献几度；
  换大尺度世界时该旋钮才有明显效果。

## 八、实测（`dotnet run --project tests/World.Tests.Local -- --world N`）

月温热惯性模型的 res4 冒烟结果为 288,122 格、12 个月，全球格均年温 12.7 °C，格年均温范围 −30.7…+26.8 °C，年降水格均 1,041 mm。下表记录此前模型的历史基准。

| res | 格数 | 年均温 | 温度域 | 年降水均值 | 气候耗时 | 全链耗时 |
|---:|---:|---:|---:|---:|---:|---:|
| 2 | 5,882 | +13.2 °C | −30.5…+26.6 | 1,162 mm | ~0.2 s | 0.28 s |
| 3 | 41,162 | +13.1 °C | −33.2…+26.8 | 1,116 mm | 0.39 s | 0.88 s |
