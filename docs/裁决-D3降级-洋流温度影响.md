## 一、动机（证据链）

1. **项目定位**：本项目的目标是星球世界生成（自然感），不是海洋气候模拟器。D3 当时的实现
   （边通量 `q_ij = −q_ji` + 迎风平流 + CFL 夹子 + 全球零和守恒）是一个小型海洋热输运模型，
   其复杂度超出了"洋流让气候更有自然感"的实际需求（防膨胀三问：消费者只需要"温度结构被洋流调制"）。
2. **实测证据（τ₀ 扫描 · 发现 1）**：四档 τ₀ 下 `dTmx` 逐位相同（0.239 °C）⇒ CFL 全局夹子
   已饱和 ⇒ **输运效应与 Speed 解耦**。严格守恒输运付出的全部复杂度，换来的效应
   对流速完全不敏感——机制存在但失去了与 D2 事实场的定量联系。
3. **待裁决项 B（输运旋钮选型）整体蒸发**：降级后不存在显式平流稳定性问题，
   CFL 上限 / 逐边 cap / 子步进 / 隐式等选型不再需要。

## 二、新语义（D3 降级版）

```
OceanCurrentField (D2 冻结事实)
  ↓ 上游格选择（确定性）
ΔT_i(m) = Gain · Influence(Speed_i) · (T_up(m) − T_i(m))
  ↓ 逐格扣除 12 月均值
dT_i(m) −= mean(dT_i(1..12))   ⇒   Σ_m ΔT_i(m) = 0（逐格精确）
  ↓
ClimateState.Temperature（月度场后处理）
```

本质 = **方向性温度趋近**（洋流把上游海区的温度**季节结构**向下游传播），
**不是**热量守恒模拟。命名同步：`oceanHeatGain` → `currentInfluenceGain`，
`OceanHeatTransportGain` → `OceanCurrentInfluenceGain`。

## 四、四个实现钉（技术决策）

1. **收敛后处理**：影响作为温度月度场的**一次性后处理**（对闭式解直接作用），
   不进 spinup 迭代。理由：趋近项依赖上游月温度（收敛中状态），进迭代会让收敛语义模糊；
   后处理确定性最强、Gain=0 退化锚最容易逐位保证。水循环在影响落地**之后**运行
   （读调整后温度，气候态内部一致）；`evapGain = 0` 时温度影响仍生效（两者正交）。
2. **年均锚升格为逐格恒等式**：`Σ_m ΔT_i(m) = 0` 由构造保证（扣均值），
   条款 10（T_ann 锚不可重定义）从"全球守恒推论"升级为**逐格精确性质**。
   注意语义：仅月内结构被调制（暖流冬季增温型），年均气候锚不变——这是设计目标不是损失。
3. **非守恒登记（契约级）**：趋近不是输运，上游不被冷却，能量不闭合。
   扣均值后只剩月内结构重排（无年均偏），气候学上无偏。本文档钉死：
   本模块是**方向性影响场**，不是热量通量；**未来不得在温度分量上叠加第二个非守恒项**
   而不重新过契约（防重复归属）。
4. **确定性规则**：
   - 上游格 `up(i)` = 海格邻居中 `−Direction_i · t̂_k` 最大且 > 0 者
     （水沿 Direction 流**入** i ⇒ 上游在 −Direction 侧）；无合格邻居 ⇒ 无上游 ⇒ 不修改；
   - `Speed_i = 0`（停滞/静风格）⇒ 不修改（逐位不动）；
   - `Influence(Speed) = Speed / (Speed + v_half)`，`v_half = CurrentInfluenceHalfSpeedKmPerMonth`
     （10 km/月，占位；P4-5e/O-O2 标定旋钮；关断 = Gain 0 或 v_half = ∞）；
   - Jacobi 读法：全部读步初快照场，写入临时结果后统一落盘 ⇒ 与格处理顺序无关；
   - 固定扫描顺序 ⇒ 同输入逐位可复现。

## 六、对 O-O2 / P4-5e 的影响

- **任务简化**：只剩 Speed 量级标定（τ₀ = 4× 与否），不再有"速度与严格热通量守恒同时成立"
  的耦合约束。原"发现 2：单一 τ₀ 不够"只关乎速度分布形状，与影响模块解耦。
- **影响量级成为独立旋钮**：`Gain × Influence(Speed)`，随 Speed 单调（不再被 CFL 夹子钉死）。
- **τ₀ 扫描 harness**（`OceanTau0Scan`）更新：`dTmx` 改测月度影响幅度，
  零和断言改为逐格年均锚断言。
