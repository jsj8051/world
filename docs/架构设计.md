## 1. 总体架构：生成与游玩解耦 + 五层世界事实

```
┌──────────────────────────────────────────────────────────────┐
│ 表现层（怎么画）                          World.Render(.UI)  │
│   BallView（LOD网格/剔除/拾取/高亮）· MapMode（取色策略）      │
│   CellQuery（高亮环带纯函数）· MapDock / CellInfoCard         │
│   RiverLineOverlay（样条河面 + 屏幕空间 shader）              │
├──────────────────────────────────────────────────────────────┤
│ World Simulation（世界如何运行）          World.WorldGen       │
│   Precipitation → RiverNetwork → RiverGraph / BasinGraph /   │
│   LakeState → WaterTopology     WorldGen   │
│   ★ 只消费 Final，不看生成依据                                │
├──────────────────────────────────────────────────────────────┤
│ SpatialIndex（如何高效询问）                                   │
│   FinalSpatialIndex —— nearest / distance / within            │
├──────────────────────────────────────────────────────────────┤
│ Final（世界究竟是什么）★唯一世界事实源★                       │
│   FinalGeography：FinalLand / FinalLandmassId /               │
│   FinalDistToCoast / FinalLandFraction / FinalRegionOfCell   │
├──────────────────────────────────────────────────────────────┤
│ Placement（世界如何生成）                                     │
│   ContinentLayout → LandSeaField → H3LandSeaProjector →│
│   SurfaceResolver → GeologicalRegions → TectonicField →      │
│   MountainSkeleton / RegionalLandforms / VolcanoField →│
│   HeightComposer ⇒ HeightM                │
├──────────────────────────────────────────────────────────────┤
│ 基础设施                    World.Utils(.H3) / World.Domain /  │
│   H3 球面网格 · SpatialScale（唯一面积距离口径）· Archive    │
│   LogicGrid / CivSim / HexPlanet / Services / Camera          │
└──────────────────────────────────────────────────────────────┘
```

### 1.1 两条核心解耦

| 解耦 | 含义 |
|---|---|
| **生成 ↔ 游玩** | 地图是**存档**，不是场景。游玩只读存档，不重新生成（承旧设计，仍成立） |
| **Placement ↔ Final** | **Final 是唯一世界事实源**。下游只消费 Final，不看生成依据 ⇒ 可替换任一生成器而不动下游 |

### 1.2 空间底座：H3 球面网格

- 网格 = **H3 六边形球面**（`World.Spatial.Ball`），一次构建永久只读
- 球面网格数据层：`Ball.CellIds` / `CellDirs`（格心单位方向）/ `CellNeighbors`
- `res0` = 官方 res1 = **122 格**；`GetNumCells(r) = 2 + 120·7^r`
  - 实测格数：res1=842 / res2=5,882 / res3=41,162 / **res4=288,122**
- 渲染分块 = res0 基格（122 块），每块两档 LOD 网格

### 1.3 连续优先原则

每层暴露 `Sample(dir)` 连续查询口；**逐格数组降级为"该连续函数在格心的一次采样"**。
测试断言"数组 = 采样，逐位同"。

⇒ 好处：LOD 换档、局部高分辨率、任意方向查询都不需要重建数组。

## 3. 世界生成链（Placement 内部）

### 3.1 海陆结构（连续场 + 分位校准）

```
ContinentLayout（大陆锚点蓝噪声撒布 + size/shape/rotation）
    → LandSeaField（域扭曲 + 三尺度连续场）
    → H3LandSeaProjector（逐格投影 + 海陆比分位校准 ⇒ ThresholdUsed）
    → SurfaceResolver（★唯一海陆口径：IsPlacementLand / OceanFactorAt / BathymetryAt）
```

**为什么用"分位校准"而不是"阈值"**：海陆比 = 切分位位置 ⇒ 滑块真正可控。
（对比已清退的 B 线：那里海陆由**板块身份**定死，目标占比是"陆板数"占比，
无法分出半岛/海湾——**范式差异**，不是等价替换。）

### 3.2 地质区域与构造

- `GeologicalRegions`：两级 Voronoi + 七类型五因素约束式打分 + Lloyd 松弛
  （`RegionType`：Plain / Highland / Basin / Mountain / Plateau / Rift / Coastal）
- `TectonicField`：陆块主轴（PCA）+ 构造强度连续场 + 锚点池。
  ★**只答"哪里容易"，不负责任何形状**（Field 层的职责边界）

### 3.3 Field / Feature / Morphology

| 层 | 实现 | 形态手法 |
|---|---|---|
| 山脉 | `MountainSkeleton` + `MountainSystemFeature` | 主脊高度曲线 + 曲线支脉树 + 方向场排斥 + 跨海表达 |
| 高原 / 盆地 | `RegionalLandforms`（`PlateauFeature` / `BasinFeature`） | 高原帽 / 盆地下挖 |
| 火山 | `VolcanoField` + `VolcanoFeature` | 径向锥 |

**特征优先级**（成文约定，非实现偶然）：**列表后位覆盖先位**
`Mountain(4) > Basin(3) > Plateau(2) > Base(0)`。

**没有万能地形区域公式**：山脉用沿线坐标 s+d、盆地用局部 2D、火山用径向 r/θ、
河流用流线 s+d、海岸用离岸距离 d。

### 3.4 高度合成

`HeightComposer` 是**最终地表连续单一事实源**：
`Base → 按序 lerp 特征链 → 三档变化（80/130/260 m）→ MinLand 钳制（30 m）`。

★**绝对高度 lerp 语义**（取代"+N 米增量"）：
`FinalHeight = lerp(当前, TargetM, Influence)` ⇒ **峰高只有一个语义来源**。

## 4. 水文与水系（World Simulation）

### 4.1 两个高度（D-11 · 永久）

```
FinalHeight ──→ 渲染 / 判读 / LakeState（原始洼地语义）
     │
     └─(填洼 HydrologyRoutingSurface)─→ FlowDirection / BasinGraph / FlowAccum
```

- **填洼是派生预处理**，不写回 `FinalHeight`
- `DepressionCount` / `FillDepthM` 始终基于**原始**高度
- ⚠️ **D-16 教训**：若 `LakeState` 从填洼后的 BasinGraph 派生，
  **开启填洼后内流湖全部消失**（实测3,671 → 0）

### 4.2 四个水系统概念不互相吞并

| 类型 | 职责 | 明确不承担 |
|---|---|---|
| `RiverGraph` | 河流**内部**拓扑 | 不管流域、不管湖泊 |
| `BasinGraph` | 流域归属与终止 | **不判湖**（原子事实优先于 `Kind` 分类） |
| `LakeState` | 湖泊状态（成湖 + 水量平衡） | 不重定义河流 |
| `WaterTopology` | 水体**之间的连接** | 不重定义前两者 |

### 4.3 河流表现（River v2.0 · 已冻结）

三层契约（永久）：

```
事实层RiverNetwork / RiverGraph / WaterTopology / RiverGeometry
   → 表现几何 RiverPresentationSpline（centripetal Catmull-Rom，锚点保真·偏差 ≤ 0.15）
   → 视觉     RiverSurface（screen-space width · NDC depth bias · no radial lift）
```

★**H3 六方向 ≠ 视觉六方向**：H3 只是水文采样与拓扑来源，连续样条才是表现几何。
⇒ "河流像木板"的根因在表现层已隔离，**不要靠改水文/改阈值去缓解**。

**不表达物理河宽**（已冻结）：只做符号粗细系统（5 档），
不做河宽/河岸/flow animation / LOD2-3。

## 8. 两条已清退的旧线（勿重建）

| 线 | 曾经的范式 | 为什么不该重建 |
|---|---|---|
| **A 线**（`MapGen`/`Biome`/`MapView`/`Tectonics`） | Goldberg 逻辑格 + 五阶段管线 + 10 图层查看器 | 与 Final 事实源**冲突**；存档与领域词汇已按类型语义分离保留 |
| **B 线**（`World.NoiseWorld` 噪声单体） | **板块身份定海陆** + L0–L5 噪声栈 + 域内秩 | 新架构是**连续场 + 分位校准 + 绝对高度 lerp**，能分出半岛/海湾；旧范式是**范式回退**不是等价替换 |

**清退纪律**：判定问题是"**它是不是仍然代表 Final 世界事实的一部分**"，不是"有没有人引用"。
**只加新 → 切消费者 → 跑测试 → 再删旧**（反序会炸编译）。

**资产封存代替代码迁移**：旧线的高价值工程经验（板块八次迭代史 / 地球 LUT 数据来源 /
Fritsch–Carlson 推导 / PropagateMax 收敛论证）已提取到
`docs/newdecision/封存-NoiseWorld设计史料.md`。
★**"旧代码质量很高"不是迁移理由** —— 价值用文档承载，不用生产树承载。
