# world 架构设计（Architecture）

> 中世纪 4X 国家策略（Godot 4.7.1 mono / .NET 8 / C# 12）。
> 本文档描述 2026-08 重构后的现状架构；配套《开发规范.md》管代码约定。
> 核心原则：**生成与游玩解耦**（参考 Dwarf Fortress / Civilization——地图是存档，不是场景）。

---

## 1. 总体架构：双层 + 存档解耦

```
┌────────────────────────────────────────────────────────────┐
│ 纹理层（观感，对齐逻辑格 5km²/格，2026-08-10 口径统一）    │
│   MapViewer / Planet 网格渲染、图层着色、箭头流线             │
│   GridN 对齐模拟 n：10n²+2 顶点 = 逻辑网格顶点，无需插值     │
├────────────────────────────────────────────────────────────┤
│ 逻辑层（模拟，n=64~128 目标）                               │
│   板块 / 气候 / 河流 / 矿藏 / 土壤——全部纯 C# 数组，后台线程 │
│   Task.Run 生成，主线程只读（不碰 Node/渲染 API）            │
├────────────────────────────────────────────────────────────┤
│ 存档层（MapArchive v9 段表，user://maps/*.mpa——历史 v3/v5 见 §5） │
│   球面顶点数据直写二进制；游戏运行时只读存档，不重新生成      │
└────────────────────────────────────────────────────────────┘
```

关键决策：
- **球面直通（v3 定案）**：模拟与显示共用同一球面顶点网格（Icosahedron 细分，顶点数 = 10n²+2），无平面中转、无投影。MapViewer 每格颜色**最近顶点直读**（数组 O(1)），Shepard 插值仅用于生成期/预览平滑。
- **热路径纯 C#**：模拟数据用 float[]/byte[]/Vector3[] 原生数组；GodotObject 派生对象只在渲染边界出现（详见《开发规范.md》性能红线）。

## 4. 生成管线（PlanetPipeline 五阶段）

```
输入：PlanetParams（Seed / 自转方向 / 倾角 / 距日 / 自转速度 / 网格 n）
      板块模拟在管线外（MapGenerator 驱动，进度 UI，产出海拔+物质场）
        │
        ▼
Stage1 气候   温度/降水/biome + 洋流场（盛行风 → 科里奥利 → 雨影）
Stage2 水文   河流迭代（动态流向 + 输沙侵蚀沉积，**可改海拔**）→ 湖泊 → 流域
Stage3 生态   河岸带（沿岸 Riparian）
Stage4 资源   矿藏（矿化强度 + 分位数）／ 土壤肥力（biome 基础 ± 地形气候惩罚）
Stage5 统计   min/max 范围 → 写存档（MapArchive v3）
```

- 纯计算：无 Godot 对象依赖、无 GD.Print（后台线程安全），同步/异步两路径共用同一 `Run()`。
- 板块模拟（`TectonicsSimulation.Run`）不在管线内：耗时长（n=64 600My ≈ 2.5~3min），由 MapGenerator 分阶段上报进度。
- 星球参数：`Seed / RadiusKm(星球半径，用户输入) / ProgradeRotation(顺转/逆转) / AxialTilt(0~90°) / Insolation(相对 1AU) / RotationSpeed(相对 24h) / TectonicsGridN / NumContinents(大陆块数 2~20)`——物理参数 + 构造格局 + 种子，全部 [Export] 可 headless 覆盖（`-- --seed=7`）。
- **星球大小口径（2026-08-10 定案）**：每格固定 5 km²（平均值，Icosahedron 胞近似均匀）。用户输入半径 R → n = round(√(4πR²/50)) 派生（顶点 = 10n²+2），反算实际半径 R' = √(50n²/4π) 保证 4πR'²/N ≈ 5 km²。可行域 R∈[8,511] km（n∈[4,256]）。所有数值（人口密度→每格人口、食物流）以"格"为单位，km² 只是换算显示。
- **构造格局参数（2026-08-10）**：大陆块数 N 是**无量纲格局旋钮**（与格数/格面积正交）——ranks 噪声频率 = N/2π（单位球坐标，噪声链路已无 6371 标度；此前固定 0.00016@6371km 等价 6.4 块）。N=2 超大陆（最大块 ~88% 陆地）/ N=20 碎陆（~18%）。校验 N ≤ n/2（每块跨径 4n/N 格，<8 碎渣）。板块输出为 rad 角度格局，与星球实际半径无关（小星球等比缩小）。

## 5. 存档格式（历史：MapArchive v5，Magic "MPA1"）

> ⚠️ **历史章节**：本段描述 2026-08 中期的自然层存档（v3 球面 → v5 半径头部）。
> 现状：`.mpa` **v9 段表格式**（2026-08-23 单存档化 v7 → 概念分组 v8 → 功能定性 v9）；`.cmp` **v17**；`.gmp` v3。
> 段表容器（ChunkWriter/ChunkReader）与布局见《存档段表格式设计.md》。

```
头部（固定）        Magic 4B + version 2B + seed 4B + radiusKm 4B（v5 加，星球半径 km；旧档无=6371 地球）
                   + vertexCount 4B
                   + 顶点 12n B（Vector3）
                   + 海拔 min/max + 海拔 n×4B
                   + 温度 min/max + 温度 n×4B
                   + 降水 min/max + 降水 n×4B
                   + biome n×1B
尾部扩展（向后兼容追加式，旧版无 = 默认值）
   ext1 自转方向 1B + ext2 自转速度 4B + ext2b 轴向倾角 4B
   ext3 洋流：方向 3×4B + 冷暖 4B + 强度 4B（每顶点）+ psi 4B（每顶点；⚠️ 无条件写满，null 补零——
       读取端 ver≥4 无条件读，条件写会致河流段错位，2026-08-10 修）
   ext4 河流：级别 n×1B + 流向 n×4B (+ 流量 n×4B)
   ext5 湖泊：级别 n×1B
   ext6 矿藏：级别 n×1B（(富度<<4)|矿种）
   ext7 土壤：肥力 n×1B（1-5）
   ext8-10 季风强度 n×1B + 月降水 12n×1B + 月温度 12n×1B
```

兼容策略：**版本只增不减，尾部追加**。`Version = 5`（v5：头部加 radiusKm），读端 `ver > Version` 拒绝；旧存档缺尾段 = 默认值（无洋流/无河流/半径 6371）。v2 平面存档写/读保留（调试对比用）。

## 6. 图层系统（MapViewer 10 层）

| # | 图层 | 数据来源 | 渲染 |
|---|---|---|---|
| 0 | 海拔 | elev | 连续高度色带（非线性分段） |
| 1 | 温度 | temp | 色带 |
| 2 | 降水 | precip | 色带 |
| 3 | 生物群系 | biome | BiomeColors 分类色 |
| 4 | 盛行风 | WindField | 箭头/流线稀疏采样（非涂色） |
| 5 | 洋流 | 存档 ext3 | 闭合环流圈，每圈只显最外层（网上洋流图式），红=暖蓝=寒 |
| 6 | 河流 | 存档 ext4 | 每条河独立颜色，支流汇合随主河色 |
| 7 | 流域 | 现场算 | 以河流为中心的流域划分（无阈值） |
| 8 | 矿藏 | 存档 ext6 | 矿种色 |
| 9 | 土壤 | 存档 ext7 | 肥力 1-5 色 |

性能机制：构建时每格采样一次到缓存数组，**切图层 O(1) 查表只重算颜色**（秒级，不重建网格）；切图层用取消令牌中断旧任务 + 挂载新网格前清旧 `_planetMesh`。

## 7. 物理模型要点

| 系统 | 模型 | 关键机制 |
|---|---|---|
| 板块 | tectonics.js 移植（Schellart 2010 速度模型） | 板内网格 + 欧拉旋转；slab pull + 拖曳力平衡；均衡补偿；洋壳年龄重置维持密度差驱动（请求棘轮是板块数收敛主因，已修） |
| 气候 | 盛行风主导 | 风 = 科里奥利偏转 + 雨影效应；降水噪声只作小扰动，不主导（用户定案：物理主导） |
| 洋流 | 流函数法 | 闭合环流圈追踪 |
| 河流 | 动态流向 + 输沙 | 侵蚀/沉积可改海拔；内流河断流自然实现；收敛检测；河谷三角洲；河岸生态带 |
| 矿藏 | 矿化事件累积 | 裂谷/俯冲/增生热液 + 沉积 + 变质在板块演化中累积强度；**分位数模型**（倾向分 × 固定百分位 + 微扰，禁绝对阈值） |
| 土壤 | 分位数相对阈值 | biome 基础 + 冲积/火山加成 − 坡度/气候惩罚，肥力 1-5 |

## 9. 防错基础设施（2026-08-19 历史 bug 根因重构）

> 背景：反复出现的 bug 归因后发现根因集中在**改一处漏多处**（断链）与**手写多份同步**（重复）。
> 以下基础设施把这些隐患从"靠人记"变成"结构性杜绝"。

### 9.1 参数关联化（消除断链）

原则：**每个物理量只有一个源头，其余全部引用**。

| 统一源 | 被替代的散落值 | 规则 |
|---|---|---|
| `MapArchive.DefaultRadiusKm`（6371） | MapGenerator/TectonicsSimulation/Tectonophysics/SphereGrid 的裸 6371 | 禁止散落 6371/6330/6367 魔数 |
| `BiomeClassifier.OceanLevel`（0） | MonsoonSystem/ClimateFields/MonsoonDiag 的 0.02f 海陆判定 | 改海陆阈值只动一处 |
| `BiomeClassifier.AlpineLevel`（0.5） | MonsoonSystem/MonsoonDiag 高海拔雪判据 | 同上 |
| `MonsoonSystem.ElevLapseRatePerM`（0.006） | 海拔温度递减率 3 处 | 改直减率只动一处 |
| `MonsoonSystem.MonthCount`（12） | 月循环/月数组 20+ 处裸 12 | 月份数单一来源 |
| `RiverSystem.DefaultWaterThreshold/LakeThreshold/DefaultRounds` | PipelineFields/RiverDiag 的 5000/200/8 与默认 400 矛盾 | 河流阈值/轮数单一来源 |
| `MapViewer.OverlayLiftFactor`（1.01） | 浮高系数 1.01/1.012 四处 | 防 z-fighting 统一 |
| `Icosahedron.VertexCountFor/GridNFromVertexCount/VertexCountForLong` | 10n²+2 公式 8 处 + 反推 4 处 | 公式唯一源（Long 版防存档伪造溢出） |
| `CivSimContext.FissionTensionStart=SplitPop`、`ChiefdomEvalEvery=TerritoryRebuildEvery` | 注释说"跟随"却写死的 12/10 | 参数互引而非复制值 |
| `MapGenMenu.CellAreaKm2`（5.0） | 口径公式 50.0 裸数 | 5km²/格口径单一来源 |

### 9.2 场契约（FieldCodec）——杜绝双重归一化类 bug

`World.MapGen.FieldCodec`：场数值 ↔ 存档 byte 的**唯一编解码入口**（2026-08-05 双重归一化全黄案的根治）。

- 比例场（季风强度/月降水比例 Σ=1）：`RatioToByte` / `ByteToRatio`
- 温度场（−60~60°C → 0-255）：`TempToByte` / `ByteToTemp`
- 月降水：`ByteMonthPrecipToMm`（比例 × 年降水）

byte 化/解码曾散落 MapGenerator×6、MapViewer×3、WildCrops×4、MonsoonDiag×3、CivSimDiag、OceanCurrentDiag——改编码语义只动 FieldCodec 一处，调用点公式禁止手写。

### 9.3 布局驱动存档（ArchiveLayout）——杜绝正文错位类 bug

`World.LogicGrid.ArchiveLayout`：.gmp/.cmp 自然段布局的**唯一长度来源**。

- 字段表（类型 × 是否每顶点）→ `BodyLength(n, ver)` 推导（53 头 + 94/格 v2 精确吻合）
- `GameMapArchive.ReadBody` 读后**布局长度断言**：读位 ≠ 布局长度 → 拒读（错位类 bug 最后防线）
- `CivMapArchive.Peek` 原硬编码 `53+94n` 魔数已替换——布局一改即断链的隐患消除

### 9.4 管道卫生检查——杜绝 NaN/全 0 静默写档

- `PlanetPipeline.SanitizeNaNs`：全字段扫描（原只查海拔/温度/降水 3 个主字段——月场/洋流场的 NaN 会静默写档，下游显示全错）
- `PlanetPipeline.HealthCheck`：写档前暴露 NaN 计数/全 0 异常场（同步路径；后台线程跳过，因含 GD.Print）
- `World.Diagnostics.FieldCompare`：公共 diff 工具（**NaN 视为相等**——Math.Abs(NaN−NaN)=NaN 让 maxDiff<1e-3 恒 false → 假 FAIL；各 diag 不得再造轮子）

### 9.5 索引映射收敛（TileIndex）——杜绝双索引错位类 bug

`World.MapView.TileIndex`：显示格（Goldberg 面）↔ 逻辑格（Icosahedron 顶点）映射唯一入口（2026-08-18 63km 错位案的根治）。

- `FaceToVertex(f)`：显示面 → 逻辑顶点（读逻辑数据必经）
- `FacesOf(v)`：逻辑顶点 → 显示面列表（写显示数据必经，如驻扎格势力/人口）
- 不变量：逻辑数据按顶点空间读写，显示数据按面空间读写，禁止裸下标互串
- MapViewer 曾散落 `_tileVerts[id]` 12 处 + 手写顶点→面反查表——全部收编

### 9.6 桶索引预构建加固——杜绝 Collection modified 崩溃

`MapData.EnsureBuckets` / `GameGrid.EnsureBuckets`：惰性构建 + 后台线程并行采样 = 并发修改集合崩溃（历史难定位 bug）。

- 规则：**任何产出自建索引对象的工厂方法，返回前必须主线程预构建**（MapArchive.Read、GameGrid.FromMapData 已做）
- 加固：首次构建若在后台线程（`OS.GetMainThreadId` 对比）→ 立即 PrintErr 警告暴露调用方遗漏

### 9.7 一键回归（verify.sh）——杜绝"改完没验证"与增量 build 静默失败

`scripts/verify.sh`：`dotnet build -t:Rebuild` → **DLL 时间戳断言**（增量 build 静默失败检测）→ 4 组 headless 回归（TectonicsTest n16 / LogicGridDiag n64 往返 / MonsoonDiag / CivSimDiag T 全套）→ 汇总退出码。

- `--fast` 模式：只跑 n16 快测试（~1min）
- 上线即抓 2 个真 bug：TectonicsTest 默认路径漏 Quit（headless 挂死）；MonsoonDiag 无 --out 覆盖源档
- 每次改完代码必跑；T40 性能基线自动防劣化

## 10. 技术决策记录（含否决项）

| 决策 | 结论 | 理由 |
|---|---|---|
| 动态 LOD | **否决 → 静态烘焙** | 反复出 bug，用户质疑成熟度；改 ChunkMeshBuilder 静态分块 |
| 平面投影中转 | **否决 → v3 球面直通** | 数据流直接性：板块本就在球面上生成，无需投影再转回 |
| 噪声生成地形 | **限制作初始条件** | 最终地形由板块物理塑造；降水由风/科里奥利/雨影主导 |
| 矿藏绝对阈值 | **否决 → 分位数模型** | 判定阈值必须相对该星球分布（通用性） |
| 显示层 Shepard 插值 | **否决 → 最近顶点直读** | 渐变观感"一团团"；Shepard 只用于生成期预览 |
| 参数散落硬编码 | **收编 → 统一源引用** | 一改就出问题（断链）；每个物理量单一来源，其余全部引用（§9.1） |
| byte 编解码手写公式 | **收编 → FieldCodec** | 双重归一化全黄案；编码语义变更只动一处（§9.2） |
