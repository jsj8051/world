# 数据结构设计：地壳运动演化

状态：**第 3 步已通过**（含地幔池）；第 4 步落地见《落地-地壳演化结构》。本文件只设计类型与约束，不是实现代码。

## 1. 已批准边界

路线 A：固定 H3 网格，球面刚体移动地壳材料并按覆盖面积重映射。现有生成是统一演化的 t=0 初始化，不保留独立静态模式。首版含碰撞、俯冲、裂谷、扩张、走滑、构造高程、海底年龄和火山；不含侵蚀、沉积、板块自动分裂合并、地幔动力学与持久化历史存档。

## 2. 先列样例

以下为构造器/校验器的规格样例，不是可加载的整份世界。片的 Footprint 以场景夹具中真实 H3 格多边形 P(i) 或其合法裁剪片表示，不能用空数组代替。

| 样例 | 输入数据 | 预期 |
|---|---|---|
| 零步陆壳 | PlateId=0, Cell=42, Footprint=P(42), Material=Continental, ProvinceId=0, ThicknessKm=35, BirthTimeMa=null, ReferenceElevationM=600, ReferenceThicknessKm=35, ExtensionStrain=0 | 合法；海底年龄视图为 null；600 m 是已经存在的初始地形，不再乘垂直倍率 |
| 零步老洋壳 | PlateId=1, Cell=43, Footprint=P(43), Material=Oceanic, ProvinceId=-1, ThicknessKm=7, BirthTimeMa=-80, ReferenceElevationM=-4200, ReferenceThicknessKm=7, ExtensionStrain=0 | t=0 时海底年龄=80 Ma；模拟时间与材料出生时间允许不同符号 |
| 俯冲入池 | 原库存=500，SubductedVolumeKm3=1000，无释放 | 地壳减少1000，新库存=1500；地壳加库存总量不变 |
| 地幔释放 | 原库存=1500，无入池，ReleaseVolumeKm3=100，ReleaseTo=NewOceanic | 新库存=1400，新洋壳增加100；总量不变 |
| 库存不足 | 原库存=0，无入池，新洋壳需求=100 | InsufficientMantleMaterial；整步不提交，库存仍为0 |
| 半格覆盖 | 在格 44，两个不重叠片分别覆盖 40% 和 60%，PlateId 分别 0、1 | 两份材料均保留；公开 PlateOfCell[44]=1，不删除少数覆盖片 |
| 新生洋壳 | t=1 Ma, Material=Oceanic, BirthTimeMa=1, ThicknessKm=7, ProvinceId=-1 | 出生当刻年龄=0；后续变老；新生体积进入 NewOceanicKm3 |
| 非法洋壳 | t=1 Ma, BirthTimeMa=2 或 ThicknessKm=-1，或覆盖片自交/重复覆盖 | 拒绝候选状态；报告稳定错误码和片位置；不覆盖最近合法状态 |

所有片必需关联合法板块和球面多边形；其余字段默认见后表。没有可无条件运行的全零“默认演化世界”。

## 3. 类型与所有权

全部新增数据载体沿用 World.Data 命名空间、Data/Carrier、Data/Constants、Data/Spec 分层；算法仍归 World.Logic。

| 类型 | 职责 / 不负责 |
|---|---|
| EvolutionSpec | 可序列化的物理与数值配置；不保存当前时间或运行结果 |
| EvolutionDefinition | 初始化时冻结的完整参数副本、模型版本、网格身份；不跟随 UI 参数修改 |
| EvolutionFrame | 最近合法的已提交地质状态；只读所有权，不对外暴露可写数组 |
| EvolutionClock | 整数地质步编号与固定步长；不记录墙钟时间 |
| PlateMotion | 板块身份、物理角速度和当前姿态；壳型不放在板块上 |
| SpherePoint / RotationD | 双精度球面方向 / 单位四元数；与 Godot 场景无关 |
| CrustFragmentSet / CrustFragment | 按格组织的球面覆盖片及材料状态，演化唯一真源 |
| EvolutionProjection | 材料投影到 H3 的只读逐格视图，全部可重建 |
| EvolutionBoundaryField | 与当前 PlateBoundarySet 逐边对齐的物理运动和过程分类 |
| MantleReservoir | 全球被动地幔物质库存；不模拟地幔动力学，不吸收数值误差 |
| EvolutionBudget | 当前步与累计物质收支；不是第二份材料状态 |
| EvolutionControl | 播放、暂停、目标步和墙钟时间请求；不参与地质物理公式 |
| EvolutionProblem | 结构化校验/推进错误，纯数据 |

关系：一个 Definition 对应一段演化历史；一个 Frame 有一个 Clock、P 个 PlateMotion、一份 FragmentSet、一个 MantleReservoir、一份 Projection、一个 Budget。一个格有一到多个 Fragment；每片只属于一个板块和一种材料。边界集和逐边场同属一份 Projection。完整世界发布还包含同一地质步的气候、水文、索引。

## 4. 基础字段

表中“必填”表示无可接受的隐式默认；所有浮点均须有限。所有字段非空，除显式标 null 的字段。内部计算长度 km、时间 Ma、高程 m、体积 km³；1 cm/yr = 10 km/Ma。

### EvolutionDefinition

| 字段 | 类型 / 默认 | 约束与语义 |
|---|---|---|
| ModelVersion | int / 1 | 必须为支持版本；决定积分、几何、收支与排序语义 |
| HistoryId | Guid / 创建时生成 | 单次初始化历史的身份；Frame/命令必须匹配；不参与物理计算或确定性结果比较 |
| InitialSpec | 私有冻结 WorldSpec 副本 / 必填 | 深复制完整初始化参数，含 Evolution；不引用可修改 Active，对外只暴露只读标量或防御性副本 |
| H3Resolution | int / 4 | 生产固定 4；实验夹具可用其他合法档 |
| RadiusKm | double / 必填 | >0；取项目实际物理半径，不是显示半径 |
| GridFingerprint | string / 必填 | 对有序 CellIds、球面顶点和半径的 SHA-256；重演必须相同 |

### EvolutionClock

| 字段 | 类型 / 默认 | 约束与语义 |
|---|---|---|
| StepIndex | long / 0 | >=0；提交一步才改变 |
| StepYears | long / 100000 | >0；初始化后冻结，不随播放倍速改变 |
| TimeMa | double / 派生 | StepIndex × StepYears / 1000000；乘法前转 double，整数计步须检查溢出 |

固定步长在初始化时验证最大位移不超过最小邻格距的 1/4；不满足则拒绝初始化，要求减小 StepYears，不在运行时隐式改变积分网格。累计不足整步的时间只存在 Control。时间跳转对齐固定步并显示实际目标，超过 long 范围则拒绝。

### PlateMotion

| 字段 | 类型 / 默认 | 约束与语义 |
|---|---|---|
| PlateId | int / 必填 | [0,P)，等于板块表下标；历史期间固定 |
| OmegaRadPerMa | SphereVectorD / 必填 | 三个有限 double；不是单位方向；允许零矢量 |
| Orientation | RotationD / (0,0,0,1) | X/Y/Z/W 四个 double；模与 1 的误差 <=1e-12 |
| IsActive | bool / 派生 | 是否还有材料；全被俯冲后 false，ID 仍保留，绝不复用 |

SpherePoint 的 X/Y/Z 为 double、模与 1 的误差 <=1e-12；SphereVectorD 也是 X/Y/Z，但无单位模约束。Orientation 是从 t=0 到当前的姿态；Fragment 的几何已在当前世界坐标中，禁止再次叠乘累计姿态。几何只承受当前步的增量旋转。

### CrustFragmentSet

| 字段 | 类型 / 默认 | 约束与语义 |
|---|---|---|
| CellStart | int[N+1] / 必填 | CSR，首项0、单调，末项等于片数 |
| Fragments | CrustFragment[F] / 必填 | 每格至少一片；总数 F 受 Int32 容量约束，越界失败而非丢片 |

Fragment 无持久全局 ID：引用键为 (StepIndex,CellIndex,LocalOrdinal)，仅该帧有效；裁剪/合并后不得拿旧序号指向新片。不承诺逐片家谱。H3 CellId 为稳定 ulong；CellIndex 只对当前网格有效。

### CrustFragment

| 字段 | 类型 / 默认 | 约束、单位与示例 |
|---|---|---|
| PlateId | int / 必填 | 当前宿主板块；陆—陆缩短后的转移必须保留材料体积 |
| Material | CrustType / 必填 | 复用 Oceanic、Continental；不允许未定义枚举 |
| ProvinceId | int / 必填 | 洋壳=-1，陆壳>=0；指向初始化来源省，省允许跨板块 |
| Footprint | SpherePoint[] / 必填 | 至少3顶点，当前世界坐标；球面测地弧、外向统一绕序、简单非退化，位于宿主格内；裁剪产生多连通区域必须拆片 |
| ThicknessKm | double / 必填 | >0；例如洋壳7、陆壳35；面积×厚度为当前材料体积 |
| BirthTimeMa | double? / null | 洋壳必填且<=当前 TimeMa；陆壳必须null；可为负以表达初始老海底 |
| ReferenceElevationM | double / 必填 | 随材料搬运的初始/新生基准高度；初始化取最终 HeightM，不再乘 VerticalScale |
| ReferenceThicknessKm | double / 必填 | >0；基准对应的壳厚，不因当前增厚改写 |
| ReferenceOceanAgeMa | double? / null | 洋壳>=0，陆壳null；基准高度对应的年龄，用于只计算后续冷却增量 |
| ExtensionStrain | double / 0 | >=0 的累计伸展应变；无量纲；新生洋壳清零 |
| TectonicReliefM | double / 0 | 有符号 m，随材料搬运的非均衡构造地形历史（如海沟挠曲、裂谷）；不包含已由厚度均衡计算的抬升 |
| VolcanicReliefM | double / 0 | >=0，随材料搬运的火山附加地形；不是物质体积账本 |
| VolcanicRateKmPerMa | double / 0 | >=0，本片当前火山厚度增生速率；0为不活动 |

AreaKm2 由 Footprint 在物理球半径上计算，不另存第二真源；VolumeKm3=AreaKm2×ThicknessKm；OceanAgeMa=TimeMa−BirthTimeMa。片是同材料的数值近似单元，不保证恢复每一份混合前的年龄谱。仅同 PlateId/Material/ProvinceId 且几何可拼接的片可聚合，厚度按面积加权，出生时间按材料体积加权，地形基准按面积加权；不得因“多数板块”而删除少数材料，跨板块聚合禁止。

高程是地形量，不是质量守恒量。当前片高程由基准高度、相对基准的壳厚/均衡变化、相对基准年龄的冷却变化、TectonicReliefM 和 VolcanicReliefM 派生。物理系数见 Spec。VolcanicReliefM 只表达未被平均壳厚刻画的局部地形分量，不得重复计算同一增生导致的均衡抬升。

所有面积加权地形字段包含 ReferenceElevationM、ReferenceThicknessKm、ReferenceOceanAgeMa、ExtensionStrain、TectonicReliefM、VolcanicReliefM、VolcanicRateKmPerMa。上述可聚合条件只是必要条件：首版只合并材料状态各字段完全相同的相邻片，不合并不同年龄或不同基准的片，避免非线性冷却导致人为高程漂移；此前的加权规则定义读视图/收支统计，不授权有损材料聚合。

稳定排序：各格按 PlateId、Material、ProvinceId、规范化几何顶点序、材料标量字段升序排列；环起点取 X/Y/Z 字典序最小顶点，保留统一绕序。几何及数值归并始终沿该序，不依赖线程完成顺序。BirthTimeMa 相同但其他字段不同的片仍分开保存。例中未列的基准厚度等于当前厚度，洋壳参考年龄等于样例时刻年龄，TectonicReliefM/火山/伸展缺省为0。

片的分裂保留材料标量并重新计算几何；碰撞后的宿主板块和局部厚度允许改变，来源省仍保留。任何材料/板块变化都必须对应已批准的构造过程，不能只为缩小数组而修改身份。

## 5. 派生视图与兼容

EvolutionProjection 包含以下只读数据；全都带同一个 StepIndex，不允许写回 Fragment：

| 字段 | 类型 / 约束 |
|---|---|
| PlateOfCell | int[N]；按材料覆盖面积取最大板块，平手取最小 PlateId |
| Crust | 现有 CrustField；主导壳型按覆盖面积取最大，平手取 Continental；陆壳省在主导陆壳材料中按面积取最大，平手取最小省号 |
| HeightM | float[N]；片高程按面积加权；double 转 float 前验证有限和可表示 |
| OceanAgeMa | double?[N]；格内全部洋壳按体积加权，纯陆壳为 null；混合格即使显示陆壳也可有洋壳年龄 |
| OceanicCoverage | double[N]，范围[0,1]；用于解释混合格年龄 |
| VolcanicRateKmPerMa | double[N]；按面积加权 |
| PlateBoundaries | 现有 PlateBoundarySet；主导板块归属的派生索引，非材料真源 |
| Boundary | EvolutionBoundaryField；与 PlateBoundaries 的边数和顺序一致 |
| TerrainFacts | 当前地形的海陆、陆块、海岸距离等，只读派生 |

CrustField 的 Type/ProvinceId/Provinces 保持现有契约。Provinces 保留初始化 ID、SeedCell、SeedPlateId；SeedCell 仅表示历史出生位置，不代表当前质心。CellCount 按当前“主导陆壳省”逐格重计，可为0，省表不压缩或重编号。未来输入必须通过投影视图获取壳型，不能同时把旧初始化 Crust 当当前真源。

主导板块边界会漏掉同一格内部的部分覆盖接触，因此碰撞、张裂与俯冲消解必须读取材料覆盖几何；禁止只靠 PlateOfCell 边界决定材料去留。逐边场用于宏观构造带与显示，不替代材料接触关系。

### EvolutionBoundaryField

数组均与当前 PlateBoundarySet.Edges 对齐。NormalSpeedKmPerMa、TangentSpeedKmPerMa 为 double[E]；法向按规范 CellA→CellB，负汇聚、正张裂；切向按中点外法向与法向的叉积确定正向。MotionKind 为 Inactive/Convergent/Divergent/Transform；ConvergenceKind 为 None/Collision/Subduction；UnderthrustingPlateId 为 int[E]，非俯冲=-1；陆陆碰撞不标作洋壳俯冲。低法向且低切向必须 Inactive，不冒充走滑。

为兼容现有三值 BoundaryKind，新增 Inactive 枚举值且更新全部消费者；不改变既有值的数值编码。现有 EdgeMotion 保留“无量纲初始地形控制量”含义，不能将 km/Ma 直接塞入它；演化展示和过程使用新的物理场。现有静态算子仅用于 t=0，不作为演化输入真源。

## 6. 地幔池、守恒账本与帧

### MantleReservoir

每份 EvolutionFrame 有且仅有一个全球被动物质池；不按格分布，不模拟地幔对流、温度、化学组分或动力学。不持独立 ID，生命周期跟随当前演化历史。入池后不保留原板块、省号和海底年龄；释放洋壳作为新材料从当前时间开始计龄。

| 字段 | 类型 / 默认 | 约束与语义 |
|---|---|---|
| StoredVolumeKm3 | double / 必填 | 有限且>=0，当前可供释放的库存；t=0 取 InitialMantleVolumeKm3 |

此处统一采用**等效材料体积**记账，池中 km³ 与地壳材料体积的换算比为1；不表达高压地幔实际几何体积，不能称作考虑密度相变的质量守恒。既有密度参数只服务均衡地形。若以后引入压缩、熔融产率或成分转换，需要重新审查质量模型。

EvolutionFrame 必填成员：Definition、Clock、PlateMotion[P]、FragmentSet、Mantle、Projection、Budget；Mantle 类型为 MantleReservoir，无默认空帧。Frame 的地质数据与对外 WorldFacts 必须对齐 StepIndex；WorldFacts 新增 Evolution 只读入口，初始化与后续都非空，诊断可读池库存。

### EvolutionBudget

以下字段全部为有限 double，单位 km³；初始/当前库存、流入流出字段均>=0，只有残差允许有符号：

| 字段 | 意义 / 零步值 |
|---|---|
| InitialCrustVolume、InitialMantleVolume | 冻结的零步地壳体积和地幔库存，历史期间不变 |
| PreviousCrustVolume、CurrentCrustVolume | 本步前后地壳体积；零步均等于 InitialCrustVolume |
| PreviousMantleVolume、CurrentMantleVolume | 本步前后地幔库存；零步均等于 InitialMantleVolume，Current 必须等于 Mantle.StoredVolumeKm3 |
| StepSubducted、TotalSubducted | 俯冲入池量，本步与累计；零步0 |
| StepReturned、TotalReturned | 其他有明确构造来源的回收量，本步与累计；零步0，与俯冲不重复计量 |
| StepNewOceanic、TotalNewOceanic | 从池释放并形成新洋壳的量，本步与累计；零步0 |
| StepVolcanic、TotalVolcanic | 从池释放并形成火山增生材料的量，本步与累计；零步0，不重复记已经计入新洋壳的量 |
| CrustResidual、MantleResidual、TotalResidual | 本步地壳、库存、合计残差，派生；零步0 |
| CumulativeResidual | 当前地壳+池库存减去初始总量，派生；零步0 |

记 I=StepSubducted+StepReturned，O=StepNewOceanic+StepVolcanic：

- CrustResidual = CurrentCrustVolume − PreviousCrustVolume − O + I。
- MantleResidual = CurrentMantleVolume − PreviousMantleVolume − I + O。
- TotalResidual = CurrentCrustVolume + CurrentMantleVolume − PreviousCrustVolume − PreviousMantleVolume。
- CumulativeResidual = CurrentCrustVolume + CurrentMantleVolume − InitialCrustVolume − InitialMantleVolume。

库存的独立初始/累计约束为 CurrentMantleVolume = InitialMantleVolume + TotalSubducted + TotalReturned − TotalNewOceanic − TotalVolcanic（容差内）。必须同时检查各分账和总账，不能让地壳正误差与库存负误差相抵后算通过。

### 物质边界与错误

- 俯冲材料从地壳移除时全部进入池；真实地质过程中明确退回的多余材料计 StepReturned，必须有对应地壳减少量。
- 碰撞与面积重映射本身不增加/减少材料体积；陆壳缩短通过面积减少、厚度增加表达，不将碰撞剩余材料默认丢入池。
- 数值覆盖误差、裁剪碎片或无来源的体积偏差不能当“多余物质”存池冲账，超容差仍失败。
- 新生洋壳和火山增生不再来自无限外部供给，必须有等量库存扣除。当前步入池量允许计入该步可用量，故释放约束为 O <= PreviousMantleVolume + I。
- 所有释放需求先合计校验，不靠遍历顺序抢库存。库存不足时整步拒绝并报告 InsufficientMantleMaterial；不产生负库存、不自动补池、不留下未填的海底空洞；最近合法帧不变。
- 零步地壳由初始化给定，不扣地幔池，二者共同构成封闭模型的初始总量。InitialMantleVolumeKm3=0 合法，但尚无回收时的新生请求会失败。
- 容量首版不设上限，也不加入独立释放速率参数；实际释放需求仍受扩张/火山过程决定，库存是总量约束而不是新动力源。

海底年龄是状态，不是守恒量，不将平均年龄相同宣称为保留完整年龄分布。

## 7. 配置字段（EvolutionSpec）

## 8. 控制状态与生命周期

EvolutionControl：Status 为 Uninitialized/Paused/Playing/Seeking/Faulted；RequestedYears 为 decimal 默认0（>=0，墙钟请求累计）；YearsPerSecond 为 double 默认1000000（有限且>0）；TargetStep 为 long? 默认null（仅 Seeking 时非空）；LastProblem 为 EvolutionProblem? 默认null（Faulted 时非空）。播放速度不写入物理定义，不影响重演结果。

合法转换：Uninitialized→Paused（初始化成功）；Paused↔Playing；Paused/Playing→Seeking；Seeking→Paused（完成或取消）；运行失败→Faulted；Faulted→Paused 仅允许显式确认并恢复最近合法帧，或重新初始化。初始化失败保持 Uninitialized 并返回错误；非法控制转换返回错误且不改变状态。暂停不清除小于一步的 RequestedYears；显式 Seek/重新初始化清零请求余量。取消跳转停在最近合法帧，不发布半步。

全局 Reset 创建新的 Definition 和 StepIndex=0，清理旧候选帧/请求；旧已发布帧在读者释放前保持有效。板块全部材料失效时保留 ID 和运动记录，不做自动合并/分裂。省表同样不重编号。参数修改只对下次重新初始化生效，播放倍率除外。

## 9. 校验与错误

EvolutionProblem 字段：Code（枚举）、Path（非空 string）、StepIndex（long >=0）、CellIndex（int?）、PlateId（int?）、Message（非空 string）、Actual（double?）、Limit（double?）；默认均无，必须按错误实际填入。Code：InvalidParameter、InvalidTransition、InvalidGeometry、InvalidCoverage、InvalidReference、NonFiniteValue、BudgetExceeded、InsufficientMantleMaterial、CapacityExceeded、TimeOverflow、UnsupportedModelVersion。

配置/初始化层拒绝非法参数和物理尺度；结构构造器拒绝不等长数组、非法引用、非有限数、非法枚举；候选帧提交校验覆盖面积、同格无重叠、账本残差、时间版本对齐。体积容差 = AbsoluteTolerance + RelativeTolerance×相关体积基准；同时校验单步和累计收支。超限不截断厚度、不删除材料、不自动改物理参数。

身份与几何不变量：每格片的并集覆盖完整格域且内部互不重叠（容差内）；全部材料在球面上恰覆盖一次；各片体积>0；板块号合法；陆壳来源省合法；洋壳 BirthTimeMa<=TimeMa；派生数组均与同一网格对齐；边界数据同一 StepIndex。

## 10. 序列化、迁移与所有权

本期只持久化 WorldSpec.Evolution 配置，不新增运行时存档。EvolutionDefinition.ModelVersion=1 是重演语义版本；未来存档需另立 schema，当前不得伪称 JSON 序列化 Frame 就能恢复。

旧参数档没有 Evolution 段时，使用新增 EvolutionSpec 的完整默认实例；显式 null 或非法字段值拒绝该候选参数装配并报告，不能半应用。未知字段沿用现有 JSON 严格校验。默认参数档补完整新段；现有用户档不自动写回或覆盖，只有用户主动保存才加入新段。新代码向旧代码回退前恢复备份参数档；旧代码会拒绝未知 Evolution 段。

WorldSpec.CopyTo、WorldParams 的段识别/路径解析/校验需同步支持 Evolution，数值解析补 long（StepYears），不能仅支持现有 int/float/double。冻结定义采用独立深副本，不修改现有 Active 的实例身份约定。不修改现有 Plate.Omega 的初始语义；物理角速度单独存放于 PlateMotion，单一比例转换，禁止混用不同单位。

运行时采用候选帧单写、已提交帧只读。集合对外用 ReadOnlyMemory/IReadOnlyList 等只读口，构造时复制外部输入或接收内部明确转移所有权的数据；仅 readonly 属性包住可写数组不算不可变。现有 WorldFacts 的公开数组因兼容保留，但发布后生产者不得再写，渲染线程不持有候选缓冲区。只有成功提交时才更换整帧引用；取消/失败释放候选而保留最近合法帧。回到零步通过冻结 Definition 重演，不依赖当前 UI 的可变参数。
