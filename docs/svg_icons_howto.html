扁平小图标是怎么制作的

三种主流做法 · 一条决定"像不像"的原理 · 专业流程五步

一、主流就三条路

做法 A · 矢量软件手绘

Figma / Illustrator / Inkscape

钢笔工具画贝塞尔曲线，用布尔运算（并集/挖空）拼出形体，调圆角与间距，最后导出 SVG。所有专业图标库都是这么产出的：统一网格 → 逐图标精画 → 社区审查。优势是任意定制，代价是手绘功夫。

适合：品牌定制、需要独特语义的图标
做法 B · 开源库换色即用

Phosphor / Lucide / FontAwesome

MIT 开源图标库（可商用）。一条命令拿到高质量 SVG 路径：api.iconify.design/ph/fist-fill.svg?color=%23c9a24d。质量由社区几千人打磨过，比手快，比手稳。

适合：通用语义（拳头/握手/金币/人群）
做法 C · 代码手写 path

SVG path / 程序化几何

直接写坐标：矩形=4点，圆=1圆+半径。几何规整的符号（建筑/货币/星）很轻松；但有生命感的形体（手/动物）极难——轮廓差一点，语义就翻车。

适合：几何符号、需要代码可控的场景

二、核心原理：扁平图标 = 轮廓即语义

扁平图标去掉了体积和光影，轮廓是唯一的信息通道。人眼识别不是"整体比对"，而是抓 2~3 个特征点——只要你把特征点画对，几笔就认得出；特征点画错，画得再精细也没用。

我第一版画的"拳头"：
宽横块 + 竖直柄
特征点 = 锤头 + 柄 → 人眼判定"锤子"
同一底座，什么都不是——
直到你加上特征点
轮廓本身没有语义
同样底座 + 3 个特征点：
四个指节圆 · 横搭拇指 · 短手腕
语义就从"锤"翻转为"拳"
虚线网格 = 8px 设计网格；红线 = 特征点所在位置

三、专业流程五步（图标库都这么走）

定语义

一个词说清它代表什么。"力量"还是"主权"？词不同，特征点就不同。

列特征点

解剖对象：拳头 → 指节/拇指/腕；银行 → 山墙/立柱/台阶。列不出来就先别画。

上网格

4px 或 8px 网格对齐，全组统一圆角、统一线宽或填充风格。

光学补偿

同尺寸下圆和方的"视觉面积"不同，要微调；整套图视觉重量一致。

导出复核

64px 下缩小到 16px 看辨识度，换底色看对比，同组并排看风格。

落到本项目：金币、银行、人群这类"几何符号"——特征点简单，代码手写稳（你已验证 OK）；拳头、握手这类"人体语义"——特征点藏在生物结构里，手写成本高、容错低，正确姿势是拉 Phosphor/Lucide 的填充版换色。刚才拉取失败只是网络证书问题（CRYPT_E_REVOCATION_OFFLINE），换网络或加 curl -k 即可，一条命令换全套，风格和原图高度一致。
