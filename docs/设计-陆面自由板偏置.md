# 设计：陆面自由板偏置（freeboard）

> 起因：同一 seed 的地形图上，大陆内部散着上百处「浅海」（res4：127 处、占陆地 2.7%）。
> 本文记录这个现象的真正成因、补的那一项、以及补上之后的读数与副作用。

## 一 成因不是 bug

陆面 = `LandBaseM`(9.6) + 三档噪声（σ ≈ 14.9 m），海面 0 切在分布的 **0.64σ** 处
⇒ 三成以上的陆壳落在水下。而**淹没位置由噪声决定，与离岸距离无关**：
大尺度那层（10,349 km）给出成片的沉没区，中 / 细两层（602 / 320 km）在内部撒出一颗颗小水洼。

真实地球相反：陆壳被浮力托在海面之上（陆壳厚 35 km / 密度小，洋壳 7 km），
被淹的陆壳几乎都在边缘（陆架 / 陆坡），内部只在克拉通盆地、裂谷、前陆盆地、冰盖压陷处成海。
这条「陆壳整体被托多高」的物理，原模型里没有对应项——三档变化场只管形状。

## 二 口径

```text
d_i   = 该格到最近洋壳格的大圆距离（km；多源 Dijkstra，截断 = FreeboardSpanKm）
t_i   = smoothstep(0, FreeboardSpanKm, d_i)        // 海岸带 ≈ 0，深内陆 = 1
lift  = FreeboardLiftM × t_i                        // 加在陆面基底上
```

- **用「到洋壳的距离」而不是「到海岸的距离」**：海岸本身是高度场切出来的（循环依赖）；
  洋壳位置是上游 ⓪ 的既有事实，且它正是大陆块体的边界——离它越远，陆壳越厚、越接近均衡面。
- **落点**：`LandFieldOps.Build` 里与三档变化场相加，因此发生在重映射、`aboveSea`、
  `OceanDepthOps` 之前 ⇒ 海岸线 / 陆架 / 离岸距离 / 世界事实全部按新海岸重算（与
  《设计-地形真实感改造》§8.1 对顺序的要求一致）。
- **关断**：任一项 ≤ 0 ⇒ 全 0，逐位回到旧世界。

## 三 参数

| 参数 | 出厂 | 含义 |
|---|---|---|
| `Terrain.FreeboardLiftM` | 12 | 深内陆的抬升量（生成基准米，×`VerticalScale` 20 ⇒ 240 m）；0 = 关断 |
| `Terrain.FreeboardSpanKm` | 1200 | 斜坡长：距洋壳多远涨到满值；取大陆半径的量级 |

## 四 实测（seed 42，res 4，4096×2048）

| 读数 | 改动前 | 改动后 |
|---|---|---|
| 陆地占比 | 27.4% | **37.1%** |
| 内陆水体 / 陆地 | 2.7% | **1.3%** |
| 内陆水体处数 | 127 | **85** |
| 中位水体面积 | 5,472 km² | 7,721 km² |
| 内陆水深度 | −20…−360 m | −20…−360 m（未变） |

深处的碎水洼基本消失，留下的是少数成片的内海；浅水带从「大陆内部撒点」变成「沿岸成环」。

## 五 已知副作用（都是这项的必然结果，不是缺陷）

1. **陆地占比 +9.7 点**：freeboard 的本义就是抬高陆壳——地球 29% 的陆地正是被它托起来的。
   37.1% 落在《设计-地形真实感改造》§6.1 给 `Earthlike`/`Pangea` 的 35–42% 验收带内。
2. **大陆合并**：最大陆块从 6.4% 涨到 12.5%——内海收窄后，原先被它分开的陆块连成一片。
3. **海岸线变粗、湾岬变小**：海面现在切在离洋壳几百公里的缓坡上，轮廓更贴大陆块体边界。
   想找回细碎湾岬，可仿照 `MountainBeltWarpKm` 给距离场加一层噪声偏移（尚未做）。
4. **不能靠压基线抵消**：`LandBaseM` 9.6 → 6.0 能把陆地压回 32.1%，但水洼反而涨到 46 处
   ——碎斑被推回海岸，等于用同一笔钱买回同一个问题。

## 六 调参

同一 seed 的扫描（**全为 res 3 / 2048×1024**，与 §四 的 res4 不同分辨率，陆地占比差约 2 点）：

| 配置 | 陆地 | 内陆水 / 陆地 | 水洼数 |
|---|---|---|---|
| `LiftM` 0（关断） | 26.7% | 2.3% | 42 |
| `LiftM` 8 | 33.0% | 0.7% | 43 |
| `LiftM` 12（出厂） | 35.4% | 1.8% | 28 |
| `LiftM` 16 | 37.2% | 1.5% | 20 |
| `SpanKm` 700 / `LiftM` 12 | 36.6% | 1.3% | 23 |

`LiftM` 8 与 12 之间有个台阶：抬不满时，斜坡中段的水洼只是变浅、并不消失，
数量降不下来；过了这个台阶，剩下的才是真正的大盆地（数量骤降、单块变大）。
