# 世界生成空间 · 04 · 山脉骨架（阶段 4，已落地）

> 定位：承接用户 2026-10-02 阶段 4 决策——**山脉 = 骨架 + 噪声细化**，噪声不决定山在哪里。
> 上篇：[03-地质区域](设计-世界生成空间-03-地质区域.md)（MOUNTAIN 区域 = 骨架宿主）。

## 0 一句话

每个 MOUNTAIN 区域生成一条**蜿蜒主脊**（球面曲线）+ 70% 概率一条**斜向分支**；逐格取到脊的最小角距 `d`，高度包络 = `exp(−d²/σ²) × 脊高`，再乘 ridged 噪声细化（`0.7 + 0.6×ridged ∈[0.7,1.3]`，均值≈1 保能量）——**骨架定位置与包络，噪声只造峰谷锯齿**。

## 1 决策逐条对照

| 决策 | 落地 |
|---|---|
| 4.1 主脊（Spline/Bezier 蜿蜒曲线） | 以区域质心（Lloyd 收敛种子）为锚、随机方位直线双向延伸 ±L/2，横向蜿蜒 = 低频 fBm 采直线基准点 ×260 km（**位置合成**而非增量积分——无漂移）；点列 ~20 km 步长 |
| 4.1 分支 | 主脊 1/3~2/3 段取点，行进切向在切平面内斜转 50°~105° 分叉；长度 ×0.45、高度 ×0.7、σ ×0.8（支脉更细更矮）；70% 概率 |
| 4.2 距离 → 高度 | `d = min(格, 脊点列)` 球面角距；`exp(−d²/σ²)`，σ 基准 130 km（山体半宽量级）× 抖动 |
| 4.3 ridged 只做细化 | `detail = 0.7 + 0.6×(1−\|n\|)²`——乘性调制包络（均值≈1），不参与定位 |
| 区域 = 控制图（03 §十八） | 只有 `RegionType.Mountain` 的区域生成脊；`AreaKm2` 调脊长（大区域山长）；`Region.Seed`（Lloyd 收敛位置）为脊锚 |

性格旋钮（`MountainSkeleton`，构造可覆写；面板接线走 S5）：主脊长 1400 km、脊高 4200 m、σ 130 km、蜿蜒 260 km。

## 2 实现决定（判读要知道的）

1. **性能**：逐脊**角帽预筛**（帽 = 脊点包围 + 3σ 余量；`exp(−9)≈1e-4` 截断）+ 海格跳过。res4 全链 11.8 s，骨架增量 ~0.1 s——空间索引待实测超预算再立（先对再快）。
2. **可见海拔合成**：`DisplayElevation = 投影基线 + 区域类型偏移（03 占位）+ 骨架加成`。峰顶 ≈ 2240 + 1500 + 5460 ≈ 9 km 量级——雪线白是山的直觉画面；S3 真实 Height Generator 落地时区域偏移撤位。
3. **测试球分辨率纪律**：res1 格宽 ~800 km >> 生产 σ 130 km——比格网还窄的山采不到。`MountainSkeleton` 构造器开放骨架性格覆写（测试用 σ×4），生产默认地球量级不变。
4. **蜿蜒是位置合成**：每步由"直线基准点采噪声得横移"直接合成，非行进增量积分——不会漂移出区域。

## 3 红线（测试钉死，7 例新增于 647 总盘）

1. 骨架存在性：MOUNTAIN 区域数 = 主脊数（控制图定山位）。
2. **逐格公式对照**（分辨率无关）：每个陆格加成 = Σ 脊 `exp(−d²/σ²)×H×detail`，值域带 [0.7,1.3] 精确包络。
3. 3σ 外加成近零（衰减 + 帽截断）；海格恒 0。
4. 陆格加成方差 > 0（ridged 细化生效——噪声是细化工具非定位工具）。
5. 同种子逐位同（脊点列/加成场）。

## 4 v3 重构（2026-10-03，特写判读驱动——「区域山脉场 → 纵向高度场 → 曲线支脉树」）

用户特写判读暴露三缺陷同根（主轴几何线+固定高度+随机支脉），按决策 04v2 §①-⑦ 系统重构：

1. **主脊纵向高度曲线**（治"脊线全线雪白"）：HeightM 常数 → 控制点（K=7，归一化到
   [0.45,1.0]——峰垭极差构造保证）+ Catmull-Rom 沿轴插值 + 轴向中噪声 ±15%；
   detail 从 ±55% 降到 **±8%**（detail 不再负责主起伏）。逐点高度随点列走
   （\`PointHeightM[]\`），采样取最近点的轴向高度。
2. **支脉曲线生长**（治"死直辐条"）：固定角度+直线 → **相关随机游走**（heading 动量 0.75
   + 小随机转角，主脊 ±0.045 / 支脉 ±0.11 rad/步）；支脉分级（一级 1~2 条 σ×0.55 长 0.3~0.5×、
   二级 2~3 条 σ×0.38 短）、**起点按主脊高程加权**（≥55% 基准高才 long 支脉）、
   高度沿支脉衰减（起点 0.8/0.6 × 末端 −45%）。
3. **方向场 + 排斥**（治"平行双 Range 无地质逻辑"）：主 Range 方位 = 陆块主轴（方向协方差
   PCA 幂迭代）± 30° 扰动 + 低频方向噪声 ±25°（本线无板块模拟——板块边界切向场是
   结构回归时的替换源）；System 间近平行排斥（中点距 <1400 km 且角差 <25° → 重掷 ≤6 次）。
4. **渐变雪线 SnowOverlay**（表现层，必须在最终高度之后）：硬阈值 2800 → smoothstep
   (局部雪线 ±250m)，局部雪线 = 2800 + 气候噪声 ±300m；渲染器把山地档色向雪白 lerp。
   已接 --maps/--cont 两渲染器；场景色带采纳走后续批次。

测试 +2（主脊峰垭起伏 ≥1.9×构造保证 / v3 逐格公式逐点高度口径），652 绿。

## 6 v3.2 构造骨架与地表表达分离（2026-10-03，跨海山系）

用户拍板核心规则：**不问"山脉能不能跨海"，问"这条构造山系在海洋中以什么形式表达"**——
骨架与地表表达分离，三层模型（Tectonic Range → Elevation Expression → Surface Features）：

1. **骨架跨海连续**：主脊/支脉行走不再感知陆海（陆格硬门控退役）；锚点仍在陆上
   （构造核心口径）。
2. **海洋表达式** \`OceanFactor(dir)\`：陆 = 1；海 = exp(−3t)，t = 归一化海深（海陆场 raw
   相对校准阈值）——浅海保留高（海底脊抬进岸棚档/露成岛链）、深海趋零（构造衰减消失）。
   连续无台阶 ⇒ 海岸附近无一刀切断头（§八）。
3. **支脉门控**：起点池过滤深海段（t > 0.5 不生支脉）——海底只保留主构造（§七）。
4. 合成接线：海格 = 投影海侧 + 山脊表达（HeightComposer 与 --cont 渲染器同源）；
   \`OceanFactor\` 升公共 API（渲染器/测试同源）。

验证：652 测试绿（加成有界/逐格公式含表达式同源）；seed 9 连续图可见浅海青色海底脊、
脊上岛链白点、深海衰减消失。**已知观感项**：海底脊呈细条青线（σ 160 的窄包络），读作
"发光虫"——后续可让海洋中包络展宽（σ×1.5~2）呈台地状，登记 T5。
