## 0 一句话

地形先在**连续空间**里由场函数叠加合成（空间函数，不建大数组、不依赖 H3），H3 六边形只是**采样结果**；水文等模拟直接长在 H3 邻接图上——「H3 不再限制地形生成算法，反而成为世界模拟的统一空间基础」。

## 1 三层 → 代码映射（全部已落地）

| 决策层 | 代码 | 契约要点 |
|---|---|---|
| ① 空间场（连续） | `scripts/noise_world/worldgen/SphericalField.cs` | 抽象 `Sample(单位方向)`；组合子族：`FbmField`（fBm）/ `RidgedField`（(1−\|n\|)^k ∈[0,1]）/ `WarpedField`（域扭曲，**amp=0 逐位退化直采**）/ `WeightedSumField`（负权重 = 减法）/ `PositiveField`（正瓣） |
| ② 组合 | `scripts/noise_world/worldgen/ElevationFieldStack.cs` | `Elevation = 大陆基(扭曲fBm) + 山脉(ridged) + 高原 − 盆地 + 细节`，输出**米域**（海平面 0）；种子经 `DeterministicRandom` **固定次序**派生（W1/W2/W3→大陆→山→高原→盆地→细节，增删场不挪已有层的场） |
| ③ 离散化（H3 采样） | `scripts/noise_world/worldgen/H3TerrainSampler.cs` | 单点（格心）/ 多点（格心+角点加权，`CenterWeight` 默认 0.5；五边形按实际角数均分）；格值恒在采样点 min/max 包络内 |
| ④ H3 图上模拟（水文） | `scripts/noise_world/worldgen/H3Hydrology.cs` | 单流向（**严格下降**边 ⇒ 无环；平局取格索引最小；海格 = 出口）+ 汇流累积（`FlowAccum = 1 + Σ上游`，海格恒 1）；内流洼地登记 `SinkCount`（填洼/湖面留后续） |

参数表 `WorldGenParams`（同文件）：框架期独立小表，**不接** `[NoiseParam]` 面板（现役 `TerrainNoiseParams` 是噪声地形线的单一事实源，两表不共享实例）。

## 2 红线（测试钉死，20 例全绿于 617 总盘）

1. **确定性**：同种子同方向逐位同；`Sample` 无状态（交错采样不改结果）；水文同输入逐位同。
2. **解耦**：场不依赖 Ball——同 res 不同半径实例采样一致（容差 = 方向浮点差 × 振幅的量级论证，实测 0.016 m / 断言 0.1 m）。**换 res 不动生成算法**的地基。
3. **组合子不变量**：ridged ∈[0,1]、正瓣 ≥0、域扭曲 amp=0 逐位等价直采、加权和 = 手工线性对照、米域值域被振幅和包络。
4. **水文不变量**：流向严格下降（无环的三色标记全图验证）；`FlowAccum` 精确递归式；海格恒 1 不接收；单峰岛链全部到海；平原全 sink。
5. **多点采样**：格值 ∈ 采样点包络；`CenterWeight=1` 逐位退化为单点。

测试：`WorldGenFieldTests` / `H3TerrainSamplerTests` / `H3HydrologyTests`（`tests/World.Tests/`）。

## 3 与噪声地形线的关系（并存，不互改）

- **现役渲染链不动**：`NoiseWorld.tscn → NoiseTerrain`（域内秩 + 板块身份定海陆 + 地球 LUT）保持原样，597 旧测试全数保留通过。
- 本框架初版场源全部 = 噪声，海陆 = **米域 0 横切**（无板块身份）——这是框架与现役线的**已知语义差**，不是缺陷：身份定海陆（"是什么就是什么"）与地球 hypsometry 基线是语义升级，走迁移（见 §4）。
- 两线共享的资产：`SphericalFbmNoise`、`DeterministicRandom`、`Ball`（H3 球壳数据层）。

## 5 差异登记（框架实现 vs 决策原典文字）

- 原典示意 `Field(x, y)` 平面函数 → 落地为**球面单位方向** `Sample(Vector3)`（3D 噪声直采 |p|=1，无接缝无极点畸变；与现役采样入口 `Ball.CellDirs` 同构）。
- 原典"多点采样 center/north/south/east/west" → 落地为**格心 + H3 角点**（六边形自然角采样，五边形 5 角）。
- 原典伪代码 `find lowest neighbor` 未定义平局/洼地 → 本框架补**严格下降 + 平局格索引最小 + sink 登记**（确定性优先）。
