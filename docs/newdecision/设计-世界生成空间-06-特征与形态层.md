# 世界生成空间 · 06 · Field + Feature + Morphology（架构决策，已落地骨架）

> 定位：承接用户 2026-10-03 架构决策——**"区域"不该是所有地形生成的统一空间单位**。
> 大陆/山脉/丘陵/盆地/峡谷/火山天然不同尺度、不同形状、不同边界；强行依附 Region
> 就是"先切块再往块里塞地形"。正确分层：**Field（原因）→ Feature（对象）→ Morphology
> （生长规则）→ Terrain Field（高度贡献）**。
> 上篇：[04-山脉骨架](设计-世界生成空间-04-山脉骨架.md)（v3.2 已是事实上的第一个 Feature+Morphology）。

## 0 一句话判断（决策 §十）

> **Region/Field 回答"这里发生什么事情比较容易"；Feature 回答"具体形成的东西长什么样"。**
> 两种信息彻底分开；不存在万能地形区域公式（§十一：山脉用沿线坐标 s+d、盆地用局部
> 2D、火山用径向 r/θ、河流用流线 s+d、海岸用离岸距离 d）。

## 1 落地代码映射

| 层 | 代码 | 职责 |
|---|---|---|
| **Field** | `TectonicField`（新） | 陆块主轴（PCA）、**构造强度连续场**（区域类型 → 基值：Mountain 1.0 / Highland .75 / Rift .7 / Plateau .6 / Plain .35 / Basin .3 / Coastal .2，Shepard 帽插值，跨海连续）、锚点池 + 强度加权选址、方向扰动噪声。**只回答"哪里容易"，不负责任何形状** |
| **Feature** | `TerrainFeature` 基类（新）：Anchor / OrientationRad / **Intensity（场读数）** / **Scale3（纵/横/垂三元组）** / 预筛帽；`MountainSystemFeature : TerrainFeature`（第一个完整 Feature，骨架 Generate 时注册，Scale = 脊长/2σ/脊高） | 离散地质对象的公共身份 |
| **Morphology** | `MountainSkeleton`（重构定位）：中心线随机游走 + 轴向高度曲线 + 支脉树 + 海洋表达式——**MountainRange 的生长规则**；实现 `IHeightContribution`（`Sample(dir)` 统一口） | "这个东西具体长成什么样" |
| 合成 | `HeightComposer`（不变） | 只认 `IHeightContribution`——特征内部形态对合成器不可见 |

## 2 这次重构改变了什么

1. **环境场上收**：PCA/方向噪声/锚点池从 MountainSkeleton 肚子里抽出为 `TectonicField`——未来盆地/火山/峡谷的 Feature **直接读同一构造场**（`IntensityAt` + 各自阈值），不碰总架构。
2. **选址语义升级**：山脉锚点从"池内均匀随机"改为**强度加权**——山真的长在"构造强度高"的地方（Field 的"原因"语义第一次闭环）。
3. **身份与形态分离**：`MountainSystemFeature` 只携带身份（锚/走向/强度/尺度），形态数据（点列/剖面/支脉）留在 Morphology——将来序列化/调试/UI 逐层可查。
4. **GeologicalRegions 降级为轻量背景**（决策 §六 TectonicDomain 方向）：仍产出区域类型与基础高度，但不再约束 Feature 形状——山脉本来就跨多个区域（v3 事实），现在架构上也承认了。

## 3 红线（+4 例于 656 总盘）

强度场 ∈[0,1] 且造山带中心 > 0.4；主轴单位/零口径；锚点池不跨陆块不含海格；同种子场逐位同。

## 4 数据语义链重构（2026-10-03，决策 07——用户五步方案落地）

上轮分析的三症状（掩码分裂/三口径/双重计入）同根：**缺少明确的数据语义链**。整体落地：

**数据链固定为**：Base Terrain → Placement Geography（生成依据）→ Landform Generation
→ **FinalHeight**（唯一地表真相）→ **Final Geography**（FinalLand/Landmass/Region/Coast
——世界事实）→ World Simulation（水文/气候/生态只认这层）。

1. **双掩码拆分**：`PlacementLand`（投影器改名，生成依据——特征抬升前的状态，不再进入
   下游）vs `FinalLand`（新 `FinalGeography`：最终高度 > 0 派生——**山脊抬出的岛屿自然
   成为正常陆地**，掩码分裂问题构造性消除）。`FinalLand ⊇ PlacementLand`（MinLand 钳制
   推论，测试钉死）。
2. **唯一海陆口径**：`SurfaceResolver`（RawAt/IsPlacementLand/OceanFactorAt/BathymetryAt）
   ——山脉海洋表达式、深海剖面、海岸衰减全部走它；`OceanFactor` 独立实现删除。合成器
   逐格分支判据改用**放置区域掩码**（多点口径与选址同源——单点口径在海岸与掩码不一致
   的教训进代码注释）。`--cont` 降级为表现层（逐像素读 `SampleSurface`，同一世界真相）。
3. **目标绝对高度语义**（替代"+N 米增量"）：`IHeightContribution` → `ITerrainField`
   （`(influence, targetM)` 对）；`SampleSurface` 执行 lerp 链：
   `h = Base → lerp(PlateauTarget 2050) → lerp(BasinTarget 350) → lerp(MountainTarget
   4200×profile) + large/medium/detail`——**峰高只有一个语义来源**（调脊高不再牵动基座）。
   RegionalLandforms/MountainSkeleton 全部迁移（高原顶面 ±12% 即 Flatness 语义）。
4. **FinalGeography**：FinalLand 连通分量陆块、双向海岸距离、最终区域归属（山脉新增
   岛屿 → `RegionIndexAt` 归入最近构造域）。
5. `HeightComposer.SampleSurface` = **最终地表连续单一事实源**（表现层同读；两口径差异
   仅限掩码边缘格，各自内部自洽）。

测试 +4 于 660（FinalLand⊇Placement / 陆块完备 / 海岸图距 / 同种子）；HeightComposer/
MountainSkeleton 测试全面改写为 lerp 链精确界口径。**登记 T7**：`PlacementLandFraction`
现为 0/1 粗粒度占位（连续分数化走多点采样器重构）。

## 5 后续特征接入指引（决策 §八的兑现路径）

新增一种地形 = 三步，**零总架构改动**：
1. `XxxFeature : TerrainFeature`（身份 + Scale3：参考 §二尺度表——山间盆地 50-300/20-100 km、火山 5-30 km、峡谷 50-500/1-20 km）；
2. Morphology 生成器（自己的参数化：盆地=局部 2D 帽、火山=径向锥、峡谷=沿线负贡献）；
3. 在 `HeightComposer` 加一项贡献（或并入既有特征组）。
RegionalLandforms 的高原帽/盆地下挖即此模式的既有实例（未继承基类，迁移登记 T6）。
