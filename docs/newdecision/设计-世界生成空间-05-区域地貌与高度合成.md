## 0 合成总公式（决策 §六，唯一海拔出处）

```
Height = continent（投影大陆基线）
       + mountain（山脉骨架，阶段 4）
       + plateau（高原帽，阶段 5）
       − basin（盆地下挖，阶段 5）
       + regionalNoise（区域细节 ±80 m）
```
合成后 1 pass 图上平滑（`h' = 0.6·h + 0.4·邻居均值`，仅陆格参与——海岸线不模糊）。
`HeightComposer.HeightM` 是**唯一**逐格海拔出处（视图/信息卡/判读都读它）。

## 1 阶段 5：区域地貌场（RegionalLandforms）

| 场 | 驱动 | 形态 | 参数 |
|---|---|---|---|
| 高原帽 PlateauAddM | PLATEAU 区域 | 区域尺度高斯帽（σ = 区域等效半径 ×1.25）：全区抬成台地、边缘平滑降坡；顶面 ±18% 中频噪声（"┌─┐ 但不是完美平顶"） | 台面 1150 m（基线 ~940 → 台面 ~2000 高地档） |
| 盆地下挖 BasinDipM | BASIN 区域 | 同构反向（"\＿＿/"） | 中心下挖 520 m |

**盆地泛滥双保险**（决策 §七警告：盆地大量生成 ⇒ 河流系统大量孤立内流盆地）：
① 配额压到 0.06；② **每陆块硬上限 `MaxBasinsPerLandmass = 2`**——超上限的 BASIN 区域保留类型标签但不生成场（应用计数 `AppliedBasinsPerLandmass` 可查）。

HIGHLAND / PLAIN / COASTAL / RIFT 暂不生成大尺度场（基线 + 细节噪声呈现；裂谷条带留后续）。

## 2 阶段 4 连带修正（"雪山圆盘"根因）

用户截图判读：雪线白占可见陆地 ~40%、无峰谷无山链。三层全是加法且无谷：

1. **大陆基线压低**：投影层陆侧映射 2240 → **940 m** 顶——`ContinentalElevation` 回归"丘陵以下"语义（阶段 6 公式的第一项），山/高原由后继场拔起，基线自己不进高地档。
2. **MOUNTAIN 区域常数偏移退役**：`TypeElevOffsetM` 全表删除（它把整个区域先抬 1500 m，未算骨架已过雪线）——区域类型改为**驱动场**：MOUNTAIN→脊、PLATEAU→帽、BASIN→挖。
3. **峰谷对比拉大**：脊高 4200 → 2400 m；detail `0.7+0.6×ridged` → **`0.45+0.55×ridged`**（峰谷比 2.2:1）——脊带内部峰 ~3300 过雪线、谷 ~1980 不过，山链在雪线上下穿越，`/\/\/\` 形态成立。

## 3 红线（测试钉死，5 例新增于 651 总盘）

1. 合成公式**平滑精确界**：逐格 `band = ±noise + (1−SmoothSelf) × 邻居代数和极差`（盆边/山边邻居差数百米，带宽逐格算——固定带宽会被平滑突破）。
2. 方向性：高原场覆盖格均值 > 陆地均值 > 盆地覆盖格均值。
3. 盆地上限：`AppliedBasinsPerLandmass` ≤ 2/陆块（直接读应用计数——帽覆盖跨区域格，按格统计会虚高）。
4. 海格 = 投影原样（陆上合成不污染海洋深度剖面）。
5. 同种子逐位同。
