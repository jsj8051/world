## 0 合成总公式（决策 §六，唯一海拔出处）

```
Height = continent（投影大陆基线）
       + mountain（山脉骨架，阶段 4）
       + plateau（高原帽，阶段 5）
       − basin（盆地下挖，阶段 5）
       + regionalNoise（区域细节 ±80 m）
```
合成后 1 pass 图上平滑（`h' = 0.6·h + 0.4·邻居均值`，仅陆格参与——海岸线不模糊）。
`HeightComposer.HeightM` 是**唯一**逐格海拔出处（视图/信息卡/判读都读它）。

## 1 阶段 5：区域地貌场（RegionalLandforms）

| 场 | 驱动 | 形态 | 参数 |
|---|---|---|---|
| 高原帽 PlateauAddM | PLATEAU 区域 | 区域尺度高斯帽（σ = 区域等效半径 ×1.25）：全区抬成台地、边缘平滑降坡；顶面 ±18% 中频噪声（"┌─┐ 但不是完美平顶"） | 台面 1150 m（基线 ~940 → 台面 ~2000 高地档） |
| 盆地下挖 BasinDipM | BASIN 区域 | 同构反向（"\＿＿/"） | 中心下挖 520 m |

**盆地泛滥双保险**（决策 §七警告：盆地大量生成 ⇒ 河流系统大量孤立内流盆地）：
① 配额压到 0.06；② **每陆块硬上限 `MaxBasinsPerLandmass = 2`**——超上限的 BASIN 区域保留类型标签但不生成场（应用计数 `AppliedBasinsPerLandmass` 可查）。

HIGHLAND / PLAIN / COASTAL / RIFT 暂不生成大尺度场（基线 + 细节噪声呈现；裂谷条带留后续）。

## 2 阶段 4 连带修正（"雪山圆盘"根因）

用户截图判读：雪线白占可见陆地 ~40%、无峰谷无山链。三层全是加法且无谷：

1. **大陆基线压低**：投影层陆侧映射 2240 → **940 m** 顶——`ContinentalElevation` 回归"丘陵以下"语义（阶段 6 公式的第一项），山/高原由后继场拔起，基线自己不进高地档。
2. **MOUNTAIN 区域常数偏移退役**：`TypeElevOffsetM` 全表删除（它把整个区域先抬 1500 m，未算骨架已过雪线）——区域类型改为**驱动场**：MOUNTAIN→脊、PLATEAU→帽、BASIN→挖。
3. **峰谷对比拉大**：脊高 4200 → 2400 m；detail `0.7+0.6×ridged` → **`0.45+0.55×ridged`**（峰谷比 2.2:1）——脊带内部峰 ~3300 过雪线、谷 ~1980 不过，山链在雪线上下穿越，`/\/\/\` 形态成立。

## 3 红线（v1，5 例；v2 后口径见 §5）

1. 合成公式**平滑精确界**：逐格 `band = ±noise + (1−SmoothSelf) × 邻居代数和极差`（盆边/山边邻居差数百米，带宽逐格算——固定带宽会被平滑突破）。
2. 方向性：高原场覆盖格均值 > 陆地均值 > 盆地覆盖格均值。
3. 盆地上限：`AppliedBasinsPerLandmass` ≤ 2/陆块（直接读应用计数——帽覆盖跨区域格，按格统计会虚高）。
4. 海格 = 投影原样（陆上合成不污染海洋深度剖面）。
5. 同种子逐位同。

## 5 v2 系统级重构（2026-10-03，批量判读驱动）

100 张批量判读图暴露"宏观结构已有、空间尺度与高度范围没匹配全球视觉尺度"四症状（山太窄少/盆地不可见/大陆内部平/高原像斑点）——四症状同根，按决策 05v2 §①-⑦ 系统级重做（非调参）：

1. **Region Base Elevation**（§九/§十）：每区域一枚基础高度（七类位域：Plain 80-450 / Highland 500-1100 / Basin 150-600 / Mountain 900-1600 / Plateau 900-1700 / Rift 100-500 / Coastal 20-120，区内随机取值），经**归一化高斯帽插值**（σ = 等效半径×1.4，向邻区溢出重叠）展开成连续场 `BaseElevationField`——大陆内部大尺度梯度、无色块拼接（§十一）。
2. **MountainSystem 跨区域**（§一/§三）：数量由**陆块尺度**定（`k = clamp(√面积/2000 × random(0.8,1.2), 0, 4)`/陆块），不再由 MOUNTAIN 区域数决定；轴起点 70% 从 MOUNTAIN 区域格抽（控制图仍定"哪里适合山"）；每 System = 主 Range（σ~250 km 山脉带、长轴跨区域 ≤4000 km）+ 2~3 支 Ridge（σ ×0.32 脊线级）——System→Range→Ridge 三层宽度（§二）。
3. **Plateau/Basin 大尺度化**（§十五）：帽 σ 下限 1200/1000 km（大面积影响场非斑点）；盆深 700 m。
4. **合成公式升版**（§十二）：`H = H_region(插值场) + H_mountain + H_plateau − H_basin + H_large(260/5000km) + H_medium(130/600km) + H_detail(80/90km)`——尺度纪律 large > medium > detail；投影层陆侧基线退役（H_region 取代）。
5. **海平面保底**：陆格钳 ≥ 30 m——盆地挖穿 + large variation 曾使内陆出现大片"蓝色内流海斑"（物理不成立；低洼语义由 relief 承载）。
6. **判读图 relative relief 调色**（§六/§七）：`relief = h − 同域邻域均值`，明暗 ×[0.78,1.18]——绝对高度给基础色、相对高度调明暗（盆地 380 m 也读得出低洼，不染棕）。

读数：脊数 9.2 → **43-70** 条/世界（System 化）；651 测试绿；100 张 `userdata/maps/batch100/`（1024×512 等距圆柱，relief 调色）。测试口径更新：主 Range 数 ≤ 4×陆块数（跨区域语义）；合成带宽含三档 variation；Range/Ridge 宽度层级比 ≥2.0。

## 6 连续查询口重构（2026-10-03，架构债清偿）

用户判读点破架构债：概念上各层是连续场，但输出接口全是逐格数组——H3 采样渗进了每个模块的
Generate 入口，「连续世界 → H3 只是采样」停在口号上。重构后**每层暴露连续查询口**，逐格数组
降级为「该连续函数在格心的一次采样」（单一事实源，数组与连续图构造上不打架）：

| 层 | 连续口 | 数组的地位 |
|---|---|---|
| GeologicalRegions | `RegionIndexAt(dir)` / `BaseElevationAt(dir, fallback)`（Shepard 帽插值） | `BaseElevationField` = 采样 |
| MountainSkeleton | `HeightAddAt(dir)`（帽预筛 + min 角距包络 × ridged 细化） | `ElevationAddM` = 陆格采样 |
| RegionalLandforms | `PlateauAt(dir)` / `BasinAt(dir)`（帽列表驻留） | `PlateauAddM/BasinDipM` = 采样 |
| HeightComposer | `SampleLand(dir, …)`（§十二公式连续形态 + 海平面保底） | `HeightM` = 采样 + 1 pass 图上平滑 |

图上平滑归位为**离散化后处理**（抗混叠），连续场本身不含；海侧公式常数经 `SeaSpreadUsed` 回读
（海陆同源）。新验证口：`--cont=seed` 逐像素直接采样连续场出图（等距圆柱），与 H3 版同世界
可并排判读——海岸无格锯、山链平滑、区域内梯度连续。测试 651 绿（数组=采样，逐位同）。
