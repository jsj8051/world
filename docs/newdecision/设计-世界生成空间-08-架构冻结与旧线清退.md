## 2 Field / Feature / Morphology 三层（永久）

| 层 | 回答 | **不回答** | 代码 |
|---|---|---|---|
| **Field** | 哪里容易发生什么（构造/环境背景） | 任何形状 | `TectonicField`（连续场 `Sample(dir)`） |
| **Feature** | 具体生成了什么（离散对象，自带尺度/走向/影响场） | 为什么长在这里 | `MountainSystemFeature` / `PlateauFeature` / `BasinFeature` / `VolcanoFeature` |
| **Morphology** | 这东西具体长成什么样（生长规则） | — | 各 Feature 文件内的骨架/帽/锥体生成 |

- 最小公约数：`TerrainFeature.cs` 仅 59 行（`Scale3` / `TerrainFeature` / `ITerrainField`）
- **组合器只认 `ITerrainField`口**：`(influence, targetM) = SampleAt(dir)`
- **绝对高度 lerp 语义**（取代"+N 米增量"）：
  `FinalHeight = lerp(当前, TargetM, Influence)` ⇒ **峰高只有一个语义来源**
- 特征优先级（成文的约定，非实现偶然）：**列表后位覆盖先位**
  `Mountain(4) > Basin(3) > Plateau(2) > Base(0)`
- **不存在万能地形区域公式**：山脉用沿线坐标 s+d、盆地用局部 2D、火山用径向 r/θ、
  河流用流线 s+d、海岸用离岸距离 d

## 3 River 2 水文契约（v2，永久）

### 3.1 四个水系统概念不互相吞并

| 类型 | 职责 | **明确不承担** |
|---|---|---|
| `RiverGraph` | 河流**内部**拓扑（source/downstream/confluence/tributary/trunk/outlet） | 不管流域归属、不管湖泊 |
| `BasinGraph` | 流域**归属与终止** | **不判湖** |
| `LakeState` | 湖泊**状态**（内流盆地是否成湖 + 水量平衡） | 不重定义河流 |
| `WaterTopology` | 水体**之间的连接**（组合层） | 不重定义河流/湖泊 |

### 3.2 依赖契约（编译期钉，16 条架构测试）

| 契约 | 内容 | 测试名 |
|---|---|---|
| **§2** | `RiverNetwork` **不得依赖** `FinalSpatialIndex` —— 基础水文拓扑由自身 flow graph 决定，索引只做二级操作 | `RiverNetwork_OnlyDependsOnFinalLayer` |
| **§2A** | 水文**只消费** `annualPrecipMm` 数组；降水来源已拍板 | `Hydrology_DoesNotReferenceLegacyClimateLine` |
| **§2C-A** | `BasinGraph` **不依赖** `Lake` —— `termination ≠ lake` | `BasinGraph_DoesNotDependOnLake` |
| **§3.8** | `BasinGraph` 是**流域拓扑，不是 Lake**：原子事实（`TerminalCell` / `TerminatesAtOcean`）**优先于** `Kind` 分类 | 同上|
| **§2C-B** | `LakeState` 必须消费**原始地形**的内流洼地分区，不是路由表面上的 BasinGraph | `Hydrology_ReadsFinalHeightButNotSynthesis` |

### 3.3 沉淀的永久验收原则：nearest 必须验"距离 + 身份"

> **所有 nearest 查询必须同时验证距离正确与对象身份（label）正确。**
> BFS 结构对而 label 错时，distance 全对但"是谁"失效。
>
> **实测教训**：河流 label 恒 0 时全部 dist 正确、`NearestRiver` 恒返回格 0。
> （钉在 `SpatialIndexTests.NearestRiver_MatchesBruteForce_IdentityAndDistance`）

### 3.4 D-11 双高度语义（永久）

```
FinalHeight (Composer.HeightM)      ├── 地貌/ 渲染 / 判读 + LakeState 原始洼地语义
                                     └── (填洼后) HydrologyRoutingHeight ──→ FlowDirection / Basin / FlowAccum
```

- **填洼是水文计算的派生预处理**，不是世界地形被填平；**绝不回写 `FinalHeight`**
- `DepressionCount` / `FillDepthM` 始终基于**原始**高度
- `DefaultUseDepressionFill` = **true**（显式 `false` 是退化/诊断模式）
- ★**D-16 教训**：填洼只改"水怎么走"，不改"湖是否存在"。
  若 `LakeState` 从路由表面的Basins 派生 ⇒ **开启填洼后内流湖全部消失**（实测 3,671 → 0）

## 4 ★B 线清退（2026-10-05 用户拍板 · 本次新增）

### 4.1 判定问题与回答

> **判定问题**："B 线（`World.NoiseWorld` 旧单体噪声线）是不是仍然代表 Final 世界事实的一部分？"

**回答：不是。** 它的海陆语义（板块身份定海陆）与新架构（连续场 + 分位校准）
**是两种范式**，不是等价替换：

| | B 线（旧） | 新架构 |
|---|---|---|
| 海陆来源 | 板块身份（离散，**每板全同**） | 连续场**分位校准** |
| 陆地占比口径 | **陆板数**占比（面积跟随吞并结果） | **面积**占比（可控） |
| 能否分出半岛/海湾 | **不能**（一块板必全陆或全洋） | 能（连续场） |
| 高度合成 | 增量叠加 `elev += shape * belt * M` | **绝对高度 lerp** `lerp(当前, TargetM, Influence)` |

⇒ 走清退路径（承 `07 §10` 四步法）：**① 非生产 ✅ → ② 非 Final 真相源 → ③ 有限兼容 → ④ 删除**。

### 4.2 B 线命运定义（正式）

```
NoiseWorld（World.NoiseWorld 旧单体）
│
├── 生成逻辑→ 清退
│   NoiseTerrain（L0-L5 噪声栈）/ NoisePlates（板块八次迭代）
│   NoiseClimate（温度风降水群系）/ TerrainNoiseParams（双事实源）
│   NoisePlanet / NoiseWorldManager（已被 WorldGen* 重写）
│
├── 参数 / UI  → 清退
│   NoiseParamPanel + NoiseParamAttribute（反射面板，唯一消费者=旧场景）
│
├── 场景      → 清退
│   scenes/core/NoiseWorld.tscn / scenes/noise_world/NoiseParamPanel.tscn
│
└── 表现资产  → **保留并去噪**（有真实消费者，生成语义为零）
    ├── NoiseBallView → Render.BallView + Render.CellQuery
    ├── NoiseMapMode  → Render.MapMode（基类 + 两个色带常量）
    ├── NoiseDock     → Render/UI（信号出口）
    └── NoiseCellPanel→ Render/UI（哑组件）
```

> ★**现状标注（2026-10-09）**：`Render/UI/` 的语义已明确收窄为「**可挂场景的哑组件（Node）**」——
> 上表两项 `MapDock` / `CellInfoCard` 均为 `: PanelContainer`，符合；
> 而地图坞驱动类 `MapDockController`（普通 C# 类·**非 Node**，独占坞的状态机）**不属此类**，
> 已从 `Render/UI/` 移入 **`scripts/Render/Controllers/`**（ns `World.Render.Controllers`）。
> 该目录**刻意只有一个文件**，是对"各目录 1 文件 = 纯层级噪声"的一次用户拍板例外，
> 理由是类目语义明确（"非 Node 驱动"），后续同类应归此，而非为单个类临时开目录。
> ⇒ 表现层子层现为平级三类：`.UI`（哑组件）/ `.Controllers`（驱动）/ `.Constants`（共享常量）。

> **定义**：不是"把旧线迁到新线"，而是"**从旧线上回收仍有消费者的纯表现抽象，然后删除旧线**"。

### 4.3 ★实测修订：表现资产是 **4 类**，不是 2 类

迁移评估报告初版断言"新线只依赖 `NoiseBallView` + `NoiseMapMode` 两类"，**该结论错误**。
由契约测试 `NewWorldLine_MayDependOnApprovedRenderContracts` 实测抓出：

主入口场景 `WorldGenWorld.tscn` 的面板层实际挂的是**旧线脚本**：

```
WorldGenWorld.tscn:6  ext_resource → scenes/noise_world/NoiseCellPanel.tscn
                                            → NoiseCellPanel.cs
WorldGenWorld.tscn:7  ext_resource → scenes/noise_world/WorldGenDock.tscn
                                            → NoiseDock.cs（仅场景根节点改名 WorldGenDock）
WorldGenManager.cs:18,19,32,36  NoiseCellPanel _cellPanel; NoiseDock _dock;
```

两者经核实为**纯哑组件**（生成语义为零）：
- `NoiseDock`：只发 `ModeSelected(int)` 信号 + 按鼠标更新按钮高亮，**不认识任何生成类型**
- `NoiseCellPanel`：只被喂 `ShowCell(id, lat, lng, elevM)`，**不感知星球与相机**

> ★★**方法学教训（比这个具体结论更重要）**：
> 依赖扫描**必须同时覆盖 `.cs` 与 `.tscn`**。Godot 的**场景挂载本身就是引用边**——
> `WorldGenManager` 引的是 `NoiseDock`/`NoiseCellPanel`，只grep 类名会漏掉整个 `.tscn` 引用面。
> 本次错误正是"用 `NoiseWorldManager|NoiseBallView` 搜索"造成的。

### 4.4 ★表现层例外契约（允许清单 vs 禁止清单，双向钉）

新线命名空间 `World.NoiseWorld.WorldGen` 是旧线 `World.NoiseWorld` 的**子命名空间**
⇒ C#作用域规则让新线**不加 `using` 就能直接看到**父命名空间的类型
⇒ `NewWorldLine_DoesNotDependOnLegacyWorldLine` 的四命名空间黑名单
（`World.Biome` / `MapGen` / `MapView` / `Tectonics`）**完全管不到这一条**。

⇒ 把例外**正式编码**（不再靠命名空间黑名单隐式放过）：

|方向 | 内容 | 测试名 |
|---|---|---|
| **允许** | `NoiseBallView` / `NoiseMapMode` / `ElevationBandMode` / `NoiseDock` / `NoiseCellPanel` | `NewWorldLine_MayDependOnApprovedRenderContracts` |
| **禁止** | `NoiseTerrain` / `NoisePlates` / `NoiseClimate` / `TerrainNoiseParams` / `NoisePlanet` / `NoiseWorldManager` / `NoiseParamPanel` / `ElevationFieldStack` | `NewWorldLine_MustNotDependOnLegacyGenerationTypes` |

两个测试都**按类型名匹配**而非 `typeof` —— 清退是"先加新 → 切消费者 → 再删旧"，
写 `typeof(旧类)` 会让迁移中途类型消失时测试编译不过。

### 4.5 ★双事实源（同名不同义）

`TerrainNoiseParams` 与新线的 `LandFraction` **同名不同义**：

| | 口径 |
|---|---|
| 旧线 `LandFractionTarget` | **陆板数**占比（面积跟随吞并结果） |
| 新线 `LandFraction` | **面积**占比（`H3LandSeaProjector` 分位校准） |

**同为 0.29 时两者结果完全不同** ⇒ 误接会**静默改掉海陆比，无任何运行时症状**。

此前这条边界只有 `ElevationFieldStack.cs:74` 的一句注释保护，现升级为硬契约：
- `NewWorldLine_MustNotDependOnLegacyGenerationTypes`（禁引用 `TerrainNoiseParams`）
- `LandFraction_IsAreaBasedNotPlateCountBased`（**直接实测**新线侧确实是面积口径）

| 河流表现 | res 无关连续中心线 + 屏幕空间符号宽度；**不表达物理河宽** | ✅ FROZEN |

⇒ 这四项**不得被任何子系统反向绑架**。水文有效工作尺度偏 res2 是
**模型的尺度适配缺陷**，正确处置是让水文适配 res4，**不是把世界降级到 res2**。

### 防膨胀三问（建任何"层"之前必过）
1. **能否由既有事实表达？**（能 ⇒ 加字段/查询，**不加层**）
2. **能否由组合层表达？**（能 ⇒ 放 `WaterTopology` 一类）
3. **现在有真实消费者吗？**（没有 ⇒ **不建**）

### 两条元原则
1. **退化解原则**：新物理量/权重/场进入既有算法，必须有可验证退化解
2. **原子事实优先于分类**：分类不得覆盖事实
