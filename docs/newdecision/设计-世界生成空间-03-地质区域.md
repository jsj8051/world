# 世界生成空间 · 03 · 地质区域（阶段 3，v2 已落地）

> 定位：承接用户 2026-10-02 二次决策（§一~§二十完整 pipeline）——区域系统是**大尺度空间骨架/控制图**
> （"这个位置倾向出现什么地形"），**不是板块模拟、不是地形标签**；先划分区域、再决定类型。
> v1（同日早）的"逐格最近种子 + argmax 定类型"按新决策重做；大陆归属的数学圆弧问题一并修正。

## 0 v2 修订的动因（用户截图判读）

v1 出图暴露两个结构问题：① 「大陆」模式下连片陆地内部出现**未扭曲 Voronoi 的数学圆弧**归属分界；
② 区域边界生硬、大小无结构。根因 = 归属判据在未扭曲坐标 + 区域系统只有"最近种子"一层。
v2 按决策 20 步 pipeline 全量重做。

## 1 v2 pipeline（决策 §二十 的落地对照）

| 决策步骤 | 落地 |
|---|---|
| ② Poisson Disk 区域种子 | 最小角距拒绝采样（`PoissonMinGapKm=900`），候选从**本大陆真实格集合**抽取 ⇒ 种子必在大陆内（嵌套性构造保证） |
| 种子数 = area/target × random(0.8,1.2) | `TargetRegionAreaKm2=400 万`（地球量级），抖动 ±20%（决策 §四：不同世界不总刚好 N 个） |
| ③ Seed Weight = BaseSize × SizeNoise | 低频 fBm（8000 km 波长）采种子位置 ⇒ 大小变化**空间连续**（相邻区域相关，防"巨大区域贴细条区域"，§六） |
| ④ 加权 Voronoi（score = distance/weight） | `RegionAt`：本大陆种子中 argmin(扭曲角距/weight) |
| ⑤ Lloyd Relaxation 1~2 次 | `LloydIterations=2`：种子 ← 区域质心（H3 格心均值），收敛即停（moved 检测防过度规则，§七） |
| ⑥ Boundary Domain Warp | 区域边界专用扭曲场（2500 km 波长、700 km 幅度，独立于海陆扭曲）；**查询在连续扭曲坐标上判** |
| ⑨ Region Field → H3 Sampling | H3 格只是连续场的查询点（§九）——**不在格上改归属** ⇒ 区域不破碎 |
| ⑦ 邻接图 | H3 边扫描建区域邻接（`Region.Neighbors`） |
| ⑧ Features | `Region`：`AreaKm2 / LatitudeRad / CoastDistanceKm / Continentality / Neighbors / Weight`（§十的表，ruggedness/elevationPotential 留 S3 随 Height Generator 落地） |
| ⑨⑩ 打分 + 全局配额 | 五因素打分（距海岸/面积/纬度/邻接/随机基座）+ **配额缺口修正**（`TypeQuota={plain .35, mountain .15, highland .15, plateau .10, basin .10, coastal .10, rift .05}`，缺口×权重进分——统计先验非机械，§十七） |
| Softmax 概率选型（§十五） | `P ∝ exp(score/T)`，T=0.35，DeterministicRandom 累计抽样（确定性）——COASTAL 最高分也可能偶成 PLAIN |
| RIFT 硬约束（§十四） | 不邻接高地系（Highland/Mountain/Basin）⇒ 概率置零——地质结构逻辑 |

## 2 连带修正：大陆归属扭曲化

`ContinentId` 从"未扭曲格心 argmax"改为**海陆场同系扭曲坐标上的锚点归属**（`LandSeaField.SampleWarpDir` 新公共口）——大陆分界与海岸线弯曲同源，v1 的数学圆弧消失。这也是 §九"先连续场再采样"在阶段 1 层的兑现。

## 3 语义纪律（决策 §十八，必须长期守住）

**RegionType ≠ TerrainType**。区域类型是控制层（MOUNTAIN_REGION ⇒ Height Generator 生成山链骨架 ⇒ HIGH_MOUNTAIN/FOOTHILL/VALLEY…），不是地图标签。当前 `TypeElevOffsetM` 常数偏移（±1.5 km）只是占位表现——S3 用真正的山脉/盆地生成器按区域类型定幅，届时撤偏移。

## 4 读数与红线

- res4 实测：29.0% 陆、**32 区域**（面积口径）、11.7 s 全链。
- 测试 9 例（641 总盘）：嵌套性逐格、区域数面积口径（粗粒度 < 细粒度）、Features 物理单位值域、同种子逐位同（含 Lloyd 后种子）、类型多样性、**RIFT 硬约束**、COASTAL 近海中位、合成海拔逐格精确。
