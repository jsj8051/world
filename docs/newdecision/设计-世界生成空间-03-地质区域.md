# 世界生成空间 · 03 · 地质区域（阶段 3，已落地）

> 定位：承接用户 2026-10-02 追加决策 §五——"地壳划分"思想的**生成辅助层**（明确不叫板块模拟、不是模拟）：
> 加权 Voronoi 在大陆内生成 `GeologicalRegionId`，类型按**五因素约束式打分**分配（明令不纯随机）。
> 上篇：[02-海陆结构](设计-世界生成空间-02-海陆结构.md)（阶段 1+2）。

## 0 一句话

两级 Voronoi：第一级 = 大陆锚点（阶段 1），第二级 = 大陆内区域种子（从**本大陆真实格集合**抽取 ⇒ 区域永不跨大陆）；每区域按 距海岸/区域大小/大陆位置/邻接/随机权重 五因素打分定类型，区域类型调制可见海拔（Northern Highlands / Central Plains / Basin 的画面雏形）。

## 1 与决策逐条对应

| 决策要求 | 落地 |
|---|---|
| 加权 Voronoi → GeologicalRegionId | `GeologicalRegions`：区域种子带 weight ∈[0.8,1.2]，归属 = 角距/weight 最小（乘法加权，与阶段 1 归属同哲学） |
| 七类型 PLAIN/HIGHLAND/BASIN/MOUNTAIN/PLATEAU/RIFT/COASTAL | `RegionType` 枚举 + 打分表 + `TypeElevOffsetM`（区域调制海拔） |
| 不直接随机赋类型 | 打分制：约束项为主（①–④），随机权重只做基座扰动（⑤，幅度 0.35 < 任意约束项满值） |
| 根据大陆位置 | 质心纬度因子（低纬内陆偏 PLATEAU）+ 大陆嵌套（区域先随大陆定域） |
| 根据距离海岸 | `relCoast` = 区域平均离海跳数 / 全球最大（沿岸 → COASTAL 平方拉力；内陆 → HIGHLAND/PLATEAU） |
| 根据区域大小 | `relSize` = 区域格数 / 所在大陆均值（大区域偏 PLATEAU、小区域偏 BASIN）+ 区域数按大陆面积定（`CellsPerRegion` 粒度旋钮，2–8 区域/大陆） |
| 根据邻接关系 | 区域邻接图（H3 边扫描）+ pass3 调制：邻接高地系 → MOUNTAIN/BASIN 加分，按 RegionId 序贪心定案（山脉连绵涌现、确定性保持） |
| 根据随机权重 | 每区域每类型一份 `DeterministicRandom` 固定次序扰动；RIFT 双重随机门槛（稀有偶发） |

## 2 关键实现决定

1. **种子从本大陆格集合抽取**（best-candidate 候选 = 大陆真实格心）：区域种子天然落在大陆势力内，嵌套性由构造保证（测试逐格验证）。
2. **贪心定案序 = RegionId 升序**：邻接加分读已定案邻居 ⇒ 单调确定；代价是邻接语义在编号序上非对称（框架期接受，登记为后续可改空间序——按质心纬度排序等）。
3. **区域调制海拔**：`ElevationM = 投影海拔 + TypeElevOffsetM[区域类型]`（Plain +120 / Highland +650 / Basin −450 / Mountain +1500 / Plateau +950 / Rift −280 / Coastal 0）——辅助层量级（±1.5 km），真实地形高度仍是后续阶段（01 §4 S3）。视图吃合成海拔 ⇒ 区域感直接上画面。
4. **粒度旋钮**：`CellsPerRegion`（默认 4500 格/区域；res4 ≈ 18–21 区域全洲）——res1 测试球按 ~120 缩粒度验证全链。

## 3 场景与判读

- `WorldGenPlanet.Regenerate` 串联：锚点 → 场 → 投影 → 地质区域；视图海拔 = 区域合成版。
- 点格判读行升级：`land / 大陆 / 区域N(类型) / 离海 / 离岸 / elev`。
- res4 实测：29.0% 陆、**21 区域**、11.5 s 全链（区域层 +0 s 级：O(格 × 本大陆种子数)）。

## 4 红线（测试钉死，8 例新增于 640 总盘）

1. 分区：陆格全覆盖 / 海格 −1；**区域不跨大陆**（嵌套性逐格验证）；区域数每大陆 ≥1 且 ≤8；同种子逐位同（区域号/类型/质心/合成海拔）。
2. 类型：七类表内；小球种子下 ≥2 种类型（防全 Plain 假通过）；COASTAL 区域平均离海 ≤ 全体中位；MOUNTAIN 必邻接高地系。
3. 合成海拔 = 投影 + 区域偏移（逐格精确）；高地系区域海拔均值 > 平原系。
