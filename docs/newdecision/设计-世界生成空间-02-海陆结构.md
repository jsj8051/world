## 0 一句话

先撒**大陆锚点**（蓝噪声，不挤簇），每锚点带 size/shape/rotation/coastComplexity；影响场叠低频噪声 + 域扭曲 + 中/小三尺度调制出**海陆结构**（只管 LandMask/ContinentId/离岸距离，不管高度）；H3 采样离散化，分位校准精确钉死海陆比；主场景已切 `WorldGenWorld.tscn`。

## 2 关键实现决定（判读时要知道的）

1. **海陆比分位校准**：连续场阈值 0 只是形状语义；精确占比在离散层钉死——全格采样排序取 `1−target` 分位为阈值（继承现役「目标陆地占比」滑块的精确可控性）。res4 实测 29.0% 对 29% 目标。
2. **归属判据归一化**（踩坑修正）：影响场值 = `weight × smoothstep`（强度语义），但**归属 = argmax smoothstep（除以权重）**。若用未归一化影响判归属，长条大邻（拉伸 2.2）的尾巴在 0.4 rad 外仍有 ≈0.8 影响强度，能吞掉远端锚点的全部领土——归一化后每锚点中心恒归属自己（Voronoi site 保证，测试钉死）。
3. **ContinentId 用未扭曲格心方向**：大陆归属是板块感分区，不被海岸噪声撕碎；海岸线扭曲只作用在 LandMask 上。
4. **多点采样进投影**：投影默认 `CenterAndCorners`（格心+角点加权）——海岸阈值横切处不因格心恰好落在脊上而突兀（原典 §五的可检验代理：阈值附近擦边格数不多于单点模式）。
5. **性能读数**：res4 288k 格全链 11.9 s（多点采样 7 点/格 × 每点 5 组噪声查询）。优化空间明确（锚点影响预筛、采样去重），框架期不做。

## 4 红线（测试钉死，15 例新增于 632 总盘）

1. 锚点：同种子逐位同；数量；蓝噪声间距 ≥0.4 rad；属性值域；切向轴正交。
2. 影响场：锚点中心影响 ≥ 自身权重；外推单调不升；归属中心恒自身。
3. 海陆场：同种子逐位同；扭曲幅度 0 改变场；值域被权重上界 + 噪声幅度包络。
4. 投影：海陆比命中目标 ±2pp（29% 与 60% 双点）；海拔符号 ⟺ Land；ContinentId 陆全覆盖/海 −1；距离源侧 0 / 对侧 ≥1；BFS 图距递推；同输入逐位同。
5. 多点采样：两种模式都过校准门 + 擦边格代理断言。

测试：`ContinentLayoutTests` / `H3LandSeaProjectorTests`。
