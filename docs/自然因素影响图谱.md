# 自然因素影响图谱

> 2026-08-16 建立。列出**项目中的所有自然因素**，每个因素标注：
> **影响它的因素（来源）+ 影响程度（量级）+ 影响方式（物理机制/公式）**。
> 与 `气候反馈环.md` 配套：反馈环 = 本图谱中成环的路径；本图谱 = 全部因素影响全貌。
> 数值均来自代码标定（改系数须同步两处文档）。

## 1. 海拔（地形）

| 影响它的因素 | 影响程度 | 影响方式 |
|---|---|---|
| 板块构造（位移场）| ±9km | 碰撞隆升 / 裂谷沉降（板块模拟 Displacement）|
| **自然侵蚀-堆积（四介质搬运）** | 山地 −1~3km / 低地 +堆积 | 板块模拟每步 `ApplySurfaceProcesses`：**水蚀**=**产流**（Budyko：它随 PET 走，干旱 ⇒ 严格 0）+**风蚀**=干燥度×裸露度×环流带风强+**重力**=超门槛落差（不需要介质）+**冰川**=低温×积雪；四者再乘**岩性 K**。高格减/低格加，物质守恒。**v1.21 已落地**（产流 + 闭合降水 + K），见 §18 |
| 河流侵蚀/堆积 | 河谷 −1~2km / 三角洲 +堆积 | 动态流向 + 输沙侵蚀沉积（Stage2）|
| 海平面 | 0 参考 | 海拔 = 位移 − 海平面（水量守恒重解）|

它影响：温度（−6°C/km）、降水（抬升增雨 + 雨影）、生物群系（高山/冰盖）、河流（流向）、土壤（坡度惩罚）、大陆性（到海岸距离）

## 18. 侵蚀堆积（地表搬运，**四介质**：水 / 风 / 重力 / 冰川）

> **v1.21（2026-09-18）已落地**：侵蚀从"一个写死的全局常量降水当门"改成**按介质**——介质不存在，
> 该介质的侵蚀就**严格为 0**（不是"很小"）。判据在 `H3SurfaceProcesses`（`ErosionMedium`），
> 读口 = `HexDynamicDiag` 的 `[侵蚀介质]` 行 + `--precip=0`（干世界 A/B）。
> **v1.21 相对 v1.20 的三处"去无中生有"**（用户 2026-09-18 的判据："不要无中生有"）：
> ① 水介质改吃**产流**（Budyko）而不是"降水÷本行星均值"——后者会把绝对水量抹掉；
> ② 降水用**闭合后**的（全球 Σ = 洋面蒸发总量，λ）；③ 新增**岩性可蚀性 K**。

| 介质 | 门（什么才有它） | 强度 | 依据 / 落地常量 |
|---|---|---|---|
| **水**（坡面径流） | **产流** `R = P·(1 − 1/√(1+(P/PET)²))`（`P → 0` 或 `PET ≫ P` ⇒ **严格 0**） | `R / 467.5`（截顶 1.5）× **K** | Budyko/Turc-Pike；`RunoffRefMmPerYear=467.5` = 参考气候（P=1050、T=10°C）的产流 |
| **风**（风蚀） | 环流带风强 × **干燥度**（= `1 − AI = PET/(P+PET)`，**有界**）× **裸露度** | 0.5× × **K** | §18「风强 × 干旱度」+「biome 裸露」；`WindErodibility=0.5`，风强按带档（Hadley 0.6 / Ferrel 1.0 / Polar 0.8） |
| **重力**（块体运动/崩塌） | 格间落差 > 门槛（**不需要介质**，也不乘 K） | 3×（超出部分） | 陡崖崩塌；`GravityReliefThresholdM=1500` / `GravityErodibility=3` |
| **冰川**（冰蚀） | 年均温 < 0°C **且** 有降水（雪） | `2 × min(P/1050, 1)` | 冰下磨蚀+拔蚀；`GlacierTempC=0` / `GlacierErodibility=2` |
| **PET / AI**（新，v1.21） | `PET(T) = 700 × 2^((T−10)/10)`（C-C 式，mm/yr）；`AI = P/(P+PET)` | — | `H3Climate.PetMmPerYear` / `AridityIndex` / `RunoffMmPerYear`（纯函数，演化步与终态同源） |
| **K 岩性可蚀性**（新，v1.21） | 柱内**软/硬物质厚度占比**：软 = 沉积物/沉积岩、硬 = 变质岩 | `clamp(1 + 1.5·f软 − 0.6·f硬, 0.5, 2)` | 盆地充填后变软（易被冲开）、变质盾地变硬（留住高地）；**不需要新场**（从 5 个守恒池派生） |
| 坡度 | 主控（四介质共用的搬运形状） | ∝ 高度差（相邻下坡） | 四介质都沿"落差"搬运，只是各自的**门与倍率**不同 |
| 裸露度 `(1−V)` | 由 **AI 分档插值**（沙漠 1.0 / 草原 0.6 / 森林 0.1） | 只作用于**风**（§18 的 biome 裸露只挂风；见下面的拍板项） | `H3Climate.BarenessFromAridityIndex`；真 biome 层落地后改读 V |
| **风蚀：沿风场搬运/风弱落沙** | ∝(1−局部风强) | 黄土/沙丘带 | **未做**：与坡面搬运是不同的**拓扑**（沿风场），属下一批（河流输沙已有同型"沿流向+落淤"） |
| 板块模拟侵蚀阶段 | ErosionScale 倍率 | `ApplySurfaceProcesses` 每步（ModelErosion/ModelWeathering/成岩/变质） | |
| 河流（输沙）| 河谷 −1~2km / 三角洲 +堆积 | 动态流向侵蚀/沉积（`H3FluvialTransport`）| 已是"按降水门 + 沿流向搬运 + 落淤"。⚠️ 它仍吃**未闭合结构场**（把 λ 折进 `CarryCoef`，既有约定）；侵蚀侧已改吃闭合场 ⇒ 两者差一个 λ 常数（见登记） |

**标定纪律（关键）**：**没有归一化**。参考气候（P = 1050 mm/yr、T = 10°C ⇒ PET = 700）下
`产流 = 467.5` ⇒ 水介质 = 1（与 v1.19 那个全局常量口径同源）；但这颗行星实际有多少水、多热**真的进强度**。
⚠️ v1.20 那版按"降水 ÷ 本行星域均值"归一 ⇒ **绝对水量被抹掉**：只有地球 1/3 雨量的世界照样按地球强度被蚀
——那正是"无中生有"，已删除（`WaterWeightAbsolute` 这个分叉不再存在）。

**降水的闭合（v1.21，关键）**：`H3Precipitation` 出的是**未闭合结构场**（只定"雨下在哪"，总量不定）。
每步按 `λ = EvapRefMmPerYear × 洋格数 / Σ结构场` 闭合（`Σ降水 = 洋面蒸发总量`，`H3WaterCycle` 同口径）
⇒ 侵蚀的水介质吃 `λ × 结构场`。实测本行星 **λ ≈ 1.5~1.7**（结构场把雨量低估了 ~1.6 倍）：
闭合后陆面平均降水 **≈ 710 mm/yr**（结构场原值 390）——**这之前侵蚀强度锚在一个偏小的任意尺度上**。

**与 §18 原文的有意偏离**（都留了旋钮）：
1. 局地降水权重下限取 **0**（原文 0.2）——口径是"介质不存在则不为该介质"；下限 0.2 会让**无水世界照样被水蚀**，
   与"无水世界必须零水蚀"的诉求冲突。要原文值把 `WaterWeightFloor` 调到 0.2。
2. 风强按**环流带档位**取——本模型 `H3Wind.WindAt` 返回**单位向量**（只出方向不出风速）。**拍板项**：
   风场出风速场后改为直接读。
3. **`(1−V)` 只挂在风蚀上**（原文只给风蚀挂了 biome 裸露；用户 2026-09-18 的新提案把 `(1−V)` 也挂到水蚀上）。
   挂水蚀会与 1.5 截顶叠加成 10 倍量级的重标定（森林 AI≈0.6 ⇒ 裸露度 0.1）⇒ **待拍板**：
   若确认挂水蚀，`RunoffRefMmPerYear` 要同步重定。现用 `BarenessFromAridityIndex` 的 AI 分档当代理。

**实测（res3 / 8 板 / seed42 / 600 My，v1.21 产流口径）**：
`[侵蚀介质]` 份额 = 水 26~43% / 风 13~39% / 重力 1~41% / 冰川 20~29%；
介质率（陆格均值）水 0.31~0.45、风 ~0.22、冰 ~0.20；**K 1.000 → 1.072**（沉积盆地随演化变软）；
闭合 **λ ≈ 1.53~1.71**、闭合降水 **706~719 mm/yr**、**产流 291~339 mm/yr**（产流/降水 ≈ 45% ✓ 地球 ≈ 40%）、
**AI ≈ 0.31~0.39**、**零产流格 1~4%**（干旱格：PET ≥ P ⇒ 水蚀严格 0）。

| v1.20 四介质·归一 | 382 / 2329 / 4328 | 19.4% | 5491 | 82 / 1089 / 10042 |
| **v1.21 四介质·产流** | **263 / 2675 / 4229** | **18.3%** | **5656** | **101 / 1226 / 10803** |

读法：p90 一路上升（2220 → 2675，**起伏被保住**）、max 一路下降（4796 → 4229，**尖峰被削**）——
这正是四介质 + 挠曲想要的形状变化；但 **陆占比一路下降**（23.4% → 18.3%，海平面 +784 m）——
**总侵蚀仍然偏强**，与"大陆半沉/整片绿平板"是同一件事（05 §13.3 #16），仍需拍板调 `ErosionScale`。

**同一行星档设 `--precip=0`（无水世界，`PrecipitationScale`）实测**：份额 =
**水 0% / 风 30~100% / 重力 0~70% / 冰川 0%**（无雪），风化仍在（机械风化靠风 ⇒ 判据口 2~5e6）、
地形仍在演化（600 My：陆海拔 p50 299 / p90 2926 / max 4192 m）——**无水世界不会被冻成静物**，
这正是这次改造要的东西：重力份额从 step 1 的 0% 涨到 65~70%（构造造出陡边后块体运动接管）。
⚠️ 注：`--precip=0` 只关**降水**；真正的"无洋壳 ⇒ 无蒸发 ⇒ 无降水"还需要一个行星档预设
（`OceanFraction=0` 那条路），登记为下一项。

**还没清的"无中生有"候选（登记，未改）**：`ModelWeathering` 的粗糙度输入是**全图平均高差**
（`avgDiff`，每个出露基岩格都按**全球**均值高速率风化，与该格自身坡度/降水无关）——这是老树的标定公式。
按"侵蚀需要介质/局部条件"的本意，它该换成**局地**量（该格坡度或局地降水）。改动会动沉积物收支
⇒ 与 §13.3 #16 一起拍板。

它影响：海拔（山地夷平/低地堆积）、土壤（坡度/冲积）、沉积（三角洲/冲积平原）、矿藏（变质/沉积矿化）
