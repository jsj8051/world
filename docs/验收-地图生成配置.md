# 地图生成配置验收

状态：第 6 步待用户验收。源码运行验证通过；Windows 独立发布包验证未完成，不能视为需求全部验收通过。

## 运行入口

环境：Windows、.NET 8 SDK、Godot 4.7.1 Mono。主入口为 `scenes/app/AppRoot.tscn`，在 Godot 编辑器按 F5 启动；不要 F6 单跑配置页，配置会话由 AppRoot 注入。

路径：主界面 → 地理演化 → 生成地图配置页 → 生成（默认配置已应用，无需先点应用）。

- 默认配置：会话创建即为已应用状态，进入配置页直接可生成；改过控件仍需应用。
- 应用：仅本次运行生效，不写盘；重启后回到默认配置（默认配置仍视为已应用）。
- 保存：必须命名，长期保存编辑中的配置，但不隐式应用。
- 已选档案点击保存会更新原档案；另存为创建新档案。
- 选择档案只填入草稿。配置与已应用值不同时，生成提示先应用。
- 配置值只用数值或下拉。档案名称允许文字。

## 自动验证

仓库根目录执行（仅对子进程允许本地脚本，不更改系统执行策略）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify-config.ps1 -GodotExe 'D:\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe' -GenerateWorld -Capture
```

其他机器请替换 Godot 控制台程序路径。不需要真实生成时省略 `-GenerateWorld`，不需要画面截图时省略 `-Capture`。

2026-11-10 实测：147 passed / 0 failed；Release 构建 0 警告 0 错误；Godot 交互 PASS；跨进程写入及重新读取 PASS；res4 288122 格真实生成 PASS（seed=777）；有画面 OpenGL Compatibility 运行 PASS。截图保存到 `tests/generation-config-check.png`，未进行人工目视审查。

持久化自动验证使用 `userdata/configs/verification/profiles.json`，只更新该测试目录的 Verification Islands 档案，不覆盖正式 `userdata/configs/generation_profiles.json`。测试不清除此文件，方便重复检查。正式与测试均写游戏目录，不写 `res://` 或 AppData。

## 布局

- 配置项按三列排布：每个 Tab 用 `GridContainer(columns=3)`，每格是“标签 + 控件”的纵向单元，海陆/地形两项、气候三项各自并排。
- 配置卡片铺满整个窗口：卡片直接铺满视口，只有主题面板自身的内边距，不再居中收缩。
- 配置页签区吃掉剩余高度，左侧已保存配置列表与右侧设置区同高。
- “返回主界面”在左下角，“生成”在右下角，两者分列页脚两端。

## 配色与可读性

验收反馈“主题配色太阴间、看不清”属实，已修正。原因是配置页用了深色背景 `(0.12, 0.14, 0.13)`，而应用主题的文字是深褐色 `(0.227, 0.173, 0.102)`，形成深底深字；页签还漏配了主题项，落到 Godot 默认深色主题的浅色字上。

修正内容：

- 配置页背景改为与地图库一致的棕色底，内容放进浅色面板卡片，文字落在浅底上。
- 为页签、输入框、下拉菜单、对话框补全浅色样式与深色文字，命名对话框不再走默认深色外观。
- 应用主题正文字号 16 → 18，配置页各控件同步加大，窗口缩小时仍可辨认。
- 错误提示改为深红，避免浅底浅字。

实测对比度（WCAG 正文门槛 4.5:1，均为文字色与底色的实际主题值）：

| 位置 | 对比度 |
|---|---|
| 页面正文 | 8.03:1 |
| 配置列表 | 8.03:1 |
| 按钮 | 11.43:1 |
| 选中页签 | 12.37:1 |
| 未选页签 | 5.22:1 |
| 文本输入框 | 12.37:1 |
| 命名对话框 | 8.03:1 |

这些断言已写进自动检查（`RequireReadableContrast`），后续改主题若掉到 4.5:1 以下会直接失败。截图：[配置页 2560×1440](<tests/generation-config-check-2560.png>)、[配置页 1280×800](<tests/generation-config-check-1280.png>)、[主界面](<tests/main-menu-check.png>)、[地图库](<tests/map-library-check.png>)。像素统计确认旧深色底残留 0.00%、浅色面板占 93%。

## 已知限制

- 首次生成使用原有同步初始化，可能短暂阻塞界面，本轮没有重构生成管线。
- 档位表达倾向，不保证精确大陆面积或全球均温。映射数值已有测试，跨所有种子与档位组合的视觉/性能校准未穷举。
- 截图已生成但当前执行模型不支持读取图像，不能声称目视排版验收通过。
- 损坏目录会禁止覆盖以保护旧档，界面显示加载错误；文件恢复需用户处理，不提供自动修复。
- 尚未做打包版、不同DPI及极窄窗口的人工验收。第6步仅增加测试、夹具、说明，没有修改业务代码。
