## 1. 职责与输出

- 输入：`Ball`（N 格：格心/邻居表/格 id）、板块数 P（≤ N）、陆性比例 `LandFrac`、seed。
- 输出（一次性静态生成）：
  - `PlateId[]`：每格归属板块，**铺满全球**（下标与 `Ball.CellIds` 对齐）；
  - Crust 料场初值（入口 §3：Felsic/Mafic/Sediment/Age）；
  - `Elevation[]` 海拔场初值（米，0=海平面；入口 §3.1——v1.1 增补）；
  - 板表：每板记录（Id、Seed=种子格心方向、陆性标记 IsLand、Ω/R 占位——本阶段无运动，占位字段为将来扩展预留）。
- 渲染（NewBall 默认模式）：**海拔全域材质 + 边界描边带**，见 §5。
- 本模块**无演化步进**；海拔场（v1.1）随厚度场一并产出初值。**v1.3**：起伏由姊妹文档 **02** 的要素生成器在**同一次生成内**增量添加（运动学/分类/地形写入全在 02；纪律口径按入口 v12 §1 纪律 4 修订——海拔写入须可追溯机制）。

## 2. 生成算法（一次静态生成；v1.2 重写——弃胞切分，直接长在格上）

```
1. 选板块种子格：DeterministicRandom(seed) 从 N 格无重复抽 P 个格
   （partial Fisher-Yates，rng 消耗固定 P 次 → 确定性；种子格心 = 该板 Seed 方向）
2. 种子归并生长（加权区域生长，铺满全球，直接长在 Ball.CellNeighbors 格邻居图上）：
   未归属格表 unclaimed；每板块维护边界格表 frontier[p]（初始 = 种子格的未归属相邻格）
   循环直到无未归属格：
     总权重 = 各板边界格数之和 → 前缀和随机落点选板（富者愈富：大板边界大 → 抽中概率高，
     板块大小自然有方差——用户拍板 09-07）
     板内随机弹 1 个边界格归本板（该格从 unclaimed 移除，其未归属相邻格加入 frontier[p]）
   → 板块连通、覆盖全球、每格恰属一板；大小/形状由随机生长顺序自然不规则
3. 海陆赋性：同一 DeterministicRandom(seed) 续流，逐板块掷 LandFrac 概率
   → 每板块为「陆性」或「洋性」（seed 定局：同 seed 全球同局）
4. 料场初值（两级跳变，入口常量：陆 35km / 洋 7km，过渡区不预置）：
   陆性板：FelsicThick = 35000 m | MaficThick = 0    | Age = 1000（陆壳标记）
   洋性板：FelsicThick = 0       | MaficThick = 7000 m | Age = 0
   SedimentThick = 0（沉积物暂不使用，全部置 0）
5. 海拔场初值（v1.1，入口 §3.3 常量）：
   陆性板：Elevation = +LandElevM（≈+800 m）  |  洋性板：Elevation = −OceanDepthM（≈−3700 m）
   # 与厚度场同批生成的两级模板；v1.3：洋区基准随后被 02 §4 的热沉降剖面覆盖（陆区 +800 保留）

6. 运动学与地形（v1.3 起，细则全在 02）：
   抽欧拉极 Ω（rng 续流）→ 逐边两遍分类（汇聚/离散/转换/惰性）→ 洋脊 BFS 出洋壳年龄并重写洋区
   海拔基准 → 逐格省份 + 有界 BFS 距离场 → 要素生成器增量写 FelsicThick/Elevation
   # 顺序纪律：分类阶段只读本节初值场；写场阶段不再重判陆性（IsLand = 长英质厚 > 0，会被生成器改）
```

要点：

1. **归并结果是一次性初始划分，之后永不重划**（历史上"每步 Voronoi 归属重划"与"平流运动学"均已被否——本文档无任何演化步进）。
2. 归并生长保证**每格必有归属、无空洞、每板连通**；单格孤岛/空洞 = 实现 bug 信号。
3. **海陆 = 板块属性，不是独立标签层**（"板块是什么就是什么"）——二元跳变，无中间态、无过渡区，视觉为硬边界大陆块。
4. **v1.2 弃 fibonacci 胞切分层**（曾以 K≈N/100 个 fibonacci 撒点胞作归并单位）：归并单位 = H3 格本身，海岸锯齿粒度 = 单格、更自然；O(N·K) "每格归最近胞心"开销消失（曾是 res5 ≈2M 格的生成性能红线）。板数 P 直接 ≤ N 校验。
5. 板块大小天然不均：归并顺序随机 → 板块大小有方差（部分板块大、部分小）。

## 3. 参数表（初值；判读后按需调）

| 参数 | 初值 | 语义 |
|---|---|---|
| 板块数 P | 15（10–20 区间） | 全球板块总数（陆性 + 洋性）；P ≤ N |
| LandFrac | ≈1/3 | 板块为陆性的概率（≈地球海陆比；板大小方差 → 实际陆占比有涨落） |
| seed | 42（场景默认） | 定种子抽取/生长顺序/陆性，全局定局 |

## 4. 边界提取（渲染用，纯几何）

输入 `PlateId[]` + `Ball`（格心/格 id），两个派生出口共用同一异板共享边集（单一事实源）：

```
1. 遍历所有格邻居对 (i, j)：若 PlateId[i] ≠ PlateId[j] → 异板格对
2. 每对异板格求共享边：H3 门面 CellToVertexes 取两格顶点集，交集 = 共享边的两个端点
   （端点 3D 坐标 = H3.VertexToLatLng × R）
3a.【链】所有共享边按端点连通性连成链
   （端点度=2 连续追踪；度=3+ 为三板块交汇 → 在此断链，各成独立链段）
   每条链 = 一段边界折线（六边形格边锯齿，不做样条平滑——用户拍板默认）
   → ExtractBoundaryChains：测试锚定的诊断/对账基准（渲染已不消费）
3b.【描边格边集】每条共享边在边界两侧【各格】名下记账 (格 id, 顶点对规范化序)
   → ExtractBoundaryCellEdges：渲染在用（2026-09-09 v2 拍板，边粒度记账，替代旧
   角点集 ExtractBoundaryVerts——角点粒度无法区分角点属于哪条边，五边贴异板的格
   其同板边两端角点都被记账 → 整条误描，2026-09-09 用户报告后修复）
```

## 5. 渲染（NewBall 场景接线；v1.3 重写——全域材质 + 解析边距描边）

> 本节属 **UI 层**实现（入口 §2 架构分层）：本模块（逻辑层）只提供**派生数据口**（按格取海陆、边界描边格边集、统计），View/VM 装配按入口 §2.2/§2.4——区域数据与描边格边集由球视图 VM 派生，View 只负责提交 GPU。

- **全域材质（v1.2 用户拍板"材质覆盖整个球，对应区域显示对应材质"）**：一颗星球一张 `shaders/sphere_region_material.gdshader` 材质——逐格区域数据烘进 `region_data` 数据纹理（每格 1 纹素：R 海拔归一（域 = 色带停点首尾）/ G 板号色相归一 / B 陆性（`Crust.IsLand` 统一口）），格面 UV = 本格纹素中心（块内顶点同值 → 插值恒定，nearest 采样恒命中本格）；片元按 `display_mode` uniform（= `MapMode.Id`）派生区域外观：海拔模式采样色带纹理（CPU 从 `ElevationStops` 烘焙，与信息面板同一取色函数 → 天然同源）、板块模式按板号色相现算板色。模式切换只换 uniform——零几何重交、零 CPU 逐格取色。静态表面一次提交，几何常驻不动。
- **边界描边带（v1.3 解析边距，2026-09-09 定稿）**：§4 的格边集折算成**每格 6bit 旗标字节**（bit k = 边 k 是否异板边，另含五边格位/格心 z 负位），经顶点属性 COLOR.g 下发（块内常量 → 插值精确）；格心方向（UV2）与边 0 法向方位角（COLOR.r）同为每格常量。片元把自身方向投影到格心切面，对旗标边逐边求**到线段的真实距离**取 min，`band = 距离 < 带宽(= outline_width × 内切半径)`——宽度处处一致、拐角天然圆角衔接、同板边绝不描边。`outline_enable` uniform 总开关。
- 演进史（球面着色）：v0–v1.1 逐格 CPU 取色 → 顶点色全量重交（换模式 ~10ms）→ v1.2 全域材质 + 数据纹理（换模式 = 换 uniform）→ v1.3 描边解析边距（此前的"边距权重插值 + 角点帽"两代在拐角处分别出现楔形缺口与深色圆珠——插值权重方案无法表达"到边界路径的真实距离"，解析式一次到位）。
- 球自转展示已删（用户拍板 09-07，视角运动全交 OrbitalCamera）。

## 5A. 地图模式：海拔图（v1.1 新增 · 照搬老树 ElevationLayer）

> 入口 §2.5 地图模式体系的一个 `MapMode` 策略实例。**照搬**老树 `MapView/Layers/ElevationLayer.cs`（2026-08-31 ISO 9241-307 版色带，配色经用户拍板）——色带停点与分带函数迁至 new_HexWorld（UI/Modes/ 内聚），连续色带算法用通用 `World.Utils.ColorRamp`（已存在，直接复用不复制）。

### 5A.1 数据源

`Crust.Elevation`（米，0=海平面）。本阶段初值为两级常量（陆 +800 / 洋 −3700，入口 §3.3），色带呈"两档主体色 + 海陆 0 m 硬台阶"；将来要素生成器加起伏后自然出连续层次（色带与画面始终同源，无需改）。

### 5A.2 海拔色带 ElevationStops（照搬；位置 = 米，升序）

| Pos (m) | 色 | 说明 |
|---|---|---|
| -8000 | 墨紫黑 (0.043,0.055,0.133) | 海沟/深渊最暗（<-8000 恒此色） |
| -6000 | 靛蓝 #172B4F | 深海平原底 |
| -2000 | 深蓝 #2F5B8A | 大陆坡底 |
| -200 | 灰蓝 #7BA5C4 | 大陆架 |
| -50 | 浅灰蓝 #C6DCEB | 潮间带 |
| 0 | 青白 #E7F0F6 | 海面（低饱和灰蓝） |
| 0 | 天蓝 (0.45,0.75,0.90) | └ **0 m 硬台阶**（同位置双停点：海洋青白 → 陆地天蓝，色相切） |
| 500 | 浅绿 (0.58,0.78,0.32) | 低海拔末端 |

> 老树海冰判据（温度 ≤−5°C 的海）**不搬**——new_HexWorld 无温度场。

### 5A.3 分带名 ElevationZoneName（照搬，与停点断点同源）

- 海：<−6000 海沟 ｜ −2000~−6000 深海平原 ｜ −200~−2000 大陆坡 ｜ −50~−200 大陆架 ｜ 0~−50 潮间带
- 陆：0~500 低海拔 ｜ 500~2000 中海拔 ｜ 2000~5000 高海拔 ｜ >5000 极高山区
- 边界归属右侧段（与色带半开区间一致）。

### 5A.4 模式策略实例（ElevationMapMode）

- `Id=0`（默认模式）、`Name="海拔"`。
- `CellColorAt(i) = RampSampleSmooth(ElevationStops, Elevation[i])`（海拔只用于取色；陆/海判定一律走 `Crust.IsLand` 统一口，勿按海拔正负另立口径。v1.2 起本取色只喂格信息面板色块，球面渲染经色带纹理在片元侧同源派生）。
- `ShowPlateBoundaries = true`（叠加板块边界线层——海岸线即 0 m 线，双重视觉对照）。
- `TileInfo(i)`：`高度 {elev:F0} m（0=海平面）` + `类型 海洋/陆地 · 分带名`（swatch = 该格当前色）。
- 图例：`ColorRamp.RampLegendColors(ElevationStops)` 渐变条（LegendBuilder 照搬，UI 接线按需）。

## 7. 边界（不属于本模块）

- **板块运动/俯冲/碰撞**：机制演化路线已作废（入口 v9），本模块无任何演化接口。
