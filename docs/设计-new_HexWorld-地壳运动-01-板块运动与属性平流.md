# new_HexWorld 地壳运动 · 01 设计：板块运动与属性平流（H3Plate 模块）

> 系列入口：`docs/设计-new_HexWorld-地壳运动.md`（概念/红线/场与常量/目标表在此一次定义，本文档引用不重复）。
> 代码落点：`scripts/new_HexWorld/Planet/H3Plate.cs`、`H3PlateManager.cs`（现有类扩展，见 §1 现状）。
> **v2（2026-09-06）**：模型重写——v1 的"每步 Voronoi 归属重划"被否决：那会让板块永远被种子锁成均等胞、形状无记忆、物质追种子跑。正确模型：**Voronoi 只做初始划分一次；之后板块 = 持久料团，每格标签与料一起按本板刚体速度场平流**。本文档按此重写。
> **v2.1（2026-09-06）**：平流写入明确为 **ping-pong 双缓冲（零拷贝）**——所有格同时运动，必须"从旧场读、写新场"，但实现是 cur/prev 角色每步互换，**不需要**每步复制整球数据（§3/§8）。

## 0. 模块职责与模型定位

### 0.1 模型定位（先读这段，其余都建立其上）

1. **初始（一次）**：`CreatePlates` 的球面 Voronoi 切出 P 块板——只是开局切分，之后**永不重划**。
2. **之后每步**：每格带着**标签 + 料（厚度/年龄）**，沿它所属板的刚体速度场 `v_p(r) = Ω_p × r` 做半拉格朗日平流（从上游格拷贝）。板内所有格的速度场组合 = 一次整体旋转 → **整团料刚性移动、形状保持**。
3. **板块 = 料团**：板的形状 = 标签场的支撑集，**边界 = 标签的间断面，跟着料走**——料到了哪，板就在哪。板形状有记忆，初始决定、之后只随旋转演化。
4. **两板对顶天然停住**：每格只从"本板料的上游"取，没有任何机制让 A 的料流进 B 的格 → **相撞不穿透是模型的天然性质**（无需缝合兜底一类补丁）。
5. 板块**面积变化只发生在边界过程**（03 模块）：离散=脊注入新料、汇聚=海沟移除料、碰撞=料堆积增厚。板内刚体，不变形不伸缩。

### 0.2 本模块提供（对外接口）

- `Plate[]`：板表（`R`/`Ω`/`Seed`，现有字段扩展）；每步步进 `Step(dt)`；
- `PlateId[]` 标签场：随料平流（消费方：渲染、速度场查询、03 边界检测）；
- 料场（Felsic/Mafic/Sediment/Age）平流搬运 + 守恒保证；
- 诊断：标签翻转格数（= 边界移动）、逐板质量、料团连通性、无 NaN。

## 2. 数学模型

### 2.1 板旋转（欧拉，全局系角速度）

- 每板旋转矩阵 `R_p`（局部→全局，Godot `Basis` 3×3）。`Seed_p` 定义在局部系（初始 `R=I` 时即全局方向）。
- **`Ω_p` 存全局系**（rad/My，现有随机生成方式不动）。`dt`（My）。增量旋转 = 旋转向量 `Ω_p·dt` 的轴角矩阵 `ΔR_p`：
  ```
  R_p_new = ΔR_p(Ω_p · dt) · R_p        // 左乘：Ω 全局系
  ```
- 旋转矩阵在本模块的用途：① 算每格平流的上游回溯方向（§2.2）；② 诊断板心轨迹 `g_p = normalize(R_p·Seed_p)`。
- **数值卫生**：累积失正交（`|det R − 1| > 1e-4`）→ Gram-Schmidt 重正交化。

### 2.2 属性平流（核心 —— 替换 v1 的 Voronoi 归属重算）

每步，对每格 `i`（从**上一时刻场** prev 读，写**本时刻场** cur）：

```
p      = prevLabel[i]                       // 本格当前所属板（t 时刻标签）
y      = ΔR_p(−Ω_p·dt) · c_i                // 沿本板刚体速度场回溯 dt：精确球面旋转（不是切平面近似！）
s      = 最近邻(全格, y)                    // 上游格（空间索引，§2.4）
curLabel[i] = prevLabel[s]                  // 标签跟料一起搬
cur 料[i]   = prev 料[s]（Felsic/Mafic/Sediment/Age）
```

要点：

1. **回溯用精确旋转 `Rot(−Ω_p·dt)·c_i`**，不用 `c_i − v·dt` 切平面近似——后者会漂离球面、需反复 normalize，误差大。
2. **标签从上游拷贝** → 边界是标签间断面、随料走；边界格的上游若落在邻板料内 = **边界移动的正确表达**（不是混染）。板内格上游总在本板料内（内部稳定）。
3. **平流方向自洽**：`Rot(−Ω_p dt)` 把整板料"转回去"采样，等价于料团向前转了 `+Ω_p dt`（支撑集 = 原支撑集旋转）。板 = 刚性旋转体，形状保持。
4. **守恒修正（质量比，纯数学要求）**：半拉格朗日最近邻拷贝非精确守恒——汇聚/离散边界带会出现料无下游接收（湮灭）或多格争一源。逐板修正：
   ```
   r_p = Σ_old(板p 全部厚度) / Σ_拷贝后(板p 全部厚度)
   对 i ∈ 板p：FelsicThick[i] *= r_p；MaficThick[i] *= r_p；SedimentThick[i] *= r_p
   Age 不缩放（年龄是时钟不是质量）
   ```
   ⚠️ 不要用格数比（依赖映射分布、方向易错）。逐板一次归约，代价可忽略。
   > 与 03 的交接：汇聚边界被"顶住"的料在守恒修正里被回收（Σ_old > Σ_拷贝 → r_p > 1 摊回板内）。03 若做俯冲吞没，以 01 报告的无下游料为回收源，**吞没发生过的料不得再摊回板内**（防双算，03 详设成对写）。
5. **标签锐利性**：最近邻硬拷贝无插值 → 边界保持 ≤1~2 格锯齿，无中间态、长期不模糊（内部格永远取内部料）。**理论验证项：异形板跑 360° 后形状误差 ≤1~2 格**（§6）。
6. **dt 约束**：`dt ≤ 0.5·格宽/板速` ⇒ 上游回溯点距本格 ≤ 0.5 格 → 最近邻源必在邻域内、平流不跳变。

### 2.3 为什么不是 Voronoi 重划（决策记录）

| | Voronoi 每步重划（v1，已否决） | 料团平流（本版） |
|---|---|---|
| 板形状 | 种子锁死的均等胞，无记忆 | 初始决定、持久、随旋转刚性移动 |
| 物质 | 追种子领地跑 | 就是板本身（料 = 板） |
| 碰撞 | 种子可互穿 → 需补丁兜底 | 对顶天然停住，无穿透态是模型性质 |
| 复杂度 | O(N·P) | O(N)、天然并行（每格独立读上游，无写冲突） |

Voronoi 保留的唯一位置 = `CreatePlates` 初始分板（一次性，用户钦定）。

### 2.4 空间索引（res5 必需）

格心固定 → 等矩形经纬桶（桶尺寸 ≈ 1 格宽 w）一次构建全程只读；查询取目标桶+邻桶 → max dot。res3/4 调试期可线性扫描，桶路径 res5 前启用，两路径输出一致（测试对照）。

### 2.5 步长约束 dt（公式化，禁止写死）

`dt ≤ 0.5·格宽 ÷ 板速`；格宽 `w = sqrt(2·(4πR²/N)/√3)`：

| res | w | dt 上限（|Ω|=0.02, R=6371 km） | 建议 dt |
|---|---|---|---|
| 3 | ~120 km | 0.47 My | 0.4 My |
| 4 | ~45 km | 0.18 My | 0.15 My |
| 5 | ~17 km | 0.067 My | 0.05 My |

## 3. 单步流程伪代码（ping-pong 双缓冲，零拷贝）

**为什么必须双缓冲**：所有格同时运动，格 i 的上游 s 在本步也可能被更新——若就地写，先被更新的格会污染后读它的人（"每个板块都在动"，读旧值必须从干净的上一步场取）。**但实现不需要"复制一份球"**：cur/prev 两份场轮换角色，且平流是全格写（每格都写 cur），所以没有任何格需要预拷贝旧值。

```
# 场以 ping-pong 组织：labelA/labelB、felsicA/felsicB…（或 struct-of-array 双份）
# prev = 本轮只读场，cur = 本轮只写场；step 结束互换引用（零拷贝）

step(dt):
  # 1. 板旋转
  for p: R_p = ΔR(Ω_p·dt) · R_p;  重正交化检查
  # 2. 平流（每格只读 prev、只写 cur 自己下标 → Parallel.For 无竞争无锁）
  for i (Parallel.For):
      p  = prevLabel[i]
      y  = Rot(−Ω_p·dt) · c_i                # 精确球面回溯（§2.2）
      s  = 最近邻桶查询(y)                    # §2.4
      curLabel[i] = prevLabel[s]
      cur 料[i]   = prev 料[s]（4 场）
  # 3. 守恒修正（就地，cur 上，逐板）
  for p: r_p = Σ_old(p)/Σ_new(p);  厚度三场 *= r_p（Age 不动）
  # 4. 统计（§6）：标签翻转格数、逐板质量、料团连通性
  # 5. 角色互换：prev ↔ cur（换引用/指针，零拷贝）
```

- **没有"快照/复制"步骤**——全格平流意味着 cur 每个下标都被写，无需初始化；拷贝式快照（先整球复制再原地改）是浪费（res5 每步白花 ~40 MB 读写）。
- 只有未来出现"部分格更新"（某模块只改边界带、其余格保留旧值）时，才需要 cur 先 = prev 的初始化——届时按需加，不在本模块。

## 4. 常量与输入（引用入口 §3.3，不重复定义）

实际使用：板块数 P（默认 8–12）、`|Ω| ∈ [0.005, 0.02]`、dt（§2.5）、seed。料初值本模块只需占位（label + 均匀厚度即可）；真实初始模板在 02。

## 5. 边界现象与模块边界（先读，防实现期越界）

| 现象 | 本模块的行为（平流自然给出） | 归属 |
|---|---|---|
| 两板离散（背向） | 边界带各自向板内取料，中间无"空位"概念——离散的**新料注入**必须显式做，否则两板只内部流动、面积不变 | 03：脊注入（在离散边界格写入 age=0 新洋壳料） |
| 两板汇聚（相向） | 边界带每格仍只取本板料 → **边界停在对顶处，天然无穿透**；料在边界"顶住"，无下游的部分在守恒修正里回收 | 03：判定俯冲（吞没前沿：下插侧前缘格按 v_conv 整格移除、料分派回收/增生/岩浆、标签翻给仰冲板）或碰撞（把回收料在带内叠厚） |
| 转换（走滑） | 两侧速度切向不同 → 边界带料沿切向持续替换（标签不变） | 03：分类用（01 只保证平流正确） |
| 板心接近/轨迹相交 | **不再是问题**——没有种子竞争，料团相遇即顶住 | —（v1 的"无穿透态补丁"作废，模型天然满足） |

- 03 的边界检测原料：本模块输出**标签翻转格**（每步哪些格换了板）与翻转方向、**无下游料量**（守恒修正的回收量，逐边界带报告）→ 03 据此定位边界带、判定类型、并取吞没/碰撞的料源。

## 6. 验证与测量项（对照目标判读，不预设门槛）

| 测量项 | 看什么 |
|---|---|
| 刚性/形状保持 | 标记异形料团（含凹形）跑 360°+：形状误差 ≤1~2 格；料团质心轨迹 = `R·Seed` 解析旋转（偏差 <1e-3） |
| 平流方向 | 已知 Ω 的板：料团整体移动方向/速率 = Ω×r 理论值（构造平直边界平移用例，边界格翻转速率 ≈ v/格宽） |
| 守恒 | ΣFelsic/Mafic/Sediment 相对初始漂移 < 1e-3（守恒修正后） |
| 顶住测试 | A 撞静止 B：B 初始领地无 A 标签渗入（允许边界 ≤1 格锯齿），B 料质量不变——**无穿透是模型性质，测它防实现 bug** |
| 双缓冲正确性 | 就地更新实现必然翻车（料在运动方向被"拖尾"污染）——用"料团平移用例"对照：ping-pong 结果 = 解析平移；就地实现 ≠ |
| 标签锐利/长跑 | 200 My：无 NaN、标签无碎斑（单格孤岛 = 实现 bug 信号） |
| 确定性 | 同 seed 跑两次 → 每步统计序列逐位一致 |
| res 同构 | 同 seed res3/res4 形态一致；桶路径与线性路径输出一致 |

## 7. 性能预算（res5 参考）

每格：1 次桶查询（常数候选）+ 从 prev 读 5 场（label 4B + 4×4B = 20B）+ 写 cur 20B ≈ 80 MB/步 ≈ **3 ms**（带宽下限）；无快照拷贝。计算量（旋转回溯 4×4 矩阵 × 向量）另加几 ms → **每步 < 10 ms，天然并行**。全演化 4000 步 ≈ 1 分钟内。内存：双份 5 场（int[N] + 4×float[N]）×2 ≈ res5 80 MB，无压力。

## 8. 已知坑（实现前先读）

1. 上游回溯**必须用精确旋转** `Rot(−Ω_p·dt)·c_i`；`c_i − v·dt` 切平面近似会漂离球面。
2. **不要做"先复制整球再原地更新"的快照式实现**——就地更新会污染（上游被本步改过），复制则白花 40 MB/步；正确 = ping-pong 双缓冲角色轮换（§3），全格写所以零拷贝。
3. 平流方向 vs 标签翻转语义：**边界格翻转 = 边界移动，正常**；若板**内部**格翻转 = 速度场错 / dt 超限 / 料初值不连通。
4. 拷贝不守恒 → 逐板质量比修正（§2.2-4）；修正放 Age 上是错的。
5. 累积旋转失正交 → 每步重正交化。
6. 最近邻取整平局 → 确定性规则（如固定取 id 小者）；桶/线性两路径同规则。
7. 五边形格面积略异 → 质量比修正用实际 Σ 免疫。
8. 单位向量浮点 dot 可能 >1 → clamp；上游点 y 归一化。
9. 初始料团必须连通（Voronoi 胞天然连通；将来自定义初始板形状要保证）。
10. 并行确定性：每格只读 prev、只写自己 cur 下标 → 无竞争；统计用确定性归约。
