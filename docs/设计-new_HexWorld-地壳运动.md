## 1. 总纲：水平运动如何变成地形

板块运动是**水平**的，地形是**垂直**的。中间的转换器是边界应力改变地壳的**厚度、温度与弯曲形状**，再由重力换算成海拔。任何构造地形都是下述三个"垂向引擎"之一或叠加：

| 引擎 | 物理 | 效果 | 主导地形 |
|---|---|---|---|
| 均衡（Airy） | 地壳漂在密度更大的地幔上（冰山原理） | 加厚→浮高；减薄→沉低 | 大陆高原/平原、造山带、裂谷盆地 |
| 热状态 | 岩石圈是冷却中的热边界层：壳下冷却段随年龄增厚、变重 | 洋壳从脊轴出发→冷却段 0→100 km→柱渐重→海底沉降（≈2500+350·√年龄 的经验等价物） | 洋中脊、深海平原、被动陆缘变深 |
| 弹性挠曲 | 岩石圈有刚度，可弯 | 加载/弯折处下凹、相邻处上拱 | 海沟加深、前陆盆地、外缘隆起 |

### 1.1 两条红线（A 路线的纪律，全系列适用）

- **R1 海拔唯一来源**：`Elevation` 只有一处写入——每步由整柱均衡从（厚度场, 冷却段场, 海平面）全场导出（§4 核心公式）。任何边界过程**不得直接写海拔**。
- **R2 边界过程只操作物质场与年龄**：边界按相对运动分类后，只做厚度场的**添加/移除/搬移**与 `Age` 改写。禁止"为了让某地形出现"而设的特殊 if。

> 后果：地形是**涌现信号**，不是操作目标。同一板块对从张转压时，物质操作自然反转，地形随之演化（裂谷→洋盆→俯冲→碰撞闭环）。数值只许通过 §3.3 常量与 §4 公式调出；"某地形出不来"先查机制链，**禁止直写 if**。

### 1.2 物质不变量

| 物质 | 场 | 守恒规则 | 语义 |
|---|---|---|---|
| 长英质 felsic（陆壳本体） | `FelsicThick` | **守恒**（碰撞=叠加；裂谷减薄=显式近似损耗通道，03） | 不可从地幔新生，只能搬运/拼合/损耗 |
| 镁铁质 mafic（洋壳本体） | `MaficThick` | 与地幔交换：可新增（洋脊出生）、可移除（俯冲回收） | 物质密度**恒定**（冷却效应不在壳内） |
| 沉积物 sediment | `SedimentThick` | 搬运守恒 | 04 起可用 |
| 冷却岩石圈段 | `(派生) tl` | 洋格随 `Age` 增长（√律），陆格常量；随料平流与壳同迁 | 承载引擎二的全部权重 |

### 1.3 分辨率与尺度纪律（目标 res5，测试 res3/4）

| res | 格数 N = 2+120·7^r | 格面积 | 格宽 w（对边距） | 用途 |
|---|---|---|---|---|
| 3 | 41,162 | ~12,400 km² | ~120 km | 当前测试 |
| 4 | 288,122 | ~1,770 km² | ~45 km | 当前测试 |
| **5** | **2,016,842** | **~253 km²** | **~17 km** | **最终目标世界** |

1. **一切以格为单位的量必须参数化**：物理尺度（km）÷ 当前格宽 = 格数，禁止硬编码——换 res 不改机制。示例：弧沟距 100–150 km → res3 1 格 / res4 2–3 格 / res5 6–9 格；单步位移上限 0.5 格（dt 规则见 01 §2.5）。
2. res5 全格遍历每步 O(N)；平流上游最近邻查找需空间索引（01 §2.4）；**机制时间常数一律用 My 不用步**。
3. 可分辨地形单元 ≥ 1–2 格；亚格细节（单火山锥 2–20 km、洋脊中央裂谷 10–25 km）不进模拟层，需要时渲染层装饰。

## 3. 数据与常量（一次定义，各模块文档引用不重复）

### 3.1 全局地壳场（与 `Ball.CellIds` 对齐，长度 = H3 格数）

```csharp
public class Crust
{
    public int[]   PlateId;        // 每格当前归属板块（随料平流，01）
    public float[] FelsicThick;    // 长英质厚（m）——大陆本体
    public float[] MaficThick;     // 镁铁质厚（m）——洋壳本体（物质密度恒定）
    public float[] SedimentThick;  // 沉积物厚（m）（04 起可用，可置 0）
    public float[] Age;            // 洋壳年龄（My）；陆壳恒为 ~1000（标记）
    // —— 派生（每步刷新，不落档）——
    // float[] CoolingThick;       // 壳下冷却段厚 tl：洋格 = f(Age)，陆格 = 常量（02 起）
    // float[] Elevation;          // 海拔 m（02 起，§4 公式唯一写入）
}
```

存档只存 4 个厚度/年龄场 + PlateId；派生场每次加载后重建。与老树 8 物质场的关系：H3 res3–5 每格宽 17–120 km，格内分不出岩性细节，压缩为 3 物质 + 年龄 + 冷却段（岩性留给下游按厚度与位置派生）。

### 3.2 板块 `H3Plate`（现有 → 扩展）

```csharp
public class Plate
{
    public int Id;
    public Vector3 Seed;            // 板中心（局部系原点，初始 R=I 时即全局方向；仅诊断/统计用）
    public Vector3 Omega;           // 角速度 rad/My（全局系；首批固定随机，进阶浮力驱动 04）
    public Basis  R;                // 局部→全局旋转矩阵（01 起每步左乘增量旋转，供平流回溯与诊断）
}
```

> 板只持旋转与统计（板 = 旋转参数 + 由标签场定义的料团）；物质场一律全局格数组（§3.1）。**初始划分用一次 Voronoi（`CreatePlates`），此后板块形状由料团平流持久演化，不做任何归属重划**（模型语义见 01 §0.1/§2.3）。

### 3.3 常量与校准目标

| 常量 | 初值 | 说明 |
|---|---|---|
| ρ_felsic | 2700 kg/m³ | 陆壳物质密度（**恒定**） |
| ρ_mafic | 2950 kg/m³ | 洋壳物质密度（**恒定**——不用"ρ随Age"：壳仅 7 km 折不进冷却重量，且会与冷却段双算） |
| ρ_sediment | 1500 kg/m³ | 未压实（压实/成岩后置） |
| ρ_water | 1030 kg/m³ | 海水 |
| ρ_mantle | 3300 kg/m³ | 软流圈基准（均衡参考） |
| α | 3e-5 /K | 地幔热膨胀系数 |
| Δρ_l = ρ_mantle·α·ΔT_l | ≈80 kg/m³（ΔT_l≈800 K 初值，旋钮 50–100） | 冷却段平均过密——引擎二全部权重 |
| L(age)（洋下冷却段厚） | 10 + 90·√(Age/200) km，0→100 km | √律 = 半空间冷却；陆下 `L_cont` = 100 km 常量 |
| 初始壳厚 | 洋 7 km / 陆 35 km | 初始模板两级（大陆块+洋盆），过渡区不预置（02 详设） |
| 俯冲资格 | Age > 80 My（初值） | = 柱过剩质量转正的近似（03 详设） |
| 碰撞软上限 | 65–70 km | 语义 = 重力垮塌/侧向逃逸（03，非删质量） |
| 单步位移 | < 0.5·格宽 | dt 规则见 01 §2.5 |
| seaLevel | 常量（首批）或体积守恒（04） | **全局量**——海拔绝对零位只能由海水量定 |

**校准目标（02 的唯一调参工作，调常量不许加 if）**：标准大陆（felsic 35 km）→ ≈0 m；洋脊轴 → −2.5 km（冷却段参数不足时热上涌项补差，02）；200 My 老洋盆 → −5.5 ~ −6.5 km。

## 4. 主循环与核心公式（总览；每步的详细设计在各模块文档 §5）

```
0) 板旋转 + 标签/料平流（守恒修正）          —— 01 板块运动（料团刚性走，边界=标签间断面）
1) 年龄推进 → 冷却段刷新                    —— 02 场与均衡
2) 边界分类（相对速度 → 操作类型）           —— 03 边界与物质操作
3) 边界物质操作（脊注入/俯冲移除/碰撞堆积/转换）—— 03
4) 整柱均衡导出海拔（唯一 Elevation 写入）    —— 02
5) [可选] 挠曲修正                          —— 04
6) [可选] 侵蚀/沉积                         —— 04
7) [可选] 海平面体积守恒、浮力驱动、超大陆     —— 04
```

**核心公式（定义级，正式推导/校准流程见 02）**——整柱模型（柱顶至补偿深度 C≈150 km，C 在公式中消去）：

```
柱 = [空气/海水段] + 壳 tc（ρc 恒定）+ 冷却段 tl（ρl = ρ_mantle + Δρ_l）+ 软流圈补段（ρ_mantle）

disp = tc·(1 − ρc/ρ_mantle) − tl·Δρ_l/ρ_mantle      // 相对"无壳无冷却段的全软流圈柱顶"
Elevation = disp − seaLevel                          // seaLevel 全局量（常量/体积守恒）
```

要点：① 冷却必须显式放在壳下（壳 7 km 太薄折不进洋脊 3 km 抬升，v3 已证）；② seaLevel 是全局量——洋陆高差是双柱比较结果，绝对零位由全球海水量定，单柱局部解不出；③ 洋壳冷却 √律 = 经验"水深 ≈ 2500+350·√年龄"的物理来源。

## 6. 地质速查（防实现时想歪）

- **洋中脊海拔是"热胀浮起"不是"堆出"**：模型里 = 轴部冷却段≈0（柱最轻）。冷却段 = "从轴部出发后逐渐长出来的负重"。
- **山脉/高原是"加厚后浮起"不是"推高"**：碰撞增厚 35→70 km 抬高壳浮力项，根部压入地幔（山根）。
- **海沟为什么深**：板片下弯 + slab pull 牵引（挠曲，04），不是"它缺了壳"；纯均衡海沟 = 正在被移除的老洋壳深水格（≈−6.5 km 上界）。
- **火山弧为什么离海沟 100–150 km**：板片俯冲 ~100 km 深才脱水熔融，水平距离 = 深度/倾角。
- **大陆架/被动陆缘**：裂谷减薄 + 冷却沉降 + 海侵的自然产物；初始模板不预置过渡区（老树曾预置——A 路线不预置）。
