# 验证：地图保存与加载

状态：第 6/6 步验证包。适用范围：本轮地理地图（`.wmap`）的保存、识别、加载与只读浏览。
不包含：文明演化、可玩世界、人口与经济。

## 1. 运行方式

### 1.1 直接运行游戏

```powershell
# 在编辑器里按 F5，或：
& 'D:\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe' --path E:\godotGames\world
```

启动后进入主界面。主界面不生成任何世界，日志中不应出现 `[WORLD]` / `[TERRAIN]` / `[CLIMATE]`。

页面与展示层按需加载：`AppRoot` 只实例化主界面，进入某个功能时才加载对应页面；世界展示层 [WorldPresentation.tscn](<../scenes/render/WorldPresentation.tscn>) 作为可复用子场景，由地理演化页或浏览页在打开时实例化，不参与启动。

地图存档位置固定为游戏目录下的 `userdata/saves`，不再使用 `user://` 的 AppData 目录，也不提供自定义位置的文件对话框。编辑器运行时为项目目录，导出后为可执行文件所在目录。

存档边界由 `IGeographyMapRepository`（`scripts/Application/Storage/`）负责保存、加载与列表；`GameMapRepository`（`scripts/Infrastructure/Maps/`）固定目录并调用地图包编解码。`WorldManager.SaveMap` 只生成快照，地图库与浏览页只拿路径，不各自拼目录。

页面通过 `IAppPage.Configure(PageContext)` 接收取消令牌与可选能力（`Notice`/`Progress`），不反查场景树；返回、开图与提示经应用层动作端口调用，端口由组合根 `AppShell` 实现（2026-11-14 起已无 `IPageNavigator`）。独立 F6 运行时能力全为空，页面自行降级。

## 2. 手工验收流程

### A. 保存地图

1. 主界面点「地理演化」，等待 res4 世界生成完成。
2. 左上角点「菜单」→「保存地图」。
3. 底部状态文字显示保存路径。
4. 文件位于：

```text
<游戏目录>\userdata\saves\map_<时间戳>.wmap
```

编辑器运行时即 `E:\godotGames\world\userdata\saves`，不会落到 `C:\Users\...\AppData`。

本次实测：res4 地图 `216,662,566` 字节，保存约 `8.4 s`。

### B. 重启后加载

1. 关闭并重新启动游戏，回到主界面。
2. 点「地图库」。列表应出现刚保存的地图名称，右侧显示「可识别的地理地图」与完整路径。
3. 选中后点「加载所选地图」，进入只读地图浏览。
4. 可切换地图模式、点选格子查看信息卡；返回用左上角「菜单」→「返回地图库」。

地图库只列出游戏目录下的存档，不再提供「导入地图数据…」或自定义目录选择。

### C. 损坏文件必须被拒绝

1. 把一个 `.png` 或任意文本文件改名为 `broken.wmap`，放进 `userdata/saves`。
2. 地图库列表该项显示「损坏或缺失：…」。
3. 点击「加载所选地图」不会进入浏览页，状态栏显示带错误码的提示。

### D. 版本不支持必须被拒绝

清单中 `schemaVersion` 不是 `1` 的包，探测结果为「不支持」，不会加载。

## 5. 已知限制

1. 加载是主线程同步执行：res4 约 5.5 秒，期间界面会停顿，加载提示不一定来得及重绘。
2. res4 地图包约 216 MB；文件上限为 512 MB，接近上限的增长需要重新审查。
3. 文明演化、可玩世界、人口经济本轮完全不实现；主界面对应按钮禁用。
4. 地理演化页与浏览页共用 `WorldPresentation.tscn` 与 `AppMenu.tscn`，只保留各自的页面级脚本；展示层不包含世界生成器。
5. 迟到提交/取消由 `LoadOperation` + `LoadOperationBinding` + `LoadCommitGuard` 统一承担，已覆盖浏览、生成、演化三条路径（`SceneContracts` 的旧操作状态机已删除）。
