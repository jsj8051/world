## 〇、总纲

- **实体 = 社会单元，一个 `CivEntity` 类**：从部落开始（方案甲）。石器时代实体无组织结构（Np/H/F/M 属后续阶段）。
- **科技 = 能力解锁**：每个科技解锁一项能力加入实体能力池；**使用 = 实体每 tick 的收益选择**（生产方式、定居与否都是选择，不是强制）。
- **跳变解绑**：没有硬编码时代切换。农业 = 种子科技，结构变化是能力组合 + 实力积累的涌现现象。
- **时代（EpochKind）= 反应性统计标签**：只用于显示/统计，不驱动任何机制。
- **自然层（GameGrid）全程只读**；确定性：同 seed 同网格同结果；注册表按 Order 每 tick 执行。
- **参数惯例**：本文所有数值为量级标定（"合理科学即可，不硬标定"），验证时看涌现结果再校准；带 ★ 的为已定稿常数。

## 一、实体状态（CivEntity）

| 状态 | 类型 | 语义 | 初始/范围 |
|---|---|---|---|
| Id | int | 实体唯一 id | 递增 |
| Cell | int | 所在格（部落领地 = 1 格） | 起源格 |
| P | float | 人口 | 起源 100 |
| TechKeys | Set\<string\> | 已获科技 key 集合（**字符串可读，非位掩码**：如 "fire","handaxe"） | {"stone_core"} |
| OriginCell / BornTick | int / int | 历史记录 | — |
| Dead | bool | 死亡标记（定期 compact，防 List.Remove O(n)） | false |
| CultureShare | ShareEntry×2 | **人口上的文化分布** top-2：(key,份额)×2，Σ=1；key 字符串可读（"cult_3"，同科技风格） | 起源单文化 (key,255) |
| CultureGroupShare | ShareEntry×2 | **人口上的文化群分布** top-2：(key,份额)×2，Σ=1 | 起源单群 (key,255) |
| ReligionShare | ShareEntry×5 | **人口上的宗教类型分布**：固定 5 key（animism/shaman/ancestor/polytheism/monotheism）Σ=1（机制层） | animism=255 |
| ReligionCultShare | ShareEntry×2 | **人口上的具体宗教派别** top-2：(key,份额)×2，动态 key "relig_N"（身份层，规则同文化群：起源独立、分裂 0.5% 分化、格级 0.3 同化，不跨格传播） | 起源单派别 (relig_N,255) |

**身份 = 人口份额，不是实体标签**（用户拍板 2026-08-06：人口才是实际载体）：
- 身份是**人口的组成分布**——一个部落内部可同时有信泛灵和信萨满的人口；文化同化 = 份额转移（人口改信），不是改实体一个标签。
- 文化/文化群/宗教派别 = **字符串 key**（与科技同风格，存档/诊断可读："cult_3;cult_9"、"relig_0"）；宗教类型 = 固定 5 key 常量表。
- 分裂时**份额等比例继承**（人口分走，身份随人口走）；合并时按人口加权融合。
- 格级/显示：主导身份 = 格内人口最大份额（MapViewer 直读；文化图层用 key 稳定哈希上色）。
- 技术 key 表（16 项）见 §八；**key 全表存档可读**，诊断直接打印 "fire;handaxe" 而非位掩码。

## 三、起源播种（OriginModel，Order 0）

```

排序按 BaseK 降序，取前 30% 为富饶区（智人摇篮=东非稀树草原，富饶优先）
N = OriginCount（默认 3，参数可调 1–6）
起源格选择（用户拍板 2026-08-06）：富饶区池内随机（Random(seed)），约束：
  - 两两球面格距 ≥ Dmin（默认 12 格 ≈1300 km，防扎堆）
  - 优先不同大陆（BFS 陆地连通分量检测；大陆数 < N → 余量在最大大陆内远距分散）
每起源格：1 部落，P=100，TechKeys={"stone_core"}，ReligionShare=泛灵 1.0，
  CultureShare/CultureGroupShare = 独立标签 k（每摇篮独立文化/文化群，互不同源）
同 seed 同结果（Random(seed) 确定性）
```

## 四、能量核算与生产方式（物理内核）

### 4.1 承载密度（biome → 人/km²，Binford 狩猎采集密度量级 ★）

| BiomeType | 环境（柯本） | 密度 人/km² |
|---|---|---|
| IceCap | 冰原（EF） | 0（不可居；火/皮毛后按 §4.5 下限） |
| Tundra | 苔原（ET） | 0.05 |
| Subarctic / Alpine | 亚寒带（Dfc）/ 高山 | 0.05 |
| HotDesert / ColdDesertKoppen | 沙漠（BWh/BWk） | 0.05 |
| TropicalRainforest | 热带雨林（Af） | 0.15 |
| TropicalMonsoon | 热带季风林（Am） | 0.20 |
| TropicalSavanna | 稀树草原（Aw） | 0.45 |
| HotSteppe | 热草原（BSh） | 0.45 |
| ColdSteppe | 冷草原（BSk） | 0.35 |
| HumidSubtropical | 湿润亚热带（Cfa） | 0.30 |
| Oceanic | 海洋性（Cfb） | 0.30 |
| MonsoonSubtropical | 冬干亚热带（Cwa） | 0.25 |
| MediterraneanHot / MediterraneanCool | 地中海（Csa/Csb） | 0.30 / 0.25 |
| ContinentalHot / ContinentalWarm / ContinentalDry | 大陆性（Dfa/Dfb/Dwa） | 0.30 / 0.25 / 0.20 |
| Riparian | 河岸/沼泽湿地 | 0.60（Binford 湿地资源最丰） |
| DeepOcean/Ocean/FrigidOcean/TropicalOcean | 海洋 | 0（不可居） |

（★ 全部为量级标定，看涌现结果再校准；旧值 4–11 化石不列，§十一 删除）

Y_猎0 = 密度 × 邻水加成 × 胞面积（胞面积 ≈ 4πR²/N，n=64 约 12450 km²）
  邻水加成只乘一次：Riparian 格 = 1.0（湿地密度 0.60 已含）；其余 LakeLevel>0 或邻 Riparian 格 ×1.5；否则 ×1.0
（无科技时 K=Y，c=1 归一化）
Y_猎0 = BaseK × 河流加成          （无科技时 K=Y，c=1 归一化）
```

### 4.2 狩猎产量（觅食耗竭模型）

```
Y_猎 = Y_猎0 × 工具乘数链（石核1.1 × 火1.2 × 手斧1.15 × 细石器1.3 × 弓箭1.4 × 研磨器1.15 …）
e_猎(P) = Y_猎 / (P + h)，h = 0.3·Y_猎（★ 半饱和人口，随产量缩放，资源耗竭项）
  P 小 → e 高（人均富余）；P 大 → e 低（马尔萨斯压力）
  ★ h 随 Y_猎 缩放后：狩猎稳态人均 e = 1/1.3 = 0.77（与工具科技 M 无关——工具只抬 K 不抬稳态人均）
  ★ e_猎 仅用于生产方式选择比较（§4.4）；能量核算用 e = Y/P（§二 Order 10）
```

### 4.3 农业产量（种子解锁后可用）

```
Y_农 = 种子基线 × f(SoilLevel) × φ(生态位适宜度)，f: Soil1=0.4, 2=0.6, 3=0.8, 4=1.0, 5=1.2（★ 待校准）
  φ = §9 生态位适宜度（连续值 ∈ (0,1]；气候不适 → φ 低 → 产量低 → 不转农）
  种子基线（量级）：小麦 4×Y_猎0 / 粟 3.5× / 水稻 6× / 玉米 5× / 土豆 4×（水稻需水已含于 φ，无独立 ×0.5）
e_农(P) = Y_农 / P − w，w = 0.2（★ 耕作劳动成本差，Sahlins：觅食工时短；0.3→0.2 见 §4.4 稳态论证）
```

### 4.4 生产方式选择（每 tick，Order 30）

```
方式 = argmax( e_猎(P), e_农(P) )          ← w 已含于 e_农 定义，无双扣；只比较拥有的能力（无种子则只有狩猎）
滞回防抖：收益差 |e_猎 − e_农| < 0.02 → 保持当前方式（防来回跳）
  滞回带 0.02 必须 < 农业稳态差 0.03（否则锁死切换）
  生产方式影响 Y：狩猎 → Y=Y_猎；种田 → Y=Y_农
稳态论证（★ 定稿依据，2026-08-06）：
  狩猎稳态 e = 1/1.3 = 0.77（h 缩放后与科技无关）；农业稳态 e = 1 − w = 0.8 > 0.77 → 站稳不退农
  发明瞬间（P=Y_猎=M·Y_猎0）转农条件：F·f·φ > 0.97·M（F=种子基线倍数，M=工具乘数链）
    全科技 M=3.16 + 小麦 Soil3 适宜（F·f=3.2）→ 勉强转；粟 Soil3（2.8）→ 不转（农业 K<狩猎 K，自动拒绝）
    Soil4+ 肥地 / 高基线作物才值得全科技部落转农 → 生产方式由格子属性（土壤/气候）主导
P* 由选择逻辑涌现：人口升 → e_猎 降 → 自然跨过 e_农 → 转种田；φ 低/土壤差/成本高 → 继续狩猎
```

### 4.5 寒冷区解锁（火 T02 / 皮毛 T04）

```
寒冷区判定：biome ∈ {IceCap, Tundra, Subarctic, Alpine}（新函数，随 biome 清理新增）
  火    → 寒冷区 K 下限 = 0.05·面积 ×3（可居但贫瘠）
  皮毛  → 再 ×3（0.45·面积，接近草原密度 0.45——皮毛衣物后西伯利亚可居）
（实现为 K = max(K, 下限)，见 §五 增长公式的 K 合成）
```

## 五、人口增长、分裂、迁徙

### 5.1 增长（Order 20）

```
K 合成：K = max(Y / c, 寒冷区下限) = max(Y, 下限)   （c=1 ★；Y = 当前生产方式产量）
P *= exp(r_eff·(1 − P_格/K_格))，r_eff = 0.005/年 × 100 年 = 0.5/tick ★
  ★ P 为部落人口；K 与压力因子用格级（格内所有部落共享同一 P_格/K_格 → 部落比例不变）
  格总人口 = Σ 格内部落 P（每 tick 缓存 CellPop，同 v2）
  饿死人（用户拍板 2026-08-06）：P_格 > K（压力超过）→ 增长为负 = 饿死人；P<K 增长期 s=e−1>0（盈余）
  指数形式防 P>K 爆负（P>K 时指数 <0 自然衰减）
```

### 5.2 分裂（segmentary lineage，Order 80 前段）

```
部落 P > SplitPop = 400（★）→ 同格裂变：
  新部落带走 45%（SplitShare ★），**身份份额等比例继承**（人口分走，文化/文化群/宗教随人口走）
  TechKeys 完整继承（分裂瞬间技术相同，此后各自发明/学习——不因同源共享）
  文化群分化：分裂时 0.5% 概率生成新文化群 id（方言→语言群，漂变）——作用于新部落的主导份额
格内上限 MaxTribesPerCell = 8（★ 性能 + 社会密度双约束，超限不分裂、迁徙优先）
快照遍历（新部落下 tick 再判，防同 tick 连锁）
```

### 5.3 迁徙（Order 80 后段）

```
饱和迁徙：格 P > 0.75·K → 最大部落分出 50% 迁往相邻宜居格
  （目标：无人格最高优先，其次高 K/低密度格）
探路迁徙：P>100 部落 2%/tick → 迁出 30% 至 1–3 跳内最高 K 无人格（跳跃扩散）
跨海：无独木舟不跨海；有独木舟 → 可跨 1 格海洋（短距）
迁徙守恒：迁出立即减源格人口（防总人口虚增——v2 踩过的坑）
迁徙极限（用户拍板 2026-08-06）：目标判定全失败（邻格都住满/无宜居格）→ 留在原地不迁
  → 格人口最终填满 → P_格/K → 1 → 压力（§6.2 阈值 0.7）必达，农业压力触发链不断
```

### 6.2 发明（Order 40）

```
硬门槛检查：依赖（TechKeys 含前置 key）→ 环境判定 → WildCrops（种子）→ 通过才进入速率计算

通用发明（Kremer，★ 人口-知识模型）：
  λ_i = k_i · (P_部落 / P_ref_i) · (1 + 知识/16) · env_i · (1+γC)
    知识 = TechKeys.Count（累积性：发明越多越会发明）
    P_部落 = 部落人口（实体独立发明，TechKeys 是实体字段）
    env_i = 环境匹配 1.0 / 不匹配但非硬门槛 0.3（如寒冷区外发明皮毛衣物慢而非不可能）
    γC = 0（石器时代无复杂度）
  随机判定：Rng.NextDouble() < λ_i → TechKeys.Add(key_i)

压力触发（种子专属，Boserup 被逼出来的）：
  条件 = WildCrops 位 ✓ + P_格/K_格 > 0.7（★ 压力阈值 = 格子人口压力，量级待校准）
       + SoilLevel ≥ 3 + 依赖 ✓
  满足 → 以基础概率 invProb=0.005/tick 获得（起源区少数发明，非全员）
  不满足 → 发明率 0，只能传播
```

### 6.3 传播（Order 50）

```
接触定义：同格实体对 + 相邻格边界（领地格邻接）
传播概率（每 tick 每接触）：
  p = SpreadBase_i × 接触修正
  SpreadBase 分级：极易 0.08 / 易 0.05 / 中 0.02 / 难 0.008（★ 量级）
  Rogers S 曲线：传播只向"未持有 key"实体；已持有者比例高 → 源多 → 扩散加速（自然涌现）
  依赖检查：目标未持有但前置缺失 → 不传（或先传前置）
种子传播修正：p ×= clamp(φ_目标格, 0.3, 1.0)（φ=生态位适宜度连续值——适宜度高的格传得快，最低 0.3 勉强种）
贸易：旧石器无货币，物物交换（礼物交换）——传播 ×2 加成保留给后续阶段
```

## 七、文化互动与宗教演进

### 7.1 文化标签（Axelrod 相似度互动，快——作用于 CultureShare）

```
格级聚合（用户拍板 2026-08-06：每个格子同化，不分部落）：
  每 tick 每格一次：格级份额 = 格内各部落份额按人口加权聚合 → 演化 → 按人口加权分摊写回各部落
同化（格内）：主导份额 x → x' = x + 0.3·(1−x)（主导文化每 tick 同化其余份额的 30%，人口改信主导文化）
相邻格接触（代表实体对）：
  相似度 = (主导 Culture 相同 ? 0.5 : 0) + (主导 CultureGroup 相同 ? 0.5 : 0)
  sim > 0.5 → 以 (sim−0.5) 速率转移份额；sim ≤ 0.5 → 不互动（保持差异——Axelrod 局部收敛全局多样）
份额守恒：转移量从源份额扣减，Σ=1（格级执行，写回后各部落 Σ 仍 =1）
```

### 7.2 文化群（Abrams-Strogatz 份额竞争，慢——作用于 CultureGroupShare）

```
格内多实体（不同文化群）——份额 = 各群人口占比（top-2 存储）
竞争（每 tick 每对，份额级）：
  dx/dt = (1−x)·s·x^a − x·(1−s)·(1−x)^a    ★ Abrams & Strogatz (2003)
    x = 群 A 份额；s = 群 A 人口占比（地位）；a = 1.31（★ 活力指数，原文标定）
  数值解算：份额按 d 转移，保持 Σ=1；top-2 之外份额并入第 2 位
分化：分裂时 0.5% 新文化群（§五）；吞并时随实体消亡
（格内文化群 < 2 时竞争方程跳过）
```

### 7.3 宗教（份额场，不读时代 ★——双层：类型 5 key 机制层 + 具体派别身份层）

```
类型 ReligionShare（固定 5 key，机制层）：
  初始：animism 1.0，其余 0
  升级（份额转移，速率 0.05/tick，条件全实质变量）：
    泛灵→萨满：盈余 s>0 + 细石器（key="microlith"）
    萨满→祖先：农业（种子）+ 定居（后续阶段能力）     ← 石器时代不可能，天然锁死
    祖先→多神 / 多神→一神：后续阶段

```

   ↘          ↘ grinding → seed_*×5（wheat/millet/rice/corn/potato）→ agriculture（母科技·概念位）
fire → clothing（御寒枝）
   ↘ canoe（跨海枝）
   ↘ storage → pottery（存储枝：可存储盈余，后续阶段酋邦的能力基础）
```

三条枝：**武器枝**（效率，Y 乘数链）、**御寒枝**（环境扩张，K 下限链）、**存储枝**（结构分水岭，Testart——能力保留给后续阶段使用）。

**关键标注**：
- 农业产生 = 压力触发（P/K 高才可能，Boserup——被逼出来的），非主动发明。
- 种子传播最难：种子环境适配（同一作物不能直接换纬度过活）——扩散慢符合史实（农业波前 0.6–1.3 km/年 vs 旧石器工具泛大陆同步）。
- 独木舟/皮毛衣物/存储/陶器的依赖都是**强相关硬门槛**（烧凿、烧制、切割、熏制），非排序。

## 九、种子洒落机制 + 野生作物层 WildCrops

**种子发明只在起源区**：环境 ✓ + 压力 P_格/K_格 高 + SoilLevel≥3 同时满足的少数实体（内生 1–5 起源中心，分散在不同气候区）；不满足条件的实体发明率 ≈0，**获得种子唯一途径 = 接触传播**（从起源中心扩散）。传播受环境适配限制（种子不对气候 → φ 低 → 产量低 → 实体继续狩猎）。所有种子产量 Y_农 ×= f(SoilLevel) × φ，肥地/适候高、薄地/不适候低。

```
WildCrops[n]：byte bitmask，每格存在哪些野生种（5 位 = 5 种子科技）
生成（生成管线 Stage 资源阶段，与矿藏/土壤同层；纯自然层，与人文无关）：
  1. 适宜度：加权高斯生态位（BIOCLIM/MaxEnt 式，Phillips et al. 2006）
     适宜度_i(cell) = exp(−Σ w_j·((x_j − x_ideal_j)/σ_j)²)
     x_j = 年均温 T / 年降水 P / 降水季节性(MonthPrecip 冬雨夏雨湿润) / 海拔
     x_ideal_j·σ_j = FAO 农业气候学生态位参数
  2. 分布区：适宜度 > 全球分位数 P70（相对该星球分布）
  3. 群聚洒落：分布区在适宜区内部以斑块/聚簇形态洒落（离散分布，非均匀铺开）
  4. 不做保底：星球无匹配气候 → 该野生种天然灭绝（WildCrops 位全 0，诊断警告）
读取：旧档缺 WildCrops 段 → 现场重推导（确定性重建，同 seed 同结果）
显示：MapViewer 可选"野生作物分布"图层（5 色，后置非核心）
```

**生态位参数（FAO 数据）**：

| 野生种 | 理想年均温 | 理想年降水 | 降水季节性(MonthPrecip) | 特殊 |
|---|---|---|---|---|
| 小麦 | 15°C(σ6) | 400–700mm | 冬雨(冬半年占比>0.55) | 钙质土偏好 |
| 粟/高粱 | 10°C(σ7) | 300–600mm | 夏雨 | 耐贫瘠(Soil 权重低) |
| 水稻 | 25°C(σ4) | >1000mm | 最干月>50mm(湿润) | 河湖加成 |
| 玉米/豆类 | 22°C(σ5) | 800–1500mm | 雨季分明 | — |
| 土豆 | 10°C(σ5) | 600–1000mm | 冷凉(最热月<20°C) | 海拔加成 |

**种子发明条件**：格内 WildCrops 位=1（野生种存在，隐含气候+土壤）+ 压力 P_格/K_格 高。分布区大小控制"哪里能种/扩散目的地"，压力控制"哪里起源"——角色分离。
