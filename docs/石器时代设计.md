## 〇、总纲

- **实体 = 社会单元，一个 `CivEntity` 类**：从部落开始（方案甲）。石器时代实体无组织结构（Np/H/F/M 属后续阶段）。
- **科技 = 能力解锁**：每个科技解锁一项能力加入实体能力池；**使用 = 实体每 tick 的收益选择**（生产方式、定居与否都是选择，不是强制）。
- **跳变解绑**：没有硬编码时代切换。农业 = 种子科技，结构变化是能力组合 + 实力积累的涌现现象。
- **时代（EpochKind）= 反应性统计标签**：只用于显示/统计，不驱动任何机制。
- **自然层（GameGrid）全程只读**；确定性：同 seed 同网格同结果；注册表按 Order 每 tick 执行。
- **参数惯例**：本文所有数值为量级标定（"合理科学即可，不硬标定"），验证时看涌现结果再校准；带 ★ 的为已定稿常数。

## 一、实体状态（CivEntity）

| 状态 | 类型 | 语义 | 初始/范围 |
|---|---|---|---|
| Id | int | 实体唯一 id | 递增 |
| Cell | int | 所在格（部落领地 = 1 格） | 起源格 |
| P | float | 人口 | 起源 100 |
| TechKeys | Set\<string\> | 已获科技 key 集合（**字符串可读，非位掩码**：如 "fire","handaxe"） | {"stone_core"} |
| OriginCell / BornTick | int / int | 历史记录 | — |
| Dead | bool | 死亡标记（定期 compact，防 List.Remove O(n)） | false |
| CultureShare | ShareEntry×2 | **人口上的文化分布** top-2：(key,份额)×2，Σ=1；key 字符串可读（"cult_3"，同科技风格） | 起源单文化 (key,255) |
| CultureGroupShare | ShareEntry×2 | **人口上的文化群分布** top-2：(key,份额)×2，Σ=1 | 起源单群 (key,255) |
| ReligionShare | ShareEntry×5 | **人口上的宗教类型分布**：固定 5 key（animism/shaman/ancestor/polytheism/monotheism）Σ=1（机制层） | animism=255 |
| ReligionCultShare | ShareEntry×2 | **人口上的具体宗教派别** top-2：(key,份额)×2，动态 key "relig_N"（身份层，规则同文化群：起源独立、分裂 0.5% 分化、格级 0.3 同化，不跨格传播） | 起源单派别 (relig_N,255) |

**身份 = 人口份额，不是实体标签**（用户拍板 2026-08-06：人口才是实际载体）：
- 身份是**人口的组成分布**——一个部落内部可同时有信泛灵和信萨满的人口；文化同化 = 份额转移（人口改信），不是改实体一个标签。
- 文化/文化群/宗教派别 = **字符串 key**（与科技同风格，存档/诊断可读："cult_3;cult_9"、"relig_0"）；宗教类型 = 固定 5 key 常量表。
- 分裂时**份额等比例继承**（人口分走，身份随人口走）；合并时按人口加权融合。
- 格级/显示：主导身份 = 格内人口最大份额（MapViewer 直读；文化图层用 key 稳定哈希上色）。
- 技术 key 表（16 项）见 §八；**key 全表存档可读**，诊断直接打印 "fire;handaxe" 而非位掩码。

## 四、能量核算与生产方式（物理内核）

### 4.1 层1 空间生产力 R（自然层静态场；2026-08-17 两层模型定稿，替代密度表）

两层模型总纲：人口受两层制约——
  层1 空间：每格自然生产力 R（猎物再生/植被产出），由气候（Miami NPP）× 水文（水因子）决定，先于人类存在；
  层2 食物：每 tick 实际产出 F vs 消耗 D=P·c 的流（§五），盈余驱动增长。
  ★ K 不再是外部常数：P 自动停在 F(P)/c 平衡点（涌现）。

R = k × min(NPP_T, NPP_P) × 水因子      （Miami 模型，Lieth 1975，NPP 净初级生产力）
  NPP_T = 3000 / (1 + exp(1.315 − 0.119·T))     T = 年均温 °C
  NPP_P = 3000 × (1 − exp(−0.000664·P))         P = 年降水 mm
  min() = Liebig 最小因子律（干旱/寒冷限制）
  水因子：Riparian 或 LakeLevel>0 或邻 Riparian 格 ×1.5；否则 ×1.0（原邻水加成保留）
  k = 标定常数：R 均值落在 Binford 量级（旧密度表 0.05~0.60 人/km² 作锚，★ 待校准）

量级（NPP g 干物质/m²/年 → R 人/km²）：
  沙漠 ~100 → ~0.03   草原 ~600 → ~0.15   温带林 ~1200 → ~0.30   雨林 ~2000+ → ~0.50（水因子后 ~0.75）
  R 底图动态范围 ~30 倍（旧密度表 12 倍）；全图 100~1000 倍主要靠 §4.3 农业尖峰
（疾病因子：湿润热带 ×0.3~0.5，二期挂——2026-08-17 用户拍板一期不做）

F_猎0 = R × 胞面积     （无科技时 F=R·面积，c=1 归一化；胞面积 ≈ 4πR²/N，n=64 约 12450 km²）

### 4.2 狩猎产量（层2 食物流；猎物再生率恒定近似）

```
F_猎 = R × 胞面积 × 工具乘数链（石核1.1 × 火1.2 × 手斧1.15 × 细石器1.3 × 弓箭1.4 × 研磨器1.15 …）
  R 为层1 空间生产力（§4.1）；工具乘数链 = techs.csv carry 链（M，全科技 ≈3.16）
  ★ 猎物再生率恒定近似（不随 P 耗竭；种群动态二期）
e_猎(P) = F_猎 / (P + h)，h = 0.3·F_猎（★ 半饱和人口，随产量缩放，资源耗竭项）
  P 小 → e 高（人均富余）；P 大 → e 低（马尔萨斯压力）
  ★ h 随 F_猎 缩放后：狩猎稳态人均 e = 1/1.3 = 0.77（与工具科技 M 无关——工具只抬 F 不抬稳态人均）
  ★ e_猎 仅用于生产方式选择比较（§4.4）；能量核算用 e = Y/P（§二 Order 10）
```

### 4.3 农业产量（层2 食物流；灌溉 × 冲积土 × 种子 × 劳动 → 尖峰）

```
F_农 = R_农 × 种子系数 × φ × 劳动因子
  R_农 = R × 灌溉因子 × 冲积土因子          （空间选择性：只有河谷/冲积平原享受跳跃）
    灌溉因子：Riparian 或 LakeLevel>0 或邻 Riparian 格 ×5；否则 ×1（河谷尖峰来源；★ 待校准）
    冲积土因子：SoilLevel 5 → ×3，4 → ×2，≤3 → ×1（冲积平原富集；★ 待校准）
  种子系数：小麦 4 / 粟 3.5 / 水稻 6 / 玉米 5 / 土豆 4（techs.csv agri:value，★ 待校准）
  φ = §9 生态位适宜度（连续值 ∈ (0,1]；气候不适 → φ 低 → 产量低 → 不转农）
  劳动因子 = min(1, P_农_格 / P_劳动)，P_劳动 = 0.1 × (R_农 × 种子系数 × φ × 面积)   （★ 待校准）
    P_农_格 = 格内农业部落总人口；P < P_劳动 → 开垦不足、产出按比例缩水（Boserup 集约化，Boserup 1965）
    正反馈闭环：人少 → 开垦不足 → 产出低 → 涨不动；人口过线 → 产出跳升 → 人口涨 → 更多开垦 → 顶到单产上限
e_农(P) = F_农 / P − w，w = 0.2（★ 耕作劳动成本差，Sahlins：觅食工时短；0.3→0.2 见 §4.4 稳态论证）

农业尖峰量级：河谷格 F_农 = R(0.5) × 灌溉5 × 冲积土3 × 种子6 ≈ 45 人/km²
  非灌溉格保持 R（≤0.75）→ 河谷 vs 沙漠差 >100 倍（历史锚点：尼罗河谷 vs 撒哈拉）
```

### 4.4 生产方式选择（每 tick，Order 30）

```
方式 = argmax( e_猎(P), e_农(P) )          ← w 已含于 e_农 定义，无双扣；只比较拥有的能力（无种子则只有狩猎）
滞回防抖：收益差 |e_猎 − e_农| < 0.02 → 保持当前方式（防来回跳）
  滞回带 0.02 必须 < 农业稳态差 0.03（否则锁死切换）
  生产方式影响 F：狩猎 → F=F_猎；种田 → F=F_农（实际产出，含劳动因子）
★ e_农 比较用潜在产出（劳动因子=1）：否则人口少的部落开垦不足 → e_农 低 → 永不转农（死锁）。
  转农后增长核算才用实际产出（含劳动因子，§5.1）。
稳态论证（★ 定稿依据，2026-08-06）：
  狩猎稳态 e = 1/1.3 = 0.77（h 缩放后与科技无关）；农业稳态 e = 1 − w = 0.8 > 0.77 → 站稳不退农
  发明瞬间（P=F_猎=M·R·面积）转农条件：R_农/R × F·φ > 0.97·M（R_农/R = 灌溉×冲积土，F=种子系数，M=工具乘数链）
    Soil4+ 肥地 / 灌溉河谷 / 高基线作物才值得全科技部落转农 → 生产方式由格子属性（灌溉/土壤/气候）主导
P* 由选择逻辑涌现：人口升 → e_猎 降 → 自然跨过 e_农 → 转种田；φ 低/无灌溉/成本高 → 继续狩猎
```

### 4.5 寒冷区解锁（火 T02 / 皮毛 T04）

```
寒冷区判定：biome ∈ {IceCap, Tundra, Subarctic, Alpine}（随 biome 清理新增）
  火    → 寒冷区 F 下限 = 0.05·面积 ×3（可居但贫瘠）
  皮毛  → 再 ×3（0.45·面积，接近草原密度 0.45——皮毛衣物后西伯利亚可居）

```

## 五、人口增长、分裂、迁徙

### 5.1 增长（Order 20；2026-08-17 两层食物流定稿，K 退役）

```
格级场（每 tick 刷新）：D_格 = P_格 × c（c=1 ★ 归一化：1 单位产出 = 够 1 人吃 1 年）
部落增长（用户拍板 2026-08-17：按部落，不共享格因子）：
  F_i = 部落当 tick 实际产出（狩猎 §4.2 / 农业 §4.3；农业用含劳动因子实际产出）
  P_i ×= exp(r_eff · (1 − D_i/F_i))，r_eff = 0.005/年 × 100 年 = 0.5/tick ★
    盈余 S_i = F_i − D_i > 0 → 增长；缺口 → 饿死（用户拍板 2026-08-06：P>K 负增长）
  P_i < 1 → 灭绝（饿死判定保留）
按部落含义：同格农业部落 F 大 → 涨快；狩猎部落 F 小 → 停滞/萎缩 → 格内比例自然分化
  （历史上采集者被农民人口取代的涌现；迁徙/分裂压力仍按格，§5.2-5.3）
格压力（迁徙/种子触发用）：P_格 / F_格（F_格 = Σ 格内实体 F_i；即 P/K 的 K=F/c 语义）
```

### 5.2 分裂（segmentary lineage，Order 80 前段）

```
部落 P > SplitPop = 400（★）→ 同格裂变：
  新部落带走 45%（SplitShare ★），**身份份额等比例继承**（人口分走，文化/文化群/宗教随人口走）
  TechKeys 完整继承（分裂瞬间技术相同，此后各自发明/学习——不因同源共享）
  文化群分化：分裂时 0.5% 概率生成新文化群 id（方言→语言群，漂变）——作用于新部落的主导份额
格内上限 MaxTribesPerCell = 8（★ 性能 + 社会密度双约束，超限不分裂、迁徙优先）
快照遍历（新部落下 tick 再判，防同 tick 连锁）
```

### 5.3 迁徙（Order 80 后段）

```
饱和迁徙：格 P_格/F_格 > 0.75 → 最大部落分出 50% 迁往相邻宜居格
  （目标：无人格最高优先，其次高 F_格/低密度格）
探路迁徙：P>100 部落 2%/tick → 迁出 30% 至 1–3 跳内最高 F_格无人格（跳跃扩散）
跨海：无独木舟不跨海；有独木舟 → 可跨 1 格海洋（短距）
迁徙守恒：迁出立即减源格人口（防总人口虚增——v2 踩过的坑）
迁徙极限（用户拍板 2026-08-06）：目标判定全失败（邻格都住满/无宜居格）→ 留在原地不迁
  → 格人口最终填满 → P_格/K → 1 → 压力（§6.2 阈值 0.7）必达，农业压力触发链不断
```

### 6.2 发明（Order 40）

```
硬门槛检查：依赖（TechKeys 含前置 key）→ 环境判定 → WildCrops（种子）→ 通过才进入速率计算

通用发明（Kremer，★ 人口-知识模型）：
  λ_i = k_i · (P_部落 / P_ref_i) · (1 + 知识/16) · env_i · (1+γC)
    知识 = TechKeys.Count（累积性：发明越多越会发明）
    P_部落 = 部落人口（实体独立发明，TechKeys 是实体字段）
    env_i = 环境匹配 1.0 / 不匹配但非硬门槛 0.3（如寒冷区外发明皮毛衣物慢而非不可能）
    γC = 0（石器时代无复杂度）
  随机判定：Rng.NextDouble() < λ_i → TechKeys.Add(key_i)

压力触发（种子专属，Boserup 被逼出来的）：
  条件 = WildCrops 位 ✓ + P_格/F_格 > 0.7（★ 压力阈值 = 格子人口压力，量级待校准）
       + SoilLevel ≥ 3 + 依赖 ✓
  满足 → 以基础概率 invProb=0.005/tick 获得（起源区少数发明，非全员）
  不满足 → 发明率 0，只能传播
```

### 6.3 传播（Order 50）

```
接触定义：同格实体对 + 相邻格边界（领地格邻接）
传播概率（每 tick 每接触）：
  p = SpreadBase_i × 接触修正
  SpreadBase 分级：极易 0.08 / 易 0.05 / 中 0.02 / 难 0.008（★ 量级）
  Rogers S 曲线：传播只向"未持有 key"实体；已持有者比例高 → 源多 → 扩散加速（自然涌现）
  依赖检查：目标未持有但前置缺失 → 不传（或先传前置）
种子传播修正：p ×= clamp(φ_目标格, 0.3, 1.0)（φ=生态位适宜度连续值——适宜度高的格传得快，最低 0.3 勉强种）
贸易：旧石器无货币，物物交换（礼物交换）——传播 ×2 加成保留给后续阶段
```

### 7.1 文化标签（Axelrod 相似度互动，快——作用于 CultureShare）

## 九、种子洒落机制 + 野生作物层 WildCrops

**种子发明只在起源区**：环境 ✓ + 压力 P_格/F_格 高 + SoilLevel≥3 同时满足的少数实体（内生 1–5 起源中心，分散在不同气候区）；不满足条件的实体发明率 ≈0，**获得种子唯一途径 = 接触传播**（从起源中心扩散）。传播受环境适配限制（种子不对气候 → φ 低 → 产量低 → 实体继续狩猎）。种子产量 F_农 = R_农 × 种子系数 × φ × 劳动因子（§4.3），肥地/灌溉河谷/适候高、薄地/不适候低。

```

  1. 适宜度：加权高斯生态位（BIOCLIM/MaxEnt 式，Phillips et al. 2006）

     x_j = 年均温 T / 年降水 P / 降水季节性(MonthPrecip 冬雨夏雨湿润) / 海拔

  2. 分布区：适宜度 > 全球分位数 P70（相对该星球分布）
  3. 群聚洒落：分布区在适宜区内部以斑块/聚簇形态洒落（离散分布，非均匀铺开）
```

- **旧档放弃（用户拍板 2026-08-06/08-17）**：.cmp v4（两层公式变更，续跑行为不同）、v3 部落表、旧 biome 值（4–11）存档一律不兼容，读档报错要求重新生成——不做兼容转换。
