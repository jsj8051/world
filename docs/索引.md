## 4. 核心架构（单段摘录）

三层解耦（详见《架构设计.md》）：

```
┌─ 纹理层（观感，对齐逻辑网格 5km²/格，2026-08-10 口径统一）
│    MapViewer / Planet 网格渲染、图层着色、箭头流线
└─ 逻辑层（模拟，n=64~128 目标）
     板块 / 气候 / 河流 / 矿藏 / 土壤 —— 全部纯 C# 数组，后台线程 Task.Run 生成
└─ 存档层（MapArchive，user://maps/*.mpa）
     球面顶点数据直写二进制；游戏运行时只读存档，不重新生成
```

- **球面直通（v3 定案）：** 模拟与显示共用同一球面顶点网格（Icosahedron 细分，顶点数 = 10n²+2），无平面中转、无投影。MapViewer 每格颜色 = 最近顶点直读数组。
- **热路径纯 C#：** 模拟数据用 `float[]/byte[]/Vector3[]` 原生数组；GodotObject 派生对象只在渲染边界出现。
- **生成与游玩解耦：** 地图是存档，不是场景。

## 5. 脚本模块索引

> 命名空间总约定：`World.<模块>`，与 `scripts/` 子目录对应。
> `*` 标记为跨模块“单源常量/契约”的关键类（改一处即断链的收敛点，详见《架构设计.md》§9）。

### 5.1 Tectonics — `World.Tectonics`（板块构造，tectonics.js 移植）

| 文件 | 类 | 职责 |
|---|---|---|
| `TectonicsSimulation.cs` | `TectonicsSimulation` | **全局指挥**：每 step 年龄化 → 并行板块 Move → 合并碰撞/缝合 → 超大陆裂解 → 裂谷/俯冲（新老洋壳 + 增生楔）→ 位移 + 挠曲 + 保容海平面 → 表面侵蚀/变质回写。输出 `Plates/WorldCrust/Displacement/Elevation/TopPlateMap/SubductionMask` 及矿物前驱场 `MineralHydro/MineralSed/MineralMeta` |
| `Plate.cs` | `Plate`, `MatrixOps` | 刚性板块原语：携带自身地壳 + 3×3 旋转矩阵；`Move`（Scheldart 浮力驱动 + 刚体旋转 + 种子爬山最近邻）；`ResampleCrustToGlobal` |
| `Crust.cs` | `Crust`, `MaterialDensity`, `Units` | 每顶点 8 个地壳物质量数组（沉积/沉积岩/变质/长英质深成-火山/镁铁质深成-火山/年龄）+ 静态表面模型 `ModelErosion/ModelWeathering/ModelLithification/ModelMetamorphosis` + 浮力/厚度/密度派生 |
| `SphereGrid.cs` | `SphereGrid` | Icosahedron 球面网格 + 邻接 + 快速 Voronoi 最近邻（Lat/Lon 哈希桶） |
| `Tectonophysics.cs` | `Tectonophysics` | 物理核心：Scheldart 下插牵引速度、板块旋转矩阵拟合、边界法向、地幔聚流分割（asthenosphere flood-fill） |
| `FieldOps.cs` | `FieldOps` | 纯数值场算子：标量/向量场乘法、形态学 Erode/Dilate、梯度/散度、Diffuse(Laplacian)、统计 |

**输出链：** 板块演化产出**海拔（Displacement/Elevation）**、**物质场（地壳 8 池）**、**结构（板块图/俯冲掩码）** 与**矿物前驱场** → 进入 `World.MapGen` 管线。

> **实现要点（读代码前须知）**
> - 无平面中转，内建无量纲单位球，内部锚定地球半径 6371km，把海拔按 √(R/R⊕) 缩放；网格取自 `World.HexPlanet.Icosahedron`，存档走 `MapArchive`。
> - **演化分步**（`RunWithProgress`）：年龄化 → 并行 `Plate.Move`（Schellart 浮力驱动速度 + 刚体旋转矩阵）→ `MergePlatesToMaster` 叠入 `WorldCrust`（长英质守恒加厚、顶层板块决定镁铁质/年龄、70km 厚度封顶=简化俯冲）→ 超大陆缝合/裂解（>25% 全球触发）→ 裂谷/俯冲（洋脊新生洋壳 + 大陆裂谷减薄 + 深埋变质回收入增生楔 `Accretion`）→ 位移+挠曲+保容海平面 → 侵蚀/变质回写。
> - **矿物前驱场**：`MineralHydro`（裂谷/俯冲/增生→Cu/Au）、`MineralSed`（沉积加厚→煤/盐）、`MineralMeta`（变质→宝石/铁），以事件计数器累加。
> - **并行警告**：多处 `Parallel.For` 要求只读共享状态（桶须预构建）；`Plate.Move` 用 `ThreadLocal` 临时缓冲防竞态。

## 6. 诊断模块（Diagnostics，headless 回归入口）

> 目录 `scripts/Diagnostics/`，命名空间 `World.Diagnostics`（**`TectonicsTest.cs` 例外在 `World.Tectonics`**，早于 DiagContext 体系）；场景在 `scenes/diag/`（16 个场景）。`ArchiveDiag.cs`/`PerfLog.cs` 是基础设施，非独立场景。
> 统一入口模式（《开发规范.md》）：重建 → **DLL 时间戳断言** → 4 组 headless 回归（verify.sh）→ 退出码判定。headless 启动：
> `Godot --headless --path <proj> res://scenes/diag/<name>.tscn --quit-after N -- --<参数>`，参数经 `OS.GetCmdlineUserArgs()` 读取；每个 diag 用 GD.Print 断言 + `GetTree().Quit(code)`。
> ⚠️ 退出码约定：`CivSimDiag/LogicGridDiag/MonsoonDiag` 等断言类 0=全过/1=有 FAIL；而导出类（TempDiagnosis/PolarPreview/TiltDiag/RidgeDiag/SpeedDiag 等）多为**巡检式，读档失败仍 quits 0**。判回归以 verify.sh 选用场景为准。

**共享基础设施**
- `DiagContext`（ArchiveDiag.cs）：直读存档 `.mpa` 免重跑板块模拟（秒级）。`ArchiveDiag.TryLoad` → `MapArchive.Read` → 由顶点数 `Icosahedron.GridNFromVertexCount` 反推 n（10242→n32…）→ 复用同拓扑 `SphereGrid`；**依赖懒加载** `ctx.Require<T>(key, computer)`（新字段 = 一行 Require）；内置懒依赖 `ElevNorm/ElevM/Precip/Temp/Biome/ElevSpan`（按最近顶点映射，NaN→0）。
- `FieldCompare`：**共用 NaN 感知 diff 工具**（历史“存档往返 NaN 误判 FAIL”根治）：`Eq/MaxDiff/MaxDiff3/ByteDiff/Bytes2DDiff/IntDiff`，NaN↔NaN 视为相等。

## 7. 存档格式（MapArchive v5）

```
头部（固定）  Magic "MPA1" 4B + version 2B + seed 4B + radiusKm 4B(v5 加)
             + vertexCount 4B + 顶点 12n B(Vector3)
             + 海拔 min/max + 海拔 n×4B + 温度 …+ 降水 …+ biome n×1B
尾部扩展     ext1 自转方向 1B + ext2 自转速度 4B + ext2b 轴倾角 4B
             ext3 洋流（方向 3×4B + 冷热 4B + 强度 4B，每顶点 + psi 4B）
             ext4 河流（等级 n×1B + 流向 n×4B [+ 流量 n×4B]）
             ext5 湖泊 等级 n×1B；ext6 矿藏 等级 n×1B（(丰富度<<4)|矿种）
             ext7 土壤 肥力 n×1B（1-5）；ext8-10 季风强度 + 月降水12n + 月温12n
```
兼容策略：**版本只增不减、尾部追加**。`Version=5`；读端 `ver>Version` 拒读；旧档缺尾段 = 默认值。`.gmp/.cmp` 布局由 `ArchiveLayout` 单一来源（§9.3）。
