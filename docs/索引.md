## 3. 四层架构与依赖规则

《架构设计.md》定义的分层（**依赖只向下，反向引用一票否决**）：

```
L3 视图/交互（Godot Node）   MapView · UI · Camera · Diagnostics · noise_world/Noise*
        │  只调用 L1 公开 API 与 L2 服务；UI 逻辑不得下沉
L2 服务层（跨场景通信唯一通道）  EventBus · LogService · ArchiveService · UserPaths
        │  只依赖 L1/L0
L1 生成/模拟（确定性、可 headless） Tectonics · Biome · MapGen · CivSim/Engine · Gameplay
        │  只依赖 L0
L0 纯模型/数学（不依赖 Godot 节点，可单测）
        HexPlanet · LogicGrid · Utils · MapGen/Model · CivSim 纯模型 · Tectonics 数学
```

**关键纪律**

- 单类单文件；拆大类用 `partial` 分片，命名 `原类名.职责.cs`，放**同目录**（移动文件须同步改 .tscn 脚本路径）。
- 命名空间 `World.<模块>`，与 `scripts/` 子目录对应。
- 一切随机走 `DeterministicRandom`（SplitMix64，状态可序列化）；禁裸 `System.Random` / 时间种子。
- 日志统一 `LogService.Log/LogErr`（ADR-0004）：L1 允许调用（唯一豁免），**L0 纯模型禁止打印**，后台线程保留 `GD.Print` 直调。
- 存档统一走 `ArchiveService`；格式与随机状态入档规则不许散落。
- 诊断场景统一继承 `DiagSceneBase`。

## 5. 存档格式（全段表化，2026-08-23）

**容器**（`Utils/ArchiveChunk.cs`，ZIP 式尾目录）：
```
[4B] magic "MPA1"|"CMP1"|"GMP1"
[2B] skeletonVer   容器骨架版本（.mpa=6 / .cmp=15 / .gmp=3）
[2B] reserved
[..] 数据区        各段依次：[4B] segMagic + [2B] segVer + 数据
[12B×K] 段表       { type | offset(相对文件头) | length }
[12B] 尾目录       { 段表偏移 | 段表字节数 | tailMagic "CHKT" }
```
设计要点：段表在文件尾（写端顺序写无需回填）；加新系统 = 注册新 segMagic，未知 type 跳过（不会整档错位）；IO 用 `System.IO` → **存档往返可进单元测试**。

| 格式 | Magic | 版本 | 段清单 |
|---|---|---:|---|
| `.mpa` 世界档 | `MPA1` | **v9** | HEAD · VERT · ELEV · TEMP · PREC · BIOM · OCEN · RIVL · RIVF · RIVV · LAKE · MINE · SOIL · MONO · MPRC · MTMP · **CIVI**（文明段，v8+） |
| `.cmp` 文明档 | `CMP1` | **v17** | HEAD · NATR · TRIB · LAND · STTL · WARS · **EVNT** · **STAT** · **PLAY** · REFS |
| `.gmp` 逻辑网格 | `GMP1` | **v3** | BODY（内部布局仍 v2，含 psi） |
| `.sav` 游玩档 | — | — | `Gameplay/SaveArchive.cs`（`Ext=".sav"`） |

**哨兵块**：`EVNT`(0x45564E54 事件历史) / `STAT`(0x53544154 国家档案) / `PLAY`(0x504C4159 玩家会话) 位于 CIVI 顺序流尾部——旧档无此哨兵 → 读端回退为空，不破坏流。
**版本策略**：旧档一律作废（用户拍板），读端拒绝 Older；详细布局/验证配方见《存档段表格式设计.md》。
