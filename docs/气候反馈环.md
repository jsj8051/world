# 气候反馈环清单（三态决策表）

> 2026-08-16 建立（气候层封版依据）。规则：每个反馈环必居其一——**已闭环**（一步解析收敛）/ **单向截断**（影响 < 精度，不回流）/ **忽略**（低于下一阶，标注理由）。
> 新增因素先对照本表：已处理的环不重复加，低于精度的环不加。复杂度上限 = 环数（O(n) 非 O(n²)，环与环不嵌套）。

## 二、气候场流水线（单向 + 局部闭环）

```
Stage1（PlanetPipeline）：
  海拔/海陆（板块模拟）→ 第一遍洋流（WindField，供温度修正）
  → 年均温 + 年降水（ClimateGenerator）
  → 【湿润降温修正】T = T₀ − k·P/(1+g)          ← 环1 入口预修正
  → 月温度/统一风场/月降水（MonsoonSystem，含雨影 w=V·∇h）
  → 洋流第二遍（统一风场年合成 + β + 热成风）     ← 环2 存档场
  → 柯本分类（真实月数据）
Stage2 水文 → Stage4 矿藏 → Stage5 土壤
```

关键：**每个闭环的修正都加在源头场**，下游场的计算结构不变 → 流水线依然单向（每场只算一次），无跨层耦合。
