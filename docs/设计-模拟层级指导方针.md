# 设计-模拟层级指导方针

**状态**：草案 v0.1 —— **待判读拍板**
**定位**：本文件是**指导方针**，不是模块设计。它只规定「什么东西可以算一层」「层与层怎么约束」，**不规定任何具体机制的数值、参数或实现**。
**适用范围**：全部模拟层（地壳运动 / 气候 / 人文）。凡新增或重写模拟类设计文档，须先过本方针。

**触发（2026-09-22）**：既有 11 层划分被判为**分类不当**——它们按"执行顺序"排布，里面混装了六类不同性质的东西；两条本应横切全局的约束（质量守恒、单值性）被降格成"第 8 步的动作"。由此确认一条结论：

> **补丁之所以必须存在，是因为约束被降格成了步骤。**

---

## §1 第一原理：什么叫「一层」

一个划分要被称为「层」，必须同时满足**五条**：

| # | 条件 | 反例（不满足时它其实是什么） |
|---|---|---|
| 1 | **同性质**：一层里只放同一种性质的东西 | 混装 ⇒ 无法用统一判据检查 |
| 2 | **单向依赖**：只依赖其下层，不回指 | 回指 ⇒ 循环依赖，不可分别验证 |
| 3 | **显式契约**：给出什么量、什么单位、什么时刻、什么口径 | 靠注释 ⇒ 口径修复反复发生 |
| 4 | **可独立检查**：有自己的一组自洽判据 | 无判据 ⇒ 只能靠"看起来对不对" |
| 5 | **可复现（确定性）**：同输入同输出、**逐位一致** | 不可复现 ⇒ 无法判读、无法对账 |

**不满足这五条的，就不是层。** 它是以下三者之一：**接口**、**约束**、或**一条通路**。这三者都不占"层"的位置。

---

## §2 类别学：模拟里的东西只有四种性质（完备）

| 性质 | 定义 | 自己演化？ | 有副作用？ | 谁能写它 |
|---|---|---|---|---|
| **状态** | 随时间演化的事实源，唯一权威 | 是 | — | 只有状态层内部（经其接口） |
| **派生量** | 由状态**唯一确定**，可随时重算、丢弃无损 | 否 | 无 | 无人写它（纯函数） |
| **过程** | 读状态 → 写状态 | 否（它改状态） | **有** | 只写状态层暴露的接口 |
| **事件** | 改变**拓扑/结构**（非连续量：连通性、归属划分、存在性） | 否 | **有** | 同上，但只改结构类字段 |

**判定规则**：
- 重算一次结果不变 ⇒ **派生量**（不该有缓存、不该被写）
- 反复执行会累积 ⇒ **过程**
- 改变了"谁是谁的邻居/谁属于谁" ⇒ **事件**
- 没有它就什么都没有 ⇒ **状态**

## §3 五条横切约束（不是层，不占步骤位置）

约束的定义：**它对全局成立，且必须在每一条相关通路上被检查**。把约束做成"某一步做一次配平"，必然退化为兜底。

| 约束 | 内容 | 检查方式 |
|---|---|---|
| **A 守恒** | 质量／水量／能量的进出逐步闭合 | **每一条改该量的通路各自对账**，残差可测；**不许**在一个集中位置一次配平 |
| **B 单值性** | 每个物理量在全模拟中**只有一个定义处、一个版本** | 接口契约检查 + 运行时探针（同一量若有两个来源，必须能报出差异） |
| **C 时间一致** | 驱动场的时刻 = 被驱动状态的时刻 | 禁止用上一步的场驱动本步的状态；能报出场-态时差 |
| **D 尺度自洽** | 每个物理量落在其**物理定义域**内 | **不许靠截断把量压回去**；截断触顶率必须可测且应当接近 0 |
| **E 机制无重叠** | 同一效果不由两个机制同时负责 | 效果归因唯一；发现两个机制做同一件事 ⇒ 删其一 |

**推论（重要）**：若某条约束只能靠"在末尾加一个伺服/截断"来满足，则**该约束的分类是错的**——它被降格成了步骤。

> **约束 D 的边界（防误用）**：截断并非一律禁止——**离散方案自身的稳定条件**（如显式平流的 CFL 条件）
> 是"固有约束"，它的存在不违反 D。违反 D 的是：**当截断常年触顶、由它决定物理量时**。
> 判据是**触顶率**：健康状态应接近 0，若常态 100% 则说明本构没关门（见 §6-1）。

`设计-new_HexWorld-地壳运动-08-自洽性审计.md`（该文件自本次起**只作执行记录**，判据部分以本方针为准）。

## §4 层级清单（规范）

四类层，按依赖单向排列：

### S 状态层（唯一事实源）

**状态内依赖序（2026-09-22 拍板）：热 → 几何 → 归属。**
上游状态**不得**读下游状态，也**不得**读任何多元分类标签——即**热只能读热自己**
（不许拿"是不是陆"这类几何/成分标签来栅住热过程）。

| 状态 | 说明 | 依赖 |
|---|---|---|
| **热** | 系统的热状态（既是状态、又是参数源、又是几何源——**三身份耦合，必须显式声明**） | 只读自身 |
| **物质／几何** | 系统的物质构成与其派生的几何量 | 读热 |
| **归属** | "谁属于谁"的标签场 | 读几何/物质 |

**更新次序 vs 读取限制（2026-09-22 补充）**：依赖序规定的是**更新次序**。
上游**可以**读下游的**上一步**值（**显式滞后耦合** = 标准算子分裂）；**禁止**读下游**本步刚更新**的值。
> 理由：热—几何耦合是**固有约束**（厚柱保温、冷柱变厚变浮），消不掉，只能选表达方式。

**契约**：
1. 状态层**只能**由过程层与事件层经其显式接口修改；任何人不得直接写状态内部字段。
2. **反向边禁止**：下游不得改写上游。凡现存的反向耦合（如"厚陆壳格冻结热年龄"）必须改写为
   "对下游的显式输入"或"事件后果"，**不得**以实现细节留在上游规则里。
3. **多元标签不得进物理**：任何二值/多元分类标签（如"陆／洋"）**不得**作为上游状态的输入，
   只能是派生层的观测量。（**待办 T1**，见 §7）

### D 派生层（无副作用，可随时重算）
| 派生 | 唯一来源 |
|---|---|
| **物性强度**（黏度／屈服强度／刚度） | 热 + 物质成分 |
| **力源** | 物质与几何 |
| **几何输出**（形变位移、水位） | 物质 + 力源 + 约束 A（水量） |

**契约**：派生层是**纯函数**——不得缓存、不得被写、不得持有跨步状态。若发现它在缓存 ⇒ 说明它被当成了状态。

### P 过程层（有副作用，按序执行）
| 过程 | 读 | 写 |
|---|---|---|
| 本构与解算 | 派生（强度、力源） | 速度场（**不写状态**） |
| 板级／块级投影 | 解算输出 | 相干运动场（**接口，不是层**） |
| 物质运输 | 运动场 + 状态 | 物质分布 |
| 边缘机制 | 分类 + 运动场 | 物质分布（含进出账） |
| 形变-摊平（屈服流等） | 状态 | 物质分布 |
| 地表过程 | 水面/降水 + 状态 | 物质分布 |

**契约**：
1. 过程层**只写状态层的接口**，不写派生层。
2. 每个过程**必须**声明它属于哪条守恒通路（约束 A 的对账点）。
3. 过程层**禁止**给任何物理量加"外部截断"（见 §6-1）。

### E 事件层（拓扑变更）
缝合 / 裂解 / 重启等：改变归属划分与连通性。
**契约**：
1. 事件层**只改结构类字段**（归属、连通、存在性），**不得**借机修改连续量；且事件必须可复现（确定性）。
2. **定序（2026-09-22 拍板）**：事件**只在过程层末端**发生；**派生层不得读事件结果**——
   派生层在每个过程步开头按当时状态重算，事件造成的拓扑变化由**下一步的重算**自然吸收。

## §5 层间契约（规范）

任何一条层间接口，必须写清**四件事**，缺一不可：

1. **量**：传的是哪个物理量
2. **单位**：量纲与单位
3. **时刻**：**同刻**（禁止用上一步的场驱动本步的状态——时间错配）
4. **口径**：**哪个版本**（若同一量存在多个中间版本，必须指明传的是哪一个，并说明其余版本为何被丢弃）

> **示例（抽象）**：过程 X 传给过程 Y 的"运动场"，必须指明它是**解算原始场**、**相干投影场**，还是**经安全限幅后的场**——三者是三个不同的物理声明，不可混用。

---

## §6 禁止清单（本方针的核心）

1. **禁止在过程层给物理量加外部截断。** 截断的存在 = 声明本构没关上门；正确做法是修**声明该量定义域的那一层**。
2. **禁止把约束降格成步骤。** 守恒类约束必须逐通路检查，不许"末尾配平"。
3. **禁止同一物理量有第二个定义处。** 发现两处 ⇒ 必须删除其一，并说明保留哪个、为什么。
4. **禁止时间错配。** 用旧的场驱动新的状态 = 偷换物理。
5. **禁止为症状新增机制。** 先定位到**层**，再改那一层；跨层打补丁一律驳回。
6. **禁止跨层直写。** 过程层不得写状态内部字段；派生层不得被写。
7. **禁止用调参让结果数字变好。** 正确是自洽的**产物**，不是可以单独瞄准的目标。
8. **禁止在派生层缓存。** 缓存即状态，须归还状态层。
