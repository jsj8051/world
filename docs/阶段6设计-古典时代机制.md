## 〇、总览

### 0.1 三层实体定义（本次重构的正本清源——用户 2026-08-23 提问"国家是什么定义，和部落有什么不同"）

| 层级 | 定义 | 本质 | 生灭 | 权力载体 |
|---|---|---|---|---|
| **部落 Polity** | 格内社会单元，活实体：人口 P、文化标签/文化群、技术位掩码、宗教、领地（影响力圈）、声望、库存 | **人的血缘集团**——人就是一切 | 分裂（血缘裂变）、迁徙、吞并/合并 | 无专职权力（band 头人 = 声望） |
| **酋邦 Chiefdom** | 至尊酋长 + ChiefReach 半径内归附的部落（派生） | **个人庇护网络**——patronage，权力绑定个人 | 君主死 → 继承窗口危机 → 可能瓦解 | 君主个人（声望/再分配） |
| **国家 State** | **制度机器**：都城聚落（载体）+ 行政节点（官职绑定场所）+ 税制（贡赋池）+ 疆域（行政网络）+ 君主（制度的主管，可替换） | **制度层**——凌驾于部落之上的制度，不依赖任何个人 | 贡赋断流 / 都城被征服 / 行政失效——**不随君主死亡** | 制度（官职/税制/法律），君主只是主管 |

**核心原则：国家不是"更大的部落"，是不同层级的存在**——部落可以在国家内被臣属/登记，但部落仍是部落；
国家的实体性**嫁接在聚落网络上**（都城 + 行政节点，复用"场所比人长寿"语义），不引入新的国家实体表。

## 一、⓪ 国家重定义（制度实体模型）

### 1.1 现状的问题（用户 2026-08-23 指出的三个名不副实）

| # | 现状（阶段4 标签式国家） | 问题 |
|---|---|---|
| ① | 国家中心 = 酋长个人（StateId = 至尊酋长 Id） | "制度化"了中心却还是个人——官僚在哪？没有官职/机构，EliteFrac 0.25 只是参数 |
| ② | 国家随个人生灭：崩溃路径含"继承绝嗣" | 史实相反：国王死国家还在（官僚制延续），王朝绝嗣只是换王朝 |
| ③ | 国家成员 = 酋邦成员 = 个人庇护半径 | 国家没有"疆域"（行政边界），只是酋长的圈扩大版 |

**结论：四个机制差异（税率×2/精英×2.5/冲突×0.5/继承豁免）全是参数，没有结构性差异——国家 = 酋邦的高级皮肤。**

### 1.2 重定义：国家 = 制度实体（五个构件）

```
国家 State = {
  都城 Capital        = 聚落实体（Level ≥ 2，**制度载体**——场所比人长寿）
  行政节点 Nodes      = 次级中心聚落（Level ≥ 1，**官职绑定场所**：机构是聚落，不是人）
  税制                 = 贡赋池（制度化征收：税率恒定，不靠君主威望）
  疆域                 = 行政网络覆盖（都城 + 节点 + 沿边境登记）——不依赖君主位置
  君主 Monarch         = 国家内 Prestige 最高成员（**虚拟头衔，可替换**——制度的主管）
}
```

- **国家中心从"酋长个人"改为"都城聚落"**：载体是场所（比人长寿），君主只是占据制度位置的人；
- **官职绑定聚落而非个人**：行政节点（次级中心）就是"官职"的物理化身——聚落不随人死，官僚制天然存续；
- **君主 = 虚拟头衔**：国家内 Prestige 最高成员（不必占据都城——加冕是制度行为，不是搬迁）；
- **全部派生，零新存档字段**：都城/行政节点 = Habitations 段已有；贡赋池/成员 = 已有；君主 = Prestige 派生——**国家实体性 = 聚落网络，不新增实体表**。

### 1.3 结构性差异（国家 vs 酋邦——不再是参数，是规则分叉）

| 维度 | 酋邦 | 国家（制度实体） |
|---|---|---|
| **存续** | 君主死 → 继承窗口危机 → 可能瓦解 | 君主死 → **换君主**（Prestige 最高者继位）→ 国家继续 |
| **疆域** | 君主个人半径（ChiefReach，随君主位置） | 行政网络（都城 + 节点 + 沿边境登记）——不随君主移动 |
| **官僚** | 精英比例（EliteFrac 参数） | 行政节点聚落（场所实体）——官职=机构 |
| **税制** | 个人贡赋（互惠，随君主威望波动） | 制度化征收（贡赋池，规则恒定） |
| **继承** | 继承窗口（Kirch：权力真空→内战） | 制度化推举（Prestige 继位——官僚制不中断） |

史实：无文字也能有国家（印加结绳、早期城邦），但**文字 = 国家规模的跃迁**（印加 600 万 vs 罗马 6000 万——文书行政支撑帝国）。

| 国家形态 | 条件 | 能力 |
|---|---|---|
| **早期国家**（城邦） | 阶段4 **三条件**（都城/贡赋/存续——2026-08-24 拍板：次级中心移除，首都即可承担行政网络） | 税制 + 都城 + 君主更替（Prestige 继位）——但行政半径有限（口传行政） |

## 二、机制② 文字行政（基于重定义：继承制度化 + 行政吸纳）

### 2.1 史实锚点

- **楔形文字源于记账**（税册/王表）：官僚行政是文字的第一用途（Uruk 泥板 = 谷物/牲畜账目）；
- **帝国 = 文书行政**：阿契美尼德波斯/罗马靠文书档案跨越千里统治——文字让统治**脱离个人关系网络**（韦伯：文书行政是官僚制的技术基础）；
- **酋邦 vs 帝国**：酋邦 = 个人再分配圈（半径有限）；帝国 = 制度化行政疆域（半径由文书网络决定）；
- 已有先例：战争吞并（ConqueredBy）= 武力路径的"半径外归属"；文字行政 = **和平路径**的对称物。

### 2.2 机制规则（基于⓪ 国家重定义）

**① 继承制度化**（国家存续性）：官僚国家君主死 → Prestige 最高成员继位（虚拟头衔更替）→ 国家不灭；
早期国家君主死 → 现状继承窗口危机（行政薄弱，P9 拍板）。

**② 行政吸纳**（帝国扩张）：

| 步骤 | 规则 | 说明 |
|---|---|---|
| ① 候选 | 非君主 band（未被征服、领土存在） | 行政登记的是臣民，不是君主 |
| ② 判定 | 存在官僚国家（君主持 writing），且 dist(e.Cell, 都城.Cell) ≤ AdminReach **且 e 领地接触该国行政疆域**（任一国成员领地接触，P4 ✅） | 行政网络沿边境延伸（文书/驿道） |
| ③ 竞争 | 多国争抢 → 该国君主 Prestige 最高者得（平局 → 较小 Id） | 同庇护竞争规则（确定性） |
| ④ 效果 | e 登记入国（成员 + 纳税 + 秩序覆盖） | 与 ConqueredBy 同构（强制归属的和平版） |

- **接线**：被吸纳成员自动纳入国家机制（税制/秩序/继承——按国家成员判定）；
- **优先级**：行政吸纳 > 个人庇护（制度 > 个人，Weber，P5 ✅）；ConqueredBy（武力）仍最高优先；
- **涌现**：行政归化 → 成员↑ → 贡赋池↑ → 国家更稳 → 再吸纳——帝国滚雪球；酋邦边缘部落被吸走 → 小型酋邦瓦解（史实：帝国边缘酋长领地并入）；
- **确定性**：无 Rng、固定遍历序（Prestige 降序 + Id 升序）→ T04 读档续跑无分叉；
- **存档**：全部派生 → **零新字段，版本不变**。

## 三、后续机制（占位——每个做完上一个再细化）

### ① 货币经济（coinage → TradeModel(55) 双路径；P1 形态待拍板）

- 史实：吕底亚铸币（前 600）——货币解除物物交换的**双巧合需求**（一般等价物）；
- 规则（形态 A 推荐，无实体）：coinage 部落对间走货币路径——门槛放宽、量 ×3、距离衰减放宽、城市枢纽加成 → 货币部落成枢纽、中心-边缘结构涌现；
- 前提（P2 ✅）：bronze_chariot + **writing**（铸币 = 冶金 + 记账）；
- 存档：零新字段。

### ③ 常备军（standing_army → WarModel(51) PowerOf 加项）

- 史实：斯巴达/罗马军团——职业兵脱离生产；军力 ≠ 全民皆兵；
- 规则：国家有 standing_army → 军力 += 贡赋池投入 × 转化率（职业军强度，独立于人口）→ "人口少军强"涌现；
- 存档：零新字段（贡赋池已在档）。

### ⑤ 圣典宗教（writing + ReligionType 4 → ReligionModel(70)）

- 史实：佛教/基督教 = 文字教义 → 传教脱离血缘与地域（普世化）；
- 规则：社会有 writing → 宗教传播不再要求接触（抄写传教）；一神教解锁跨文化群传播加成。

### ⑥ 长途商路（sail → TradeModel(55) 第二通道）

- 史实：丝绸之路/地中海——多跳中转、枢纽集散；
- 规则：货币 + sail → 贸易升级为"商路通道"（沿格链多跳传播、衰减更缓、枢纽中转加成）；跨海贸易出现。

### ④ 城市功能化（law_code → HabitationModel(48) 等级重写）

- 史实：Çatalhöyük 万人仍是村庄——城市 = 剩余/权力/贸易中心，非人头（Childe）；
- 规则：聚落升级从 Dwell×P 阈值改为功能驱动：粮仓盈余集中 → 城镇；都城（= 国家制度载体）→ 放宽；贸易枢纽（货币流量）→ 城市；人口降为次级门槛；
- 依赖⓪（都城语义）与①（枢纽信号）。
