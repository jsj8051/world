## 四、纪律（本系列专用，长期有效）

1. **无日志名 / 无 `[SW-INST]` 行的数字，一律不进表**；
2. **实测与估算分列**（估算必须标外推指数来源）；
3. 判据**跑前写死**，字面命中**不得淡化**（作用域要缩就由判读方明说并担责）；
4. 引用已登记结论前**先 grep 原文**；
5. 墙钟**不进判据**，且**跨批比较必须先有同批基线**；
6. **验收只写目标与测量项、不设达标线**（完成度由用户对照判读）。
