## 2 方程与离散化（架构级契约；最终形态归专业 Agent）

### 2.1 被替换的对象（现状）

薄席黏性 Stokes 的垂向积分形式：解速度场 `v` 使 `∇·(2η ε̇(v)) + f = 0`（**准静态，无 ∂v/∂t**）；本构门 **系数形式** `K_eff = max(min(K0, YW/|Δv|), K_floor)`（`H3ThinSheet.cs:1707-1770`；`YW = Y·W` = 整边屈服力）；外层 **12 轮 Picard** 更新 `K_eff`（**每轮一次 `CapEdgesByYield` 全边遍历**），内层 **CG（≤400 迭代）** 解线性子问题。

### 2.2 B 的两段

**第一段 = 局部隐式单扫（lagged implicit）**

把全局平衡换成逐格更新，**本格项隐式、邻居项滞后**：

```
对每格 i：   D_i · v_i^(n)  =  b_i − Σ_{j∈N(i)} A_ij · v_j^(n−1)
D_i        = 本格（对角）算子，含 K_eff(i)          ← 刚性项放左端 ⇒ 无条件稳定
v_j^(n−1) = 邻居速度，取上一轮（lagged）
```

- **1 次扫** = 1 遍历（读邻域 + 写本格）；**2 次扫** = 邻域同步 2 次（初值，见 §5）。
- ★**在最新速度上算帽**：逐格更新本格时，用**本格已更新的 `v_i` 与滞后邻居**评估该格各边的力（Gauss-Seidel 意义）⇒ **不留"帽比场更旧"的额外时差**。
- **关键**：对角隐式处理的正是**刚性项** ⇒ **不需要 CFL、不需要限幅、不需要伺服**（`-14 §3` 的正路 (i)）。
- **与已退役路线的区别**：退役的是「**显式**推进 + 限幅/CFL/伺服」；B 是**隐式 lagged**，且**不设任何钳制**。

**第二段 = 一次性粗层长波校正（每步 1 次）**

```
r  = b − A·v^(final)          ← 细层残差（★必须用投影力 F，见 §2.3 落地点 2）
r_H = MGRestrict(r)            ← 限制到粗层（复用现行实现）
δv_H = 解粗层低频问题(r_H)      ← 粗层 1-2 遍历（便宜：L1=1.000 L2=0.143 L3=0.181）
v   ← v + MGProlong(δv_H)      ← 延拓回细层
```

- **目的**：补回第一段丢掉的长波（板尺度）平衡。
- ★**成本论证（架构师）**：现行 V-cycle 贵在**细层平滑**（`L0 = 5.000-7.000`），而 B 只需要**粗层低频修正**（`L1+L2+L3 = 1.324` 当量）⇒

### 2.3 ★帽的落地：**力形式本构**（构造专家判定 2026-09-27；原 §11-2 的答案）

> 一句话：**帽不是"解完后要削掉的东西"，它是"力的定义"。**

**力形式（与现行系数形式等价改写）**：

```
F(Δv) = max( K_floor·Δv , min( K0·Δv , YW·sgn(Δv) ) )
```

| 分支 | 条件 | 力 | 切线（斜率） |
|---|---|---|---|
| 弹性 | `K0|Δv| ≤ YW` | `K0·Δv` | `K0` |
| 塑性平台 | `YW/K0 < |Δv| ≤ YW/K_floor` | `YW·sgn(Δv)` | `0`（理想塑性） |
| 地板 | `|Δv| > YW/K_floor` | `K_floor·Δv` | `K_floor` |

**性质**：三分支分段线性、**单调非减、连续**（max/min 复合 ⇒ 可积为**凸势**、是其次微分）⇒ ① 局部隐式更新**唯一解、可闭式分支求解**（返回映射：试算 → 判分支 → 投影重算，固定 2-3 步、**无迭代判据**）；② **恒正定**：`K_eff ∈ [K_floor, K0]`，比值 `K0/K_floor = 3e23/1e20 = **3000**`（**物理界**，不是数值钳制）。

**落地三要点（缺一不可）**：
1. **切线-投影分离**：解 `v` 用**切线** `K_eff`（保证对角隐式、无条件稳定；★**塑性分支切线 = 物理地板 `K_floor`，不是数值 ε**），而**凡"力"被定义/消费之处一律用投影力 `F`** ⇒ **末态不变量精确成立、与扫次数无关**（因为它是所用力字段的定义性质）；剩下的只有"力与 v 的**一致性残差**"——那正是单扫+粗层本来就要背的失真，与平衡残差**同源同阶**（同一个滞后误差），**不额外引入失真**。
2. **在最新速度上算帽**（本格已更新的 `v_i` + 滞后邻居，Gauss-Seidel 意义）。
3. **分支判定确定性**：边界用与现行同一严格不等号（`stress > YW`）、**不留 ε 依赖**；因不需 `YW/|Δv|` ⇒ **除零奇异与 `MathF.Max(speed,1e-30f)` 哨一并消失**。

**必须走力形式的五处（落地清单）**：
1. 单扫逐格更新的**边力装配**（对角切线用 `K_eff`）；
2. ★**粗层残差** `r = b − A·v`（**限制前**）—— 否则粗层修的是"错的残差"；
3. ~~**通量运输**消费的边力/速度~~ ⇒ ★**已澄清（构造专家亲核）：运输消费的是速度、不是力 ⇒ 落地点 3 = 「无需改动」**。证据：签名 `H3FluxTransport.Step(… Vector3[] velocityRadPerMy …)`（`H3FluxTransport.cs:129-131`）；用量 `TangentialSpeed(velocityRadPerMy[i], radial, t)`（:193-194）、方向 `velocityRadPerMy[from]`（:412）；全文件对 `Yield` 的引用只有参数声明 `YieldForcePerLengthN = 3e12f`（:67），**不在运输的消费路径上**。帽约束的是**应力**而不是速度 ⇒ 运输只需拿到"与投影力自洽的那个解"，由 §3 的**强制顺序**保证；
4. **诊断与事件触发链**（`StrainRate` / 屈服边计数 / 缝合裂解判据）：★**屈服边计数必须由力形式分支判定给出**（不得从滞后系数反推，见 §3 写死 3）；`StrainRate` 的**计算时点**见 §3 强制内部顺序；
5. **跨步状态传递**（无记忆律下 `K_eff` 每步重算；若走 (d) 则状态量随步传递）。

**代价 = 零新增遍历，而且更省**：帽分支算术**融合进单扫已有的边循环**（该循环本来就要读 `_edgeK`、算 `Δv_t`）⇒ 额外遍历 **0**；且现行"每轮一次 `CapEdgesByYield` 全边遍历"可**一并省掉** ⇒ 现行每步 12 轮 = **12 次帽遍历**，B 档下 = **0 次**。每边多算的只是几个比较/乘加，**无新访存**。
**铁门三条全过**：① 投影 = **本构定义本身**（**不是事后限幅**）；② 固定遍历数（无收敛判据、无迭代上限）；③ 对角隐式 + `K_eff ≥ K_floor` 恒正定（局部算子上界一致 ⇒ 无 CFL 需求）⇒ **不退化显式**。

**★顺带消掉旧风险「失真不可调」**：自由度 = **"失真"随扫次数单调** ⇒ **旋钮在扫次数，不在帽**（M7 的 3/5/8 曲线就是这个旋钮）⇒ `-14 §7 风险 4` **就此降级**。

**★不变量要照实际律写（重要修正）**：地板分支在 `|Δv| > YW/K_floor ≈ **6 m/yr**` 时让应力**重新超过 Y** ⇒ 真实不变量是

```
|F| ≤ max( YW , K_floor·|Δv| )
```

真实板速 `1e-2 m/yr` 永不触及，但**一旦触及即警报、不得静默**（见 M13 + 风险 9）。

**被判否的两条（留档，防重走）**：
- **(a) 单扫内联施加一次（系数滞后）**：等价于"解→帽→解"退化成 **1 轮 Picard**；系数滞后于速度场 ⇒ 塑性集**系统性滞后一拍**（会聚/加速区：K 偏大 ⇒ 解出的 Δv 偏小 ⇒ 应力**低于** Y、塑性没被激活、局部应变被高估；减速/事件后区：K 偏小 ⇒ 应力**超 Y 无上界**，超多少取决于 Δv 变化倍数）⇒ 末态保不变量只能**事后限幅 = 铁门明文禁止**（09-23 卸载的补丁链正是这一族：`PlasticStressFloorFraction` / `ViscosityRatioCap`）。
- **(c) 帽移进粗层校正段**：**范畴错误** —— 帽是**逐边局部**约束（屈服带常 1-2 格宽），粗层是**长波校正**基函数；在粗层施加 ⇒ **屈服站位被空间抹平/错位**，而"哪些边屈服"正是决定裂解/缝合位置的世界线量（同 cap 换档已实测缝合 3 vs 4；错位 2.52 格即致结构分歧）⇒ 仅可作**长波塑性残差的补充校正**，**不可作为帽的主施加点**。

**第四条路 (d)（登记为条件升级路径，不现在做）**：把帽做成**状态量的返回映射（增量本构）**：

```
试算  σ_tr = σ_e^(old) + K0·(Δv − Δv_pl^(old))
投影  σ_e^(new) = Π_[−YW, +YW](σ_tr)          ← 精确、点态、无迭代
塑性增量 Δv_pl^(new) = Δv − σ_e^(new)/K_floor  ← 地板 = 残余黏性
```

不变量在**状态层**按构造成立，**与求解器扫次数、与速度场收敛度完全解耦**（最强的"按构造成立"保证）；代价 = 本构**从无记忆变有记忆** ⇒ **世界线必然重标定**（属**用户拍板项**；B 必须作为新档），内存 +1 float/边。**触发条件**：`(b)` 在 M15/M16 判读上**出带**时直接升级到 (d)。**不为 (d) 阻塞第一段 spike。**

### 2.4 ★名词分离（防全项目误引）

| 词 | 含义 | 需要迭代吗 |
|---|---|---|
| **不变量**（局部、逐边） | `|F| ≤ YW`（地板分支见 §2.3 修正） | **不需要**——它是本构输出（力的投影）的定义性质，**任何速度场代入都自动成立** |
| **一致性**（全局） | 用这些饱和后的力做平衡，得到的 `v` 与这些力**互相自洽** | **需要**——这才是 Picard 环在收敛的东西（现行判据 `‖Δu‖/‖u‖ ≤ 1e-3` 检的是**速度更新**，不是帽集合） |

**推论**：单扫架构下"帽怎么按构造成立"的答案**不是**"再找个地方把帽塞进去"，而是**把帽的定义从"解后修正的系数"搬到"算子内的力"**。系数形式必须迭代，是因为系数要**回喂**给求解器；力形式不需要，因为投影在**力被使用的地方**就地成立。

## 3 每步执行顺序与数据流（接入点）

```
H3DynamicTectonics.Step()
 ├ 状态派生（温度 / 厚度 / 黏度 / 本构门）                          ← 不动
 ├ ★【B 档】AdvanceOnePass()：局部隐式单扫 ×2 → **粗层校正 ×1** → **然后才算派生量**  ← 替换「12 轮 Picard × CG」
 │   └ ★★**强制内部顺序（构造专家必修 2）**：双扫 → **粗层校正** → **之后才** `ComputeStrainRates()`
 │      与一切由速度派生的诊断/事件输入。理由：现行 `ComputeStrainRates()` 在 `Solve()` 末尾
 │      （`H3ThinSheet.cs:470`，Picard 循环之后），其产物经 `_riftStrainSheet.StrainRate → _riftStrain`
 │      （`H3DynamicTectonics.cs:1375`）进裂解种子；**B 档粗层校正会再改一次速度场** ⇒ 若应变率在
 │      校正前定稿，事件判定读到的是**被后续校正改掉的旧速度** ⇒ M15/M16 测的**不是事件所用的那个场**。
 │   └ 帽 = 力形式，融合进边循环（§2.3）⇒ 0 额外遍历、省 12 次帽遍历/步
 ├ 通量运输（owner 随物质 + 逐格场）                                ← 不动（接口不变；见 §2.3 落地点 3）
 ├ 地表过程 / 海平面（Airy + 挠曲）                                ← 不动
 └ 事件判定（缝合 / 裂解 / 重启）→ PlateId 拓扑                     ← 不动（消费力口径见落地点 4）
```

- **对外契约不变**：每步一次调用、**原地更新同一批场** ⇒ 下游（通量运输/地表过程/海平面/事件）**零改动**。
- **诊断口新增**：每步**实际遍历数 + bytes/步** ⇒ 取代"迭代数"成为**主成本口径**。
- **确定性**：固定遍历序 + 固定归约序（**禁原子加 / 乱序归约**）⇒ 13 支指纹逐位可复现；且**没有"容差收敛 ⇒ 迭代数随浮点细节漂移"这一路不确定源** ⇒ 比现行**更容易**保证确定性。
- ★★**禁止缓存力（构造专家写死 3）**：力必须在**使用点现场投影**（粗层残差 / 屈服边计数 / 诊断 / 事件输入皆然）；**禁止**双扫后缓存一份 `F` 再跑粗层校正 —— 那样**末态不变量立即失效**（退化成 §2.3 判否的系数滞后变体）。⇒ `LastYieldedEdges` / `SolverYieldedEdgesLastStep`（`H3DynamicTectonics.cs:305`）必须由**力形式分支判定**给出，**不得从滞后系数反推**。
