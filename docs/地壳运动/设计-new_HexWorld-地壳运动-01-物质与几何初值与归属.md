## 2. S 状态的完整清单（**一次定义处**）

### 2.1 物质八场（`H3PlateFields`）

各场是**柱质量**（单位 **kg/m²**；厚度 = 质量 ÷ 密度，见 §2.3）。
下标与 `Ball.CellIds` 对齐，长度 = N（格数）。

| 场 | 语义 | 分组 |
|---|---|---|
| `Sediment` | 松散沉积（未固结） | **守恒组** |
| `Sedimentary` | 沉积岩 | **守恒组** |
| `Metamorphic` | 变质岩 | **守恒组** |
| `FelsicPlutonic` | 长英质侵入岩 | **守恒组** |
| `FelsicVolcanic` | 长英质喷出岩 | **守恒组** |
| `MaficVolcanic` | 镁铁质喷出岩（洋壳主体） | **顶层裁决组** |
| `MaficPlutonic` | 镁铁质侵入岩 | **顶层裁决组** |
| `Age` | **年龄**（单位 **My**，非秒；见 §2.6） | **顶层裁决组** |

### 2.2 归属 `PlateId[]`

`int[]`，每格归属的板号；**`-1` = 无主**（平流撕裂出的空洞，待裂谷填新洋壳）。

> ⚠️ **语义与现状**：`PlateId` 是**标签（int）**，不是物质 —— 它**不具备可加性**，
> 因此**不能像八场那样随物质按份额输运**。它的正解见 **§4**。

### 2.4 三组划分

| 组 | 成员 | 语义 |
|---|---|---|
| `_allPools` | **8**（七物质池 + `Age`） | 全部逐格标量场 |
| `_conservedPools` | **5**（`Sediment` … `FelsicVolcanic`） | **守恒组**：只在组内转移，进出必须记账 |
| `_topDecidedPools` | **3**（`MaficVolcanic` / `MaficPlutonic` / `Age`） | **顶层裁决组**：由平流的顶层裁决决定归属（不按份额混合） |

> **分组不是分类癖，它决定输运规则**：守恒组按**份额混合**（广延量、可加），
> 顶层裁决组按**落点裁决**（不可混合）—— 详见 09 §3.2「属性输运总账」。
> ⚠️ **`Age` 与两个镁铁质池同组**，但三者的物理性质并不同类（见 §2.6）。

### 2.5 常量

| 常量 | 值 | 语义 |
|---|---|---|
| `EarthRadiusKm` | 6371 km | 运动学换算用地球半径（**与渲染半径 `Ball.Radius` 无关**：物理量一律用此常量） |
| 陆壳参考厚 `LandReferenceThicknessM` | **35 000 m** | 陆壳参考厚（= 自由板 800 m + Airy 反解）；v1.11 由 28 300 抬起 |
| 洋壳参考厚 `OceanicReferenceThicknessM` | 7 000 m | 两级料场的洋侧 |
| 陆基准高 `LandBaselineM` | 800 m | 陆格自由板高度（相对海平面） |
| 洋基准深 `OceanDepthM` | 3700 m | 洋格海拔初值模板 |
| 单位换算 | **1 cm/yr = 10 km/My** | `StepMy = 4 My` ⇒ 1 cm/yr 走 40 km |

### 2.6 ⚠️ `Age` 的语义警告（S 状态层的已知问题）

`Age` 目前是**一个被成分标签把守的标量**：

- 代码里只有**洋格**累积年龄（`if (!IsLand(i)) Age[i] += stepMy`，`H3DynamicTectonics.cs:613`），
  陆格被冻结在 `Age = 1000`（"陆壳标记"）。
- 而 `Age` 是**整条热—几何—力源链的枢纽**：热沉降 / 热亏缺 `D` / 弹性厚度 `Te` / 力源都读它。
- ⇒ **它是"用一个数代表一个分布"的最大一处**，且**它的门控来自二元的陆/洋标签**。

**改造方向**（详见 **09 §4/§7**）：`Age` 的累积**去门控**，改由**该柱的热状态**给出（连续规则）。

> **性质三分**（09 §3.6）：`Age` 作状态 = 物理；**由二元标签门控** = **概念错**。

## 3. 初值生成算法（v1.2 重写 —— 弃胞切分，直接长在格上）

```
1. 选板块种子格：DeterministicRandom(seed) 从 N 格无重复抽 P 个格
   （partial Fisher-Yates，rng 消耗固定 P 次 → 确定性；种子格心 = 该板 Seed 方向）
2. 种子归并生长（加权区域生长，铺满全球，直接长在 Ball.CellNeighbors 格邻居图上）：
   未归属格表 unclaimed；每板块维护边界格表 frontier[p]（初始 = 种子格的未归属相邻格）
   循环直到无未归属格：
     总权重 = 各板边界格数之和 → 前缀和随机落点选板（富者愈富：大板边界大 → 抽中概率高，
     板块大小自然有方差——用户拍板 09-07）
     板内随机弹 1 个边界格归本板（该格从 unclaimed 移除，其未归属相邻格加入 frontier[p]）
   → 板块连通、覆盖全球、每格恰属一板；大小/形状由随机生长顺序自然不规则
3. 海陆赋性：同一 DeterministicRandom(seed) 续流，逐板块掷 LandFrac 概率
   → 每板块为「陆性」或「洋性」（seed 定局：同 seed 全球同局）
4. 料场初值（两级跳变，过渡区不预置）：
   陆性板：FelsicPlutonic = 35000 m 等效质量 | Mafic = 0 | Age = 1000（陆壳标记）
   洋性板：Felsic = 0 | MaficVolcanic = 7000 m 等效质量 | Age = 0
   Sediment / Sedimentary / Metamorphic = 0（暂不使用）
5. 海拔场初值：
   陆性板：Elevation = +LandBaselineM（800 m）  |  洋性板：Elevation = −OceanDepthM（3700 m）
   # 两级模板；洋区基准随后由动态路线的洋底热沉降律覆盖（陆区 +800 保留）
```

**要点**：

1. **归并结果是一次性初始划分**（历史上"每步 Voronoi 归属重划"与"平流运动学"均已被否）。
   ⚠️ 但 **"永不重划"与 §4 的归属语义冲突** —— 见 §4。
2. 归并生长保证**每格必有归属、无空洞、每板连通**；单格孤岛 / 空洞 = 实现 bug 信号。
3. **海陆 = 板块属性，不是独立标签层**（"板块是什么就是什么"）—— 二元跳变、无过渡区。
4. **v1.2 弃 fibonacci 胞切分层**：归并单位 = H3 格本身，海岸锯齿粒度 = 单格；O(N·K) "每格归最近胞心"开销消失（曾是 res5 ≈ 2M 格的生成性能红线）。
5. 板块大小天然不均（归并顺序随机 ⇒ 大小有方差）。

## 4. 归属语义（★ v2 新增；承接 09 §3.4）

### 4.1 现状：两个互相冲突的来源

| # | 来源 | 内容 |
|---|---|---|
| ① | **生成期**（本文档 §3） | 归并生长写一次 `PlateId[]`，**之后永不重算**（02 §1；`H3DynamicTectonics.cs:429/967` 写死） |
| ② | **平流期**（02 / 06） | 物质**逐边流动** —— 通量路径下物质跨板迁移 |
| ③ | **跳格路径的顶层裁决** | 落点裁决取"整柱密度最小者"的板号（`H3PlateAdvection.cs:354-367`） |

⇒ **同一个"归属"有三个来源**，违反**方针 §3-B 单值性**。
根因：**`PlateId` 被当成"格位属性"（不随物质走），而它的语义要求它随物质走。**

### 4.2 正解：归属是**派生量**，不是状态

**`owner[格][板]`**：每格维护"各来源板贡献的**广延量**"，**随物质按同份额输运**；

```
归属[格] = argmax_p owner[格][p]        // 只读，不改场；并列取【最小板号】（保证可复现）
```

**它与"划分"的根本区别**：`argmax` **只读**，不写任何场 —— 没有裁决、没有多数决、没有外部规则。
**归属直接读物质。**

### 4.3 增 / 减只有两个来源（**没有第三种**）

| 来源 | 性质 | 何时发生 |
|---|---|---|
| **① 通量驱动** | 连续、逐格、边界推进 | 常规 |
| **② 拓扑事件** | 离散、整块、生命周期 | 缝合 / 裂解 / 重启 |

**五个驱动源逐个定性**：

| 驱动源 | 能否改归属 |
|---|---|
| 同板内部通量 | **不能**（板内物质流动不改板号） |
| **跨板边界通量** | **唯一常规增减机制** |
| 俯冲 | **不改 donor 归属**（等比例移除）；**上盘格可能翻** |
| 新生物质（薄柱注壳 / 弧回流） | **就地归属** |
| 生命周期（缝合 / 裂解 / 重启） | **唯一允许整块改归属处** |

### 4.4 已被否掉的规则（防重蹈）

| 规则 | 为什么否 |
|---|---|
| **R1「最轻者胜」**（把跳格顶层裁决移植过来：整柱密度最小者得归属） | ❌ 撤（两次）。**几何最近源**反例：连通分量 11 / 孤立格 0；**密度裁决**反例：连通分量 162 / 孤立格 108 ⇒ 两者都**制造**孤立格 |
| **R0 分板器重划分** | ❌ 同为"**外部规则替物理做决定**" |
| **R2 邻域多数决** | ❌ 同上 |

⇒ **共同毛病**：它们都是**外部规则**。正解不需要任何规则（§4.2）。

### 4.5 状态

**待落地**（09 §9 的 **T1-0a** 批）。在此之前，**02 §1 的"永不重算"仍是现行行为**，
本文档把它登记为**已知的语义冲突**，不假装已解决。

## 6. 几何派生口：边界提取（渲染用，纯几何）

输入 `PlateId[]` + `Ball`（格心 / 格 id），两个派生出口共用**同一异板共享边集**（单一事实源）：

```
1. 遍历所有格邻居对 (i, j)：若 PlateId[i] ≠ PlateId[j] → 异板格对
2. 每对异板格求共享边：H3 门面 CellToVertexes 取两格顶点集，交集 = 共享边的两个端点
3a.【链】所有共享边按端点连通性连成链
   （端点度 = 2 连续追踪；度 = 3+ 为三板块交汇 → 断链，各成独立链段）
   每条链 = 一段边界折线（六边形格边锯齿，不做样条平滑——用户拍板默认）
   → ExtractBoundaryChains：测试锚定的诊断/对账基准（渲染已不消费）
3b.【描边格边集】每条共享边在边界两侧【各格】名下记账 (格 id, 顶点对规范化序)
   → ExtractBoundaryCellEdges：渲染在用（边粒度记账，替代旧角点集 ExtractBoundaryVerts
      —— 角点粒度无法区分角点属于哪条边，五边贴异板的格其同板边两端角点都被记账 → 整条误描）
```

⚠️ **本节的输入 `PlateId` 正是 §4 要改造的量** —— 归属变成派生量后，边界提取的输入须改为"派生归属"。

## 7. 渲染（NewBall 场景接线）

> 本节属 **UI 层**实现（方针 §4 分层）：本模块（逻辑层）只提供**派生数据口**（按格取海陆、边界描边格边集、统计）。

- **全域材质**：一颗星球一张 `shaders/sphere_region_material.gdshader` —— 逐格区域数据烘进 `region_data` 数据纹理
  （每格 1 纹素：R 海拔归一 / G 板号色相归一 / B 陆性），格面 UV = 本格纹素中心；片元按 `display_mode` uniform 派生区域外观。
  模式切换只换 uniform —— **零几何重交、零 CPU 逐格取色**。
- **边界描边带**：§6 的格边集折算成**每格 6bit 旗标字节**（bit k = 边 k 是否异板边），
  经顶点属性下发；片元对旗标边逐边求**到线段的真实距离**取 min —— 宽度处处一致、拐角天然圆角衔接、同板边绝不描边。
- 演进史：v0–v1.1 逐格 CPU 取色 → 顶点色全量重交 → v1.2 全域材质 + 数据纹理 → v1.3 描边解析边距
  （此前的"边距权重插值 + 角点帽"两代在拐角处分别出现楔形缺口与深色圆珠）。
- 球自转展示已删（用户拍板 09-07，视角运动全交 `OrbitalCamera`）。

> 老树海冰判据（温度 ≤ −5 °C 的海）**不搬** —— new_HexWorld 无温度场。

### 8.3 分带名 `ElevationZoneName`（与停点断点同源）

- **海**：< −6000 海沟 ｜ −2000 ~ −6000 深海平原 ｜ −200 ~ −2000 大陆坡 ｜ −50 ~ −200 大陆架 ｜ 0 ~ −50 潮间带
- **陆**：0 ~ 500 低海拔 ｜ 500 ~ 2000 中海拔 ｜ 2000 ~ 5000 高海拔 ｜ > 5000 极高山区
- 边界归属右侧段（与色带半开区间一致）。

### 8.4 模式策略实例（`ElevationMapMode`）

- `Id = 0`（默认模式）、`Name = "海拔"`。
- `CellColorAt(i) = RampSampleSmooth(ElevationStops, Elevation[i])`
  （海拔只用于取色；**陆/海判定一律走 `Crust.IsLand` 统一口**，勿按海拔正负另立口径）。
- `ShowPlateBoundaries = true`。
- `TileInfo(i)`：`高度 {elev:F0} m（0=海平面）` + `类型 海洋/陆地 · 分带名`。
- 图例：`ColorRamp.RampLegendColors(ElevationStops)`。

## 9. 测量项（对照判读，**不预设"算完成"门槛**）

| 测量项 | 看什么 |
|---|---|
| 海陆形态 | 大陆块数 ≈ 陆性板数（约 1/3 × P）；大小分布自然；无细碎孤岛 / 单格陆斑 |
| 边界描边 | 描边带沿全部异板共享边连续覆盖、骑缝对称（角点集对账 = 提取 bug 信号，`H3PlateStaticTests` 自动断言） |
| 海陆占比 | 陆格占比 ≈ `LandFrac`（± 板大小方差） |
| 场完整 | 每格有归属板（无空洞）；每板连通；厚度 / 年龄 / 海拔场无 NaN |
| 两级模板 | 陆格 felsic 35 km、海拔 +800 m；洋格 mafic 7 km，且**海拔与年龄按洋底热沉降律一致** |
| 确定性 | 同 seed 两次生成 `PlateId` / 厚度场**逐位一致** |
| 材质同源 | 全域材质海拔画面与信息面板色块一致（同一 `ElevationStops`）；模式切换即时无重交卡顿 |
| **归属单值性（待落地）** | §4 落地后：归属的**三个来源归一**，且**没有外部裁决规则**参与 |

## 10. 本模块的边界（不属于本模块）

- **演化（时间步进 / 平流 / 边界物质注入回收 / 均衡求解）**：不属本文档 → **02**（P 过程层）。
- **热**：不属本文档 → **04**（S 状态层·热）。
- **本构与解算**：→ **06**。**形变与水位**：→ **05**。
- **地形要素**（山脉 / 洋脊 / 海沟 / 裂谷等）：现由**动态路线涌现**（现 02 + 06），
  **不再有"一次性写场的要素生成器"**（该路线随旧02 删除，见 入口 §4.1）。
  「大陆架」空洞的根因是**无水位**，其**后果已由 05 根治**（入口 §4.1 A4）。
