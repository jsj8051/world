## §1 问题陈述（实测，非推断）

### 1.1 "陆／洋"有两个互相冲突的定义

## §2 目标与非目标

**目标**
1. **消除双定义**："陆／洋"全局只留**一个定义处**（方针 §3-B）。
2. **上游干净**：热不得读任何几何/成分标签（方针 §4-S-2/-3）。
3. **机制去二元**：地壳内部机制的判据从"陆/洋 二元"改为**连续量**（成分比值／厚度／浮力／出露）。
4. **标签降为观测**："陆／洋"成为**派生层观测量**，供显示、统计、气候边界条件使用。

- **不改**网格、不改守恒 CA 平流、不改"归属随物质走"。
- **不引入**新的实体/概念（奥卡姆：本任务只做**减法**）。

## §3 原子量的定义（本任务的"原子"是什么）

**原子量**（每格柱的物理量，不可再分的状态）：

| 原子量 | 现状字段 | 备注 |
|---|---|---|
| 厚度 | `Thickness` | 总厚 |
| 成分池 ×5 | 长英质深成/喷发、镁铁质、沉积、沉积岩、变质 | 保持七池口径不变 |
| 归属 | `PlateId` | 随物质走 |

| `IsFelsicDominated`（长英质主导） | 派生层，成分比值 | 需要"成分域"语义的机制（见 §6） |

### 3.1 网格的地位（一切归属困惑的根，必须先钉死）

**本模型的网格是欧拉固定网格**：邻居表/格心在构造期写一次，运动过程**从不改变拓扑**。
⇒ **没有"产生格子 / 消灭格子"这回事**：

| 机制 | 真相 |
|---|---|
| 俯冲"消除质量" | 从**已有格**按份额**扣**物质（扣掉的那部分回地幔／增生到上盘） |
| 注壳"产生格子" | 往**已有格**补镁铁质到阈值 ⇒ 产生的是**物质**，不是格 |
| 俯冲后"格去哪了" | 格一直在。柱被扣薄 ⇒ ④ 把它当薄柱补成新生洋壳（`Age=0`）⇒ **格没变，内容被换了** |

**但板块是拉格朗日实体**（一个在动的刚体）⇒ 它无法靠"格子移动"表达。
**这就是归属问题的唯一根源**（见 3.3）。

### 3.2 每个属性的输运规则（**总账**：这个运动过程里每个量怎么动）

| 属性 | 现状怎么动 | 位置 | 性质判定 |
|---|---|---|---|
| 七池质量 | 逐边迎风：`转移量 = 柱质量 × 份额`，`份额 = 位移/格距` | `H3FluxTransport:113-190` | **离散近似**（几何口径偏差，见 3.4） |
| 成分比 | 随质量（七池同一份额）⇒ 搬运份额成分不变 | 同上 | ✅ 物理正确 |
| **`Age`（热年龄）** | **格位照抄** | `:104` | ❌ **概念错**：不可加量被当可输运量（见 3.3） |
| **`PlateId`（归属）** | **格位照抄**；批量改写只来自生命周期（缝合/裂解/重启/碎片清理） | `:105`、`H3DynamicTectonics:699/1743` | ❌ **概念错**：与物质脱钩（见 3.3） |
| 海拔 | **派生**（物质 + 水位 + 挠曲） | `H3Isostasy` | ✅ |
| 速度场 | 上一步解算器输出（滞后耦合，已拍板） | 阶段 2 | ✅ |
| 板片账户 | 按俯冲边入账（`SlabInflow`） | `:229-236` | ✅ 但**挂在化石标签名下**（受 3.3 牵连） |

**守恒总账**：搬运组内 = 纯转移；进出只有两户 —— **创建**（薄柱注壳 + 弧回流）／**销毁**（俯冲回地幔）。

### 3.3 三个"用一个数代表一个分布"的地方（用户 2026-09-22 指出）

**症状**：一个格收到多来源物质，各来源的属性不同 ⇒ **单一标量表达不了**。

**① 热年龄的多值问题**

跳格用 `ageMax`（同板合并）／`topAge`（异板裁决），通量**干脆照抄** —— **两者都是"用一个数代表一个分布"**。

**但正解不是"存多值"**（状态爆炸，且在份额流里无从定义），而是做出**可加性审计**：

| 量 | 可加？ | 混合规则 | 判定 |
|---|---|---|---|
| 质量（七池） | ✅ 广延 | 相加 | 直接输运 |
| `Age` | ❌ **不可加** | "平均年龄 50 My" 物理上**无意义**（混合体没有 50 My 的冷却史） | **必须换量** |
| **热亏缺 `D = ∫ρc(T_p − T)dz`（J/m²）** | ✅ **广延** | 相加 ⇒ **与质量同一套通量规则** | **换它** |

⇒ **把不可加的强度量换成可加的广延量，"多值"问题自动消失**：新物质带自己的 `D` 进来，
`D_total = ΣD`（能量守恒、物理正确），**不需要任何新机制**。再由 `D` **反解**出等效年龄
喂回现有解析式（沉降／浮力／热流／Te）⇒ **既有公式一字不改**。
**副产品**：厚柱热阻大 ⇒ `D` 增长慢 ⇒ **"陆壳冻结"成为自然结果，不再是 `if (!IsLand)` 二元门控**。

⇒ **这就是 T1-A（§4）的落地形式**：`Age` → 可加的热亏缺 `D`（一次解决"多值"与"二元门控"）。

**② 归属的多值问题**：见 3.4。

**③ 泛化判据**：任何"用一个数代表一个分布"的场，先问**它是不是广延量**；
若是 ⇒ 混合就是加法；若不是 ⇒ **要么换成广延量，要么承认它只是派生观测**（不许当状态输运）。

### 3.4 归属：三种形态必须分开（2026-09-22 用户的观察）

用户："一个板块内的格子都是团聚在一起的，为什么会突然变成其他板块的？"
—— 这其实是**三个不同的问题**，混在一起会误判：

| 形态 | 事实 | 判定 |
|---|---|---|
| **1 从来不随物质走** | 通量生产模式下 `PlateId` 是**照抄**的格位属性 ⇒ 板边界 = **初始分块的化石**，与物质脱钩 | **这才是真问题**（问题不是"突然变"，而是"从来不动"） |
| **2 生命周期整块变** | 标签的**唯一**批量改写来源 = 缝合／裂解／重启／碎片清理 ⇒ 观感 = 一整块突然换色。且缝合判据（板对顶死接触比例）**与归属语义毫无关系** | 纯启发式，登记；不是 bug 但需明说 |
| **3 物理量裁决生毛刺** | 若按"最轻者胜"移植 ⇒ 边界带相邻格互相翻转 ⇒ 归属性毛刺/飞地 | **已实测反例**（见下） |

**⚠️ 撤回 2026-09-22 早先的提案**：§9.1 曾把「R1 最轻者胜」列为推荐。**该提案作废** ——
`skill cell-grid-simulation-debugging` 铁律 2 记着实测：**归属交给密度裁决 → 连通分量 162、孤立格 108；
改"几何最近源" → 11 / 0**。理由是**物理量逐格连续变化，用它决定归属 ⇒ 边界带翻转**。
跳格里该规则能成立，是因为**整格腾空再落位**使归属跟着落位物质天然连片；
通量里格**不腾空**、多来源份额叠加 ⇒ 该"凭什么连片"的前提消失 ⇒ 退化成病理形态。

**正解形式：归属的变化由通量给出，不由任何外部规则给出**

**⚠️ 再撤回一次（2026-09-22 用户指示）**：下面的 R0「分板器重划分」与 R2「邻域多数决 + 碎块并入」
**也是补丁** —— 它们是"外部规则替物理做决定"。用户原话：
> 「一个板块它现在占据了这些格子，什么情况它占据的格子会增加减少都想清楚，才行。**而不是你去人为划分**。」

⇒ **正确的做法是把"占格集合的增/减机制"逐条推出来**，让归属自己长出来。

**(1) 状态量：`owner[格][板]` = 该格物质里来自板 p 的质量（kg/m²，与七池同量纲）**

- **与七池质量同一套通量规则**（`Transfer` 里一并搬运，同一份额）—— **广延量，可加**
  （与 §3.3 的可加性判据一致：归属质量天然满足，所以它能像质量一样输运）。
- **归属**：`PlateId[c] = argmax_p owner[c][p]`；`Σowner = 0` ⇒ 无主格（待注壳补）。
- **这不是"划分"**：argmax 是**从物质直接读出**的，没有外部规则参与。

**(2) 占格集合的增/减条件（把话说全）**

设格 c 当前归属 A。输运后：

| 情形 | 条件 | 机制 |
|---|---|---|
| **A 增加 c**（A 新占一格） | `owner[c][A]` 由非最大 → 变最大 | A 的物质经**边通量**流入 c，且超过该格原有最大来源 |
| **A 失去 c**（A 少占一格） | `owner[c][A]` 由最大 → 变非最大 | 外来板的物质流入并超过 A |
| **不变** | 最大者未变 | 见下 3 / 4 |

**五个驱动源，逐个说清（哪些能改归属、哪些不能）：**

| # | 驱动 | 对归属的作用 |
|---|---|---|
| 1 | **同板内部通量** | **不能改**。owner 只在 A 内部搬 ⇒ 每格仍 100% A ⇒ **板内部天然稳定**（这是自洽性的重要一环） |
| 2 | **跨板边界通量** | **唯一的常规增减机制**。A↔B 互相流过 ⇒ **边界推进/后退** ⇒ 占格集合变大变小 |
| 3 | **俯冲** | donor 按份额 f **整体等比例**移除 ⇒ **混合比不变** ⇒ **donor 归属不变**（洋壳下沉后该格仍属洋板，符合物理）；但**上盘格**获得"余额增生"⇒ 上盘格**可能翻**（增生楔归属） |
| 4 | **弧回流 / 薄柱注壳（新生物质）** | **新生物质没有来源板** ⇒ **就地归属**（继承该格当前归属）。**这不是人为规定，是"新生物质就地入册"**——否则归属场会出现永久无主格 |
| 5 | **生命周期（缝合/裂解/重启）** | **唯一允许"整块改归属"的地方**。因为它们是**拓扑事件**（两块并一块／一块裂两块），本来就不是通量事件 |

**(3) 架构分界（这条是本节的核心结论）**

> **归属的变化只有两种来源：**
> **① 通量驱动**（连续、逐格、边界推进）—— **从物质读出**；
> **② 拓扑事件**（离散、整块、生命周期）—— **是事件本身**。
> **没有第三种。尤其没有"外部划分"。**

**(4) 循环依赖（已被"滞后耦合"覆盖）**

`归属 → （分组）→ 速度场 → （通量）→ 归属` 是闭环。
已在 §4 / §5 拍板用**滞后耦合**（算子分裂）处理：**本步归属由"上一步速度"驱动的通量决定；
本步速度由"上一步归属"分组算出**。⇒ 该闭环**不需要额外机制**。

**(5) 连通性/形状是"结果"，要靠量测判读 —— 不许预先补丁**

**不预设任何连通性补丁。** 先让它自己长，用现成量测器读：

| 量测口 | 期望 | 若不符 |
|---|---|---|
| `OwnerlessCellsLastStep` | 只剩"物质被扣空"的格，且被注壳立即补 | 查注壳资格（§1.4 缺口） |
| `PlateComponentCountLastStep` | **连通分量数 = 板数** | 见下方证伪 |
| `LocalMinorityCellsLastStep` / `IsolatedPlateCellsLastStep` | ≈ 0 | 见下方证伪 |

**若连通性没有自然涌现，那是关于"通量格式"的真实发现，不是要打补丁。** 候选解释（先判定，再动手）：
- **(a) 一阶迎风的数值扩散**把边界抹成弥散带 ⇒ 带内 argmax 犬牙交错。

### 3.5 几何口径审计（份额的分母）

`份额 = 位移 / 分母`，**分母选错 = 常数级失真**。把等边六边形当"边长 = 格距 `d` 的方形"：

```
真值（有限体积）：跨面质量 = σ · L_face · vΔt，σ = 柱质量/A_cell
   等边六边形：L_face = d/√3，A_cell = (√3/2)d²  ⇒  L_face/A_cell = 2/(3d)
   代码用的：                                        1/d
   ⇒ 转移量 = 真值 × 3/2   ⇒ 有效速度整体偏大 1.5×
```

- 这是**常数**失真（**与分辨率无关**）⇒ **不破坏自洽**，但污染标定
  （"为什么实到速度与规定速度差着一截"）。**与 CFL 钳制那类分辨率相关的失真性质不同，必须分开报。**
- 修法：用 `L_face/A_cell`（可从网格预计算，与 `_edgeRadial` 同批）替代 `1/d`。

## §4 `Age` 的改造（本任务的技术核心）

**现状**：`Age` = "累积的时间"，由一个二元开关门控（陆格冻结、洋格累加）。

**本质问题**：把**一个连续的热状态**（岩石圈有多"冷"、多"厚"、热流多小）压缩成了**一个二元分类 + 一个计数器**。

**候选改造（三选一 → 见 §10-Q1）**：

| 改造 | 内容 |
|---|---|
| **替代量：热时间常数 τ(柱)** | 每柱由**厚度 + 成分**给出热时间常数 τ；热状态按 `dT/dt = −(T−T_surf)/τ` 之类演化。**"陆壳冻结"成为 τ 很大的自然结果**，不再是开关 |
| **保留 Age 但去门控** | `Age += stepMy · w(柱)`，权重 `w` 由连续量（热流/埋深/绝缘）给出，`w→0` 即"冻结" |
| **保留 Age、只换输入** | 累积条件从"有长英质"改为"**热状态允许**"（即按方针 §4-S：热只读热自己） |

**关键物理事实（必须承认）**：**热与几何是真耦合**（热状态取决于柱的绝缘性；几何取决于热沉降/浮力）。
所以"热的时间常数依赖厚度/成分"这条边**无法真的消除**，只能选择**怎么表达**：

1. **滞后耦合**：上游读下游的**上一步**值（标准算子分裂）。工程上最常见；不违反"单向依赖"的精神（上游不读**本步**下游）。
2. **把"绝缘性"升为热状态量**：热状态自带"等效热阻"，由热自己演化，几何只提供初始/边界。
3. **承认耦合、放弃严格序**（回退到方针 §7 的选项 b）。

**已拍板（2026-09-22）：采用「滞后耦合」。**
上游（热）读下游（几何/成分）的**上一步**值——标准算子分裂（operator splitting）。

> **契约（同时补入方针 §4-S）**：状态内依赖序规定的是**更新次序**；
> 上游**可以**读下游的**上一步**值，**禁止**读下游**本步刚更新**的值。
> 理由：热—几何耦合是**固有约束**（厚柱保温、冷柱变厚变浮），消不掉，只能选表达方式。

### 9.1 T1-0a 的规则（**已修正**：不走"最轻者胜"移植）

**初版提案（2026-09-22 早先，已作废）**：把跳格 `H3PlateAdvection.cs:354-367` 的顶层裁决
