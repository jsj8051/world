## 0.0 落地记录（v0.2）

- **P0 ✅ `H3Gpe.cs`**：逐柱 GPE 纯函数（水柱 + 七物质池密度序堆叠 + 岩石圈热盈余 + 正常地幔到补偿深度；z 向上为正口径）。
  锚点测试（H3GpeTests）钉住三个解析量级：脊-翼差 **+3.1e12 N/m**（文献洋脊推力 1–4e12）、高原-老洋差 ~1e13（抬升杠杆）、陆-老洋差为正（陆内拉张口径）。
  ⚠️ 已钉死的方向性坑：岩石圈冷收缩是**密度盈余**不是亏损（H3ThermalColumn"负浮力在冷岩石圈上"）——写反则洋脊推力反向。
- **P1 核心 ✅ `H3ThinSheet.cs`**：逐边粘性弹簧网络 + GPE 梯度体力 + 逐边应力帽（粘度帽法塑性）+ Picard×对角预条件 CG（矩阵自由、固定预算）。
  行为测试（H3ThinSheetTests）：均匀 GPE 恒零、阶跃场顺梯度流动、屈服定位（max/mean 应变比高于纯粘性对照）、异实例逐位确定。
- **落地中踩掉的两个结构性坑（测试钉住，勿回退）**：
  1. **算子符号**：准静态平衡必须装成拉普拉斯口径 `ΣK(v_i−v_j) = F_i`（正定）——按"拖拽力"直觉装成 `ΣK(v_j−v_i)` 则算子负定，CG 第一步即 `pAp ≤ 0` 退出、全场零速；
  2. **旋转零模**：边缘剪切算子对刚体旋转零耗散（自由行星绝对旋转不可观）——加 `RotationGaugeFraction`（×平均刚度 1e-4）规范锚消奇异；
  3. **塑性退化**：完全塑性（帽后 K→0）速度尺度无界——加 `PlasticStressFloorFraction`（1e-3 ductile 底粘度，标准粘塑性正则化）。
- **P1 ✅ 影子接线 + 标定 + 基线**：`HexDynamicDiag --shadow=1`——每 25 步采样（GPE = 当时位移-海平面 → 解算 →
  `H3ThinSheet.CompareWithKinematics` 对比），输出旧运动学/薄席均速（cm/yr）与方向一致率；只记不改，
  生产管线零变化。对比统计为纯函数（ShadowStats，单测覆盖换算/阈值/一致率）。
- **标定结论（2026-09-19 res1 首跑 + res3 基线）**：
  - 默认档 `SheetViscosityPaS = 3e23`（文献薄席档顶端，老冷岩石圈）、`PlasticStressFloorFraction = 0.1`
    （屈服边最多软化 10×）、`RotationGaugeFraction = 0.025`；
  - **规范锚 = 底层拖曳**（本轮最重要的物理发现）：超硬薄席自身几乎不可流动，板速尺度由地幔对
    板底的黏滞阻力决定——旧模型 `v = F·δ/(η·A)` 的阻力项在 B 方案里的身份就是规范锚。res1 标定
    一次，res3 无需重调即落在同数量级；
  - 初始 μ=1e21 + floor=1e-3 时薄席均速 786 cm/yr（5 个数量级偏差、随时间增长）——即"完全塑性塌缩 +
    缺底层拖曳"的退化，已由上述三旋钮消除。

## 0. 一句话

把"力学层解速度、物质层裁决跳格"的两层架构，换成"**应力经流变本构直接解出变形场，物质运输只是它的输运**"的单一连续层——幻影力、顶死裁决、屈服流、缝合/裂解/重启的大部分生命周期机器随之退休，造山带、转换断层、裂谷从屈服中**涌现**而不是被规则写死。

## 1. 背景：为什么换

### 1.1 现状管线（03 §2.2）

每步 4 My：热年龄 → 地幔热状态 → 运动学（浮力 → 力平衡解板速 → 刚体旋转拟合 → CFL 钳制）→ 平流（跳格搬运 + 密度裁决俯冲/顶死）→ 裂谷注壳 → 屈服流 → 均衡+挠曲 → 水量海平面 → 地表过程 → 缝合/裂解/重启。

### 1.2 两层矛盾的代价清单（架构税）

力学层（连续介质思路）与物质层（元胞自动机思路）对同一次碰撞给出不同答案，为了调和它们，模型里已经积累了这些**互相耦合**的补丁：

| 补丁 | 位置 | 为谁擦屁股 |
|---|---|---|
| 幻影驱动力 + 造山摩擦 μ | H3PlateMotion | 力学层算的力，物质层不认（顶死不动） |
| 顶死/俯冲密度裁决（Pass C） | H3PlateContact | 两层判据必须逐字共用，防口径漂移 |
| 屈服流（超帽柱向邻格摊） | H3DynamicTectonics 第 5 步 | 本应是塑性应力的职责 |
| 缝合/裂解/重启三件套 | H3DynamicTectonics 第 9-10 步 | 几何死锁（两板世界、超大陆冻结）的清道夫 |
| 刚体拟合的损耗 | H3PlateMotion ③④ | 均匀平移场在球面拟合为零旋转 ⇒ 规定/实到两套速度口径 |
| 碎片清理（Merge/AbsorbFragments） | 同上 | 跳格搬运撕出的孤格毛刺 |

补丁合计带来 20+ 个标定旋钮（SutureContactFraction、YieldFlowRate、OrogenFrictionMu…），每个旋钮都有一条"退回实验"注释在登记拆掉它会崩什么——**补丁之间互相踩脚，是架构错的信号，不是参数没调好的信号**。

### 1.3 为什么是现在

- 06 批次 B 已经落地双调和 CG 直接解——稀疏矩阵求解基建已在（MatrixOps、逐板/逐场求解先例）；
- 180 个 H3 测试是现成的安全网，迁移期行为对照有基准；
- 幻影力评审确认：继续打补丁的边际成本（每补一个错出一个新口径）已经高于换架构。

## 2. 目标 / 非目标

**目标**

- **G1 应力→变形自洽**：速度场由唯一一组方程解出，物质运输只是这个场的输运——幻影力这类"力说不通"的修正**在结构上不可能出现**；
- **G2 地质结构涌现**：造山带加厚、转换断层、持续裂谷带从屈服与损伤中涌现，不是规则表；
- **G3 刚性涌现**：板块"硬"是因为板内应变速率低（高黏度），不是公理——刚体旋转拟合退休，规定/实到两套速度口径合一；
- **G4 保全资产**：H3 网格、七物质池守恒记账、均衡+挠曲+水量海平面、热引擎（05）、地表过程、气候水文层、渲染/UI（只经 Crust 消费）**全部不动**；
- **G5 纪律不变**：确定性（固定遍历序/累加序/迭代数）、质量审计、判读口风格延续。

**非目标**

- 不做全地幔对流（垂直方向保持参数化：俯冲极性、板片牵引仍是通量律）；
- 不换网格、不换渲染、不动气候水文与人文层；
- 不追文献级精度：游戏档 = 形态对、量级对、可判读。

## 4. 核心设计

### 4.1 唯一动力学变量

每格一个切平面表面速度 **v(i)**（2 分量，格心切面基）。它是本步一切运动信息的唯一出处：变形率、物质通量、板缘分类、应变积累全由它派生。

### 4.2 动量平衡（准静态）

    ∇·σ = f ，   f = −∇E_GPE / h

- σ = 2μ_eff·ε̇ +（压力项）；ε̇ = 切面应变率；
- **E_GPE(i)** = 逐柱重力位能（∫ρgz dz，由现有七池柱 + 密度表 + 位移算出——全是已有量）；
- h = 岩石圈厚度（H3ThermalColumn 已有 2.32√(κt)）；
- 海沟边条件：板片账户（SlabAccounts **保留**）作为牵引 traction 加在海沟格——俯冲板片的负浮力拉地表，物理身份比现在的"账户力项"更干净。

### 4.3 本构：粘塑性 + 损伤

- **有效粘度封顶**：μ_eff = min(μ_0, (c + μ·σ_n) / (2·|ε̇|))（Drucker-Prager 屈服写成粘度帽——标准技巧，避免显式屈服面追踪）；
- **损伤 D**：高应变区 μ_0 衰减 → 剪切带定位、持续裂谷带/转换断层"记忆"——涌现的来源，也是 R2 风险的对策；
- **板内刚性涌现**：板内应变率低 → 未屈服 → μ_eff = μ_0（大）→ 近刚体。板块不再是公理，是解。

### 4.4 求解

- H3 邻接图上的稀疏线性系统，每边通量型未知量（守恒性好）或逐格速度（实现简单）——**已定（§8 问题 2）**：逐格速度；
- 每步：组装 A(μ_eff) → Picard 3–5 迭代（更新 μ_eff）→ 内层 CG（复用 06 的 CG 与 MatrixOps）；
- 确定性：固定迭代数上限与收敛容差、固定遍历序 ⇒ 同 seed 同结果（G5）。

### 4.5 物质运输：通量形式替代跳格

- 面通量 = 面两侧格速的法向分量 → upwind 输运七池（守恒组记账不动，质量审计照跑）；
- **俯冲** = 汇聚通量 + 海沟极性裁决（密度比较**保留**——极性本质离散）+ 俯冲通量 = 收敛率 × 海沟长度 × 板片参数（替换"跳格埋入"的整格搬运）；
- 步长 4 My、板速 5 cm/yr ⇒ 200 km/步 ≈ res3 的 1.7 格——upwind 天然稳定；若数值扩散超容忍，输运子循环 2–3 次（开放点 §8）。

## 7. 风险

- **R1 强粘度对比下收敛**：板内/板缘 μ 差 3–4 个量级，CG 变慢、Picard 抖——缓解：粘度比上限 + 06 已有的 α 场平滑先例；
- **R2 变形弥散**：无损伤则造山带过宽不像山脉——缓解：损伤变量（P3 立项），或最小化厚度尺度的局部化项；
- **R3 板块概念弱化**：PlateId 从刚体归属变拓扑标签，UI（板块模式、信息面板）与测试的语义迁移是**最大工作量项**；
