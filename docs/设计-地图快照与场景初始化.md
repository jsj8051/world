# 地图快照与场景初始化：数据结构设计

状态：第 3/6 步，待审查；本文件不是已实现功能说明。
前置：需求分析和实现方案已通过；本阶段仅交付文档，不修改业务代码、场景或项目启动配置。

## 1. 范围与实体

本轮只实现自然地理结果快照。地理地图可以浏览、作为未来文明生成输入，不能直接游玩。文明演化和游玩仅保留明确禁用的入口。不定义文明字段、空文明、文明算法或可玩世界解码器。未来可玩世界应包含地理和文明信息，但不能仅凭类别标签放行。

| 实体 | 职责 | 不负责 |
|---|---|---|
| GeographyManifest | 格式身份、地图元信息、数据块目录与兼容声明 | 生成参数回放、文明信息 |
| MapBlockDescriptor | 单个数据块的类型、形状、长度及摘要 | 根据 CLR 类型反射猜测编码 |
| GeographySnapshot | 完整已校验的持久化结果数据；拥有私有缓冲 | 求解器、渲染资源、场景节点 |
| GridSnapshot | 有序 H3 ID、坐标与尺度约定 | 地形或拓扑内容生成 |
| TerrainSnapshot | 最终海拔、陆海、陆块及距离事实 | 重新划分海陆 |
| SurfaceSnapshot | 脱离演化帧的表层、混合海岸及信息卡事实 | 演化材料、地幔或历史 |
| TectonicsSnapshot | 板块、壳型、边界、构造影响的最终结果 | 推进板块运动 |
| ClimateSnapshot | 所有月度和年度气候、三层风及洋流结果 | 重算气候或年度统计 |
| HydrologySnapshot | 河流、路由、河网、河线、流域、湖泊、水系结果 | 重新汇流、填洼、判湖或连水系 |
| QueryIndexSnapshot | 已发布最近对象标签和距离数组 | 重新选择最近对象 |
| ImportedWorldFactsSource | 从导入结果提供当前 WorldFacts | 初始化 WorldGenSimulation |
| MapProbeResult / MapLibraryEntry | 文件候选信息、兼容性、校验阶段和问题 | 承诺仅看文件头就能游玩 |
| ScreenRequest / OperationContext | 页面参数、操作身份、取消和提交资格 | 全局保存世界与生成器 |

所有名称为拟定代码名。现有名称、数值含义、数组顺序和空值语义优先，不为序列化擅自归一化。

## 2. 文件、版本和标识

- 扩展名：`.wmap`；内容为 ZIP，不靠扩展名判定合法性。
- 唯一清单条目为根目录 `manifest.json`，UTF-8 无 BOM；其余只允许 schema 中声明的 `data/` 条目。重复条目、重复块 ID、重名清单、未知条目或字段均拒绝。
- 地理协议：`format = "world.geography"`，`schemaVersion = 1`。本轮仅支持这一完整组合；不支持的格式/版本返回错误，不自动迁移、不重跑生成。
- 文件类别由已识别的协议值映射，不接受任意 `kind` 字符串声称为完整可玩世界。一般 ZIP 或其他格式不作为地理包处理。
- `mapId` 为 UUID，标识一个捕获的地理结果。首次捕获分配；同一已捕获结果的复制、改名及再次导出保留；新生成或演化后的捕获分配新 ID。不用它证明内容相同或文件可信。
- 包摘要不另造一套隐式 canonical JSON：清单声明每个未压缩数据块的 SHA-256。完整内容身份为清单中的地图 ID、地理头及整份块目录共同描述，不能只比地图 ID。
- SHA-256 用于完整性检查，不提供来源认证。清单损坏可由严格解析/语义检查发现；本轮不提供数字签名或恶意篡改认证。
- 没有旧 `.wmap` 格式要迁移；现有 PNG 和参数文件均不是地理快照，不能升级成可玩世界。今后变更块语义或必需字段必须升级协议版本。

### 2.1 GeographyManifest 字段

除明确标为可空外均必填且无隐式默认；序列化使用下列 camelCase 名称。

| 字段 | 类型/可空 | 约束、单位与含义 |
|---|---|---|
| format | string | 精确 `world.geography` |
| schemaVersion | int32 | 精确 1 |
| mapId | UUID string | 非空 UUID，标准 D 格式 |
| title | string | 去除首尾空白后 1..120 字符 |
| description | string | 必填，可为零长度，最多 4096 字符；不作为路径 |
| createdUtc | UTC timestamp string | 带 Z 的 ISO 8601；必须是有效时间，不强制早于本机时间 |
| producerVersion | string | 1..64 字符，仅溯源；不替代协议版本 |
| h3Resolution | int32 | 0..4；生产导出仍为 res4，其他档供诊断测试 |
| cellCount | int32 | 精确等于该档 H3 全球格数；res4=288122 |
| physicalRadiusKm | float64 | 有限且 >0；当前生成的物理半径为 6371 km |
| renderRadius | float32 | 有限且 >0；v1 只接收当前支持的 2.0 场景单位；不是 km |
| seaLevelM | float32 | 有限，米；生成时由权威 WorldSpec.Terrain.SeaLevelM 提取，不从着色反推 |
| monthCount | int32 | v1 精确 12；所有逐月数据一致 |
| sourceTimeMa | float64? | null=静态结果；否则有限且 >=0，Ma，仅来源说明，不是恢复游标 |
| hasProjectedSurface | bool | true 时必须有完整投影表层组；false 时必须无该组 |
| blocks | MapBlockDescriptor[] | 必需块集合由 v1 schema 决定；不能通过删目录行将必需块变成可选 |

可选语义以显式 null 表达，不用缺字段作为默认。清单不包含生成种子、完整 WorldSpec、历史 ID、演化步长、材料账本或恢复指令。坐标基准冻结为当前项目 H3+CoordUtil 的球面方向约定；未来改变坐标约定必须升级 schema。

### 2.2 MapBlockDescriptor 字段

| 字段 | 类型 | 约束 |
|---|---|---|
| id | string | schema 固定的 ASCII 小写逻辑名称，唯一；不接受 CLR 类型名 |
| path | string | 精确 `data/` + id + `.bin`；只允许字母数字、下划线、斜杠；无反斜杠、点路径、绝对路径 |
| elementType | enum string | `u8`、`i32`、`i64`、`u64`、`f32`、`f64` |
| shape | int32[] | 各维非负，维数 1..3；精确匹配 schema；乘积 checked 运算 |
| byteLength | int64 | 等于形状乘积乘元素字节数，同时等于实际解压字节数 |
| sha256 | string | 64 位小写十六进制，未压缩条目原始字节摘要 |

每个数据块只存一条属性列；复合记录拆列；没有 CLR 对象名、指针、结构体 padding、运行时对象 ID。向量固定 `[count,3]` 按 x,y,z 逐行写入；月份固定 `[12,N]`，向量月份为 `[12,N,3]`。全部 little-endian，浮点为 IEEE 754，保持原位宽及有效值的原始位，不 ROUND、不重算年度均值。

布尔用 u8，合法值仅 0/1。可空数值使用同形状 u8 有效掩码与数值块，掩码 0 的数值槽规范写正零，读入只解释为 null。空集合不是 null；数组和集合根对象不可缺省。enum 显式按语义映射，不靠源码声明顺序或强制 cast。

## 3. GeographySnapshot 组成与引用域

根属性：`Manifest`、`Grid`、`Terrain`、`Surface`、`Tectonics`、`Climate`、`Hydrology`、`QueryIndex`，均必需非 null。DTO 自己拥有数组；公开仅只读视图。导出独立复制已发布快照的数据，不假定当前 WorldFacts 的公开数组已深度不可变。现有运行期数组不对外重构为新容器，以免扩大接口变更；导出缓冲和导入发布后数据不得被任务修改。

记号：N=格数，P=板块数，E=板块边界边数，B=路由后流域数，D=原始洼地流域数，L=湖数，W=水系节点数；这些域不同，数值相等不代表实体相同。非空实体表的本地 ID 均为表下标；所有逐格数组按文件 `CellIds` 的原顺序，不按重新枚举顺序解释。

### 3.1 网格与地形

| 对象/属性 | 文件类型与形状 | 约束/含义 |
|---|---|---|
| Grid.CellIds | u64[N] | 有效 H3 ID、唯一、同分辨率、完整全球覆盖；保留原序 |
| Terrain.HeightM | f32[N] | 有限，最终海拔，米 |
| Terrain.FinalLand | u8[N] | 精确等于 HeightM>seaLevelM 的现有判据 |
| Terrain.FinalLandFraction | f32[N] | [0,1]，邻域陆格比例，不等同露出面积 |
| Terrain.FinalLandmassId | i32[N] | 海=-1，陆在 [0,FinalLandmassCount) |
| Terrain.FinalLandmassCount | i32[1] | >=0 |
| Terrain.FinalDistToCoast | i32[N] | H3 跳数，0..N-1；没有任何海格来源时全为-1；海格为0 |
| Terrain.FinalDistToLand | i32[N] | H3 跳数，0..N-1；没有任何陆格来源时全为-1；陆格为0 |

`Ball` 增加从已验证 CellIds 建立网格的构造入口，按文件序建立索引；不得先重新枚举后直接套数组。格心、单位方向、经纬度、邻接、顶点和 ID 字典可由 H3 ID 与已声明半径重建，不运行任何自然内容生成器。保留当前邻接按邻居 ID 排序的规则。若网格库不支持该数据，拒绝，不静默换档。

`physicalRadiusKm` 与 `renderRadius` 独立；现有物理尺度算法使用全局地球常量，本轮不支持任意星球物理半径，v1 导入须为当前 6371 km，避免导入后查询混用尺度。保存二者是显式标定，不是允许当前算法自动支持任意尺度。

### 3.2 表层及地壳结果（不保存 EvolutionFrame）

所有地图模式、拾取和地壳信息卡改读统一的最终结果。`WorldFacts` 增加 `Surface` 数据对象并允许从独立结果装配；生成场景可继续持有 Evolution 供控制面板使用，显示读取不以 Evolution 是否存在决定数据来源。

| 属性 | 类型/形状 | 语义 |
|---|---|---|
| Surface.SurfaceCrustType | u8[N] | 最终表层壳型，必需；与材料主导壳型分开 |
| Surface.MotionOmega | f32[P,3] | 最终用于显示的欧拉矢量；保留原静态或演化显示计算所用精度，不当作一律有物理单位 |
| Surface.Projected.EmergentFraction | f32[N] | hasProjectedSurface=true 时必需，[0,1]，实际露出比例 |
| Surface.Projected.LandHeightM | f32[N] | 同组，有限，米 |
| Surface.Projected.WaterHeightM | f32[N] | 同组，有限，米 |
| Surface.Projected.MaterialHeightM | f32[N] | 同组，有限，米；ReliefM仍由最终海拔减该值，沿用原查询精度 |
| Surface.Projected.OceanicCoverage | f64[N] | 同组，[0,1]；不同于表层壳型 |
| Surface.Projected.OceanAgeMa | f64?[N] | 同组；有效时有限且>=0，纯陆壳可为null |
| Surface.Projected.PhysicalOmegaRadPerMa | f64[P,3] | 同组，有限；来源角速度，仅作为此刻物理运动结果，不含 Orientation |
| Surface.Projected.VolcanicRateKmPerMa | f64[N] | 同组，有限且>=0；最终火山厚度增生速率，km/Ma |
| Surface.Projected.EmergentLandFraction | f64[1] | 同组，[0,1]；原已发布面积加权露出比例，不重新求和 |
| Surface.SourceTimeMa | 运行期来自清单 | 不再重复存储；static=null |

MotionOmega是显示用投影列，不是第二份运动真源：静态时精确等于Plates.Omega，演化结果时逐分量精确等于PhysicalOmegaRadPerMa转f32；导入校验一致性，不修正。其保留是为了显示浮点行为稳定，而非恢复运动积分。

无投影的静态地图通过 FinalLand、HeightM 显示；不人为合成混合海岸或物理速度。投影组全有或全无；不能用占位零数组冒充已投影数据。

### 3.3 板块、壳型、边界、构造影响

每行属性按现有公开属性逐一持久化；属性列表中的每个逗号项都是独立列。表标量使用长度1数据块。根前缀 `tectonics/`，其后按表和属性转 snake_case，其他组同样；源码名不自动反射成协议。

| 表 | 全部属性及类型 |
|---|---|
| Plates[P] | PlateId:i32，SeedTheta:f32 rad，SeedPhi:f32 rad，Omega:f32[3]，Density:f32；ID精确等于行号，数值有限 |
| Crust | Type:u8[N]，ProvinceId:i32[N]，Provinces[Q]：Id:i32、Type:u8、SeedCell:i32、SeedPlateId:i32、CellCount:i32；Q为省数。ProvinceId=-1只允许洋壳；其余在[0,Q)，省ID等于行号且壳型、逐省计数一致。SeedCell在[0,N)，SeedPlateId在[0,P)，不要求种子仍在当前省中 |
| PlateOfCell | i32[N]，每个在[0,P) |
| PlateBoundaries | PlateCount:i32[1]；Edges[E]：CellA、CellB、PlateA、PlateB均i32；Pairs[P*P]：PlateA、PlateB、EdgeStart、EdgeCount均i32；CellEdgeStart:i32[N+1]；CellEdgeIndex:i32[2E] |
| BoundaryFields | EdgeMotion:f32[E]，原归一化运动量，非km/Ma；EdgeKind:u8[E]，EdgeRoleA:u8[E]，EdgeRoleB:u8[E] |
| FinalBoundary | SideTypeA:u8[E]、SideTypeB:u8[E]、ConvergenceKind:u8[E]；NormalKmPerMa:f64?[E]、ShearKmPerMa:f64?[E]；静态物理速度为null，保留正负号 |
| TectonicChannel[6] | 每通道Sources[S]：EdgeIndex:i32、SideCell:i32、Channel:u8；DistanceKm:f32[N]，SourceIndex:i32[N]；无来源通道两数组精确为空，不扩成N个零 |

边界边 CellA<CellB，端点相邻且归属匹配；板块对分组、边顺序、逐格CSR顺序原样保存。FinalBoundary 在导出时提取最终两侧壳型及分类，以替代 BoundaryFields.Evolution 的显示依赖；不保存或重新求解完整 EvolutionBoundaryField。

构造距离有来源时 SourceIndex在[0,S)，距离有限且>=0；无来源索引为-1，距离允许非负有限截断值或正无穷，拒绝NaN/负无穷；通道S=0时DistanceKm和SourceIndex都长度0。省种子和计数沿用现有生成/投影语义，不能额外要求演化后种子格仍属于原省。

显式enum线码：CrustType Oceanic=0/Continental=1；BoundaryKind Inactive=0/Convergent=1/Divergent=2/Transform=3；BoundarySideRole None=0/Overriding=1/Underthrusting=2；ConvergenceKind None=0/Collision=1/Subduction=2；TectonicChannel ContinentalCollision=0/ContinentalArc=1/OceanicArc=2/Subduction=3/ContinentalRift=4/OceanicRidge=5。线码为新协议定义，编解码按名称映射，不假定与CLR底层值相同；未知码拒绝。

### 3.4 气候

前缀 `climate/`。除月索引外均原样持久化，不从月数据重算年数据：

| 属性 | 类型/形状 | 单位/范围 |
|---|---|---|
| PrecipitationMm | f32[N] | mm/年，>=0 |
| PrecipitationMonthlyMm | f32[12,N] | mm/月，>=0 |
| TemperatureC、HotMonthC、ColdMonthC | 各f32[N] | 摄氏度，有限 |
| TemperatureMonthlyC | f32[12,N] | 摄氏度，有限 |
| PressureAnnualHpa | f32[N] | 绝对hPa，>0 |
| PressureMonthlyHpa | f32[12,N] | 绝对hPa，>0 |
| DryMonthMm | f32[N] | mm，>=0 |
| DryMonthIndex | i32[N] | 0..11；UI的一基月份不能写入文件 |
| MonsoonStrength | f32[N] | [0,1] |
| Wind.Surface/Low/Free.Monthly | 各f32[12,N,3] | 项目归一化切向风向量，不是m/s |
| Wind.Surface/Low/Free.Annual | 各f32[N,3] | 月向量均值 |
| Wind.Surface/Low/Free.AnnualSpeed | 各f32[N] | 月模长均值，非年合向量的长度 |
| OceanCurrentDirection | f32[N,3] | 单位切向量或零 |

全部有限；风速范围和切向性使用数值容差校验而非要求浮点精确单位长度，归一化速度容差1e-5、方向范数容差1e-4、切向点积容差1e-4。校验不改变值。年度统计保留原始值，重算只能用于回归对比，不能替换数据或作不同实现顺序的精确等式门槛。WindKind线码Surface=0/Low=1/Free=2，组名固定，文件不单独重复存Kind或派生MonthCount。

### 3.5 河流、流域、湖泊与水系

前缀 `hydrology/`。下表覆盖现有所有公开持久数据；Generate方法一律不作为导入构造入口。scalar=int属性用i32[1]，其余标量按指定类型[1]。

| 对象 | 必须持久化的属性及类型 |
|---|---|
| Rivers | Downstream:i32[N]；FlowAccum:i32[N]；FlowAccumKm2:f64[N]；IsRiver:u8[N]；SinkCount:i32；RunoffAccum:f32[N]；RunoffAccumKm3:f64[N]；RunoffThreshold:f32；RiverThresholdKm2:f64 |
| Rivers.Routing | UsedFill:u8；RoutingHeightM:f32[N]；FillDepthM:f32[N]；DepressionCount:i32；MaxFillDepthM:f64；FilledCellCount:i32 |
| RiverTopology | DownstreamRiver:i32[N]；UpstreamCount:i32[N]；NodeKind:i32[N]；AccumMm:f32[N]；RiverCellCount、SourceCount、ConfluenceCount:i32；OutletCount:i32；Sources:i32[sourceCount]；Outlets:i32[outletCount] |
| RiverLines | SourceRes:i32；LineCells的PointOffsets:i32[R+1]和Cells:i32[K]；Lines的Points:f32[K,3]；LineOutlet:i32[R]。R=线数，K=所有线的点数和；空集合偏移为[0] |
| Basins | BasinId:i32[N]；TerminalCell:i32[N]；TerminatesAtOcean:u8[N]；BasinCount:i32；Kind:i32[B]；Outlet:i32[B]；Area:i32[B]；AreaKm2:f64[B]；AccumMm:f32[B]；OceanBasinCount、EndorheicBasinCount:i32 |
| Lakes | LakeCount:i32；DepressionIdOf:i32[N]；BasinIdOf:i32[L]；LakeOfBasin:i32[D]；SurfaceElevationM:f32[L]；AreaKm2:f64[L]；VolumeKm3:f64[L]；SpillElevationM:f32[L]；OutletCell:i32[L] |
| WaterSystem | NodeCount:i32；KindOf:i32[W]；RefOf:i32[W]；Next:i32[W]；ViaCell:i32[W]；NodeOfRiverCell:i32[N]；NodeOfLake:i32[L]；OceanNode:i32；RiverCount、LakeNodeCount、SinkCount:i32 |

现有单位：FlowAccum=上游格计数含自身；FlowAccumKm2/AreaKm2/RiverThresholdKm2为km²；RunoffAccum/AccumMm/RunoffThreshold为当前等效mm口径；RunoffAccumKm3为km³/年；湖VolumeKm3为库存km³。所有属性精确保留，即使名称或注释有历史歧义也不在导出时修正。

enum线码：RiverNodeKind Outlet=0/Source=1/Confluence=2/Trunk=3/Tributary=4，非河格-1；BasinKind Ocean=0/Endorheic=1；BodyKind River=0/Lake=1/Ocean=2/EndorheicSink=3。均显式映射。

关键不变量：

- 路由后Basins.BasinId和原始Lakes.DepressionIdOf是两个命名空间，绝不能互代。D必须保留LakeOfBasin的原长度，不能假设D=B或D=L。
- 湖BasinIdOf落在[0,D)，LakeOfBasin为-1或[0,L)，反向映射一致；海格DepressionIdOf=-1。无湖时L=0但D可以>0。
- SpillElevationM允许现有无溢口的NaN，原位保存；不得将它转成0、null或正无穷。其他水文float默认有限；若真实生产字段出现其他哨兵，必须回本阶段补充定义，不泛化放行NaN。
- WaterSystem.RefOf按Kind区分：River=河口格，Lake=湖下标，Ocean=-1。EndorheicSink的现有RefOf可能来自路由流域或原始洼地；v1将其定义为旧模型的opaque sink key，保持原值，禁止拿它直接关联Basins。未来若需要跨表稳定盆地身份，应另行设计升级，不在地图导入时猜测修复。
- 下游/Next为-1或合法本域索引；河流、水系不能产生自指或环；Sources和Outlets顺序保留。单格河可同时是源和口。
- 河线SourceRes精确等于地图res；Cell序列合法、PointOffsets单调首0末K，Lines与LineCells点数和顺序一致；方向点为单位球方向，不乘renderRadius后再保存。
- 河、湖、水系可为空，但根对象、空数组及必要N长度掩码必须存在。OceanNode可以是-1，即使地图存在海洋。
- 不重算填洼诊断计数；当前FilledCellCount按深度>epsilon统计，不强行按>0校验。保持已有数值定义。

### 3.6 查询索引和非持久缓存

`QueryIndex`保存NearestLandmassId、NearestLandmassDistHops、NearestRiverCell、NearestRiverDistHops各i32[N]。标签/距离都保留，缺对象时为-1；距离单位跳数。导入不重跑BFS，以免并列最近对象身份因顺序变化而变化。ID字典等查找缓存可以从已导入数据创建。

不持久化：Node、Resource、Mesh、Material、Camera、事件订阅、任务、取消句柄、LOD、相机位置、选中格、烘焙颜色纹理、临时河线网格、演化材料和Orientation。读取已保存河线点再生成显示网格是表现装配，不是重新生成河网。

## 4. 校验、错误与资源上限

结构校验分为清单/目录、数据块、引用关系三个层级。读入完整通过前不得创建可发布WorldFacts；失败不替换旧状态。字段类型不正确不作字符串转数字等宽松修复。持久层使用固定白名单，不反射加载类型，不实例化文件指定的脚本。

固定初始安全限额：manifest<=1MiB；条目<=1024；单条目未压缩<=128MiB；所有条目未压缩总和<=512MiB；文件<=512MiB；尺寸和累计长度使用checked int64并验证实际读取量；枚举、集合规模必须在分配大数组前验证。限额是安全上限不是性能承诺，res4实测若超限须回来审查，不静默增大。标题和说明不能变成文件路径，预览不执行文件内容。

`MapIssue`字段：Code:enum、Location:string、ElementIndex:int64?、Message:string。Code为UnknownFormat、UnsupportedVersion、UnsupportedScale、MissingBlock、UnexpectedBlock、DuplicateEntry、SizeLimit、InvalidShape、ChecksumMismatch、InvalidValue、InvalidReference、Cancelled、IoFailure。未知/不支持不是损坏的同义词。Location为逻辑块/属性；索引可空；面向用户的Message不泄漏内部堆栈。

`MapProbeResult`：Status枚举HeaderReadable/Unsupported/Invalid；MapId:UUID?；Title:string?；Format:string?；SchemaVersion:int32?；Issue:MapIssue?。HeaderReadable只表示有限头信息可识别，并非已完整校验。Unsupported/Invalid必须有Issue。路径和操作身份在外层MapLibraryEntry里，不写入清单。

`MapLibraryEntry`：FilePath:绝对规范化string、DisplayName:string、FileSizeBytes:int64>=0、LastWriteUtc:UTC时间、Probe:MapProbeResult；均必填。缓存信息只用于列表，加载仍须重新检查文件，不信任先前的mtime或头探测。文件枚举不能递归扫描任意磁盘。

### 5.2 显式依赖与类型

`IWorldFactsSource`只公开非空的`WorldFacts Facts {get;}`；生成场景由现有WorldGenSimulation提供，导入场景由ImportedWorldFactsSource提供。WorldFacts当前值只在完整构造后发布。渲染/地图模式/拾取/图片导出接收该契约，不接收WorldManager或生成参数；不通过接口暴露Regenerate、Step等命令。

`GeographySnapshot`与`WorldFacts`职责不同：前者为无Node/Resource的持久结果，后者为装配后的运行期取数口。Vector3若出现在现有运行期对象中只是值结构；文件中仅对应显式f32三列，不序列化Godot对象。新增结构构造口只能验证/装配，不调用任一生成器Generate/Run。

`ScreenRequest`为封闭选择：MainMenuRequest、GeographyRequest、MapLibraryRequest、MapBrowseRequest。MapBrowseRequest必须携带已校验的ImportedWorldFactsSource和地图摘要；不只传文件路径让浏览场景自行猜测初始化。GeographyRequest有明确的独立编辑器默认参数来源；其余页面直接F6运行时允许绑定本地节点，但缺请求参数必须提示并停止业务初始化，不能回退生成世界。不定义可执行的CivilizationRequest或PlayRequest。

`OperationContext`：OperationId:UUID（新操作新ID）、OwnerScreenId:UUID（场景实例唯一）、State:枚举、Progress:float32?[0,1]（不确定时null）、StageText:string、CancellationToken:仅运行期、CanCommit:由当前OwnerScreenId/OperationId及取消状态派生。不得持久化CancellationToken或UI控件引用。不沿用上个页面的WorldManager、相机或委托。

固定依赖字段均为`[Export] NodePath`，无默认猜测路径：AppRoot需ScreenHostPath/StatusBarPath；WorldPresentation需CameraPath/RenderManagerPath/UIManagerPath/DockPath；WorldGenWorld需WorldManagerPath/PresentationPath及专属工具控件路径；MapBrowser需PresentationPath/返回控件路径。实际新增节点名称与导出字段在结构落地中逐条核对；依赖缺失通过编辑器警告及初始化错误拦截，不用GetNodeOrNull后继续空运行。

### 5.3 合法状态与生命周期

应用页面：MainMenu <-> Geography、MainMenu <-> MapLibrary、MapLibrary <-> MapBrowser；不存在本轮可进入的Civilization或Playing状态。切换中只有一个提交操作有效；返回路径由明确导航请求决定，不使用失效节点作历史引用。

场景初始化：Created -> NodesReady -> Initializing -> Active；Initializing可到Failed或Cancelled；任一未释放状态可到Exiting -> Disposed。NodesReady不等于有地图数据；_Ready只绑定本地依赖，父场景统一显式初始化各组件且幂等。先让加载层有机会显示，再启动耗时工作，避免在子节点_Ready抢跑。

操作状态：Idle -> Running -> Succeeded/Failed/Cancelled；Running可进入Cancelling，Cancelling只能到Cancelled或Failed，不得Succeeded。每个新操作用新Context；终态结果不能重复发布。退出中的页面不可接收迟到任务提交，取消不能作为IoFailure展示。

所有Node/场景装配与资源释放在主线程。离开页面发出取消、停演化并解除运行期订阅；后台操作只持独立数据，不触碰已退出节点，结束后丢弃失效结果并释放缓冲。不能通过阻塞主线程等待来完成清理。导出任务持有独立复制，不能引用后台仍可能写入的数组；恢复演化只允许原操作仍有效且会话未出错/未退出。

## 6. 不变量、依赖、迁移和验证边界

- 一个GeographySnapshot拥有一份地理头与数据组；所有组共同属于一次捕获。共享mapId或数组长度相同不能证明同一时刻，捕获时需固定发布对象并复制。
- 一份地理地图可以创建多份未来文明世界；此关系本轮只记需求，不创建文明类型或空实体。任何页都不能把纯地理地图认定为可游玩。
- 导入内容数值和字段必须来自文件；仅重建数学几何及查找缓存，不调用生成/演化流程或用默认值补必需块。
- 重建显示网格、相机和字典是允许的缓存装配；河流路由、湖水量、月度气候、最终表层以及最近对象标签是保存结果，不重算。
- 无可修改的已发布地理缓冲，文件写入不修改原地图；部分写入/失败临时文件不能进入地图列表。覆盖既有目标需明确确认，不能因同名默默覆盖。
- `AppRoot`生命周期与功能场景分离，不保存所有地图和所有会话；卸载引用后释放相机、网格及订阅，不积累隐藏的世界实例。
- 现有地理算法、生产res4、图片导出、主题及独立地理调试入口保留。变更取数契约的所有模式/视图/拾取/图片导出需一起迁移，避免一半读新表一半读Evolution。
- 第4步仅落地类型/枚举/结构校验和结构测试夹具；不接通读写、场景切换或改项目主场景。第5步才实现读写、装配、tscn及行为；第6步提供实际完整文件和用户验证。
