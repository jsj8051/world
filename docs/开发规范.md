# world 开发规范（Coding Standards）

> 环境：Godot 4.7.1 mono / .NET 8 / C# 12。全程中文注释与提交信息。
> 本文件是项目落地的精简约定；完整官方依据见 Hermes skill `godot-dev-standards`。

## 1. 命名

| 对象 | 约定 | 示例 |
|---|---|---|
| .cs 文件名 | PascalCase，**必须与类名一致** | `PlanetPipeline.cs` |
| 类/方法/属性 | PascalCase | `Run()` |
| 私有字段 | `_camelCase`（下划线前缀，官方要求） | `_layer` |
| 局部变量/参数 | camelCase | `vertexCount` |
| 命名空间 | `World.<模块>`，与 scripts/ 子目录对应 | `World.MapGen` |
| 信号 | 委托名 `EventHandler` 结尾 | `[Signal] HealthChangedEventHandler` |
| 常量 | PascalCase | `public const string Magic = "MPA1"` |

- Godot 派生类必须 `partial`（source generator 要求，诊断 GD0001/GD0002）。
- 类内顺序：字段 → 属性 → `_Ready/_Process` 回调 → 方法。
- `var` 仅当右侧类型显而易见（`new Vector2(...)` / 字面量 / 强转）。

## 2. 目录约定

- `scenes/core/` 只放正式流程场景；诊断/调参场景一律 `scenes/diag/`（headless 验证入口）。
- `scripts/Diagnostics/` 集中诊断脚本（命名空间 `World.Diagnostics`），生产模块目录不放诊断代码。
- 新增 C# 脚本：`scripts/<模块>/<类名>.cs`，`.uid` 文件由 Godot 生成，**必须入库**（场景 ext_resource 按 uid 引用）。
- 文档目录 `docs/` 有 `.gdignore`（免导入）；新增文档不要删它。
- 第三方资源放 `addons/`；`project.godot` 只在需要时改。

## 3. git 约定

- 忽略：`.godot/`、`bin/`、`obj/`、`*.lscache`、`*.old`。
- **入库**：`.uid`、`.import`（官方 VCS 指南：保证 uid 稳定）、`.sln`/`.csproj`、`.gdignore`。
- `.gitattributes` 强制 `*.cs/*.tscn/*.gdshader` LF（勿动）。
- 提交信息：中文，一句话说清"改了什么+为什么"（参考 git log 历史风格）。
- 大改动勤提交；重构/移动文件用 `git mv`（保留 rename 历史）。

## 4. 验证流程（改 C# 后必做）

```bash
# 1) 全量重编译——增量 dotnet build 会静默失败（输出重定向到 .godot/mono/temp/bin/Debug/world.dll）
dotnet build -t:Rebuild          # 必须看 0 错误；对比 DLL 时间戳确认新程序集

# 2) headless 跑（诊断场景可直接验证；MapGen 全链路 n=16 ≈26s）
"D:/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64_console.exe" \
  --headless --path E:/godotGames/world --quit-after 400 res://scenes/core/MapGen.tscn

# 3) 断言：tile count = 10n²+2；DiagUtil 注册后未捕获异常 → Exit(1)（非零=失败，不傻等帧数）
```

- 验证只信真实 C# 诊断 + headless 输出；**禁止用其他语言复刻行为验证**。
- 诊断脚本写 `DiagUtil.InstallFatalHandler()`，任务异常直接退出码暴露。
- 移动脚本/场景后：`sed` 或脚本批量同步 res:// 引用（场景 uid 引用会掩盖 path 过期，headless 能跑但必须保持整洁）；**本环境 sed 不支持 `\|` 与 `\1`**，批量替换用 Python。

## 5. 性能红线

- 模拟热路径：纯 C# 数组/字典/普通类（绕开 interop）；后台线程（Task.Run）**绝不碰 Node/渲染 API**。
- 对象属性查询最慢（脚本 setter → ClassDB 链）→ 热路径先存局部变量。
- GodotObject 属性循环读写先局部累加再赋值（如 `Position += ...`）。
- 判定阈值**必须相对该星球分布**（分位数模型），禁绝对阈值/硬编码参数。
- 显示层每格颜色 = 最近顶点直读数组；Shepard 插值只用于生成期预览。

## 6. 陷阱清单

| 陷阱 | 现象 | 处理 |
|---|---|---|
| CS1612 | `Position.X = 1f` 编译错 | struct 拷贝；局部变量整体赋值 |
| snake_case API | `CallDeferred("add_child")` | 用 `MethodName.X`/`PropertyName.X` |
| 改 [Export]/[Signal] 不生效 | 编辑器看不到新字段 | 必须重新 Build |
| 删 .godot/mono | 诡异构建问题 | 删掉让它重建 |
| SetScript() | 释放 C# wrapper | `GodotObject.InstanceFromId` 重取 |
| git D（deleted）状态 | 误以为异常 | 先 `git log --format='%h %an'` 看提交者再处理 |

## 7. 生成与验证约定（世界生成管线）

- 星球参数五件套：自转方向 / 倾角 / 距日 / 自转速度 / 网格 n（+Seed），全部 [Export]。
- headless 调参：`-- --seed=7 -- --run 300` 覆盖导出属性（参考各诊断场景注释）。
- 生成结果对比必须**同参数同条件**（同 seed/同 n/同时长）才有效。
- 存档永远向后兼容：新字段走尾部追加，Version 只增不减。
