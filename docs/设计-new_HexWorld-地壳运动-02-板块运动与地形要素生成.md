## 1. 职责与输出

- 输入（全部来自 01 的产物，只读）：`Ball`（格心/邻居/格 id）、`Crust` 六场初值、板表 `PlateRecord[]`、`LandFrac`、seed。
- 输出（一次性静态生成，**与 01 同一次生成内完成，无二次步进**）：
  - `PlateRecord[].Omega`：每板欧拉极（`rad/My` 为单位的旋转向量，方向 = 转轴、模长 = 角速度）——01 预留的占位字段在此启用；
  - `Crust.FelsicThick / Age / Elevation` 被要素生成器**增量补写**（Mafic 除初值外不动；Sediment 仍全 0）；
  - 逐格**边界省份**（`TerrainProvince`，见 §3.4）+ 运动学分类（`BoundaryKind`）+ 主导边相对速率 + 距最近边界距离——**派生标注，不写进 Crust**（Crust 只存地质权威场），由 `PlateBoundary` 结果对象持有、经 `H3PlateManager` 供 UI；
  - 板/边界统计（各子型的格数、各分类的边界边数、陆洋占比）。
- 渲染：**不改**。地形全部体现在 `Elevation` 场里，海拔图模式（模式 0）自然显示；`region_data` 纹理的归一化域（色带首尾 −8000 / +6000）已能容纳本模块的海拔范围。**不新增地图模式**（用户拍板 09-10）。
- 本模块**无演化步进**：Ω 只是"一次性分类与幅度的来源"，不积分、不平流、不移动任何格。

## 2. 运动学：欧拉极抽取与相对运动

### 2.1 抽取（一次、确定）

```
for p in 0..P-1:                                   # rng 续流（01 的 DeterministicRandom(seed) 同一实例）
    u   = rng.NextDouble(); v = rng.NextDouble()     # 球面均匀抽转轴方向（勿按经纬均匀——极区会堆积）
    z   = 2u - 1;  φ = 2πv;  s = sqrt(1 - z²)
    axis = (s·cosφ, s·sinφ, z)                       # 单位向量
    speedKmPerMy = ΩMinKmPerMy + rng.NextDouble()·(ΩMaxKmPerMy - ΩMinKmPerMy)
    Ω_p = axis · (speedKmPerMy / R_earth)            # rad/My（R_earth 见 §8）
```

- 消耗 rng 次数固定（每板 3 次）→ **同 seed 同 Ω 场，逐位一致**（确定性纪律）。
- 幅度按**表面速度**给参数（`km/My`），文档里同时标注 `cm/yr` 换算便于对照地球：`1 cm/yr = 10 km/My`。
  初值区间 10–150 km/My（= 1–15 cm/yr；旧运动学代码 0.005–0.02 rad/My 换算 = 3.2–12.7 cm/yr，落在本区间内）。

### 2.2 速度场与相对运动

- 绝对速度：`v_p(r̂) = Ω_p × r̂`（`r̂` = 单位径向；速度单位 `km/My`——`Ω` 用 `rad/My`、`r̂` 用 `R_earth` 时自动得到 `km/My`）。
- **本模块只消费相对速度**：任意两板的相对速度 `v_rel = (Ω_p − Ω_q) × r̂`，与"整球共同旋转"无关。
  ⚠️ 因此**不加"全球净角动量为零"约束**（加了也只改变绝对基准，地形逐位不变）——这是本设计的一个刻意简化，且是**严格等价**的简化，不是近似。
- 题外纪律：Ω 的绝对基准任意 ⟹ 任何以"绝对速度"为输入的地形都是非物理的。地形只允许依赖 `Ω_p − Ω_q`、两侧陆性、两侧洋壳年龄。

### 2.3 边界边的几何量

对每条异板格邻居对 `(i, j)`（`i < j`，只处理一次）：取边中点方向与切向法向：

```
mid  = normalize(c_i + c_j)                  # 单位方向（两格心都在球面，和向量即中点方向）
n̂    = 把 (c_j - c_i) 投影到 mid 处的切平面后归一化     # 边界单位法向，指向"从 i 侧到 j 侧"
v_rel = (Ω_{p(i)} - Ω_{p(j)}) × (mid · R_earth)        # km/My
v_n   = v_rel · n̂                             # 法向分量（>0 = i 侧向 j 侧推进 = 两板相向 = 汇聚）
cosα  = v_n / |v_rel|                         # α = 相对速度与边界法向的夹角（|v_rel| → 0 时见 §3.4 惰性）
```

几何语义（写代码时照此，勿凭直觉改符号）：
- `v_n > 0` ⟺ i 侧板相对 j 侧板沿 `n̂` 推进 ⟺ 两板**相向** ⟺ **汇聚**；
- `v_n < 0` ⟺ 相离 ⟺ **离散**；
- `|v_n|` 小（相对速度近乎平行于边界）⟺ **转换**。

### 2.4 两遍分类（洋-洋俯冲侧判据需要洋壳年龄 → 避免循环依赖）

分类**逐边**做（同一条边的两侧格共享同一分类结果——这是"骑缝一致"的硬保证），分两遍：

```
第一遍（纯运动学 + 01 初值陆性，不依赖任何新数据）：
    逐边算 kind ∈ {汇聚, 离散, 转换, 惰性} 与"两侧陆性组合"∈ {陆陆, 陆洋, 洋洋}
→ 识别洋脊轴：离散边界的洋侧格（陆陆离散无洋侧，不产脊轴）
→ 多源 BFS 出离脊距离 → 写 Age 场 + 洋区海拔基准（§4）
第二遍（用 Age 定下插侧）：
    洋洋汇聚边 → 老侧下插（Age 大者；相等取板 Id 较小者下插，确定性 tie-break）
    陆洋汇聚边 → 洋侧下插（无需 Age）；陆侧 = 造山带、洋侧 = 海沟（见 §5.2 括注）
    陆陆汇聚边 → 碰撞（无下插侧）
→ 逐格取【主导边】（该格全部异板边中 |v_n| 最大者）→ 定该格 TerrainProvince
```

**顺序纪律（写进实现）**：分类阶段**只读 01 的初值场**；写场阶段**不再重判陆性**（`Crust.IsLand` 是"长英质厚 > 0"，要素生成器会改厚——重判会让判据随写场顺序漂移）。分类与省份在写场前**全部定局**。

## 3. 边界分类与省份

### 3.1 运动学三分类（阈值参数化）

| 条件 | `BoundaryKind` |
|---|---|
| `\|v_rel\| < InertSpeedKmPerMy`（初值 2 km/My = 0.2 cm/yr） | **惰性**（两板近乎同转，无相对运动 → 无地形） |
| `cosα ≥ +CosTransformBand`（初值 0.20） | **汇聚** |
| `cosα ≤ −CosTransformBand` | **离散** |
| 其余（`\|cosα\| < 0.2`，即夹角 78.5°–101.5°） | **转换**（无地形，作对照） |

> 阈值依据：相对速度方向在世界坐标系里近乎各向均匀 + 边界走向由 01 的归并生长决定（与运动无关）→ `cosα` 近似均匀。初值 0.20 给出 汇聚 ≈ 40% / 离散 ≈ 40% / 转换 ≈ 20% 的边界边占比（地球转换断层约占边界总长 15%，同量级）；若判读后觉得转换太少（地形碎），把阈值往 0.5 调（转换占比降到 ~1/3 但划分更锐）。**纯参数，不改结构。**

### 3.2 地质子型（由 kind + 两侧陆性 + Age 决定）

| kind | 两侧 | 子型 | 下插/脊轴侧 |
|---|---|---|---|
| 汇聚 | 陆 + 陆 | **碰撞造山** | 无（两侧对称受挤） |
| 汇聚 | 洋 + 陆 | **俯冲** | 洋侧下插 |
| 汇聚 | 洋 + 洋 | **俯冲** | 老侧（Age 大）下插 |
| 离散 | 洋 + 洋 | **洋中脊** | 洋侧 = 脊轴 |
| 离散 | 陆 + 陆 | **大陆裂谷** | 陆侧 = 裂谷带 |
| 离散 | 陆 + 洋 | **被动陆缘 + 洋脊** | 陆侧 = 被动陆缘（减薄）；洋侧 = 脊轴 |
| 转换 / 惰性 | 任意 | **无地形** | — |

### 3.3 逐格省份 `TerrainProvince`

逐格取其**主导边**（`|v_n|` 最大）的子型，再按该格在边界的**哪一侧**分成具体省份（两侧角色不同，必须分）：

| 省份 | 来源 | 地形 |
|---|---|---|
| `Orogen` | 陆-陆汇聚边的两侧格 **+ 陆-洋汇聚边的陆侧格** | 增厚 + 抬升（§5.2） |
| `Trench` | 俯冲边的**下插侧**格 | 深槽（§5.3） |
| `Arc` | 俯冲边的**上盘侧**格 | 弧岩浆增厚 + 抬升（§5.3） |
| `Ridge` | 离散边的**洋侧**格 | 脊轴（Age=0，热沉降自然浮起，§4） |
| `Rift` | 陆-陆离散边的**陆侧**格 | 地堑减薄 + 肩部（§5.4） |
| `Margin` | 陆-洋离散边的**陆侧**格 | 陆缘减薄（§5.4） |
| `Transform` | 转换边两侧格 | 无（对照） |
| `None` | 其余 | 无 |

### 3.4 惰性边界

`|v_rel|` 趋零的板对（两 Ω 近同）不产地形也不报错误——分类落到 `惰性`，其两侧格省份 = `Transform`/`None`。整颗星球可能出现"某条边界毫无地质活动"的情形，**这是模型的合法输出**（判读时算对照，不算 bug）。

## 4. 洋底热沉降（Age 场真正参与；"洋中脊 + 深海平原"的来源）

> 这一节的产出**不是叠加的隆起带，而是洋区的海拔基准**——洋中脊"自然浮起"、深海平原"自然变深"，全域一个公式，无逐格硬编码。这也是本设计里"板块运动塑造地形"最直接的一处：**洋底深度由离脊距离 ÷ 扩张速率（= 相对速度）决定的年龄推出**。

```
阶段 1：脊轴源 = 离散边界洋侧格；扩张速率 v = |v_n|，下限 MinRidgeSpreadKmPerMy（= 10 km/My = 1 cm/yr）
阶段 1b：均匀多源 BFS（只走洋格）→ 每洋格得 dRidge（跳数）与该处【局部速率】v(c) = 最近脊源速率
阶段 2：Dijkstra 累积扩张时间——边代价 = 2 · 格宽 / v(当前格)
        Age[c] = min over 路径 Σ 2·ds/v      # **年龄是积分量**：局部速率跳变只让年龄的导数跳（折痕），
                                             # 不让年龄本身跳（断崖）——消除"汇水区接缝"的关键
Age[c] = min(Age[c], AgeMaxMy)               # 封顶（初值 150 My）
不可达洋格（其洋盆无离散边界）→ Age = AgeMaxMy  # 兜底：最深洋盆
Elevation[c] = −(RidgeAxisDepthM + SubsidenceCoefM · sqrt(Age[c]))     # Parsons & Sclater 半空间冷却
```
> ⚠️ **为什么必须是积分形式（v1.1，三次返工结论）**：`Age = 2·d/v(最近源)` 在"两条速率不同的脊的汇水区相接处"有**一阶不连续**——实测相邻纯洋底格 9 My ↔ 144 My → 深度台阶 3.1 km（人工接缝，肉眼可见）。局部平滑救不了：① 邻域均值 40 轮未收敛（一阶不连续靠扩散摊不平，残差 68 My）；② 最近 K 源速率 `1/(1+d)²` 加权更糟（`1/v̄` 放大极慢脊 → 年龄差涨到 990 My）。积分形式让年龄成为路径累积量，数学上天然连续；实测相邻洋格年龄差降到 **3.2 My**（= 理论下限 `2×格宽÷最快脊速`）。

- 常数初值：`RidgeAxisDepthM` = 2500 m（脊轴水深）、`SubsidenceCoefM` = 350 m/√My、`AgeMaxMy` = 150 My。
  核对：`age=0 → −2500 m`（脊轴）；`age=131 → −6507 m`、`age=150 → −6786 m`（深海平原 −5.5~−6.5 km、老洋盆 ~−6.7 km，与知识库目标同量级）。
- **Mafic 厚度不动**（保持 7 km）：热沉降是**热状态**效应，不是壳厚效应。诚实记账（见 §6 纪律）。
- 陆格基准仍为 `LandElevationM`（+800 m）、Age 仍为 1000 My 标记位（01 语义保留）。
- ⚠️ **Age 场语义升级**：01 §3.1 里洋格 Age 是"0 占位"，本文档起改为**热沉降年龄（My，真值）**。这是"离脊距离 + 扩张速率"的纯静态推导，不含时间步进。

## 5. 地形要素生成器

### 5.1 统一写场规则（先把规则钉死，再写各要素）

```
FelsicThick[c] = 初值 + Σ_要素 Δt(要素, c)                    # 累加（厚度可多次构造叠置）
Elevation[c]   = 基准[c] + Σ_要素 Δh(要素, c)                  # 基准：陆 +800 / 洋 −(2500+350√Age)
                                                              # 来源为【地壳厚度变化】的要素：Δh = Δt · kAiry
                                                              # 来源为【热状态/挠曲几何】的要素：Δh 直接给（无 Δt）
kAiry = 1 − ρ_felsic / ρ_mantle                               # 初值 1 − 2700/3300 = 0.1818
```

- **一律累加，无覆盖、无 min/max 特例**（海沟的"更深"= 负增量加到洋底基准上，天然低于周围——不需要"取更低者"这种分支）。
- **要素间不重叠时可以并行写；重叠时按固定登记顺序累加**（顺序固定 → 浮点累加顺序确定 → 逐位可复现）。本批五个要素按 造山 → 海沟 → 弧 → 裂谷 → 被动陆缘 登记。
- **增量式 Airy 口径（诚实声明其近似）**：`Δh = Δt · kAiry` 是"相对本格当前基准"的增量响应，不是解全局均衡方程（不引入补偿深度、不求海平面零位）。这是工程近似：够出正确量级与形态，且不需要重建 02 场与均衡模块。判读若要求"海拔必须由整柱均衡导出"，那是一次更大的改动（被否路线的方向），需另立文档。

### 5.2 造山带（`Orogen`，陆-陆碰撞 + 陆-洋的陆侧陆缘）

```
d = 距该汇汇聚边的距离（有界 BFS，格步数 × 格宽 → km）
u = d / OrogenHalfWidthKm                       # 初值 600 km（半宽；全宽 ~1200 km，对齐青藏高原量级）
Δt(d) = OrogenThickenMaxM · G(u),  G(u) = 0.5·(1 + cos(π·min(u,1)))，u ≥ 1 → 0    # 半余弦 taper
Δh(d) = Δt(d) · kAiry
```

- 初值 `OrogenThickenMaxM` = 25 000 m → 峰值 `Δh` ≈ +4545 m → 峰值海拔 ≈ 800 + 4545 ≈ **+5.3 km**（知识库：碰撞带地壳 60–75 km → 海拔 +4~+5 km；本设计峰值总壳厚 35+25 = **60 km**，落在区间内）。
- 两侧对称（不区分上下盘）——陆-陆碰撞两侧同等受挤，与骑缝一致的边分类口径相符。
- **陆-洋汇聚（安第斯型陆缘）复用本组参数**（v1.2 修订）：陆侧走 `Orogen`、洋侧走 `Trench`。诚实声明其近似——安第斯型真实宽度 200–400 km、峰值 +3~4 km，本模型给的是造山带量级（有效半宽 360 km、+4545 m），**宽而缓的陆缘山脉**而非窄脊；换来的是"不新增概念、不新增参数"。原先陆侧拿岛弧参数 → 陆侧弧带 80–84% 出露成 +6.3 km 的 90 km 半宽刀刃墙（总壳厚 65 km 塞进 180 km 宽），已删。

### 5.3 俯冲带（`Trench` 下插侧 + `Arc` 上盘侧；**弧仅用于洋-洋俯冲**）

**海沟**（下插侧，纯几何下弯 → 只写海拔）：

```
d = 距俯冲边（下插侧一侧）的距离
Δh(d) = −TrenchDropMaxM · V(d / TrenchOuterWidthKm),  V = 半余弦 taper（初值 250 km）
外缘隆起（可选，初值 0 = 关闭）：d ∈ [TrenchOuterWidthKm, TrenchOuterWidthKm + OuterRiseWidthKm]
                                 处叠加 +OuterRiseHeightM（条带，半余弦包络）
```

- 初值 `TrenchDropMaxM` = 2500 m：沟底 = 该处洋底基准 − 2500。老洋壳处（−6500）→ **−9000 m**（知识库海沟 −6~−11 km ✓）；近脊年轻洋底处（−3000）→ −5500 m。
- **不写厚度**：海沟是**挠曲下弯**（弹性板 + slab pull），不是地壳减薄——纯 Airy 均衡到不了这个深度（知识库已论证）。这是 §6 纪律修订的**第一位依据**。

**火山弧**（上盘侧）：

```
d = 距俯冲边的距离（上盘侧）
Δt(d) = ArcThickenMaxM · A(|d − ArcOffsetKm| / ArcHalfWidthKm), A = 半余弦
Δh(d) = Δt(d) · kAiry
```

- 初值 `ArcOffsetKm` = 200 km、`ArcHalfWidthKm` = 150 km（知识库：弧离海沟 100–300 km）、`ArcThickenMaxM` = 30 000 m（→ 峰值 `Δh` ≈ +5455 m，总壳厚 = 上盘原壳 + 30 km）。
- ⚠️ **弧只用于洋-洋俯冲**（v1.2 修订）：上盘必须是洋板——陆-洋汇聚的陆侧改走造山带（§5.2）。理由：+30 km 是地幔源**新增**地壳，只有洋盆里才说得通；扣在 35 km 陆壳上会得到 65 km 厚、90 km 半宽的刀刃墙（实测 80–84% 出露），物理上错。
- 弧岩浆是**地幔→地壳的净输入**（合法新增通道）：上盘是洋格时 `FelsicThick` 从 0 增到 30 km —— 顺带使 `Crust.IsLand` 变真（**岛弧出露**由此自然发生，不写特判）。
- ⚠️ 弧峰能否出水取决于**该处洋底基准深度**（`−2500 − 5455 = +2955` 近脊处出水；`−6500 − 5455 = −1045` 老洋底处不出水）。这是物理上诚实的输出（岛弧出露本来就取决于洋底深度与岩浆供给量），判读时按此调 `ArcThickenMaxM`。

### 5.4 大陆裂谷（`Rift`）与被动陆缘（`Margin`，离散边陆侧）

```
Δt(d) = −RiftThinMaxM  · G(d / RiftHalfWidthKm)        # 减薄（负）
Δh(d) = Δt(d) · kAiry                                  # 负 → 下沉
肩部（仅 Rift）：d ∈ [RiftHalfWidthKm, RiftHalfWidthKm + ShoulderWidthKm]
               叠加 +ShoulderHeightM 峰值（正弦包络）——热穹窿/挠曲回弹，纯海拔（无 Δt）
```

- 大陆裂谷初值：`RiftThinMaxM` = 10 000 m（→ 地堑 −1818 m → 海拔 800−1818 = **−1018 m**，地堑积水/浅海 ✓）、`RiftHalfWidthKm` = 150 km、`ShoulderWidthKm` = 200 km、`ShoulderHeightM` = 1000 m（知识库：裂谷肩抬 1–2 km ✓）。
- 被动陆缘初值：`MarginThinMaxM` = 6000 m（→ 陆缘低地 −291 m）、`MarginHalfWidthKm` = 300 km，**无肩部**（被动边缘已冷却、无热穹窿）。
- 肩部与海沟同属"纯海拔机制"（挠曲/热），进 §6 纪律修订。

### 5.5 转换边界

**不写任何场**。这是正确输出而非遗漏——转换边界不产生也不消灭地壳。判读时它是最好的参照物：跨转换边界的海拔/厚度应当**连续**（只有陆洋属性差异会带来跳变）。

## 6. 纪律修订（实现前须与入口同步；本条是关键）

入口 §1 纪律 4 原文：要素生成器"**成对写厚度与海拔**（只写海拔制造'地形'是欺骗性数据，禁止）"。

本模块暴露了这条纪律的**表述漏洞**：真实世界里海拔有两个合法来源，而"成对写"只覆盖了第一个：

| 机制 | 写法 | 本模块实例 |
|---|---|---|
| ① 地壳厚度变化 → 均衡响应 | 写 `FelsicThick`，`Δh = Δt · kAiry` | 碰撞造山、火山弧、大陆裂谷、被动陆缘 |
| ② 热状态 / 弹性挠曲几何 → 直接给海拔 | 只写 `Elevation`（机制在案） | 海沟（挠曲下弯）、裂谷肩部（热穹窿/回弹）、洋底热沉降（§4） |

**修订后的纪律**：*海拔的每一次写入都必须能追溯到机制——要么由厚度变化经 Airy 增量导出，要么由热状态/挠曲几何直接给出（机制须在本文档登记）；**禁止"为了让某地形出现"而无机制地直改海拔**。* 判据可自动化：任何要素的 `Δh` 必须等于"登记的机制公式"在测试中的独立重算值（§10 测量项）。
> 待同步：入口 §1 纪律 4 措辞；入口 §3.3 常量表补 `ρ_mantle` / `R_earth` / 热沉降系数（跨模块共用）；01 §7 的"成对写"表述。

## 7. 距离场（有界 BFS）

- 每个"带宽度"要素需要"距其源边界的距离"。实现 = **有界多源 BFS**：源 = **逐边种子**（某格是【某条边】的某一侧角色就种进对应带，**不是**按该格的"主导省份"），深度上限 = 该要素最大带宽 ÷ 格宽（向上取整）。
  ⚠️ **v1.1 修正**：用"逐格主导省份"当种子时，边界上某格的主导边被更强的边抢走就不再当种子 → **带沿边界断续成斑块**，且相邻两格可能分属不同带（实测 10 km 接缝：`+1190 m` 紧贴 `−9101 m`）。逐边种子保证带沿整条边界连续；同一格可同时是两类带的种子（三板块交汇处本就如此）。
- **有效侧（v1.1 补正）**：造山 = 两侧陆格（跨边界对称展布 → 陆格掩码）；裂谷/被动陆缘 = 陆格；**海沟 = 下插板（同板 BFS）**；**弧 = 上盘板（同板 BFS）**。海沟若用"洋格掩码"会在洋-洋俯冲时漏到上盘洋壳上（上盘也是洋格）。
- 复杂度 O(源带面积 × 带宽)，与全球格数解耦；res5（2M 格）带宽要素的 BFS 在几十 ms 量级。
- 距离以**格步数**存，剖面函数里换算连续 `d = 步数 × 格宽Km`。格宽 = `sqrt(4π·R_earth² / N)`（等面积近似；res5 ≈ 15.9 km，与入口 §4 表里的 ~17 km 同量级）。
- 洋区热沉降的 BFS（§4）**无界**（覆盖全部洋格），O(N)。

### 11A. 已登记的空洞：大陆架（0 ~ −200 m）本模块不生成——根因是"无水位"

> **判读结论（2026-09-10 用户拍板）**：大陆架**不做，但结论必须登记在案**——它的根因不在"少了一种地形生成器"，而在模型**少了一个维度（水位）**。用户明确：**先做板壳运动，水量守恒之后单独立项**。本节留下的地质结论是为了将来立项时不必重新推导。

- **地质事实（已核准）**：大陆架 = **被海水淹没的陆地（沿海平原）**。坡折深度全球平均 ~130 m（Shepard 1973），本质是 **LGM 低海平面（−120~−130 m）的记录**；其上的 0~100 m 修正来自被动陆缘热沉降 + 沉积进积（北海/英吉利海峡坡折 ~200 m；范围 <100 m ~ >200 m）；陆架上 **60~70% 的沉积物是冰期残留沉积**，不是现在的河流带来的。
- **两个必须分开的尺度**：陆架/洋盆的 **~4.5 km** 落差来自**壳类型**（Airy：35 km 陆壳 vs 7 km 洋壳）；而 **0~200 m** 这整个区间由**水位**决定，与壳无关。
- **本模型为何生不出**：`Crust` 里**没有 SeaLevel 标量、没有水量守恒**——海只由"海拔 < 0"的取色判定表达；陆→洋是两级硬跳变。02 §5.4 的被动陆缘给的是**减薄的陆壳**（结构正确），却因为没有水位而落在**干燥的陆缘低地**上 → 出来是"浅凹 + 崖"，不是平坦浅水台地。
- **尺度约束**：res5 格宽 ≈16 km、陆架平均宽 ~80 km ≈ 5 格（能表达但粗）；res3（格宽 ~120 km）**表达不了**——此事本质到 res4/5 才有意义。
- **补法（留待水量守恒立项）**：水量守恒 = 全球水量 + **水位求解**（水位零位由全球水量定，不能由单柱局部解——这是被否路线里已论证过的结论）；有了水位，陆架就不是"生成的地形"，而是"**陆壳区里低于水位的那部分**"；再叠侵蚀/沉积/进积才谈得上坡折深度的离散。**登记结论：补地形是补症状，补水位才治根。**
