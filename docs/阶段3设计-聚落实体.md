## 一、现状与史实依据

### 1.1 现状（可复用）

| 机制 | 现状 | 聚落角色 |
|---|---|---|
| Tribe（一格一实体） | 社会单元，Cell=驻扎点，P=人口 | 聚落的**占据者**（人）；聚落 = 场所 |
| IsFarming → settle 能力 | 只加存储容量（0.5×P）+ 生育率 ×1.5 | **聚落形成条件**（农业定居） |
| Stocks（v12 存档） | 部落属性（粮仓容量挂 P） | 暂留部落（等级加成容量） |
| Chiefdom（v10 酋邦） | 至尊酋长庇护（个人半径） | 酋长聚落 = **都城**（贡赋汇聚，国家前置） |
| SplitMigrateModel | 部落可分裂/迁徙 | 迁徙 → 聚落留为**废墟**（场所比人长寿） |

### 1.2 史实锚点

- **旧石器游群无固定聚落**（现状正确——狩猎采集者移动营地，无村庄）；
- **新石器村庄**：杰里科/Çatalhöyük——固定房屋 + 粮仓 + 数百-数千人（Testart"存储→定居→盈余"链的物理端）；
- **城镇/城市**：青铜期乌鲁克/摩亨佐-达罗——集聚增长、存续数百年（考古 mound/tell：场所痕迹比人群长寿）；
- **废墟与迁移**：农业村庄因土壤耗竭/战乱废弃，但场所留存，可被再占据。

## 二、机制设计

### 2.1 实体模型（Settlement，v13 存档段）

```csharp
public sealed class Settlement {
    public int Id;           // 分配器 NextSettlementId（确定性）
    public int Cell;         // 所在格（**固定**——聚落不迁移）
    public int BornTick;     // 形成 tick
    public int Level;        // 0=新村/营地 1=村庄 2=城镇 3=城市（阈值驱动，确定性）
    public int LastLevelUpTick;   // 最近升级 tick（等级冷却）
    public int DwellFrom;    // 当前占据者定居起点 tick（= 占据部落 SettledSince）
    public int OccupantId;   // 占据部落 Id（-1=废墟/空置）
    public int RuinFrom;     // 废墟起点 tick（-1=非废墟）——v1 可省
}
```

### 2.2 形成（SettlementModel，Order 48——Chiefdom 46 与 Conflict 75 之间）

- **触发**：部落 `IsFarming`（=settle 能力，Mode 30 已派生）且无 `PlaceId`：
  - 所在格已有**废墟聚落** → 接管（继承 Level——场所比人长寿）；
  - 否则 → 新建聚落（Level 0，BornTick=Tick）。
- **狩猎部落不形成**（无 settle → 无聚落——游群照旧游动）。

### 2.3 等级演化（确定性纯函数——无 Rng，读档续跑无分叉）

`Level = f(定居时长 DwellTicks, 占据者人口 P, 聚落存续 Ticks)`（阈值 ★ 待校准）：

| 等级 | 名称 | 条件（示例） | 收益 |
|---|---|---|---|
| 0 | 新村/营地 | 形成即 0 | 基础 |
| 1 | 村庄 | Dwell ≥ 3 tick 且 P ≥ 200 | 存储容量 ×1.5 |
| 2 | 城镇 | Dwell ≥ 8 tick 且 P ≥ 800 | 存储 ×2 + 增长 ×1.25 |
| 3 | 城市 | Dwell ≥ 20 tick 且 P ≥ 3000 | 存储 ×2.5 + 增长 ×1.5（国家前置） |

- 等级提升带冷却（LastLevelUpTick，防跳级抖动）。
- **收益实现**（不搬 Stocks，最小改动）：
  - `AccumulateStorage` 容量：settle 容量 × `(1 + 0.5×Level)`（村庄 1.5×、城市 2.5×）；
  - `GrowthModel`：定居生育倍率 × `(1 + 0.25×Level)`（城市化集聚，轻量）。
- **都城**：酋长（至尊酋长庇护的 ChiefdomId 中心）占据的聚落 = 都城——等级提升判定放宽一档（个人权力中心集聚，为国家铺路）。

### 2.4 存续/继承（场所比人长寿）

- 部落**迁徙/灭绝** → 聚落 OccupantId=-1（废墟，实体保留——存档仍在）；
- 新部落迁入该格 → 接管废墟（继承 Level，DwellFrom 重置为新部落 SettledSince）；
- v1 不做废墟衰变（Level 不随时间降——考古 mound 语义）。

### 2.5 部落侧字段（v13）

```csharp
public int SettledSince = -1;   // 当前农业定居起点 tick（-1=游动中）；迁徙重置
public int PlaceId = -1;        // 占据聚落 Id（-1=无）；形成/接管时赋值
```

### 2.6 确定性（阶段3架构化红利）

- SettlementModel 无 Rng；形成/升级 = 存档状态纯函数 → 读档续跑无分叉（T04 保证）。
- SettledSince/PlaceId 入档（v13）；Level/都城 派生（SettleDerived 重建）——同 Territory/Chiefdom 模式。

- **新段**：`Settlements[]`（count + 每实体：Id/Cell/BornTick/Level/LastLevelUpTick/DwellFrom/OccupantId/RuinFrom）——紧跟 Tribes 段后；
