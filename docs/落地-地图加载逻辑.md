## 一、加载链路

### 1. 进度状态机

`LoadOperation`：`Report` 线程安全、低报钳制、NaN/越界/空阶段拒绝；`Complete/Fail/Cancel` 终态吸收；`Version` 每次可见变化递增；`Snapshot()` 锁内取同一版本。

### 2. 领域信号 + 独立监控器（解耦返工）

- `World.Data.Work.WorkSignal` / `IWorkSignalSource`：只描述“阶段、完成量、总量”，不引用进度/UI/Scene。
- `LoadProgressMonitor`：订阅任意 `IWorkSignalSource`，按 `LoadStagePlan` 加权推进 `LoadOperation`；可 `Attach/Detach/Dispose`，不创建时生产照常运行。
- 生成侧：
  - `WorldGenSimulation` 在板块/地形/气候/水文/索引完成时发 `WorkSignal`；
  - `WorldGenerationJob` 只发信号，**签名不含** `LoadOperation`/`ILoadProgressSink`；
  - `GeographyEvolutionView` 创建监控器订阅 Job，进度区间 0–0.70；渲染 0.70–1.00。
- 浏览侧：`MapBrowseJob` 只发信号；`AppRoot` 用监控器订阅，区间 0–0.75；`MapBrowserView` 只负责 0.75–1.00 的渲染进度。
- 演化侧：`WorldEvolutionSession` 只发 `WorkSignal`；`EvolutionPanel` 在忙碌开始时创建监控器订阅，结束后解除。
- 解耦验收测试：生成 Job 的 `Run` 参数无进度类型；`WorldGenSimulation` 只暴露 `Action<WorkSignal>`；监控器可在没有生产者感知的情况下单独 attach/detach。

### 3. 并行块读取

`MapPackageReader`：4 个 worker，各自独立 `FileStream + ZipArchive`；每块解压 → 长度校验 → SHA-256 → 按清单序归位；失败按最小块号稳定上报；块进度通过 `WorkSignal.Unit` 发出。

### 4. 进度层与浏览宿主编排

- `LoadProgressView`（可复用视图）+ `LoadingOverlay`（Modal 层，一次加载一实例，终态即销毁）；`LoadingOverlay` 阶段内每 100 ms 刷新已用时间。
- `AppRoot` 实现 `ILoadProgressSink`，`MapLibraryView` 经控制器把 `OpenMap(path)` 交给宿主；`AppRoot.OpenMap` 起 `MapBrowseJob`，监控器订阅，完成切浏览页。
- 失败经 `LoadFailure` + 状态条；退出应用取消。

### 5. 渲染分帧

- `BallView`：颜色 8192 格/片，逐 res0 块建 Hi/Lo；`WorldView` 推进网格后建河线；`RenderManager` 提供 `InitializeIncremental/StepBuild/BuildProgress/BuildStage`。
- `MapBrowserView._Process` 每帧 8 ms 预算推进 0.75–1.00，完成后才完成操作、隐藏遮罩。
- 生成页同样走分帧，0.70–1.00。

### 6. 演化面板与步进度

- `EvolutionPanel.tscn` 独立场景（布局在 tscn，脚本绑事件/读数/进度）。
- `CalculateToStep` 增加每步回调；会话发 `WorkSignal.Unit`（步）或 `Started`（单步/世界重建）。
- 计算期间旧帧可用；完成时 `ApplyPublishedWorld`：`BeginSwap` 禁用输入 → `RebakeView` → `EndSwap` 恢复。

## 三、已知限制

1. **生成进度是阶段级**：板块/地形/气候/水文/索引各一次跳变；阶段内百分比会停，靠已用时间每 100 ms 刷新。
2. **换帧未分帧**：实测 41–44 ms，低于 200 ms，因此整段重烘 + 输入门；若未来变慢需拆片。
3. **演化步进度没有自动化数值断言**：官方 `GeographyEvolutionCheck` 验证面板/单步/跳转，不检查进度条数值。
4. `tests/scenes/GeographyEvolutionDemo.tscn` 是旧布局场景，不在 `verify.sh` 路径内，本轮未修。

## 四、解耦边界

- `World.Logic`、`World.Data.Work`、`WorldGenerationJob`、`MapBrowseJob`、`WorldEvolutionSession` 均不引用 `LoadOperation`/`ILoadProgressSink`；只发 `WorkSignal`。
- 监控器在 `World.Scene`，由 `GeographyEvolutionView`/`AppRoot`/`EvolutionPanel` 按需创建；不创建时生产照常运行。
- 测试 `GenerationJobDoesNotExposeProgress` 用反射锁定“生成 Job 不接收进度类型”。
