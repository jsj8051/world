## 一、现状与缺口

### 1.1 已有地基（可复用）

| 机制 | 现状 | 阶段5 角色 |
|---|---|---|
| MilitMult（军事实力乘数） | 武器科技 microlith→bow 只进军事，与影响力解耦（石器 §15.2） | 战争力量的基础（已可"人口少但武器精良=军事强"） |
| ConflictModel（边境冲突，Order 75） | 软冲突：粘性僵持+压力门控+低频 → 胜率=P×MilitMult 对比 → **只夺格**（控制权+锁定+驱逐） | 冲突的"治安战"层面（阶段5 保留，另加"战争"硬机制） |
| 联盟合力 | 防御方是酋邦 → 入侵者面对酋邦总力量（Kirch） | 战争的天然兵力聚合（国家=更大联盟） |
| 政体整合 | 同酋邦 ×0.5、同国家 ×0.25、继承窗口 ×2（国家豁免） | 战争动员的组织基础（国家=暴力垄断制度化） |
| 国家机制（阶段4） | 涌现四条件 + 四项机制差异（税/官僚/秩序/王朝） | 战争的**主体**（国家=能发动征服的实体） |

### 1.2 缺口（本阶段补什么）

1. **国家没有"行为"**：阶段4 的国家只是统计标签（税/秩序/继承豁免），不能扩张/灭亡；
2. **崩溃路径缺"被征服"**：国家退化只有贡赋断流/都城失守/继承绝嗣——历史上多数国家死于战争；
3. **软冲突无组织性**：只夺格不灭邦，酋邦/国家结构永不受武力冲击（阶段4 §5 明说"冲突仍走软冲突"）。

### 1.3 史实锚点

- **Carneiro 环境限制论**：战争是早期国家形成/扩张的主引擎（苏美尔城邦互战）；
- **Tilly**："战争制造国家，国家制造战争"——战争胜利→贡赋/朝贡→国家更强；失败→瓦解；
- **Childe 城市革命**：城墙与军队是城市/国家的标配（青铜时代战争：苏美尔/埃及第一王朝）；
- **Earle 贡赋**：朝贡 = 战败方向战胜方转移剩余（贡赋机制的对外延伸）；
- **Weber**：国家 = 合法暴力垄断 → 战争权是国家专属（酋邦无正规战争，部落冲突仍是软冲突）。

## 二、机制设计（草案）

### 2.1 战争主体（拍板点 P1）

| 方案 | 内容 | 权衡 |
|---|---|---|
| **A（推荐）** | 只有**国家**能发动征服战争（Weber：暴力垄断制度化）；酋邦之间仍是软冲突 | 战争稀缺（呼应 n128 仅 1 国）；国家获得"行为"；不推翻现有软冲突 |
| B | 国家 + 大酋邦（≥10 成员）都能发动 | 战争更频繁（游戏性），但模糊"国家=暴力垄断"的史实叙事 |

### 2.2 战争=外交状态（拍板 P3：多 tick 持续，入档 v14）

**战争不是瞬时事件，而是两个国家之间的持续交战状态**（用户拍板）：
历史上战争持续多年（苏美尔城邦拉锯、王朝战争），中间有会战、有僵持、有求和。

```
War 段（存档 v14 新增，CivArchiveSchema 白名单）：
  StateIdA / StateIdB   ← 交战双方（= 国家至尊酋长 Id，StateId 语义）
  StartTick             ← 宣战 tick（时长判定：WarMaxTicks 强制停战防死锁）
  WinsA / WinsB         ← 累计会战胜场（战果分档的依据）
  LastBattleTick        ← 上次会战 tick（会战节奏：WarBattleInterval）
```

- **宣战**：国家 A 与国家 B **领地相邻** + A 贡赋池 ≥ WarMinPool + 概率门控（低频）+ 冷却
  （WarCooldownTicks 内不复宣战）；一个 tick 一个国家至多宣战 1 场（爆炸防护）；
- **交战**：每 WarBattleInterval tick 一场会战——双方军力 = Σ 成员 P×MilitMult
  （+ 都城 Level 加成 + 城墙防御方加成，P6）对比，胜率随机；败方损耗（WarLoss）；
  会战计入 WinsA/WinsB；
- **外交效果**：交战国之间**软冲突概率 ×2**（战争中的边境冲突更凶）+
  交战国之间**贸易中断**（WarTradeBlock：直接贸易 ×0）——"外交状态"不只打仗，
  还有断交的经济含义；
- **结束（战果分档，P4）**：
  - **吞并**：一方累计胜场 ≥ WarAnnexWins 且力量比 ≥ WarPowerRatio → 战败国全体成员并入
    战胜国（酋邦解散重映射、首领流放驱逐）——国家灭亡 = 被征服；
  - **朝贡**：一方累计胜场 ≥ WarTributeWins（低于吞并线）→ 战败国不灭，
    每 tick 转移 WarTributeRate × 战败国人口 入战胜国贡赋池 + 边境格割让（WarCedeCells 格）；
  - **停战**：双方持续 WarMaxTicks 无决出 → 各自恢复（损耗已发生，无赔偿）；
  - 朝贡关系**不形成新存档段**（每 tick 由 War 段在场时派生转移——朝贡是战争的延续，
    停战后即止；避免"朝贡国"成为第三个持久状态）。
- ⚠️ **存档语义（打破阶段4"零新字段"原则——用户拍板）**：战争是**过程状态**，
  不可从持久字段重建（读档必须恢复"正在交战"）→ 新增 War 段，版本 **v13 → v14**；
  旧档兼容：v13 读入无 War 段 = 无战争（CivMapArchive 兼容分支，同聚落段先例）；
  T04 读档续跑：War 段入 EntitiesEqual 对比（同 seed 同输出仍成立）。

### 2.3 战争结算（拍板点 P4——结局模式）

| 方案 | 内容 | 史实 |
|---|---|---|
| **A（推荐）** | **吞并**：战败国全体成员并入战胜国（酋邦解散重映射进战胜方酋邦/国家，首领处决或流放驱逐）——国家灭亡 = 被征服 | 苏美尔城邦吞并；国家=领土/人口的制度化扩张 |
| B | 朝贡+割地：战败国不灭，每 tick 转移贡赋给战胜国 + 边境格易主 | Earle 朝贡（更温和，国家存活） |
| **C（推荐组合）** | **按战果分档**：碾压（胜率≥75%）→ 吞并；均势险胜（50-75%）→ 朝贡+割地 | 两种历史结局都存在，由随机战果涌现决定 |

### 2.4 战争与既有机制的接线

- **国家化互馈（Tilly）**：战争胜利 → 战利品/朝贡入贡赋池 → 国家更稳（崩溃线更容易维持）；战争失败 → 损耗+贡赋池透支 → 退化风险↑（对称可逆崩溃的天然扩展）；
- **常备军**：国家 EliteFrac 0.25 的精英中隐含战士（**不加新实体**——军事强度 = 成员 MilitMult 聚合 + 都城 Level 加成；避免引入"军队"实体及其存档）；
- **MilitMult 扩展（拍板点 P5）**：科技表加青铜武器链（bronze_spear/bronze_sword/bronze_chariot，milit 列）——青铜时代 = 国家战争时代（Childe）；
- **城墙**（可选拍板点 P6）：聚落 Level≥3（城市）给防御方加成（攻城难度）——城市=要塞（Childe）。

### 2.5 国家崩溃路径补全

阶段4 崩溃三路径 + **④ 被征服**（吞并结算 → StateId 重映射 → 原国家消失）；
对称可逆不变：无滞回字段，战争结算本身就是一次性事件（入结果不入状态）。

## 四、范围边界（明确不做）

- **无玩家指挥/UI 操作**（纯涌现，延续项目哲学）；
- **无军队实体/兵种**（军事强度聚合计算，不加实体——War 段只记外交状态，不记兵力）；
- **无围城回合/战场地图**（会战 = 单 tick 力量对比结算，战争 = 多 tick 状态）；
- **无和平条约/外交系统**（战争是偶发状态，朝贡依附战争存在，停战即止）；
- **不重做软冲突**（治安战保留——战争是组织级硬机制，冲突是格级软机制，两层并存）。

## 五·补：殖民扩散与跨海（2026-08-19 用户拍板"波前推进 + 跨海合理"）

### 背景诊断（用户观察"人只占了很小一部分"）

n128 实测：陆地 39066 格、归属仅 11503（29%），且**归属格 ≈ 富饶区（R 前 30%）≈ 实体数**——
人类全挤在富饶区、一人一格，贫瘠 70% 陆地永久空置。根因三链：

1. **殖民只挑最肥格**：`PickMigrateTarget` 旧分数 = R×cost（R 绝对主导）→ 分裂永远往富饶空格挤；
2. **陡化影响力核**：`InfluenceWeightLUT = {1, 0.544, 0.192, 0}`（名义 6 跳、实际 3 跳断），
   抢邻居格需 2.1 倍实力 → 富饶区饱和后每实体 1 格锁死；
3. **波前停止**：富饶区无空格 → 分裂无目标 → 停滞。

### 修复（扩散项 + 跨海落地 + 殖民者自适应承载）

| 项 | 改动 | 史实 |
|---|---|---|
| 殖民分数 | `score = cost × (1 + ColonizeFertilityBias × R/RMax)`（**bias=0.3**，肥度最多 ×1.3）——**距离主导**：贫瘠近邻 > 富饶远邻，波前推进 | 现实殖民是压力溢出就近落地（次好地也要），非只挑最优 |
| 跨海 | BFS 扩展去掉 `!IsLandCell` 硬过滤——海洋可穿性完全交给 `TerrainCost`（**canoe=0.3 / 无 canoe=0**）；目标仍须 R>0（海/冰盖不是殖民地）；航程 = ColonizeRadius 6 跳 | 独木舟沿岸/岛链跳（波利尼西亚逐岛）；大洋洲殖民需 canoe |
| 分裂自适应 | `newPop = min(母体×45%, 目标格狩猎承载)`——殖民者带"能活的数量" | band 分裂 = 溢出小群，带走量由目的地可养决定 |
| RMax | `BuildLayer1` 记录全局 R 最大值（殖民分数归一化；不存档） | — |
| ~~领地核放宽~~ | **尝试后回退**：InfluenceWeightLUT 加 d=3-5 弱权重 + wProd 扩 6 跳 → 领地产出去中心化 → 采集经济增强、**农业门槛被压（n128 实测 farm 412→74 崩溃）**——回退（领地大小保持 3 跳；扩散靠殖民机制，不靠领地核） | — |

- 起源仍只在富饶区（史实：文明起源好地，之后扩散）；饥饿迁移/冲突驱逐共用 PickMigrateTarget → 同获跨海与扩散；
- ⚠️ 跨海"合理"的边界：6 跳 ≈ 数百 km 近海航程（不跨大洋）；无 canoe 海 cost=0 不可穿；
- **测试**：T76 跨海殖民（canoe 渡海 vs 无 canoe 阻挡）/ T77 扩散分数（贫瘠近邻赢富饶远邻；同距肥度微偏好不反转）；
- **验证**（n128/n64 演化）：
  - 贫瘠区（R<0.05）从无人 → 634 实体（扩散生效）；n64 农业增强（farm 63 vs 基线 27）；
  - 覆盖率 ~30% 无显著提升——**生态真相：狩猎采集承载锁死**（密度 0.1 人/km² 史实标定，
    总人口 = Σ 归属格承载 ≈ 1530 万），人只占领土够吃的地方（富饶区全占、中 R 区过半、
    低 R 区零星——史实 1 万年前人类同样如此）；**"铺满世界" = 农业时代**（新石器革命 →
    人口爆炸 → 定居 → 城市），是后续阶段的自然答案。
