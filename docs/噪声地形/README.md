## 系列定位

世界地形改由**球面噪声叠加栈**产出（一次生成、不演化），并**保持 `Crust` 状态契约**（接口保持型替换）。

**已知后果（明写在案）**：
- ★ `res5 150 步 ≤10 min` 的性能阻塞**对地形不再成立**（地形生成一次，不再是每宏步解算）；
- ★ 代价 = 失去动态地质演化（板块漂移 / 造山历史 / 超大陆旋回）——**用户引入的取舍**；
- 地壳系列 `16` 的 A/B/C 三轴 → 降级为备用/长期线；`13` GPU 立项不撤不推进。

## 关键事实（写代码前必看）

1. **采样入口** = `Ball.CellDirs`（逐格单位向量）；坐标换算 `CoordUtil.LatLngToSphere(H3.CellToLatLng(c), radius)`；
2. **已有基建**：`Utils/SphericalFbmNoise`（`seed, baseWavelengthKm, octaves`）、`Utils/SphericalBlobNoise`、`Biome/ISphericalNoise` + `FastNoiseLiteNoise` ⇒ **在它上面搭栈，不另起炉灶**；
3. ★ **球壳渲染目前只用海拔烘焙色带、没有顶点位移** ⇒ P0 需新增"逐格高度位移"（地壳世界同样缺 ⇒ 共用基建）；
4. **分辨率**：res3 41 162 格/~120 km、res4 288 122 格/~45 km、res5 2 016 842 格/~17 km；★`BallManager` 注释写明 **res5 网格渲染扛不住** ⇒ 视觉实验到 res4 为止；
5. **参数单一事实源** = `TerrainNoiseParams`（面板由它反射生成，导出 JSON 同结构）。
