# 文明演化模拟 v1（石器时代）

> 2026-08-05 建立。目标：**输入自然地图，输出实际游玩地图**——从石器时代演化到中世纪的总方向
> 的**第一纪元**（v1 只做旧石器/狩猎采集阶段）。自然地图全程只读，分毫不动。
> 代码：`scripts/CivSim/`（CivEngine/CivModels/CivMapArchive）+ `scripts/Diagnostics/CivSimDiag.cs`。

## 〇、定位与数据流

```
自然地图 .mpa/.gmp（只读，GameGrid 自然层）
    ↓ 输入
文明演化引擎（纪元推进，seed 确定性可复现）
    ↓ 输出
游玩地图 .cmp（自包含：自然层快照 + 文明层；源自然地图零改动）
```

- **逻辑网格 = 模拟网格本体**（10n²+2 球面顶点胞，零重采样）——文明状态直接落在 GameGrid 格上。
- `.cmp` 自然段复用 `GameMapArchive.WriteBody/ReadBody`（与 .gmp 布局完全一致），读回校验自然层零改动。
- 确定性：`Random(seed)` + 固定遍历顺序 → 同 seed 同网格必得同结果（诊断自检复现性）。

## 一、抽象建模（延续项目定案：唯一统一基类 + 注册表）

```
CivModelBase（唯一抽象基类：Name / Order / Execute / Verify）
 ├─ OriginModel      ① 部落起源（tick 0 一次性播种）
 ├─ GrowthModel      ② 人口增长（logistic + 承载力 + 超载惩罚）
 ├─ TechModel        ⑤ 技术演进（石核→手斧/火→细石器→弓箭，全局解锁）
 ├─ MigrationModel   ③ 迁徙扩散（探路播种 + 饱和溢出多路）
 ├─ CultureModel     ⑥ 文化传播（相邻同化，人口优势扩散）
 └─ CompetitionModel ⑦ 部落竞争（超载枯竭 + 冲突损耗）

CivModelRegistry（注册表：StoneAge() 注册 6 模型，按 Order 每 tick 执行）
EpochDefinition（纪元定义：Kind / Name / MaxTicks / TickYears）
CivSimContext（演化状态：CellCiv[] 格状态 + Tribe[] 部落表 + 参数）
CivEngine.Run(grid, seed, originCount) → CivSimResult
```

- 格状态 `CellCiv`：Population / Culture / Tech / TribeId（连续场，struct 数组紧凑存储）
- 部落实体 `Tribe`：谱系跟踪（起源格→主格），v1 部落=同一起源扩散的人群
- ④ 环境适应不是独立 tick 模型——是**承载密度场**（biome×水源→BaseK），init 时算、技术演进时更新

## 二、七机制与常数标定（狩猎采集人类学/考古学依据）

| # | 机制 | 模型 | 关键常数 | 依据 |
|---|---|---|---|---|
| ① | 部落起源 | seed 选 1-3 个陆地格播种 100 人，独立文化标签 | originCount=1..3 | 智人起源"摇篮"（旧石器人类适应力强，不挑环境） |
| ② | 人口增长 | `dP = r·Δt·P·(1−P/K)`，超载(>1.3K)枯竭负增长 | r=0.5%/年（游戏压缩 10×，前工业 ~0.05%/年）；tick=100 年 | 前工业人口统计学 |
| ③ | 迁徙扩散 | 探路播种(>300人恒播5%开拓无人格) + 饱和(≥75%K)主候选25%+次候选8% | 探路=持续探索 ~1km/年；n=64 每格~110km/100年≈1.1km/年 | 智人扩散速率实测（出非洲→欧亚~1km/年） |
| ④ | 环境适应 | 承载密度 K=biome密度×胞面积×水源(河湖×1.5)×技术 | 草原/稀树草原 0.45、温带 0.30、雨林 0.15、针叶林 0.10、沙漠/高山 0.05、极地 0.02 人/km² | Binford 狩猎采集密度研究量级（澳洲 0.1-0.5/沙漠 0.05/北极 0.02） |
| ⑤ | 技术演进 | 全局解锁（史前技术泛大陆传播）：tick≥60 且人口>5万→手斧+火；≥100 且>20万→细石器；≥150 且>50万→弓箭 | K×1.4/级；火(≥1)解锁极寒区 K×3 | 阿舍利手斧横跨非欧亚；塔斯马尼亚孤岛技术停滞 |
| ⑥ | 文化传播 | 相邻格人口比>3:1 → 强文化 50%/tick 同化弱格 | AssimilateRatio=3, Chance=0.5 | 农业/人口优势人群语言文化替代（同化模型） |
| ⑦ | 部落竞争 | 超载枯竭(>1.3K −5%/tick) + 全饱和冲突压入(15%尝试,30%损耗) | OvercrowdLimit=1.3 | 生态竞争/资源争夺（石器时代无"战争"） |

**终止条件**：人口连续 20 tick 增长 <1% **且覆盖不再扩张** → 提前终止（可达环境上限）；
否则跑满 MaxTicks=300（3 万年）。⚠️ 只查人口会误杀探路扩散（总人口饱和时前沿仍在开拓）。

## 三、验证结果（CivSimDiag，全部 PASS）

| 指标 | n=16 (map1.mpa, 2562格) | n=64 (map_seed42_n64.mpa, 40962格) |
|---|---|---|
| 演化时长 | 87 tick = 8700 年（提前终止） | 298 tick = 29800 年 |
| 总人口 | 1639 万 | 2022 万（~0.24 人/km²） |
| 覆盖 | 238/238 可达陆地 (100%) | 6778/7005 可达陆地 (97%) |
| 孤立大陆 | 598 格（无船不可达） | 7631 格 |
| 文化区 | 3 个（最大 131 格） | 3 个（最大 3081 格） |
| 技术 | 手斧（tick 60 解锁） | 弓箭（tick 150+） |
| 性能 | 秒级 | 3.5 秒 |
| 校验 | 自然层零改动 / 文明层往返 / 复现性 全 PASS | 同左 |

**设计意图（非 bug）**：
- **孤立大陆无人**：石器时代无船，海洋阻隔 → 对应现实（旧石器人类未达澳洲/美洲）。
- **覆盖 97% 非 100%**：剩余为极端低承载区（高山/沙漠/极地角落），人口薄或无人，符合生态现实。
- **技术全局同步**：史前技术大区域传播（阿舍利横跨非欧亚），非逐部落独立发明。
