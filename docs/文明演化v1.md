# 文明演化模拟 v2（部落模型 + 科技表格）

> 2026-08-05 建立（v1 石器时代 → v2 部落重构 + 数据驱动科技系统）。
> 目标：**输入自然地图，输出实际游玩地图**——从石器时代演化到中世纪。自然地图全程只读。
> 代码：`scripts/CivSim/`（CivEngine/CivModels/CivMapArchive/TechTable）+ `data/techs.csv` + `scripts/Diagnostics/CivSimDiag.cs`。

## 〇、定位与数据流

```
自然地图 .mpa/.gmp（只读，GameGrid 自然层）
    ↓ 输入
文明演化引擎（部落级异步，seed 确定性可复现）
    ↓ 输出
游玩地图 .cmp（自包含：自然层快照 + 部落表；源自然地图零改动）
```

- **部落 = 格内社会单元**（一格多部落，部落不占多格）——旧石器社会尺度（band/部落几十~数百人）远小于
  游戏格（n=64 每格 12450 km² 承载数千人）。"部落占多格"是农业革命后才有的事。
- **时代推进完全异步**：纪元只是存档标签，每部落按自己节奏发明/学习技术（先进与落后部落并存）。
- 确定性：`Random(seed)` + 固定遍历顺序 → 同 seed 同网格必得同结果。

## 一、部落模型（动态社会单元）

```
部落 Tribe（活实体，格内）：人口 / 文化 / 技术位掩码 / 所在格 / 起源格 / 成立tick
格 CellTribes[]（地理容器）：一格多部落（≤8，MaxTribesPerCell），总人口 = Σ 部落
```

| 机制 | 触发 | 结果 |
|---|---|---|
| **分裂**（segmentary lineage） | 部落人口 > 400 | 同格裂变，新部落带走 45%（继承技术/文化，此后独立发展=各有酋长） |
| **迁徙** | 饱和（格 >90%K）：最大部落分出 50% 迁往相邻宜居格；探路（>100 人 2%/tick）：30% 迁往无人格 | 持续扩散（旧石器 ~1km/年特性）；无船不跨海 |
| **接触**（同格直接 / 相邻格边界） | 边界格对 + 同格部落对 | 四种后果（下） |
| **冲突吞并** | 同格人口比 >3:1 | 强吞弱：人口/技术并集，弱部落消亡（消灭+占领） |
| **和平合并** | 同格人口比 0.5~2 且文化同（5‰/tick） | 融合：领地/人口/技术并集，无消灭（联盟/通婚） |
| **贸易** | 接触即贸易（物物交换，旧石器真实存在） | 统计 + 技术传播 ×2 加速（学习加速→节奏差异来源） |
| **文化同化** | 同格人口优势方 30%/tick | 弱方文化标签向强方靠拢 |

## 一·五、文化分层 + 宗教（部落身份属性）

| 属性 | 形态 | 机制 |
|---|---|---|
| **文化标签** | byte，接触同化快（30%/tick） | 语言/习俗，随部落走 |
| **文化群** | byte（语言-文化大群，起源决定） | 不做接触同化——只在分裂时 0.5% 分化出子文化群（方言→语言群，segmentary lineage 分化），吞并/合并时随部落消亡；保持多群并存（n=64 实测 7-24 个） |
| **宗教** | ReligionType 0-4：万物有灵→萨满图腾→祖先崇拜→多神教→一神教 | **演进**（绑部落技术时代，复杂化单向只升不降）+ **传播**（接触，只向更高阶段，先进宗教扩散） |

宗教演进链史实依据：尼安德特墓葬/泛灵论（旧石器早期）→ 洞穴壁画/维纳斯雕像（旧石器晚期）→
哥贝克力石阵/祖先祭祀（新石器）→ 神庙神系（青铜）→ 圣典宗教（铁器/古典）。
人种属性：用户拍板不做（科学上"人种"不成立，肤色为连续光谱，非游戏核心）。

## 二、科技系统（数据驱动，`data/techs.csv`）

- **技术 = 部落属性**（ulong 位掩码，25 项 <64）。发明看部落人口+环境+随机；传播靠部落接触（不分同源）。
- **发明门槛按时代**：旧石器 30~120 人（低门槛，传播驱动，泛大陆普及=史实阿舍利）；
  农业 -1 = **格 K 利用率 > 全球 P80**（人口压力理论 Boserup）+ 环境（河/草原/地中海）+ 低概率 →
  少数起源中心；青铜+ 2000~30000（聚落/矿藏/城市）。
- **传播**：接触部落对，概率 = SpreadBase × 贸易×2（旧石器易传 0.05，青铜难传 0.01）。
- **效果**：carry=承载乘数（K 连乘）；unlock_cold=火解锁极寒区；unlock_sea/settle/state=能力标记；
  mod_*=人文层占位（军事/贸易/政体/科研，后续人文层消费）。

25 项技术金字塔（石器 7 → 新石器 5 → 青铜 5 → 铁器 3 → 古典/中世纪 5）。

## 三、关键标定（人类学/考古学依据）

| 参数 | 值 | 依据 |
|---|---|---|
| 承载密度 | 草原 0.45 / 温带 0.30 / 雨林 0.15 / 沙漠 0.05 / 极地 0.02 人/km² | Binford 狩猎采集密度研究 |
| 增长率 r | 0.5%/年（前工业 0.05% 压缩 10×） | 前工业人口统计学 |
| 分裂阈值 | 400 人（游戏部落=数百人酋邦级） | segmentary lineage |
| 探路扩散 | 2%/tick × 30% 人口 | 智人扩散 ~1km/年 |
| 农业承载 | ×4（刀耕火种量级） | 农业人口密度 vs 狩猎采集 |
| 技术乘数 | 手斧×1.2 / 细石器×1.3 / 弓箭×1.4 / 陶器×1.2 | 工具效率提升估算 |

## 四、验证结果（CivSimDiag，全部 PASS）

| 指标 | n=16 (map1.mpa) | n=64 (map_seed42_n64.mpa) |

| 演化时长 | 301 tick = 3 万年 | 301 tick = 3 万年 |
| 部落 | 7583（均值 5 万，n=16 格大） | **80952（均值 1017 人）** |
| 覆盖 | 814/836 陆地（97%） | **7544/14636（主大陆 7005 全满；孤立大陆无船不可达）** |
| 时代分布 | 石器 4445 / 新石器 1 / 青铜 9 / 铁器 0 / 古典 3128 | **石器 51382(63%) / 新石器 2645 / 青铜 15445 / 铁器 1581 / 古典 9899** |
| 宗教分布 | 萨满 4445 / 祖先 1 / 多神 9 / 一神 3128 | **萨满 51268 / 祖先 2492 / 多神 15656 / 一神 11536** |
| 文化群 | 6 个 | 7 个 |
| 性能 | ~2 秒 | ~32 秒 |
| 校验 | 全 PASS | 全 PASS |

**异步演化的实现**：旧石器技术全部落普及（传播驱动，史实）→ 农业 37% 部落（发明+传播异步）→
青铜 19% → 铁器 2% → 古典 12% —— 部落节奏差异显著，先进与落后并存（63% 部落仍在狩猎采集）。

| 方向 | 内容 |
