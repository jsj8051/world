结构层强制的规则：

- 空 Id / 空标题 / 超长标题 / 未知入口 / 未知状态 / 未知换帧状态一律抛。
- `Progress` 必须是 `null` 或 `[0,1]` 有限值；`Completed` 必须正好 1；`Failed` 必须带 `LoadFailure`。
- 有进度或非 `Running` 的快照必须有阶段文字。
- 阶段权重 >0、总和 1（±1e-6）、Id 唯一；演化不能建加权计划。
- 没有任何缓存类型、缓存目录或序列化模型。
