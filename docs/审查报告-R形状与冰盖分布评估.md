> 路线 A · Phase 4。日期 2026-10-06。
> 上游：`docs/审查报告-P4-2-独立佐证AB.md`（⑧b，判定 = **未达重标定门槛**）。
> **本轮边界：`scripts/WorldGen/` 生产代码 0 改动；不改 `MiamiNpp` / `R` / 冰盖阈值；只新增只读诊断。**
> 本报告直接回答一个问题：**新世界（跨 seed）的响应形状，是否真的需要改变？**

## §〇 结论（一句话）

**不需要改变模型响应形状 ⇒ 不进入 `R` / `MiamiNpp` 重标定 ⇒ 可直接进入 P4-3 Biome。**
本轮把"重标定"正式改写成**不校准绝对量级、只评估响应形状；不把目标冰盖占比当常数、只评估阈值在世界生成器分布下是否合理**——三条独立支撑：

| # | 支撑 | 实测 |
|---|---|---|
| ① | **形状指标落在 Legacy 单世界的分布包络之内** | 新线 `R_raw` **P95/P5 = 3.92~6.33**（12 seed × res2/res4）；Legacy = **5.23** ⇒ 正落包络**中部**。对比度未被改变。 |
| ② | **冰盖漂移 = 大陆布局，不是阈值** | 冰盖是**干净的纬度阶跃**：`<50°` 无冰、`≥65°` 全冻、方差**全在 50–60° 过渡带**。同世界扫阈值 ±1°C 只改 **0.0~1.6 pp**；跨 seed 漂移 **4.83% → 25.09%（±135%）**。**效应比 ≈ 100×**。 |
| ③ | **无"异常肥沃膨胀"** | 新线 `R>2000%` = **6.22~18.43**，Legacy = **18.6** ⇒ Legacy 在**高端**，新世界并不更极端（方向相反）。 |

★**本轮唯一发现的真实结构漂移**（`k` 吸收不掉的那部分）：`R<600%` 极差 **107~125%**、`R>2000%` 极差 **89~94%**。
⇒ **生计空间结构随 seed 有实际漂移**。这不是模型缺陷（§四已归因），但它直接决定一条纪律：

> **任何基于 `R` 阈值占比的验收都必须跨 seed；单世界读数不构成验收。**

★ **结构性发现（本轮最有信息量的一条）**：

- **上尾 `P95` 极稳**：极差仅 **5.3%~6.3%**（res2/res4）。
- **下尾与中位漂移大**：`P5` 极差 **40%~43%**、`P50` 极差 **55%~60%**。

机制：`R_raw = min(nppT, nppP)`，而 `nppT`/`nppP` 都**上探 3000 封顶**（S 形饱和），
故高纬/中纬的暖湿格**全部挤在上尾的饱和平台**上 ⇒ `P95` 被气候模型的两条饱和曲线**钉住**；
`P5`/`P50` 由下尾的"冷/干"格决定 ⇒ 完全由世界生成器把多少陆地放在冷/干区决定 ⇒ 随 seed 漂。

⇒ 这同时解释了 §⑧b 为什么"看起来稳定"：`k` 钉的是 `P50`，而 `P50` 恰恰是漂移最大的量之一。
**真正稳的是形状的"上沿"，不是中位。**

⇒ **Legacy 的对比度 5.23 落在新世界包络的正中**（中位数 5.13~5.33）。
P95/P5 的 45% 极差 = 光照/大陆布局带来的**自然族宽**，不是"新世界形状被拉平/拉尖"。

## §四 冰盖空间分布与阈值敏感性

### 4.1 空间分布（A3：各行 = 该 `|lat|` 带**陆地**中的冰盖占比）

| `|lat|` 带 | res2 包络 | res4 包络 |
|---|---|---|
| < 50° | **0.0 – 0.8** | **0.0 – 0.8** |
| 50–60° | **0.0 – 50.0** | **0.0 – 48.1** |
| 60–65° | 78.0 – 100.0 | 80.1 – 100.0 |
| 65–70° | **100.0**（24/24） | **100.0**（24/24） |
| 70–75° | 0.0 或 100.0 | 0.0 或 100.0 |
| ≥ 75° | 0.0 或 100.0 | 0.0 或 100.0 |

| 冰线（冰盖格 `|lat|` 分位） | res2 包络 | res4 包络 |
|---|---|---|
| min | 42.7 – 64.7 | 31.5 – 62.7 |
| P5 | 48.4 – 67.9 | 48.3 – 67.6 |
| P50 | 57.1 – 77.2 | 58.5 – 77.2 |

★ **机制结论**：冰盖是**干净的纬度阶跃** ——
**低纬永无冰**（`<50°` 24/24 近零，最大 0.8%）、**极区永全冻**（`65–70°` 24/24 = 100%）、
**方差全部落在 50–60° 过渡带**（0% ↔ 50%）。`70°+` 出现 0% 的两个 seed（21/50）是**那里没有陆地**，
不是"那里不结冰"（seed21 冰线 min 64.7°、seed50 冰盖全在 50–65°）。

⇒ `ice%` 的跨 seed 差异 = **世界生成器把多少陆地放在 45–65° 过渡带** = **大陆布局**。
这与 ⑧b 的 `r(ice%land, 陆≥60°占比) = 0.968/0.958` 是同一个事实的两种表述。

### 4.2 阈值敏感性（A4：**同一世界、同一地理**，只扫阈值）

| 阈值 | −7°C | −6.5 | −6 | **−5.5** | −5 | −4.5 | −4 | −3°C | 斜率 %/°C |
|---|---|---|---|---|---|---|---|---|---|
| 新线 res2 | 3.61–22.70 | … | | **4.83–25.09** | | | | 7.36–29.05 | **0.00 – 1.59**（中 0.84） |
| 新线 res4 | 2.81–20.39 | … | | **3.97–22.55** | | | | 6.25–26.88 | **0.00 – 1.62**（中 0.95） |
| **Legacy** | 19.92 | 20.70 | 21.41 | **22.14** | 22.84 | 23.69 | 24.56 | 26.30 | **1.595** |

★ **关键比值**：

> 阈值 ±1°C 的效应：**0.0 – 1.6 pp**（斜率 0.00–1.62 %/°C）
> 跨 seed 的漂移：**4.83% → 25.09%（±135% 相对极差）**
> ⇒ **漂移 / 阈值效应 ≈ 100×**

★ **seed21 是极端例证**：斜率 **0.00**（res2/res4 均 0）。
原因：该世界**没有任何陆地格落在 `T ∈ (−7, −3)` 过渡带内**（A3 显示其 `50–60°` 带 = 0.0、`60–65°` = 100.0）
—— 冰盖是**纯阶跃**，阈值在 4°C 区间内移动**完全无效果**。

⇒ **用户预判已被证实**：在**固定世界、固定地理**下，阈值 `−5.5°C` **没有任何异常**。
`−5.5` 的取值落在"阈值响应线性段"的中间，改动它只会移动**噪声**（0.0~1.6 pp），
**不足以解释**观察到的那 135% 的漂移。

## §五 与 Legacy 单世界的对照（核心问题：有没有"形状断裂"）

把 Legacy 单世界的 8 条锚放到新世界的 **12 seed 包络**里：

| 指标 | 新线 res2 | 新线 res4 | Legacy 单世界 | 判定 |
|---|---|---|---|---|
| `R_raw` P5 | 357 – 552 | 343 – 518 | **465** | **∈ / ∈** |
| `R_raw` P50 | 852 – 1585 | 870 – 1534 | **1260** | **∈ / ∈** |
| `R_raw` P95 | 2078 – 2213 | 2062 – 2176 | **2430** | ↑ +9.8% / ↑ +11.7% |
| `R_raw` **P95/P5** | 3.92 – 6.20 | 4.11 – 6.33 | **5.23** | **∈ / ∈** |
| `R>2000%` | 6.61 – 18.43 | 6.22 – 16.34 | **18.6** | ↑ +0.17pp / ↑ +2.26pp |
| `R<300%` | 0.00 – 2.78 | 0.01 – 2.99 | **0.0** | **∈ / ↓ 0.01** |
| `ice%land` | 4.83 – 25.09 | 3.97 – 22.55 | **22.14** | **∈ / ∈** |
| 阈值斜率 %/°C | 0.00 – 1.59 | 0.00 – 1.62 | **1.595** | ✎ −0.005 / **∈** |
| 陆地占比 | 29.1 – 29.4 | 29.0 | 28.5 | 基线可比 |
| 降水侧受限 | 69.0 – 96.3（⑧b） | 同上 | 26.1 | 已归因（⑧b） |

### 结论

★ **8 条锚中 5 条严格落在新世界包络内；唯一"出界"的 2 条（`R_raw P95`、`R>2000%`）是同一事实，
且方向是「Legacy 更宽/更高」—— 新世界的高尾并不比旧世界更极端。**

具体：

- **对比度（形状的核心）= 5.23，落包络正中** ⇒ **无"形状断裂"**。
- **高尾**：Legacy P95 2430 高于新线 max 2213（+9.8%）。意义是**新世界的高尾略窄**——
  若真要找一个"差异"，它是"新世界比旧世界**少一点**极端肥沃"，**不是**"异常肥沃膨胀"。
  且这条差异同时被 `P95/P5` 落在包络内所"打折"：**Legacy 的高尾宽是绝对量级宽，不是相对对比度宽。**
- **`R>2000%`**：Legacy 18.6 恰在新线 res2 max（18.43）之上 0.17pp ⇒ 统计上不可区分；
  res4 的 max 16.34 更低是**分辨率效应**（res4 的 warm 格更细，同一气候下极端格被平均掉一部分），
  与 ⑧b 已记录的"同世界跨 res 差异中位 ~6.9%"同源。
- **`ice%`**：Legacy 22.14 落在两个 res 的包络内 ⇒ **Legacy 不是冰盖异常值，它只是新世界冰盖族的一个普通成员。**

==> **新世界产生的是一个"R 分布族"；Legacy 单世界落在族内（高尾略偏宽）。没有形状断裂。**

## §六 ★ 判定：模型响应形状是否真的需要改变？

| 用户设定的判据 | 实测 | 判定 |
|---|---|---|
| 响应形状是否被改变 | `P95/P5` 落 Legacy 包络正中（5.23 vs 3.92~6.33） | **未改变** |
| 是否出现"异常肥沃膨胀" | 新线 `R>2000%` 6.22~18.43 vs Legacy 18.6；高尾**更窄** | **无膨胀** |
| 冰盖阈值是否异常 | 同世界扫阈值 ±1°C 只改 0.0~1.6 pp；漂移/效应 ≈ 100× | **阈值无异常** |
| 冰盖漂移归因 | 干净的纬度阶跃；方差全在 50–60° 过渡带 = 大陆布局 | **世界生成器自然方差** |
| 低产/极端组合是否稳定 | `R<300%` ≤2.99%、`T<−6∧P≥2000` = 0（均为 24/24） | **稳定** |

### ⇒ **结论：不需要改变模型响应形状。**

**不进 `R` / `MiamiNpp` 联合重标定**（用户设定的门槛在 ⑧b 判定为"未达"，本轮进一步确认**没有新证据**把它推过门槛）。
**不冻结"目标冰盖占比"**——`ice%` 是**大陆布局的函数**，不是模型健康指标。
**不动 `−5.5°C` 阈值**——无证据表明它错了；固定世界上它表现完全正常。

## §七 ★ 新原则（建议冻结进 ADR-0005）

> ### 原则 14 · **禁止以 Legacy 单个世界的分布作为新世界 `R` 或冰盖阈值的目标分布；参数评估必须针对跨 seed 的新世界分布及其机制语义。**

配套解释（写进 ADR 时一并落档）：

- **为什么**：Legacy `.mpa` 是**单个世界的一个快照**。本轮实测证明了它作为"目标分布"的两个致命问题：
  ① 它的 `ice% = 22.14%` 会被误当成"健康值"，而真实的新世界 `ice%` 是 **3.97%~25.09% 的族**；
  ② 它的 `R_raw P95 = 2430` 高于新世界 max **9.8%**，若以它为靶，会驱动一次**不必要的上尾放宽**。
- **怎么用 Legacy 才是对的**：只把 Legacy 的**响应曲线形状**（如阈值斜率 1.595 %/°C、
  对比度 `P95/P5 = 5.23`）当作**量级参照**，判断是否"同阶"；**不**把它的**点值**当目标。
- **与既有原则的关系**：这条是防膨胀三问中**"有无真实消费者"**在**参数验收**上的对偶形态 ——
  **"有没有一个真实的、跨 seed 的分布，才是参数的目标"**，而不是"某个单世界算出来的数"。

★ 用户原话："**这条比『某个阈值是多少』更值得冻结。**"
