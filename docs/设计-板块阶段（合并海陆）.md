## 二 `Plate` 数据载体

```
Plate {
    int   PlateId;
    float SeedTheta, SeedPhi;   // 种子点位置（原 ThetaV/PhiV 改名，语义不变）
    float V;                    // 速率大小
    float VTheta, VPhi;         // 速度在 θ / φ 方向的分量（角速率）
    bool  IsLand;               // 板块阶段掩码回填
}
```

**命名事故**：`ThetaV/PhiV` 注释写「种子点极角/方位角」、赋值 `ToEuler(...)` ⇒ 值是**位置**，
但 `V` 后缀让人读成速度，且与速率 `V` 撞名。改名后 `VTheta/VPhi` 才真正名副其实。

**速度物理含义**：球面欧拉速率 `v = r·θ̇·e₁ + r·sinθ·φ̇·e₂`，存角速率。极点处 `φ̇` 发散（毛球定理），
种子点近极点时方向判据按纯经向运动特判。

## 三 改造

### 3.1 大陆锚点归位到板块（一对一）

锚点由 `PlateManager.BuildAnchors(seed)` 从板块派生：每块板块 → 一个锚点，
位置 = 该板块种子点方向，属性沿用值域随机派生。`ContinentCount` 参数**删除**，
与 `PlateCount` 收敛为一个数。

### 3.2 陆地场**直接在 H3 上算**（无连续场、无投影器）

逐格标量 = 影响场 + 域扭曲 + 大/中/小三尺度噪声，值域 [0,1]，`> SeaLevel` 即陆。
算法在 `PlateManager.BuildLandMask`，`H3TerrainSampler` 只负责「多点采样 + 顶点缓存 + 并行」
（入参 `Func<Vector3,float>`，与"场是什么"无关）。`PlatePipeline` 只编排、不持算法。

### 3.3 `Plate.IsLand` 真正回填

`PlateLandFill.Fill`：按板块统计陆格占比，过 `IsLandThreshold`（默认 0.5）即视为陆壳板块。
刻意破了「各阶段产物归各阶段」的严格单向性——板块自带陆地身份，字段本就留着。

> 碰撞（挤压/张裂）**不参与判陆**——它是地质区域/海拔分配的事，等下游阶段再接。

## 六 ① 区域与地形阶段分层

`TerrainPipeline` = **编排层**（只转发产物 + `Run` 里调一次 `TerrainManager.Run`）；
`TerrainManager` = **实现层**（聚合 `GeologicalRegionManager` + `HeightComposer` 两条子链）。

| 文件 | 职责 |
|---|---|
| `Logic/Geology/TerrainManager.cs` | **实现层**：按序跑两条子链 |
| `Logic/Geology/GeologicalRegionManager.cs` | 地质区域图（八类划分 + 同类连通区域编号；含 `BuildSutureDistance` / `Band` / `CullSpecks`） |
| `Logic/Geology/PlateBoundaryOps.cs` | 板块边界算子（`BoundaryHops` 边界跳数 / `BoundaryMotion` 逐格边界相对运动） |
| `Logic/Composition/TerrainPipeline.cs` | **编排层**：转发 `Regions` / `Composer`，产出 `DisplayElevation` |
| `Logic/Foundation/LandMaskOps.cs` | 逐格图算子：`Components` / `HopsFrom` / `IsLandAt`（掩码与类别的共同派生口） |
| `Data/Carrier/Region.cs` | 区域元数据载体（原嵌套类，独立成文件） |

`FinalGeography` 的陆块分量与双向 BFS 海岸距离改走 `LandMaskOps`，
其私有 `BfsFrom` 已删；`GeologicalRegionManager` 的连通遍历同样改走 `LandMaskOps.Components`。

## 五 测试与契约
