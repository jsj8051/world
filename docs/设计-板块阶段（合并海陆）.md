## 二 `Plate` 数据载体

```
Plate {
    int     PlateId;
    float   SeedTheta, SeedPhi;   // 种子点位置（原 ThetaV/PhiV 改名，语义不变）
    Vector3 Omega;                // 欧拉矢量：方向 = 极轴，模 = 角速率
    CrustType Crust;              // 壳型（生成期判定）= 本板块唯一的陆海身份
    float   Density;              // 密度（随机量，与壳型无关）：只在汇聚边界上分上下盘
}
```

**命名事故**：`ThetaV/PhiV` 注释写「种子点极角/方位角」、赋值 `ToEuler(...)` ⇒ 值是**位置**，
但没有 `V` 后缀才知道它是什么——改名后 `VTheta/PhiV/ThetaV` 这组字段才真正名副其实（该组已于 D7 整体被 `Omega` 取代）。

**运动物理含义**：整块板块绕 `Omega` **刚体**转动，逐格线速度 `v = Omega × 格心方向`——
角速度逐板块恒定、线速度随位置变。`MinSpeed` / `MaxSpeed` 就是 `|Omega|` 的值域，
`BuildSeeds` 由种子点处的切向速度反解 `Omega = 方向 × v切`（`Omega ⊥ 方向` ⇒ 种子点速度恰为该切向速度）。

## 三 改造

### 3.1 大陆锚点归位到板块（陆壳一对一）

锚点由 `PlateManager.BuildAnchors(seed)` 从板块派生：每块**陆壳**板块 → 一个锚点，
位置 = 该板块种子点方向，属性沿用值域随机派生。`ContinentCount` 参数**删除**，
与 `PlateCount` 收敛为一个数。洋壳板块不发锚点（见 §七）。

### 3.2 陆地场**直接在 H3 上算**（无连续场、无投影器）

逐格标量 = 影响场 + 域扭曲 + 大/中/小三尺度噪声，值域 [0,1]，`> SeaLevel` 即陆。
算法在 `PlateManager.BuildLandMask`，`H3TerrainSampler` 只负责「多点采样 + 顶点缓存 + 并行」
（入参 `Func<Vector3,float>`，与"场是什么"无关）。`PlatePipeline` 只编排、不持算法。

### 3.3 板块的陆海身份 = 壳型（见 §七）

壳型由 `AssignCrustTypes` 在**撒锚点之前**判定，是板块唯一的陆海身份。
`IsLandThreshold` 参数与掩码回填那套观测口径已删除。

> 碰撞（挤压/张裂）**不参与判陆**——它是高度塑造的事，等下游阶段再接。

## 七 壳型：陆壳 / 洋壳（D6）

- **新增 `CrustType`**（`Data/Constants/CrustType.cs`，命名空间 `World.Data`）：`Oceanic` / `Continental`，
  `Oceanic = 0` 为默认值 ⇒ 漏调 `AssignCrustTypes` 时全为洋壳，由 `BuildAnchors` 显式报错兜住。
- **新增 `PlateManager.AssignCrustTypes(seed, spec)`**：按「格数 × 抖动（`0.5 + rng`）」打分取前 N 块当陆壳，
  `N = clamp(round(板块数 × spec.ContinentalRatio), 1, 板块数)`（出厂 0.5 ⇒ 12 块里 6 块陆壳）。
  大板块更容易当陆壳，但不是必然。排序全序（分值 → 板块号），与线程/调用次序无关。
- **`BuildAnchors` 只在陆壳板块上派生锚点**，`Anchors` 数组按板块号升序紧凑排列（不再与板块表等长）。
  洋壳板块没有锚点 ⇒ 它上面的格只在“别处锚点的影响范围内”才可能成陆，其余是海。
- **`Crust` 是板块唯一的陆海身份**（方向：壳型 → 锚点 → 陆场 → 掩码）。
  掩码回填那套"后天观测陆格占比"的口径已砍：字段 `Plate.IsLand`、回填步骤 `PlateLandFill`、
  参数 `IsLandThreshold` 一并删除（该步骤只写不读，删后生成结果逐位不变）。
- **碰撞（汇聚/张裂）仍不参与判陆** —— 边界运动场与汇聚角色已由 `PlateBoundaryOps` 产出（见 §八），
  但**不参与判陆**：谁上盘谁下盘只影响后续的高度塑造，不影响陆地掩码。

## 八 板块运动与汇聚角色（D7 / D8）

### 8.1 运动：逐块一个欧拉矢量

- `Plate.Omega`（`Vector3`）= 方向（极轴）× 角速率；逐格速度 = `Omega × 格心方向`（`PlateBoundaryOps.TangentVelocity`）。
  **角速度逐板块恒定，线速度随位置变**。
- **旧口径的缺陷**（已废）：`VTheta/VPhi` 存的是**种子点**的 θ̇、φ̇，却被当作全场常量套到任意格上
  ⇒ 同一块板块各格实际角速度不同，**不是刚体**。取纯经向（ψ=0）时场退化为 `v ≡ e_θ`，
  散度 `div v = cotθ ≠ 0`（刚体转动恒为 0）。
- `BuildSeeds` 由种子点处的切向速度反解 `Omega`：`Omega = 方向 × v切`，`v切 = V·(cosψ·e_θ + sinψ·e_φ)`。
  `Omega ⊥ 方向` ⇒ 种子点速度恰为该切向速度；抽样次序不变 ⇒ 种子点位置与旧版逐位相同。
- `MinSpeed` / `MaxSpeed`（`PlateSpec`）语义不变：`|Omega|` 的值域。**边界相对运动场整体改变**
  ⇒ 后续按它塑造的构造带分布会变；板块划分、锚点、陆地掩码不受影响。

### 8.2 汇聚角色：上盘 / 下盘

- **`BoundaryRole`**（`Data/Constants/BoundaryRole.cs`）：`None` / `Overriding`（上盘）/ `Subducting`（下盘）。
  与壳型是**两个正交维度**——同一个上盘落在陆壳上成山脉、落在洋壳上成岛弧；下盘洋壳成海沟。
- **`PlateBoundaryOps.BoundaryRoles(ball, plateOfCell, plates)`**：
  ① 边界格取「异板块邻居里**最负**的那一对」（迎面最强的对手）定出**对侧板块号**；
  ② 对侧板块号沿邻接图扩散，**只在同板块内扩散**（不跨边界 ⇒ 两侧角色天然分开）；
  ③ 逐格按「本方板块, 对侧板块」现算角色。
- **判据（`PairRole`）**：陆×洋 ⇒ 陆侧恒上盘、洋侧恒下盘；同壳型（陆×陆 / 洋×洋）⇒ `Density` 小的当上盘。
  角点格（一个格同时挨两块异板块）由「最负的那一对」拍板，而**是否汇聚**仍按 `BoundaryMotion` 的均值口径。
- `Plate.Density` 走**独立种子流** `SeedDerivation.Plate_Density`，不混进 `Plate_Seeds`。

### 8.3 边界输入留给高度塑造

`PlateBoundaryOps` 的三个算子在 ⓪ 阶段是**纯产物**，① 阶段做地形塑造时按需消费：

| 算子 | 逐格语义 | 塑造用途（待接） |
|---|---|---|
| `BoundaryHops` | 到板块边界的跳数（边界格 = 0） | 带状的**距离场** |
| `BoundaryMotion` | 边界法向相对运动（`< 0` 汇聚 / `> 0` 张裂） | 定抬升还是下陷 |
| `BoundaryRoles` | 汇聚侧角色（上盘 / 下盘） | 定谁隆起（陆 ⇒ 山脉、洋 ⇒ 岛弧）、谁俯冲（洋 ⇒ 海沟） |

- **km 折算**：`SpatialScale.CellEdgeKm`（等积格边长 ≈ 26 km）低于真实邻格中心距，
  实测比值 ≈ 1.78（见 `SpatialScale.HopDistanceKm` 标定）⇒ 按「跳数 × 边长」折算会低估约 1.8 倍，
  定带宽时须按真实格距算。
- 三个算子当前**零消费者**（原消费者是已删的世界图地质区域子系统）。
