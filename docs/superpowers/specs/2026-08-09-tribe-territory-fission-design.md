# 部落领地（凝聚体）与裂变压力 设计

> 2026-08-09 定稿。石器时代内激活（非后续阶段预留）。
> 目标：让"部落控制多远"从参数变成**涌现现象**——无硬上限、无资格线常量，由现有机制（接触传播、文化漂变、语言群、分裂）自然产生。
> 关键洞察：项目"部落实体"（SplitPop=300 base，裂变后母体回落 ~300）对应现实 **band 游群**；"控制多格的部落"对应现实**地域部落**（500-1000 人）= band 的凝聚体。故领地 = band 凝聚体，非行政控制。

## 一、现实标定（人类学/考古学数据）

| 现实 | 数值 | 游戏映射 |
|---|---|---|
| band 游群 | 15-50 人（均值 ~25） | 游戏实体（SplitPop=300 base，裂变后母体回落 ~300） |
| 地域部落 | 平均 ~500 人（模态 200-800） | **领地层**（band 凝聚体） |
| 酋邦 | 5000-20000 人 | 后续阶段（同一凝聚机制递归） |
| band 领地 | 平均 260 km²，捕集半径 ~10km | 一格 ≈ 49,800 km²（n32 地球）≈ **190 个 band 领地** → 一格多部落合理 |
| 邻格距离 | ≈223km（RadiusKm=6371, N=10242） | 跨格凝聚 = 跨 200km+ —— 只能靠"持续接触"维持，无行政控制 |
| 人口密度 | 0.1-1 人/km²（均值 0.26） | R 中位 0.3 ✓ 已按现实标定 |
| 领地-人口缩放 | 次线性（有储存技术才出现） | 由接触衰减自然产生（远格接触少 → 漂变 → 凝聚断） |

## 二、领地层：band 凝聚体（连通分量，纯派生）

### 凝聚边（每 10 tick 重算，Union-Find）

```
band a、b 之间有凝聚边 ⟺
  ① 同格 或 相邻格（格距 ≤ 1）
  ② CultureGroupShare 主导 key（语言群）相同
  ③ 双方存活
连通分量 = 领地（无实体、纯派生状态，不入档）
格控制者 = 格内 P 最大 band（沿用现有重算逻辑）
```

### 现象 ↔ 机制对照（零新常量）

| 现实现象 | 涌现来源 |
|---|---|
| 距离衰减（控不了几百千米） | 邻格接触多 → 语言群一致 → 凝聚边在；2 跳外接触少 → 漂变(5%)分群 → 边断 |
| 部落规模门槛 | 小部落 band 少，凝聚带不动，领地自然 1-2 格 |
| 领地碎片化（方言分化） | 漂变分裂语言群 = 现实方言分化，领地随文化断裂自然分裂 |
| 无硬上限 | 凝聚体大小 = 人口×接触效率，**无 MaxCellsPerTribe 常量** |

## 三、领地加成与边界效应

```
分量内（领地 ≥2 band）：
  · 技术传播 ×1.5（SpreadModel 源→目标同分量）
  · 分裂漂变概率 5% → 2.5%（母 band 在 ≥2 band 分量内——凝聚自稳，方言漂变被抑制）

跨分量（边界软冲突，无武力）：
  · 跨边界传播 ×0.5（邻格不同分量 / 同格不同分量都算）
```

明确不做的：
- **无分裂抑制**（分裂 = 领地扩张引擎；大领地稳定靠漂变↓ 自稳，不靠不分裂）
- **无驱逐**（砍掉；同格异族只剩同化吸收路径）
- **无吞并新机制**（见下）

## 四、吞并：同化机制的自然延伸（零新机制）

现有文化同化（0.03/tick）→ 弱 band 语言群份额被主导者吞没 → CultureGroupShare 主导 key 变更 → **下次凝聚重算时并入主导者分量 = 被吞并进领地**。实体不消失，文化上归附（现实：部落间是文化吸收不是屠杀）。

## 五、裂变压力（替代纯 P>300 阈值）

```
裂变条件：P_eff > 300（SplitPop 基准，2026-08-07 已从 400 降为 300）
P_eff = P × (1 + 资源压力 + 内部张力)

资源压力 = max(0, 1 − F/P)                      ← 部落产出缺口（增长模型已有 F/P）
内部张力 = clamp((P − 300) / 250, 0, 1)         ← 超过 300 人后规模压力线性升，550 封顶；
                                                  clamp 保底 0（负值会错误压制饥荒裂变）
```

| 情形 | 计算 | 结果 |
|---|---|---|
| 盈余小部落 P=300, F=600 | 300×(1+0+0)=300 | 不裂，可继续长大 |
| 盈余 P=350（等效旧阈值） | 350×(1+0+0.2)=420 | 裂变 |
| 饥荒 P=250, F=125 | 250×(1+0.5+0)=375 | 裂变（饥荒期提前分家求存） |
| 巨型盈余 P=800 | 800×(1+0+1.0)=1600 | 连续裂变至母体回落 ~300-350 |

实现：`SplitMigrateModel` 分裂段 `if (t.P <= SplitPop) continue;` → 改判 `P_eff`。

## 六、存档：.cmp v5 不变

CellController / 分量 / 领地全部从存档状态（实体表 + 自然层）**确定性重算** → 格式不升级。读档后首次重算一次，与续跑无分叉（T04 扩展验证）。

## 七、可视化

- MapViewer 新图层**"势力范围"**（人文类）：每格按所属分量（领地）主导文化 key 稳定哈希上色，无领地的格灰色
- 格控制者（P 最大 band）作为分量显示的数据源；分量边界即颜色交界

## 八、文档同步

`docs/石器时代设计.md` §5.2 写"同格裂变"，代码实际是"邻格优先分裂"（无目标才留母格，CivModels.cs:616）——文档滞后于 v4/v5 演化，随本设计一并修正（领地机制依赖邻格分裂扩散）。

## 九、参数表（★ = 可调，T 测试标定）

| 参数 | 初值 | 说明 |
|---|---|---|
| SplitPop | 300（2026-08-07 400→300） | 裂变基准 |
| FissionTensionStart | 300 | 规模张力起算点（= SplitPop） |
| FissionTensionSpan | 250 | 张力到 550 封顶 1.0 |
| 凝聚重算间隔 | 10 tick | Union-Find O(V+E)，V≈82k（8×10242） |
| 领地传播 | ×1.5 | 同分量 |
| 跨边界传播 | ×0.5 | 跨分量 |
| 领地漂变 | 5% → 2.5% | 母 band 在 ≥2 band 分量 |

## 十一、范围边界（明确不做）

- 无战争/武力（软冲突）
- 无行政控制/维持费/贡赋（国家机制，后续阶段）
- 无驱逐/吞并新机制（同化吸收替代）
- 无硬上限常量
- 酋邦/国家层不实现（凝聚机制为其递归预留，但不落地）
